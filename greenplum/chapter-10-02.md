# §10.2 Машинное обучение в кластере

В [§10.1](chapter-10-01.md) мы разобрали установку Apache MADlib и обзор модулей. Алгоритмы MADlib выполняются **внутри** Greenplum: данные остаются на сегментах, вычисления идут параллельно. В этом разделе — **линейная регрессия** (linregr_train, linregr_predict), **логистическая регрессия** (logregr_train, предсказание класса и вероятности), **k-means** кластеризация и как устроено **распределённое выполнение** (хранение моделей в таблицах, работа по сегментам). По [MADlib — Linear Regression](https://madlib.apache.org/docs/latest/group__grp__linreg.html), [MADlib — Logistic Regression](https://madlib.apache.org/docs/latest/group__grp__logreg.html), [§10.1](chapter-10-01.md).

---

## 10.2.1. Линейная регрессия

**Линейная регрессия** в MADlib моделирует линейную зависимость скалярной зависимой переменной \(y\) от одного или нескольких признаков \(x\); метод — обычные наименьшие квадраты (OLS). Обучение сохраняет вектор коэффициентов и статистики в таблицу. См. документацию MADlib.

**Обучение:** функция **madlib.linregr_train**(source_table, out_table, dependent_varname, independent_varname [, grouping_cols] [, heteroskedasticity_option]). Параметры:

- **source_table** — таблица с обучающими данными (распределённая по сегментам как обычно).
- **out_table** — имя таблицы, в которую записывается модель: столбцы coef (FLOAT8[] — коэффициенты), r2, std_err, t_stats, p_values, condition_no, num_rows_processed, variance_covariance и др. Создаётся также таблица *_summary с метаданными.
- **dependent_varname** — выражение для зависимой переменной (например, имя столбца 'y').
- **independent_varname** — выражение для признаков; задаётся как строка, например 'ARRAY[1, x1, x2]'. Константа 1 добавляет свободный член (intercept); без неё модель без intercept.
- **grouping_cols** (необязательно) — список столбцов для группировки: по каждой группе строится отдельная регрессия (аналог GROUP BY).

Пример (по документации MADlib):

```sql
SELECT madlib.linregr_train('regr_example', 'regr_example_model', 'y', 'ARRAY[1, x1, x2]');
```

**Предсказание:** **madlib.linregr_predict**(coef, col_ind) — возвращает предсказанное значение; coef — вектор коэффициентов из таблицы модели, col_ind — массив значений признаков (в том же порядке, что при обучении). Остатки: y - madlib.linregr_predict(...). См. [§10.1](chapter-10-01.md), документацию MADlib.

## 10.2.2. Логистическая регрессия

**Логистическая регрессия** моделирует **бинарную** зависимую переменную (класс 0/1 или TRUE/FALSE): предсказывается вероятность принадлежности классу с помощью логистической функции. Подходит для классификации (например, отток клиента, повторный визит). См. документацию MADlib.

**Обучение:** **madlib.logregr_train**(source_table, out_table, dependent_varname, independent_varname [, grouping_cols] [, max_iter] [, optimizer] [, tolerance] [, verbose]). Зависимая переменная — BOOLEAN или выражение, дающее 0/1. Признаки — как в линейной регрессии, с константой 1 для intercept. В выходной таблице: coef, log_likelihood, std_err, z_stats, p_values, odds_ratios (exp(coef)), num_iterations и др. Оптимизатор: 'irls' (по умолчанию), 'newton', 'cg' (conjugate gradient), 'igd' (incremental gradient descent). max_iter и tolerance задают ограничение итераций и критерий сходимости. См. документацию MADlib.

**Предсказание:** **madlib.logregr_predict**(coefficients, ind_var) — возвращает предсказанный класс (TRUE/FALSE). **madlib.logregr_predict_prob**(coefficients, ind_var) — вероятность класса TRUE. Оба принимают коэффициенты из таблицы модели и массив признаков (тот же порядок, что при обучении). См. документацию MADlib.

Пример обучения (по документации MADlib):

```sql
SELECT madlib.logregr_train('patients', 'patients_logregr', 'second_attack',
  'ARRAY[1, treatment, trait_anxiety]', NULL, 20, 'irls');
```

## 10.2.3. K-means кластеризация

**K-means** — метод **неконтролируемой** кластеризации: данные разбиваются на k кластеров путём минимизации суммы квадратов расстояний от точек до центроидов их кластеров. В MADlib доступны варианты в зависимости от способа инициализации центроидов: **kmeans** (центроиды из таблицы или массива), **kmeanspp** (k-means++), **kmeans_random** (случайная инициализация). См. документацию MADlib по clustering.

Входные данные — таблица с точками (столбец типа массив или SVEC); параметры включают число кластеров k, функцию расстояния (по умолчанию — квадрат евклидова расстояния), максимальное число итераций и порог сходимости (минимальная доля перераспределённых точек). Результат обучения — таблица с центроидами и при необходимости таблица с назначением каждой точки кластеру. Точки с NULL или неконечными значениями пропускаются. Детали аргументов и имён функций см. в [MADlib User Documentation](http://madlib.apache.org/docs/latest/index.html) (раздел Clustering). См. документацию MADlib.

## 10.2.4. Распределённое выполнение и хранение моделей

Функции MADlib выполняются как **SQL-запросы**: план строится планировщиком Greenplum, сканы и агрегации выполняются на сегментах. Обучающие данные лежат в обычных таблицах, распределённых по сегментам (DISTRIBUTED BY); каждый сегмент обрабатывает свою часть данных. Алгоритмы реализованы через агрегаты и итерации так, чтобы промежуточные результаты объединялись на координаторе или на сегментах без выгрузки полного датасета наружу. Итоговая **модель** записывается в **таблицу** (out_table): одна или несколько строк с коэффициентами, метриками и метаданными. Эта таблица — обычная таблица Greenplum; её можно сохранять, копировать, использовать в следующих запросах для предсказания. См. [§2.4](chapter-02-04.md).

**Предсказание** выполняется SQL-запросом: соединение таблицы с данными и таблицы модели (или подзапрос с одной строкой модели), вызов функции предсказания (linregr_predict, logregr_predict и т.д.) в SELECT. Данные и модель остаются в БД; пересылка только в рамках выполнения запроса (motion при JOIN при необходимости). Для очень больших объёмов данных и тяжёлых моделей стоит следить за памятью (statement_mem, work_mem) и при необходимости увеличивать лимиты для сессии. См. [§8.4](chapter-08-04.md).

## Ключевое

- **Линейная регрессия:** madlib.linregr_train(исходная_таблица, таблица_модели, 'y', 'ARRAY[1, x1, x2]'); модель в таблице (coef, r2, std_err и др.); предсказание — madlib.linregr_predict(coef, массив_признаков).
- **Логистическая регрессия:** madlib.logregr_train(..., зависимая BOOLEAN, признаки ARRAY[...], оптимизатор irls/newton/cg/igd); logregr_predict — класс, logregr_predict_prob — вероятность.
- **K-means:** варианты kmeans, kmeanspp, kmeans_random; вход — точки (массив или SVEC), k кластеров; результат — таблица центроидов и при необходимости назначений.
- **Распределённое выполнение:** данные на сегментах, модель сохраняется в таблицу; предсказание — JOIN данных с моделью и вызов функции предсказания в SQL.

В [§10.3](chapter-10-03.md) мы разберём **статистические функции** MADlib: описательная статистика, корреляции и связь с SQL.
