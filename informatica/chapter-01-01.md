# §1.1 Что такое Informatica

Этот раздел открывает книгу об Informatica: мы вводим центральное понятие — **Informatica** как корпоративную ETL-платформу интеграции данных. Вы узнаете, что такое Informatica в контексте рынка инструментов интеграции данных, почему её называют лидером рынка, какие сценарии использования она покрывает и какую роль играет в экосистеме ETL и хранилищ данных. Без чёткого понимания места Informatica в индустрии невозможно осмысленно переходить к сравнению PowerCenter и Informatica Cloud (§1.2), архитектуре компонентов (§1.3) и связи с теорией ETL (§1.4). См. [Глоссарий](glossary.md).

## 1.1.1. Informatica: корпоративная ETL-платформа интеграции данных

**Informatica** — это корпоративная платформа управления данными (Data Management Platform), центральное место в которой занимают инструменты **интеграции данных** (Data Integration) и **ETL** (Extract, Transform, Load — извлечение, преобразование, загрузка). Компания Informatica LLC (штаб-квартира в Redwood City, Калифорния) разрабатывает и поставляет программное обеспечение для организаций, которым необходимо объединять данные из множества источников, преобразовывать их по бизнес-правилам и загружать в целевые хранилища: хранилища данных (DWH), витрины, озёра данных, облачные платформы аналитики.

По данным компании (на момент публикации): более 80% компаний из списка Fortune 100 используют продукты Informatica; платформа обрабатывает свыше 128 триллионов облачных транзакций в месяц; в портфеле более 250 интеллектуальных сервисов управления данными. Эти цифры иллюстрируют масштаб внедрения и доверия корпоративного сегмента к платформе. См. [Глоссарий](glossary.md).

Ключевые характеристики Informatica как ETL-платформы:

| Характеристика | Описание |
|----------------|----------|
| **Универсальная связность** | Подключение к разнообразным источникам и приёмникам: реляционные БД (Oracle, SQL Server, PostgreSQL, MySQL и др.), файлы (CSV, XML, JSON, Parquet), облачные хранилища (S3, Azure Blob), SaaS-приложения, потоковые источники. |
| **ETL и ELT** | Поддержка классического ETL (преобразование до загрузки) и ELT (загрузка сырых данных с последующим преобразованием в целевом хранилище); pushdown-оптимизация для выполнения логики в СУБД. |
| **Масштабируемость** | Grid-вычисления, распределённая обработка, партиционирование сессий для параллельной загрузки больших объёмов данных. |
| **Визуальная разработка** | Маппинги (Mappings) строятся в графическом Designer без обязательного написания кода; готовые трансформации (Lookup, Aggregator, Joiner и др.) переиспользуются. |
| **Управление метаданными** | Централизованный репозиторий метаданных: определения источников, целей, маппингов, workflow; версионирование и развёртывание между окружениями. |

Таким образом, Informatica — не просто «инструмент для копирования данных», а **платформа**, объединяющая извлечение, преобразование, загрузку, качество данных, управление мастер-данными (MDM) и governance в единой экосистеме. В этой книге фокус — на ETL-части: PowerCenter (on-premise) и базовых концепциях, применимых к облачным продуктам. См. [§1.2](chapter-01-02.md).

## 1.1.2. Определение: ETL и интеграция данных в контексте Informatica

**ETL** (Extract, Transform, Load) — трёхэтапный процесс интеграции данных, в котором данные **извлекаются** из одного или нескольких источников, **преобразуются** в соответствии с правилами очистки и бизнес-логики и **загружаются** в целевое хранилище (DWH, витрина, озеро данных). Informatica реализует этот процесс через объекты: Sources (источники), Mappings (маппинги с цепочкой трансформаций), Targets (приёмники), Sessions и Workflows (сессии и рабочие процессы выполнения). См. [Глоссарий](glossary.md).

**Интеграция данных** (Data Integration) — более широкое понятие, чем ETL: оно охватывает не только пакетную загрузку в хранилище, но и репликацию в реальном времени, синхронизацию приложений, виртуализацию данных, API-интеграцию. Informatica позиционирует себя как платформу **интеграции данных**, в которой ETL — один из ключевых сценариев. Для разработчика ETL-пайплайнов важно: Informatica предоставляет единую среду для проектирования маппингов (Designer), хранения метаданных (Repository), выполнения сессий (Integration Service) и мониторинга (Workflow Monitor). Подробнее этапы ETL и их соответствие компонентам Informatica — в [§1.4](chapter-01-04.md).

## 1.1.4. Сценарии использования Informatica

Informatica применяется в широком спектре сценариев интеграции данных. Ниже — типичные варианты, с которыми сталкиваются разработчики и архитекторы данных.

**Загрузка данных в хранилище (DWH) и витрины**

Классический ETL-сценарий: извлечение из операционных систем (ERP, CRM, транзакционные БД), преобразование (очистка, маппинг полей, обогащение справочниками, агрегация), загрузка в слой Staging или в финальные таблицы хранилища. Пайплайны выполняются по расписанию (ежедневно, еженедельно) в пакетном режиме. Informatica PowerCenter — один из наиболее распространённых инструментов для таких задач в корпоративном сегменте.

**Миграция данных в облако**

Перенос данных из on-premise систем в облачные хранилища (Snowflake, BigQuery, Redshift, Databricks, Azure Synapse) и озёра данных. Informatica поддерживает нативные коннекторы к облачным платформам; возможен pushdown преобразований в целевую СУБД для ускорения загрузки.

**Интеграция данных из SaaS и внешних источников**

Подключение к Salesforce, SAP, Workday, REST API и другим облачным приложениям; выгрузка в единое хранилище для аналитики. Требует коннекторов и поддержки специфичных форматов (OAuth, pagination и т.п.); Informatica Cloud расширяет набор источников по сравнению с классическим PowerCenter.

**Репликация и CDC (Change Data Capture)**

Синхронизация изменений из источников в целевые системы с минимальной задержкой; только изменённые записи (вставки, обновления, удаления) передаются в приёмник. Снижает объём передаваемых данных и нагрузку на источники. Informatica поддерживает CDC через специализированные коннекторы и репликацию в реальном времени.

**Качество данных и MDM**

Очистка, дедупликация, стандартизация; управление мастер-данными (клиенты, продукты, контракты) для обеспечения единого представления по организации. Informatica Data Quality и MDM — отдельные продукты, интегрированные с ETL-платформой; в рамках книги мы фокусируемся на ETL, но важно понимать, что платформа шире.

**Отраслевые сценарии**

- **Финансовые услуги:** загрузка транзакций, отчётность, соответствие регуляторным требованиям, обнаружение мошенничества.
- **Здравоохранение:** интеграция клинических и административных данных, единый взгляд на пациента, аналитика.
- **Производство:** данные с датчиков (IoT), управление цепочками поставок, предиктивное обслуживание.
- **Госсектор:** консолидация данных из ведомственных систем при ограниченных бюджетах.

Выбор Informatica для конкретного сценария зависит от требований к источникам, объёмам, частоте обновления, наличию on-premise инфраструктуры и стратегии перехода в облако. См. [§1.2](chapter-01-02.md).

## 1.1.5. Продуктовая линейка: PowerCenter и обзор экосистемы

Центральный продукт для ETL в on-premise среде — **Informatica PowerCenter**. Он состоит из клиентских приложений (Designer, Workflow Manager, Workflow Monitor, Repository Manager) и серверных компонентов (Repository Server, Integration Service). PowerCenter — зрелый продукт с многолетней историей; тысячи организаций используют его для критичных загрузок. Подробнее архитектура PowerCenter — в [§1.3](chapter-01-03.md).

Помимо PowerCenter, в экосистеме Informatica:

| Продукт / направление | Назначение |
|-----------------------|------------|
| **Informatica Cloud (IICS)** | Облачная платформа интеграции; Cloud Data Integration (ETL/ELT); поддержка Snowflake, Databricks, BigQuery и др. |
| **Intelligent Data Management Cloud (IDMC)** | Единая облачная платформа: интеграция, качество, governance, каталог, MDM. |
| **CLAIRE** | AI-движок на базе метаданных; рекомендации по маппингам, оптимизация, обнаружение аномалий. |
| **PowerCenter Cloud Edition** | Вариант PowerCenter для развёртывания в облаке (например, на AWS, Azure) с сохранением знакомой модели разработки. |

Стратегия Informatica: для новых проектов рекомендовать облачную платформу (IICS); для существующих внедрений PowerCenter — поддержка и инструменты миграции в облако с переиспользованием маппингов. В этой книге основное внимание — PowerCenter как наиболее распространённой и документированной ETL-платформе Informatica; обзор облачных продуктов — в [главе 13](chapter-13-01.md).

## 1.1.6. Типичные ошибки при первом знакомстве с Informatica

- **Путать Informatica и PowerCenter:** Informatica — компания и платформа; PowerCenter — конкретный продукт для ETL on-premise. Informatica Cloud (IICS) — другой продукт с иной архитектурой, хотя концепции (маппинги, трансформации) во многом схожи.
- **Считать Informatica «просто ETL-инструментом»:** платформа охватывает интеграцию, качество, MDM, governance; ETL — ядро, но не единственное применение.
- **Игнорировать облачное направление:** при выборе инструмента для нового проекта облачные варианты (IICS) могут быть предпочтительнее; знание PowerCenter полезно для поддержки legacy и миграции.
- **Ожидать «бесплатного» решения:** Informatica — коммерческий продукт; лицензирование зависит от мощности (например, по количеству процессоров или по объёму обрабатываемых данных). Для обучения доступны trial-версии и Informatica University.

## Ключевое

- **Informatica** — корпоративная платформа управления данными; центральное место занимает ETL и интеграция данных. Характеризуется универсальной связностью, визуальной разработкой маппингов, масштабируемостью и централизованным репозиторием метаданных.
- **ETL** (Extract, Transform, Load) — трёхэтапный процесс: извлечение из источников, преобразование по правилам, загрузка в целевое хранилище. Informatica реализует его через Sources, Mappings, Targets, Sessions и Workflows.
- Informatica многократно признаётся лидером рынка (Gartner Magic Quadrant, IDC); конкурирует с Microsoft, IBM, Oracle, SAP, AWS и др. Поддерживает on-premise (PowerCenter), облако (IICS) и гибридные сценарии.
- **Сценарии использования:** загрузка в DWH и витрины, миграция в облако, интеграция SaaS, репликация и CDC, качество данных и MDM, отраслевые решения (финансы, здравоохранение, производство, госсектор).
- **PowerCenter** — основной продукт для ETL on-premise; экосистема включает Informatica Cloud (IICS), IDMC, CLAIRE, PowerCenter Cloud Edition.

В [§1.2](chapter-01-02.md) мы сравним PowerCenter и Informatica Cloud и разберём, когда выбирать on-premise, когда облако и как строить гибридные сценарии.
