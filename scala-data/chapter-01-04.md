# §1.4 Первая программа

В [§1.3](chapter-01-03.md) мы познакомились с sbt, IDE и REPL. Теперь напишем первую программу на Scala: разберём, как объявить точку входа (объект с методом main или `@main`), скомпилировать и запустить код через scalac/scala, sbt и scala-cli, а также выполнить фрагмент в REPL. ## 1.4.1. Объект с методом main

Программа на Scala должна иметь **точку входа** — метод, который вызывается при запуске. Классический способ — объект (object) с методом `main`, принимающим аргументы командной строки.

**Способ 1: object с def main (Scala 2 и 3)**

```scala
object Main {
  def main(args: Array[String]): Unit = {
    println("Hello, World!")
  }
}
```

- **object Main** — объявление **объекта** (singleton): существует единственный экземпляр `Main`; к методу обращаются как `Main.main(...)`. Объекты подробнее рассмотрены в [§6.2](chapter-06-02.md).
- **def main(args: Array[String]): Unit** — метод `main`: имя фиксировано, JVM ищет именно его; параметр `args` — массив строк (аргументы командной строки); возвращаемый тип `Unit` означает «ничего не возвращает».
- **println("Hello, World!")** — вывод строки в консоль с переводом строки.

Сохраните этот код в файл, например `Main.scala` (или `src/main/scala/Main.scala` в sbt-проекте).

**Способ 2: @main (только Scala 3)**

В Scala 3 можно объявить точку входа проще — с аннотацией `@main`:

```scala
@main def hello(): Unit =
  println("Hello, World!")
```

Имя метода может быть любым (`hello`, `run` и т.д.); при запуске программа будет называться по имени метода. Аргументы командной строки можно добавить как параметры; компилятор сгенерирует код их разбора. Пример с аргументами:

```scala
@main def greet(name: String, count: Int = 1): Unit =
  for (_ <- 1 to count) println(s"Hello, $name!")
```

Для книги подойдёт любой из способов; `object` с `main` совместим со всеми версиями Scala и со Spark; `@main` удобнее для небольших скриптов в Scala 3.

## 1.4.2. Компиляция и запуск через scalac и scala

Самый низкоуровневый способ — вызвать компилятор и раннер вручную.

**Компиляция**

```bash
scalac Main.scala
```

Команда `scalac` создаёт в текущем каталоге файлы `.class` (байт-код JVM). Для `object Main` обычно появляются `Main$.class` и `Main.class`.

**Запуск**

```bash
scala Main
```

Здесь `Main` — имя объекта с методом `main`. JVM загружает класс и вызывает `Main.main(args)`.

**Одной командой (без сохранения .class)**

Команда `scala` может скомпилировать и запустить файл за один проход:

```bash
scala Main.scala
```

Компиляция выполняется во временный каталог; для быстрой проверки это удобно.

**Аргументы командной строки**

```bash
scala Main arg1 arg2
```

или

```bash
scala Main.scala arg1 arg2
```

В коде они доступны в `args`: `args(0)` — `"arg1"`, `args(1)` — `"arg2"`. Проверка длины: `args.length`, `args.isEmpty`.

## 1.4.3. Запуск через sbt

В sbt-проекте исходники лежат в `src/main/scala/`. Создайте файл, например `src/main/scala/Main.scala`, с объектом `Main` и методом `main` (или `@main def` в Scala 3).

**Структура:**

```
my-project/
  build.sbt
  src/main/scala/
    Main.scala
```

**Запуск**

В каталоге проекта выполните:

```bash
sbt run
```

sbt скомпилирует проект и запустит найденную точку входа. Если в проекте несколько объектов с `main` или несколько `@main`-методов, sbt спросит, какой запустить, или можно указать полное имя: `sbt "runMain Main"`.

**Особенности**

- sbt кэширует сборку; повторный `run` после изменений перекомпилирует только изменённые файлы.
- При первом `run` sbt может загружать зависимости — это может занять время.
- Для Spark jobs запуск обычно делают через `spark-submit` с собранным JAR; sbt используется для локальной разработки и тестов. Подробнее в [§8.4](chapter-08-04.md).

## 1.4.4. Запуск через scala-cli

**scala-cli** позволяет запустить файл без создания sbt-проекта. Сохраните код в `Hello.scala` и выполните:

```bash
scala-cli run Hello.scala
```

или короче:

```bash
scala-cli Hello.scala
```

scala-cli скомпилирует файл (при необходимости — с нужной версией Scala) и запустит программу. Подходит для скриптов и быстрых экспериментов.

**Несколько файлов**

```bash
scala-cli run Main.scala Utils.scala
```

**Указание версии Scala**

```bash
scala-cli --scala 3.3.1 run Hello.scala
```

## 1.4.5. Выполнение в REPL

Для проверки одной строки или небольшого блока кода REPL не требует создания файла.

**Простой вывод**

Запустите `scala` (или `sbt console` в каталоге проекта). Введите:

```scala
println("Hello, World!")
```

и нажмите Enter. Строка будет выведена.

**Загрузка файла**

Если код уже сохранён в файле, в REPL выполните:

```scala
:load Main.scala
```

REPL загрузит и выполнит файл; определённые в нём объекты и классы станут доступны в сессии.

**Режим :paste для нескольких строк**

Введите `:paste`, нажмите Enter, вставьте блок кода и завершите ввод Ctrl+D:

```scala
scala> :paste
// Вставьте код, затем Ctrl+D
object Main {
  def main(args: Array[String]): Unit = println("Hello!")
}
Main.main(Array())
```

Режим `:paste` обрабатывает блок целиком, что нужно для объявлений `object` или `class`, которые REPL в обычном режиме ожидает вводить построчно.

**Важно:** REPL не сохраняет введённый код. Для повторного использования и версионирования переносите логику в файлы .scala.

## 1.4.6. Типичные ошибки

- **`scalac: not found`** или **`scala: not found`** — Scala не в `PATH`; проверьте установку ([§1.2](chapter-01-02.md)) и перезапустите терминал.
- **`Main` не найден при `scala Main`** — убедитесь, что в каталоге есть скомпилированные `.class` (после `scalac Main.scala`) или что вы указываете путь к исходнику: `scala Main.scala`.
- **Ошибка «no main class»** — в проекте нет объекта с методом `main` или `@main`-метода; проверьте имя метода и сигнатуру (`def main(args: Array[String]): Unit`).
- **В REPL `object` не выполняется** — `object` только определяет класс; чтобы выполнить код, нужно вызвать метод, например `Main.main(Array())`, или использовать `:load` для файла с вызовом.

## Ключевое

- Точка входа — `object Main { def main(args: Array[String]): Unit = ... }` (Scala 2 и 3) или `@main def hello(): Unit = ...` (Scala 3).
- **scalac** компилирует .scala в .class; **scala Main** или **scala Main.scala** запускает программу. Аргументы передаются после имени: `scala Main arg1 arg2`.
- В sbt-проекте: `sbt run` из каталога с build.sbt; исходники в `src/main/scala/`.
- **scala-cli run Hello.scala** — запуск без создания проекта.
- В REPL: `println("Hello!")`, `:load file.scala`, `:paste` для многострочного ввода.

В [§2.1](chapter-02-01.md) мы начнём с синтаксиса: значения (val) и переменные (var), рекомендация предпочитать val.
