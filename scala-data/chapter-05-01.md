# §5.1 List

В [§4.5](chapter-04-05.md) мы разобрали функции высшего порядка — map, filter, foldLeft. Теперь переходим к **коллекциям**. **List** — неизменяемая упорядоченная последовательность элементов одного типа; реализован как односвязный список. В этом разделе: создание, доступ к голове и хвосту (head, tail), конкатенация (::, :::) и работа с типами List[A]. В [§5.2](chapter-05-02.md) рассмотрим Map. См. [Глоссарий](glossary.md).

---

## 5.1.1. Создание списка

Список создают через **List(...)** — элементы в скобках через запятую:

```scala
val numbers = List(1, 2, 3)
val words = List("a", "b", "c")
val empty: List[Int] = List()
```

Пустой список — `List()` или **Nil** (оба обозначают пустую коллекцию). Тип `List[A]` — обобщённый: `List[Int]`, `List[String]` и т.д. Элементы должны быть одного типа; смешивание типов даёт общий супертип (например, `List[Any]`).

```scala
val list: List[Int] = Nil
val list2 = 1 :: 2 :: 3 :: Nil   // то же, что List(1, 2, 3)
```

---

## 5.1.2. Голова и хвост: head, tail

**head** — первый элемент списка. **tail** — все остальные элементы (список без первого). Для пустого списка вызов `head` или `tail` приводит к исключению.

```scala
val list = List(10, 20, 30)
list.head   // 10
list.tail   // List(20, 30)
```

`list.tail.head` — второй элемент (голова хвоста). Разбор списка через head и tail — основа рекурсивной обработки и pattern matching:

```scala
list match {
  case Nil => "пусто"
  case h :: t => s"голова: $h, хвост: $t"
}
```

---

## 5.1.3. Оператор :: (cons)

Оператор **::** (cons) добавляет элемент **в начало** списка. Справа — список, слева — новый элемент:

```scala
val list = 1 :: 2 :: 3 :: Nil   // List(1, 2, 3)
val extended = 0 :: list         // List(0, 1, 2, 3)
```

`::` — метод правого операнда: `0 :: list` эквивалентно `list.::(0)`. Операция выполняется за O(1), так как меняется только ссылка на голову.

---

## 5.1.4. Конкатенация ::: и ++

**:::** объединяет два списка: левый список «приписывается» перед правым:

```scala
List(1, 2) ::: List(3, 4)   // List(1, 2, 3, 4)
Nil ::: List(1, 2)          // List(1, 2)
```

Метод **++** даёт тот же результат и работает для любых коллекций:

```scala
List(1, 2) ++ List(3, 4)   // List(1, 2, 3, 4)
```

И `:::`, и `++` создают **новый** список; исходные не меняются.

---

## 5.1.5. Неизменяемость

List в Scala **неизменяем**. Любая операция (добавление, удаление, замена) создаёт новую структуру; исходный список остаётся прежним.

```scala
val a = List(1, 2, 3)
val b = 0 :: a    // b = List(0, 1, 2, 3), a не изменился
val c = a.tail    // c = List(2, 3), a по-прежнему List(1, 2, 3)
```

Благодаря этому несколько переменных могут ссылаться на один и тот же список без риска неожиданных изменений. При `::` используется общее представление хвоста (structural sharing), поэтому создание новой головы — O(1).

---

## 5.1.6. Индексация и длина

**list(i)** — элемент по индексу (с нуля). Операция O(n), так как нужно пройти цепочку.

```scala
List(10, 20, 30)(0)   // 10
List(10, 20, 30)(2)   // 30
```

**length** (или **size**) — число элементов. **isEmpty** — пустой ли список. **nonEmpty** — непустой.

```scala
List(1, 2, 3).length    // 3
Nil.isEmpty             // true
List(1).nonEmpty        // true
```

Для частого доступа по индексу лучше использовать **Vector** или **Array**; List оптимизирован для операций с головой и обхода.

---

## 5.1.7. Базовые методы

Список поддерживает методы из [§4.5](chapter-04-05.md): **map**, **filter**, **foldLeft**, **reduce**, **foreach**. Примеры:

```scala
List(1, 2, 3).map(_ * 2)        // List(2, 4, 6)
List(1, 2, 3, 4).filter(_ % 2 == 0)   // List(2, 4)
List(1, 2, 3).foldLeft(0)(_ + _)     // 6
```

**take(n)** — первые n элементов; **drop(n)** — всё кроме первых n; **takeWhile**, **dropWhile** — по условию:

```scala
List(1, 2, 3, 4).take(2)    // List(1, 2)
List(1, 2, 3, 4).drop(2)    // List(3, 4)
```

---

## 5.1.8. Pattern matching по структуре

Список удобно разбирать через pattern matching. Образец `h :: t` сопоставляется с непустым списком: `h` — голова, `t` — хвост. `Nil` — пустой список:

```scala
def sum(list: List[Int]): Int = list match {
  case Nil => 0
  case h :: t => h + sum(t)
}
```

Рекурсия по head/tail — типичный приём для списков в функциональном стиле.

---

## 5.1.9. Типичные ошибки

- **head/tail на пустом списке** — `Nil.head` и `Nil.tail` выбрасывают исключение; перед вызовом проверяйте `list.nonEmpty` или обрабатывайте `Nil` в pattern matching.
- **Добавление в конец через ::** — `::` добавляет в начало; для «добавления в конец» нужно `list :+ elem` (O(n)) или перестроить список (например, через `list ::: List(elem)`).
- **Смешение типов** — `List(1, "a")` даёт `List[Any]`; для однотипных данных явно указывайте тип.

---

## Ключевое

- **List** — неизменяемая упорядоченная последовательность; создание: `List(1, 2, 3)`, `Nil`.
- **head** — первый элемент; **tail** — остальные. **::** — добавление элемента в начало (cons). **:::** и **++** — конкатенация списков.
- List неизменяем; операции создают новые списки. Индексация `list(i)` и длина — O(n).
- Pattern matching: `case h :: t` и `case Nil`. Методы map, filter, foldLeft и др. применяются как к другим коллекциям.
