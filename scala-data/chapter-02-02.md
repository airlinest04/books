# §2.2 Основные типы

В [§2.1](chapter-02-01.md) мы ввели val и var. Теперь рассмотрим **основные встроенные типы** Scala: целые (Int, Long), вещественные (Double, Float), булевы (Boolean), символы (Char) и строки (String). Они составляют основу для выражений и операций; в этом же разделе — вывод типа и приведение через методы `.toInt`, `.toDouble` и другие. Строки подробнее разбираются в [§2.4](chapter-02-04.md); здесь даётся минимальное представление для работы с операторами в [§2.3](chapter-02-03.md).

---

## 2.2.1. Целые числа: Int и Long

**Int** — 32-битное знаковое целое (от -2^31 до 2^31−1). По умолчанию целые литералы без суффикса имеют тип Int.

**Long** — 64-битное знаковое целое. Литерал Long записывают с суффиксом `L` или `l` (предпочтительнее `L`, чтобы не путать с цифрой 1).

```scala
val a: Int = 42
val b = 0
val c = -100
val big: Long = 1000000000L
val million = 1_000_000   // подчёркивания для читаемости (Scala 2.13+)
```

Диапазон Int: примерно от -2.1 млрд до 2.1 млрд. При переполнении результат «оборачивается» (wrap-around), что может дать неожиданные значения; для больших чисел используйте Long или `BigInt` (из `scala.math`).

**Byte** и **Short** — 8- и 16-битные целые; используются реже, например при работе с бинарными протоколами или Java-API.

---

## 2.2.2. Вещественные числа: Double и Float

**Double** — 64-битное число с плавающей точкой (IEEE 754). По умолчанию литералы с десятичной точкой имеют тип Double.

**Float** — 32-битное число с плавающей точкой. Литерал Float записывают с суффиксом `F` или `f`.

```scala
val x: Double = 3.14
val y = 0.5
val z = 2e3      // 2000.0
val w = 1.5e-2   // 0.015
val f: Float = 3.14f
```

При арифметике Int и Double результат — Double; Int и Float — Float. Для большинства расчётов (в том числе с данными) предпочтителен Double: выше точность, меньше ошибок округления. Float применяют при ограничениях по памяти или при работе с Java/нативными библиотеками.

**Ошибки округления** — числа с плавающей точкой приближённые. При сравнении близких значений используют допуск или библиотеки (например, `scala.math`), а для денег и точной арифметики — `BigDecimal`.

---

## 2.2.3. Boolean

**Boolean** — логический тип; два значения: **true** и **false** (в Scala пишут с маленькой буквы). Используются в условиях и логических выражениях ([§2.3](chapter-02-03.md), [§3.1](chapter-03-01.md)).

```scala
val flag = true
val ok = false
```

---

## 2.2.4. Char и String

**Char** — один символ (16-битный Unicode). Литерал в одинарных кавычках:

```scala
val letter: Char = 'A'
val digit = '9'
```

**String** — последовательность символов; тип из `java.lang.String`. Литерал в двойных кавычках:

```scala
val s1: String = "hello"
val s2 = "world"
```

Строки неизменяемы; операции над ними создают новые строки. Индексация, методы и интерполяция подробнее в [§2.4](chapter-02-04.md).

---

## 2.2.5. Unit

**Unit** — тип «отсутствия осмысленного значения». Аналог `void` в других языках. Единственное значение — `()`. Функции и методы, которые ничего не возвращают (например, `println`), имеют тип `Unit`.

```scala
val u: Unit = ()
val result = println("hello")   // result имеет тип Unit, значение ()
```

---

## 2.2.6. Вывод типа и явные аннотации

Компилятор выводит тип по контексту. Для литералов:

- `42` → Int
- `42L` → Long
- `3.14` → Double
- `3.14f` → Float
- `"text"` → String
- `'x'` → Char
- `true` / `false` → Boolean

Явная аннотация полезна, когда нужен более общий тип или при объявлении без инициализации (только для var в локальном контексте или полей класса). В REPL команда `:type выражение` выводит тип без вычисления.

---

## 2.2.7. Приведение типов: toInt, toDouble, toString и др.

Все числовые типы и String имеют методы приведения. В отличие от Java-приведения (cast) в скобках, в Scala используют вызовы методов.

**Числовые преобразования**

```scala
19.7.toInt      // 19 (дробная часть отбрасывается)
19.toDouble     // 19.0
19.toLong       // 19L
19.toFloat      // 19.0f
```

**Строковые преобразования**

```scala
42.toString     // "42"
3.14.toString   // "3.14"
true.toString   // "true"
```

**Разбор строки в число**

```scala
"42".toInt           // 42
"3.14".toDouble      // 3.14
"  123  ".trim.toInt // 123
```

Если строка не представляет допустимое число, будет выброшено исключение `NumberFormatException`. При чтении данных из файлов и API числа часто приходят как строки; перед расчётами их приводят к Int или Double через `.toInt`, `.toDouble` и т.д.

**Проверка перед приведением**

У числовых типов есть методы `isValidInt`, `isValidLong`, `isValidByte` и т.д. — они проверяют, укладывается ли значение в диапазон целевого типа:

```scala
val a = 1000L
a.isValidInt    // true
a.isValidByte   // false
```

Это помогает избежать неожиданного переполнения при вызове `.toInt` для большого Long.

## 2.2.9. Типичные ошибки

- **Переполнение Int** — арифметика с большими числами может выйти за пределы Int; при необходимости используйте Long или BigInt.
- **`"3.14".toInt`** — NumberFormatException: строка с точкой не является целым литералом; используйте `"3.14".toDouble.toInt` (получится 3) или округление.
- **Смешение типов в арифметике** — `10 + "5"` не компилируется в Scala (в отличие от некоторых других языков); явно приведите: `10 + "5".toInt` или `10.toString + "5"`.
- **Регистр Boolean** — в Scala `true` и `false` с маленькой буквы; `True` и `False` неверны.

---

## Ключевое

- **Int** (32 бит) и **Long** (64 бит, суффикс `L`) — целые; **Double** (по умолчанию для дробных) и **Float** (суффикс `f`) — вещественные; **Boolean** (`true`/`false`), **Char** (`'x'`), **String** (`"..."`), **Unit** (`()`).
- Компилятор выводит тип по литералу и контексту.
- **Приведение:** `.toInt`, `.toLong`, `.toDouble`, `.toFloat`, `.toString`; разбор строки — `"42".toInt`, `"3.14".toDouble`; проверка — `.isValidInt`, `.isValidLong` и т.д.
- При разборе строки в число возможен `NumberFormatException`; при переполнении — неожиданные значения.

В [§2.3](chapter-02-03.md) мы разберём операторы: арифметические, сравнения, логические и их трактовку как методов.
