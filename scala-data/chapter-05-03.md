# §5.3 Set

В [§5.2](chapter-05-02.md) мы разобрали Map. **Set** — коллекция **уникальных** элементов без повторений; порядок не гарантируется. В Scala Set по умолчанию **неизменяем**; для изменений на месте используют mutable.Set. В этом разделе: создание, основные операции и операции теории множеств (объединение, пересечение, разность). В [§5.4](chapter-05-04.md) повторим Option и его методы. См. [Глоссарий](glossary.md).

---

## 5.3.1. Создание Set

Set создают через **Set(...)** — элементы в скобках через запятую. Дубликаты отбрасываются:

```scala
val s = Set(1, 2, 3)
val withDupes = Set(1, 2, 2, 3, 3, 3)   // Set(1, 2, 3)
val empty: Set[Int] = Set.empty
```

Тип `Set[A]` — множество элементов типа A. Элементы должны быть **хешируемыми** (поддерживать equals и hashCode). Из коллекции дубликаты можно убрать через **.toSet**:

```scala
List(1, 2, 2, 3).toSet   // Set(1, 2, 3)
```

---

## 5.3.2. Проверка вхождения и размер

**contains(elem)** — есть ли элемент в множестве. Синтаксис `set(elem)` эквивалентен `set.contains(elem)`:

```scala
val s = Set(1, 2, 3)
s.contains(2)   // true
s(2)            // true (то же)
s.contains(5)   // false
```

**size** (или **length**) — число элементов. **isEmpty** — пустое ли множество.

```scala
Set(1, 2, 3).size    // 3
Set.empty[Int].isEmpty   // true
```

Проверка вхождения в Set — в среднем O(1); для больших коллекций Set выгоднее List при частых проверках `contains`.

---

## 5.3.3. Добавление и удаление (неизменяемый Set)

Для **неизменяемого** Set операции возвращают новый Set; исходный не меняется.

**Добавление:** `set + elem`:

```scala
val s = Set(1, 2, 3)
val s2 = s + 4        // Set(1, 2, 3, 4)
val s3 = s + 2        // Set(1, 2, 3) — 2 уже есть
```

**Удаление:** `set - elem`:

```scala
s - 2   // Set(1, 3)
```

**Несколько элементов:** `set ++ iterable` — добавить все элементы; `set -- iterable` — удалить все:

```scala
Set(1, 2) ++ List(3, 4)   // Set(1, 2, 3, 4)
Set(1, 2, 3) -- List(2, 3)   // Set(1)
```

---

## 5.3.4. Операции теории множеств

**Объединение (union):** все элементы, входящие хотя бы в одно множество. Метод **union** или оператор **|** (или **++**):

```scala
val a = Set(1, 2, 3)
val b = Set(3, 4, 5)
a.union(b)   // Set(1, 2, 3, 4, 5)
a | b        // то же
a ++ b       // то же
```

**Пересечение (intersect):** элементы, входящие в оба множества. Метод **intersect** или оператор **&**:

```scala
a.intersect(b)   // Set(3)
a & b            // то же
```

**Разность (diff):** элементы первого множества, которых нет во втором. Метод **diff** или оператор **--**:

```scala
a.diff(b)   // Set(1, 2)
a -- b      // Set(1, 2)
b -- a      // Set(4, 5)
```

**Подмножество:** **subsetOf** — входит ли одно множество в другое:

```scala
Set(1, 2).subsetOf(Set(1, 2, 3))   // true
```

---

## 5.3.5. mutable.Set

Если нужны изменения на месте, используют **scala.collection.mutable.Set**:

```scala
import scala.collection.mutable

val s = mutable.Set(1, 2, 3)
s += 4           // добавить
s -= 2           // удалить
s.add(5)         // add возвращает false, если элемент уже был
s.remove(3)      // remove возвращает true, если элемент был
```

Методы **+=**, **-=**, **++=**, **--=** изменяют множество и возвращают сам Set (для цепочек вызовов).

---

## 5.3.6. Обход и преобразование

Set — коллекция, поддерживающая **foreach**, **map**, **filter**, **toList** и др.:

```scala
Set(1, 2, 3).foreach(println)
Set(1, 2, 3).map(_ * 2)   // Set(2, 4, 6)
Set(1, 2, 3).toList       // List (порядок не гарантирован)
```

Порядок элементов при итерации не гарантируется; для упорядоченного набора уникальных значений можно использовать **SortedSet** или преобразовать в List и отсортировать.

---

## 5.3.7. Когда использовать Set

- **Удаление дубликатов** — `list.toSet` или `list.distinct` (у List есть distinct, сохраняющий порядок).
- **Быстрая проверка вхождения** — `set.contains(x)` или `set(x)` за O(1) в среднем.
- **Операции над наборами** — общие категории, объединение источников, разность (что есть в одном и нет в другом).

В контексте данных Set используют для уникальных идентификаторов, категорий, тегов; проверки допустимых значений; сведения столбцов к уникальным комбинациям.

---

## 5.3.8. Типичные ошибки

- **Ожидать порядок** — Set не упорядочен; для порядка используйте List.distinct, SortedSet или Seq с проверкой уникальности.
- **Хешируемость элементов** — изменяемые типы (List, mutable.Map) не подходят как элементы Set; нужны неизменяемые (Int, String, case class).
- **Забыть про неизменяемость** — `s + 4` не меняет `s`; результат нужно присвоить.

---

## Ключевое

- **Set** — коллекция уникальных элементов; создание: Set(1, 2, 3), Set.empty. Дубликаты отбрасываются.
- **contains(elem)**, **set(elem)** — проверка вхождения. **size**, **isEmpty**.
- **Добавление:** `set + elem`. **Удаление:** `set - elem`. **Операции:** `|` / union, `&` / intersect, `--` / diff.
- **mutable.Set** — изменяемая версия; +=, -=, add, remove.
- Порядок не гарантируется. Set используют для удаления дубликатов, быстрой проверки вхождения и операций над наборами.
