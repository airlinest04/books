# §6.1 Классы

В [§5.5](chapter-05-05.md) мы завершили главу о коллекциях. Переходим к **объектно-ориентированному** стилю Scala. **Класс** — шаблон для создания объектов с полями и методами. В этом разделе: объявление класса, параметры конструктора (они же поля), методы в теле класса и создание экземпляра через **new**. В [§6.2](chapter-06-02.md) рассмотрим объекты (singleton) и объект-компаньон. См. [Глоссарий](glossary.md).

---

## 6.1.1. Объявление класса и параметры конструктора

Синтаксис: **class Имя(параметры)**. Параметры конструктора перечисляют в скобках после имени класса:

```scala
class Person(name: String, age: Int)
```

Создание экземпляра — ключевое слово **new**:

```scala
val p = new Person("Alice", 30)
```

Параметры конструктора могут быть помечены как **val** или **var** — тогда они автоматически становятся **полями** класса, доступными снаружи:

```scala
class Person(val name: String, var age: Int)

val p = new Person("Alice", 30)
p.name   // "Alice" — чтение
p.age    // 30
p.age = 31   // допускается: age объявлен как var
p.name = "Bob"   // ошибка: val нельзя переназначить
```

- **val** — поле только для чтения (неизменяемое после создания);
- **var** — изменяемое поле.

---

## 6.1.2. Параметры без val и var

Если параметр конструктора **не** помечен val или var, он используется только внутри конструктора и не становится полем. Снаружи к нему обратиться нельзя:

```scala
class Calc(a: Int, b: Int) {
  def sum: Int = a + b
}
val c = new Calc(3, 5)
c.sum   // 8
// c.a   // ошибка: a не является полем
```

Такой параметр удобен для промежуточных вычислений при создании объекта, когда не нужно хранить значение как поле.

---

## 6.1.3. Поля и методы в теле класса

Тело класса — блок в фигурных скобках после параметров. В нём объявляют дополнительные **поля** и **методы**:

```scala
class Person(val name: String, var age: Int) {
  val birthYear: Int = 2025 - age   // поле, вычисляемое при создании

  def greet: String = s"Hello, I'm $name"

  def isAdult: Boolean = age >= 18

  override def toString: String = s"Person($name, $age)"
}
```

Все выражения в теле класса выполняются при создании экземпляра (при вызове `new`). Методы объявляют через **def**; возвращаемый тип можно опустить (компилятор выведет). Ключевое слово **override** нужно при переопределении метода родительского класса (например, `toString` из `Any`).

---

## 6.1.4. Создание экземпляра: new

Экземпляр класса создают вызовом **new Имя(аргументы)**:

```scala
val p = new Person("Alice", 30)
val p2 = new Person("Bob", 25)
```

Аргументы передаются в том порядке, в каком объявлены параметры конструктора. Тип переменной — `Person` (или `Имя` класса).

---

## 6.1.5. Доступ к полям и вызов методов

К полям и методам обращаются через точку: **объект.поле**, **объект.метод()**. Скобки у метода без параметров можно опустить:

```scala
p.name      // "Alice"
p.greet     // "Hello, I'm Alice"
p.isAdult   // true
p.toString  // "Person(Alice, 30)"
```

---

## 6.1.6. Параметры по умолчанию

Параметрам конструктора можно задать значения по умолчанию. Тогда при создании их можно не указывать:

```scala
class Config(val host: String = "localhost", val port: Int = 8080)

val c1 = new Config()                // host=localhost, port=8080
val c2 = new Config("db.example.com") // host=db.example.com, port=8080
val c3 = new Config(port = 9000)     // host=localhost, port=9000 (именованный аргумент)
```

---

## 6.1.7. Класс как модель данных

В контексте работы с данными классы часто используют для представления сущностей: запись из CSV, строка таблицы, объект из JSON. Поля соответствуют колонкам или ключам:

```scala
class User(val id: Int, val name: String, val email: String) {
  override def toString: String = s"User($id, $name, $email)"
}

val u = new User(1, "Alice", "alice@example.com")
```

Для таких моделей в Scala обычно предпочитают **case class** ([§6.3](chapter-06-03.md)): они дают автоматические `equals`, `hashCode`, `toString` и создание без `new`. Обычный `class` полезен, когда нужны изменяемые поля или сложная логика в конструкторе.

---

## 6.1.8. Типичные ошибки

- **Забыть new** — `Person("Alice", 30)` без `new` вызовет ошибку (для обычного класса; для case class `new` не нужен).
- **Обращение к параметру без val/var** — параметр, не объявленный как поле, недоступен снаружи класса.
- **Переопределение без override** — при переопределении метода родителя (например, `toString`) нужно писать **override def**.

---

## Ключевое

- **class Имя(параметры)** — объявление класса. Параметры с **val** или **var** становятся полями; без val/var — только для использования в конструкторе.
- **val** — неизменяемое поле; **var** — изменяемое.
- Тело класса: дополнительные поля, методы (**def**), выражения при создании. **override def** — при переопределении методов родителя.
- Создание экземпляра: **new Имя(аргументы)**. Доступ: **объект.поле**, **объект.метод()**.
- Параметрам можно задать значения по умолчанию; при вызове — именованные аргументы.

В [§6.2](chapter-06-02.md) мы рассмотрим объекты (singleton) и объект-компаньон для класса.
