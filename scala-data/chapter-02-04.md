# §2.4 Строки

В [§2.3](chapter-02-03.md) мы разобрали операторы; строки уже упоминались в [§2.2](chapter-02-02.md). Здесь — **работа со строками в Scala**: литералы и экранирование, **интерполяция** `s"$name"`, многострочные строки (тройные кавычки), обращение к символам и подстроки, а также методы, нужные при очистке и разборе данных — `.trim`, `.split`, `.toInt`. В [§2.5](chapter-02-05.md) рассмотрим Option и проверку на отсутствие значения.

---

## 2.4.1. Литералы и экранирование

Тип **String** в Scala — это `java.lang.String`; строки неизменяемы. Литералы задают в двойных кавычках:

```scala
val s1 = "hello"
val s2 = "World"
val s3 = "It's fine"      // апостроф внутри
val s4 = "He said \"Hi\"" // кавычки экранированы
```

**Экранирование:** обратный слэш `\` вводит специальные символы: `\n` — перевод строки, `\t` — табуляция, `\\` — сам слэш, `\"` — кавычка:

```scala
val path = "C:\\Users\\data"
val line = "Col1\tCol2\tCol3"
```

---

## 2.4.2. Интерполяция s"..."

**s-интерполяция** подставляет значения переменных и выражений в строку. Префикс `s` перед кавычками, внутри строки — `$имя` или `${выражение}`:

```scala
val name = "Alice"
val age = 30
s"$name is $age years old"   // "Alice is 30 years old"
```

Для выражений (вызовы методов, арифметика) используют `${}`:

```scala
s"2 + 2 = ${2 + 2}"         // "2 + 2 = 4"
s"uppercase: ${name.toUpperCase}"
```

Чтобы вывести символ `$`, экранируйте: `$$`:

```scala
s"Price: $$10"   // "Price: $10"
```

s-интерполяция обрабатывает escape-последовательности: `\n`, `\t` и т.д. интерпретируются. Для путей и регулярных выражений, где слэши должны оставаться буквальными, используют **raw-интерполяцию** `raw"..."`:

```scala
raw"C:\Users\data"   // обратные слэши не экранируются
```

---

## 2.4.3. Форматирование f"..."

**f-интерполяция** — аналог `printf`: можно задавать формат числа (количество знаков, выравнивание). Синтаксис `%формат` после переменной:

```scala
val x = 3.14159
f"x = $x%.2f"        // "x = 3.14"
f"value: $x%8.2f"    // выравнивание по ширине 8, 2 знака после запятой
```

Распространённые спецификаторы: `%s` — строка, `%d` — целое, `%f` — вещественное, `%.2f` — два знака после запятой. Компилятор проверяет соответствие типа переменной и формата.

---

## 2.4.4. Многострочные строки (тройные кавычки)

Строку в несколько строк задают тройными кавычками `"""..."""`:

```scala
val text = """Первая строка.
Вторая строка.
Третья строка."""
```

Переводы строк сохраняются. Внутри тройных кавычек двойные кавычки `"` не экранируют. Если первая строка содержимого начинается с `|`, метод **.stripMargin** убирает префикс до `|` в каждой строке — удобно для выравнивания:

```scala
val sql = """
  |SELECT *
  |FROM users
  |WHERE active = true
""".stripMargin
```

Многострочную строку можно комбинировать с интерполяцией: `s"""..."""`.

## 2.4.5. Индексация и подстроки

**Один символ:** `s(i)` — символ на позиции `i` (индексация с нуля). Возвращается `Char`:

```scala
val s = "hello"
s(0)   // 'h'
s(1)   // 'e'
s(4)   // 'o'
```

Выход индекса за границы приводит к `StringIndexOutOfBoundsException`. Метод `s.charAt(i)` даёт тот же результат.

**Подстрока:** `s.substring(start, end)` — символы с индекса `start` до `end` (не включая `end`):

```scala
s.substring(1, 4)   // "ell"
s.substring(0, 2)   // "he"
s.substring(2)      // "llo" — от индекса 2 до конца
```

В Scala нет срезов вида `s(start:end)` как в Python; используются `substring` и методы коллекций для `String` через `StringOps` (например, `.slice`).

---

## 2.4.6. Длина, конкатенация, повторение

**Длина** — метод `.length`:

```scala
"hello".length   // 5
"".length        // 0
```

**Конкатенация** — оператор `+`:

```scala
"Hello, " + "world"   // "Hello, world"
```

**Повторение** — оператор `*` (в Scala 2.13+ через `StringOps`):

```scala
"ab" * 3   // "ababab"
```

## 2.4.7. Методы .trim и .split

При очистке и разборе данных часто нужны два метода.

**.trim** — удаляет пробельные символы (пробел, табуляция, переводы строк) с обоих концов:

```scala
"  hello  \n".trim   // "hello"
"\t  data  ".trim    // "data"
```

Аналоги: `.stripLeading`, `.stripTrailing` (Java 11+), если доступны.

**.split** — разбивает строку по разделителю и возвращает **массив** подстрок (`Array[String]`):

```scala
"a b c".split(" ")        // Array("a", "b", "c")
"a,b,c".split(",")        // Array("a", "b", "c")
"2024-01-15".split("-")   // Array("2024", "01", "15")
```

Разделитель — регулярное выражение; точка `.` и другие спецсимволы regex нужно экранировать: `split("\\.")` для разбиения по точке.

**Сборка строки из частей:** метод `.mkString` у коллекции создаёт строку с разделителем:

```scala
Array("a", "b", "c").mkString(",")   // "a,b,c"
List("Hello", "world").mkString(" ") // "Hello world"
```

## 2.4.8. Преобразование в число: .toInt, .toDouble

Строку можно привести к числу методами `.toInt`, `.toLong`, `.toDouble`, `.toFloat`:

```scala
"42".toInt        // 42
"3.14".toDouble   // 3.14
"  123  ".trim.toInt   // 123
```

При недопустимом формате выбрасывается `NumberFormatException`. При чтении CSV или API числа часто приходят как строки; перед расчётами их преобразуют через `.toInt`, `.toDouble` и т.д. Безопасную обработку ошибок разбора рассмотрим в [§2.5](chapter-02-05.md) (Option) и [§9.3](chapter-09-03.md) (Try).

## 2.4.9. Другие полезные методы

| Метод                | Описание                              |
|----------------------|----------------------------------------|
| `.contains(s)`       | есть ли подстрока `s`                  |
| `.startsWith(s)`     | начинается ли с `s`                    |
| `.endsWith(s)`       | заканчивается ли на `s`                |
| `.replace(a, b)`     | замена всех вхождений `a` на `b`       |
| `.toLowerCase`       | строка в нижнем регистре               |
| `.toUpperCase`       | строка в верхнем регистре              |
| `.isEmpty`           | пустая ли строка                       |
| `.nonEmpty`          | непустая ли строка                     |

Примеры:

```scala
"hello".contains("ell")       // true
"data.csv".endsWith(".csv")   // true
"Spam Spam".replace("Spam", "Egg")   // "Egg Egg"
"Hello".toLowerCase          // "hello"
```

## 2.4.10. Типичные ошибки

- **`s"$name"` без префикса `s`** — строка будет буквальной, подстановки не произойдёт; нужен префикс `s` (или `f`, `raw`).
- **`.split(".")`** — точка в regex означает «любой символ»; для разбиения по точке используйте `split("\\.")`.
- **Индекс за границами** — `s(i)` при неверном `i` даёт `StringIndexOutOfBoundsException`; проверяйте `i >= 0 && i < s.length`.
- **`"3.14".toInt`** — NumberFormatException; сначала `.toDouble`, затем при необходимости `.toInt`.

---

## Ключевое

- **Литералы:** двойные кавычки; экранирование `\n`, `\t`, `\\`, `\"`.
- **Интерполяция:** `s"$name"`, `s"${expr}"` — подстановка; `f"$x%.2f"` — форматирование; `raw"..."` — без обработки escape.
- **Многострочные:** `"""..."""`; `.stripMargin` для выравнивания.
- **Индексация:** `s(i)` — символ; `s.substring(start, end)` — подстрока.
- **Методы:** `.length`, `+`, `*`, `.trim`, `.split`, `.toInt`, `.toDouble`, `.mkString`, `.contains`, `.replace`, `.toLowerCase`, `.toUpperCase`.

В [§2.5](chapter-02-05.md) мы разберём Option: как представлять отсутствие значения и безопасно извлекать результат из разбора строк и доступа к данным.
