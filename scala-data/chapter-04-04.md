# §4.4 Методы и функции

В [§4.3](chapter-04-03.md) мы разобрали анонимные функции. В Scala важно различать **методы** и **функции**: методы определяются через def и принадлежат классу или объекту; функции — это значения, которые можно передавать и хранить. Метод можно преобразовать в функцию (**η-преобразование**); это происходит автоматически, когда метод передаётся туда, где ожидается функция. В [§4.5](chapter-04-05.md) рассмотрим функции высшего порядка — map, filter, foldLeft.

---

## 4.4.1. Метод принадлежит объекту или классу

**Метод** — функция, объявленная через **def** внутри object, class или trait. Он вызывается через точку: `объект.имяМетода(аргументы)`. Метод не существует «сам по себе»; он всегда привязан к экземпляру или к объекту.

```scala
object MathUtils {
  def add(a: Int, b: Int): Int = a + b
  def square(x: Int): Int = x * x
}

MathUtils.add(2, 3)    // 5
MathUtils.square(4)    // 16
```

Метод нельзя присвоить переменной или передать как аргумент без преобразования: `MathUtils.add` — это ссылка на метод, а не функция-значение.

---

## 4.4.2. Функция — значение

**Функция** в Scala — объект: экземпляр одного из типов `Function0`, `Function1`, `Function2` и т.д. (или `(A) => B` для одной переменной). Функцию можно сохранить в переменную, передать в другой метод и вернуть из метода.

```scala
val double: Int => Int = (x: Int) => x * 2
double(5)   // 10

val add: (Int, Int) => Int = (a, b) => a + b
add(2, 3)   // 5
```

Тип `A => B` — функция из A в B; `(A, B) => C` — функция двух аргументов. Анонимные функции ([§4.3](chapter-04-03.md)) создают именно такие значения.

---

## 4.4.3. η-преобразование (eta-expansion)

**η-преобразование** (eta-expansion) — автоматическое превращение метода в функцию, когда метод передаётся в контекст, ожидающий функцию.

Пример: `List.map` ожидает функцию `A => B`. Если передать метод `square` (без вызова):

```scala
def square(x: Int): Int = x * x
List(1, 2, 3).map(square)   // List(1, 4, 9)
```

Компилятор подставляет `x => square(x)`: метод «оборачивается» в функцию. Указывать `square _` в Scala 3 обычно не нужно — преобразование выполняется автоматически.

Явное преобразование (если нужно сохранить метод в переменную или когда автоматика не срабатывает):

```scala
val f: Int => Int = square _   // Scala 2: подчёркивание обязательно
val f: Int => Int = square     // Scala 3: часто достаточно имени
```

Подчёркивание `_` после имени метода говорит: «преобразовать метод в функцию». В Scala 3 во многих случаях его можно опустить.

---

## 4.4.4. Методы без параметров: def name и def name()

Метод **без параметров** может быть объявлен двумя способами:

- **def name: Type** — метод без скобок; вызывается как `obj.name` (без `()`).
- **def name(): Type** — метод с пустым списком параметров; вызывается как `obj.name()` или `obj.name`.

Разница важна при соглашениях: методы с побочными эффектами (например, получение следующего элемента) обычно объявляют с `()`, чтобы вызов был явным. Свойства без побочных эффектов — без скобок. При η-преобразовании метода без параметров нужно писать `() => obj.name` или `() => obj.name()`.

---

## 4.4.5. Зачем различать методы и функции

На практике при передаче методов в `map`, `filter`, `foreach` и т.п. преобразование происходит автоматически — достаточно написать имя метода без вызова. Понимание разницы помогает, когда:

- компилятор ругается на «ожидалась функция, получен метод» — тогда используют явное преобразование `method _` или обёртку `x => method(x)`;
- нужно сохранить метод в переменную для последующего вызова;
- изучают типы: метод не имеет типа `A => B` в том же смысле, что и функция; у метода есть сигнатура, а у функции — тип значения.

---

## 4.4.6. Типичные ошибки

- **Забыть передать функцию, а не результат вызова** — `list.map(square)` передаёт функцию; `list.map(square(5))` передаёт результат `square(5)` (число 25), что вызовет ошибку типа.
- **Метод с пустыми скобками** — при автоматическом преобразовании могут потребоваться явные скобки или обёртка; для `def getValue(): Int` используйте `() => obj.getValue()`.
- **Перегруженные методы** — при нескольких вариантах одного метода компилятор может не понять, какой преобразовывать; в таком случае задают тип явно или пишут обёртку.

---

## Ключевое

- **Метод** — def внутри object/class/trait; вызывается как `obj.method(args)`. Не является значением.
- **Функция** — значение типа `A => B`; создаётся анонимной функцией или преобразованием метода.
- **η-преобразование** — автоматическое превращение метода в функцию при передаче туда, где ожидается функция; в Scala 3 часто не требует `_`.
- Методы без параметров: `def name` и `def name()`; различие влияет на стиль вызова и преобразование в функцию.

В [§4.5](chapter-04-05.md) мы разберём функции высшего порядка: map, filter, foldLeft и примеры их использования на коллекциях.
