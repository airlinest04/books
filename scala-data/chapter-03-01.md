# §3.1 Условие if

В [§2.5](chapter-02-05.md) мы разобрали Option и безопасную работу с отсутствующими значениями. Теперь переходим к **управляющим конструкциям**: в зависимости от условия программа выполняет разные участки кода. В этом разделе — условие **if**, ветка **else**, цепочка **else if**, а также важная особенность Scala: **if возвращает значение** (является выражением). В [§3.2](chapter-03-02.md) рассмотрим сопоставление с образцом (match) — альтернативу цепочкам if-else.

---

## 3.1.1. Синтаксис if: условие и блок

Условие записывают так:

```scala
if (условие) {
  инструкции_блока
}
```

Условие берётся в **круглые скобки**; блок кода — в **фигурные скобки**. Условие должно иметь тип **Boolean** (true или false); в Scala нельзя писать в условии «правдивые» значения вроде числа или строки — в отличие от Python, выражение в скобках должно быть строго Boolean.

Пример:

```scala
val x = 10
if (x > 0) {
  println("x положительное")
  println("проверка выполнена")
}
println("эта строка выполнится всегда")
```

При `x > 0` выполняются строки внутри блока; при ложном условии блок пропускается. Последняя строка выполняется всегда.

**Однострочный блок** — фигурные скобки можно опустить, но обычно их оставляют для единообразия и снижения риска ошибок при добавлении строк.

## 3.1.2. Ветка else и цепочка else if

**else** — ветка «во всех остальных случаях»:

```scala
if (условие) {
  блок_если_истина
} else {
  блок_если_ложь
}
```

В Scala нет ключевого слова `elif`; используется **else if**:

```scala
if (x > 0) {
  println("положительное")
} else if (x < 0) {
  println("отрицательное")
} else {
  println("ноль")
}
```

Условия проверяются по порядку; выполняется блок при первом истинном условии. Если ни одно не истинно — блок после `else` (если он есть).

Пример с несколькими ветками:

```scala
val score = 75
val grade =
  if (score >= 90) "A"
  else if (score >= 80) "B"
  else if (score >= 70) "C"
  else "D"
```

---

## 3.1.3. if как выражение: возвращаемое значение

В Scala **if является выражением**: оно имеет тип и значение. Значение последнего выражения в выполненной ветке становится результатом всего if:

```scala
val x = 10
val sign = if (x > 0) "positive" else "negative"
// sign: String = "positive"
```

Тип результата — общий супертип обеих веток. Если ветки возвращают одинаковый тип (например, обе String), результат имеет этот тип. Если ветки разных типов — компилятор выводит общий тип (например, Any).

```scala
val n = 5
val result = if (n > 0) n * 2 else -1
// result: Int = 10
```

Если ветка `else` отсутствует и условие ложно, результат — `Unit` (значение `()`). В таком случае if используется как инструкция, а не как выражение:

```scala
val x = -1
val y = if (x > 0) println("ok")
// y: Unit = ()
```

Для согласованного возврата значения обе ветки (включая else) должны возвращать совместимые типы.

---

## 3.1.4. Блоки в фигурных скобках

Блок `{ ... }` сам является выражением: его значение — значение последнего выражения внутри. Промежуточные инструкции выполняются ради побочных эффектов; результат блока — последнее выражение.

```scala
val blockValue = {
  val a = 1
  val b = 2
  a + b
}
// blockValue: Int = 3
```

Это удобно в условиях:

```scala
val result = if (x > 0) {
  val doubled = x * 2
  doubled + 1
} else {
  0
}
```

---

## 3.1.5. Вложенные условия

Внутри блока if может стоять другой if:

```scala
val x = 10
val y = 5
if (x > 0) {
  if (y > 0) {
    println("оба положительные")
  } else {
    println("x положительное, y — нет")
  }
} else {
  println("x не положительное")
}
```

При глубокой вложенности читаемость падает. Часто логику упрощают, объединяя условия через `&&` / `||` или переписывая через match ([§3.2](chapter-03-02.md)):

```scala
if (x > 0 && y > 0) {
  println("оба положительные")
} else if (x > 0) {
  println("x положительное, y — нет")
} else {
  println("x не положительное")
}
```

---

## 3.1.6. Условие и тип Boolean

В Scala условие **должно быть Boolean**. Выражения вроде `if (0)` или `if ("")` не компилируются — в отличие от Python, где числа и строки интерпретируются как «правдивые» или «ложные».

Для проверки на пустоту коллекции или строки используют явные методы:

```scala
val s = ""
if (s.isEmpty) println("пустая строка")

val list = List(1, 2, 3)
if (list.nonEmpty) println("есть элементы")
if (list.isEmpty) println("пустой список")
```

Для Option — `.isEmpty` или `.isDefined` ([§2.5](chapter-02-05.md)).

---

## 3.1.7. Типичные ошибки

- **Присваивание вместо сравнения** — `if (x = 5)` не скомпилируется в Scala (присваивание возвращает Unit); нужно `if (x == 5)`.
- **Не-Boolean в условии** — `if (1)` или `if (s)` (где `s` — String) вызовет ошибку компиляции; условие должно быть Boolean.
- **Отсутствие else при использовании как выражения** — если ожидается значение, но else нет и условие ложно, результат будет `Unit`; при присваивании в переменную другого типа возможна ошибка компиляции.

---

## Ключевое

- **if (условие) { ... } else { ... }** — условие в круглых скобках, блоки в фигурных; цепочка веток — через `else if`.
- **if — выражение**: возвращает значение последней инструкции выполненной ветки; тип — общий для всех веток.
- Условие должно иметь тип **Boolean**; «правдивость» произвольных значений не поддерживается.
- Блок `{ ... }` — выражение; его значение — последнее выражение внутри.
- При сложной логике лучше объединять условия через `&&` / `||` или использовать match ([§3.2](chapter-03-02.md)).

В [§3.2](chapter-03-02.md) мы разберём сопоставление с образцом (match) — альтернативу цепочкам if-else с более выразительным синтаксисом.
