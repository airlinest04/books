# Сортировка глоссария по буквам

## Назначение

Обработать файл глоссария: извлечь все термины, отсортировать по алфавиту и сгруппировать по первой букве. Подходит для глоссариев в формате Markdown с записями вида `**Термин** — определение` или `**Термин** (англ.) — определение`.

## Алгоритм

1. **Прочитать файл глоссария**  
   Обычно это `glossary.md` в каталоге книги (например, `catalog/data-management-storage/glossary.md`). Путь может быть указан пользователем.

2. **Извлечь термины**  
   Найти все строки-определения: начинаются с `**`, затем идёт текст термина до `**` или до ` (` / ` — `.  
   - Термин — текст внутри первой пары `**...**`.  
   - Всю строку (термин + определение) сохранять как одну запись для вывода.

3. **Определить букву для сортировки**  
   Для группировки и сортировки использовать первую букву термина (после `**`).  
   - Если первый символ — латиница или цифра, считать буквой как есть.  
   - Для кириллицы и латиницы: одна группа на букву (А, Б, В, …; A, B, C, …).  
   - Цифры можно сгруппировать в блок «0–9» или «Числа».

4. **Сортировка**  
   - Сначала сортировать по букве группы (алфавитный порядок: А, Б, В, … или A, B, C, …).  
   - Внутри группы — по полному тексту термина (без учёта регистра при сравнении, если применимо).

5. **Формирование вывода**  
   Группы оформить заголовками по букве, под каждым заголовком — список записей в формате исходного глоссария (термин + определение). **Между терминами обязательно оставлять пустую строку.** Между группами букв — разрыв `---`. Пример:

   ```markdown
   ## А

   **Актив** (asset) — ресурс, контролируемый организацией...

   **Аналитик** (аналитик данных) — специалист по анализу данных...

   **Аналитическое хранение** — слой данных для отчётности...

   ---

   ## Б

   **Бизнес-пользователь** — сотрудник, потребляющий готовые отчёты...

   **Болото данных** (data swamp) — озеро данных...
   ```

## Детали парсинга

- Запись глоссария: строка, которая начинается с `**` и содержит ` — ` (тире с пробелами) как разделитель между термином и определением.
- Не считать заголовками секций (`## А`, `## Б`) сами термины — их не извлекать как термины.
- Пустые строки и разделители (`---`) пропускать.
- Сохранять в каждой записи полный текст строки (включая ссылки вроде `См. [§1.2](chapter-01-02.md).`), чтобы не терять форматирование.

## Реализация

Реализовать на Python или в виде скрипта в репозитории:

1. Читать файл по переданному пути (или по умолчанию `catalog/*/glossary.md`).
2. Регулярное выражение или пошаговый разбор для извлечения строк вида `**Термин** ... — ...`.
3. Для каждой записи вычислить букву (первый символ термина после `**`).
4. Сгруппировать по букве, внутри группы отсортировать по тексту термина.
5. Вывести результат: для каждой буквы заголовок `## Буква`, затем строки записей. Между каждыми двумя терминами — пустая строка; между группами букв — разрыв `---`.

Если пользователь просит только список терминов без определений — вывести под каждой буквой только строки вида `- **Термин**` (или «Термин»), сохраняя группировку по буквам.

## Итог

- Вход: путь к `glossary.md` (или файл по умолчанию в проекте).  
- Выход: тот же глоссарий, термины отсортированы по алфавиту и сгруппированы по первой букве, формат записей сохранён.
