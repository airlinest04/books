# §2.3 Операторы

В [§2.2](chapter-02-02.md) мы рассмотрели основные типы и приведение. Теперь — **операторы**: арифметические (включая целочисленное деление и остаток), операторы сравнения и логические. Они нужны для вычислений, условий и фильтрации данных; в конце раздела — составное присваивание (`+=`, `-=` и т.д.), о котором мы упоминали в [§2.1](chapter-02-01.md). В [§2.4](chapter-02-04.md) перейдём к строкам: индексации, срезам и методам.

---

## 2.3.1. Арифметические операторы

Для чисел определены привычные арифметические операции:

| Оператор | Операция        | Пример    |
|----------|------------------|-----------|
| `+`      | сложение         | `3 + 5` → 8 |
| `-`      | вычитание        | `10 - 4` → 6 |
| `*`      | умножение        | `6 * 7` → 42 |
| `/`      | деление          | `10 / 4` → 2.5 |
| `//`     | целочисленное деление | `10 // 4` → 2 |
| `%`      | остаток от деления    | `10 % 4` → 2 |
| `**`     | возведение в степень  | `2 ** 3` → 8 |

**Деление `/`** в Python 3 всегда возвращает вещественное число (float), даже при делении целых нацело:

```python
10 / 2   # 5.0
10 / 4   # 2.5
```

**Целочисленное деление `//`** отбрасывает дробную часть (округление в сторону минус бесконечности, не к нулю):

```python
10 // 4   # 2
-10 // 4  # -3
```

**Остаток от деления `%`** — остаток при целочисленном делении: `a % b` даёт остаток от деления `a` на `b`:

```python
10 % 4   # 2
10 % 2   # 0
```

Для целых выполняется соотношение: `a == (a // b) * b + (a % b)`.

**Возведение в степень `**`:**

```python
2 ** 10   # 1024
4 ** 0.5  # 2.0
```

Если хотя бы один операнд — float, результат, как правило, float. Операторы `+` и `*` для строк означают конкатенацию и повторение ([§2.4](chapter-02-04.md)); смешивать числа и строки в арифметике без приведения нельзя.

## 2.3.2. Составное присваивание

Операторы вида **операция=** объединяют операцию и присваивание: выражение вида `x = x + 1` можно записать короче.

| Оператор | Эквивалент   | Пример        |
|----------|--------------|---------------|
| `+=`     | `x = x + y`  | `count += 1`  |
| `-=`     | `x = x - y`  | `total -= 5`  |
| `*=`     | `x = x * y`  | `n *= 2`      |
| `/=`     | `x = x / y`  | `x /= 10`     |
| `//=`    | `x = x // y` | `x //= 3`     |
| `%=`     | `x = x % y`  | `x %= 2`      |
| `**=`    | `x = x ** y` | `x **= 2`     |

Пример:

```python
count = 0
count += 1   # count = 1
count += 1   # count = 2
```

Для строк допустимы `+=` (добавление подстроки) и `*=` (повторение). Операнд слева должен быть уже определён (переменная или элемент изменяемой структуры), иначе будет ошибка.

## 2.3.3. Операторы сравнения

Операторы сравнения возвращают булево значение — **True** или **False**:

| Оператор | Значение           | Пример      |
|----------|--------------------|-------------|
| `==`     | равно              | `5 == 5` → True |
| `!=`     | не равно           | `5 != 3` → True |
| `<`      | меньше             | `3 < 5` → True |
| `>`      | больше             | `5 > 3` → True |
| `<=`     | меньше или равно   | `3 <= 3` → True |
| `>=`     | больше или равно   | `5 >= 5` → True |

Примеры:

```python
10 == 10    # True
10 != 5     # True
3 < 5       # True
5 >= 5      # True
```

Сравнивать можно не только числа: строки сравниваются лексикографически (по кодам символов/Unicode); в [§2.4](chapter-02-04.md) и главах про структуры данных встретятся сравнения списков и других типов. Типы смешивать обычно нельзя: `3 < "5"` в Python 3 вызовет TypeError.

**Одна распространённая ошибка:** путать присваивание `=` и сравнение `==`. В условии нужно именно `==`; `if x = 5` в Python недопустимо (присваивание в условии так не пишут), а `if x == 5` — корректная проверка.

## 2.3.4. Логические операторы

Логические операторы работают с булевыми значениями (и с объектами, интерпретируемыми как истина/ложь в логическом контексте):

| Оператор | Значение | Пример |
|----------|-----------|--------|
| `and`    | логическое И | `True and False` → False |
| `or`     | логическое ИЛИ | `True or False` → True |
| `not`    | отрицание    | `not True` → False |

**and** — истина только если оба операнда истинны:

```python
True and True   # True
True and False  # False
False and False # False
```

**or** — истина, если хотя бы один операнд истинен:

```python
True or False   # True
False or False  # False
```

**not** — инвертирует значение:

```python
not True   # False
not False  # True
```

Python использует **короткое замыкание** (short-circuit evaluation): для `and` правый операнд не вычисляется, если левый ложный; для `or` — если левый истинный. Это важно, когда справа стоит вызов функции или выражение с побочным эффектом.

**Цепочки сравнений** в Python допустимы и читаются естественно:

```python
0 < x < 10      # то же, что (0 < x) and (x < 10)
1 <= a <= 5
```

## 2.3.5. Приоритет операторов

Приоритет (порядок выполнения) от высшего к низшему в типичных случаях:

1. Скобки `()`
2. Возведение в степень `**`
3. Унарные `+x`, `-x`, `not x`
4. Умножение, деление: `*`, `/`, `//`, `%`
5. Сложение, вычитание: `+`, `-`
6. Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`
7. Логическое И: `and`
8. Логическое ИЛИ: `or`

При сомнении лучше явно расставить скобки — это не влияет на производительность и улучшает читаемость.

---

## Ключевое

- **Арифметика:** `+`, `-`, `*`, `/` (всегда float в Python 3), `//` (целочисленное деление), `%` (остаток), `**` (степень).
- **Составное присваивание:** `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=` — сокращение для `x = x op y`.
- **Сравнения:** `==`, `!=`, `<`, `>`, `<=`, `>=` возвращают bool; не путать `=` (присваивание) и `==` (сравнение).
- **Логические:** `and`, `or`, `not`; допустимы цепочки сравнений (`0 < x < 10`). Вычисление с коротким замыканием.
- Приоритет при необходимости задают скобками.

В [§2.4](chapter-02-04.md) мы разберём строки: кавычки, индексацию, срезы и основные методы (.strip(), .split(), форматирование и f-строки).
