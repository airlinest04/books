# §8.2 DataFrame

В [§8.1](chapter-08-01.md) мы разобрали Series. **DataFrame** — двумерная таблица Pandas: строки и столбцы; каждый столбец является **Series** с общим индексом строк. В этом разделе: создание DataFrame из словаря, из списка словарей и **загрузка из CSV** (read_csv), атрибуты **столбцов** и **индекса**, выбор столбца через **df['col']** и **df.col**. В [§8.3](chapter-08-03.md) рассмотрим выборку строк и ячеек, .loc/.iloc для таблицы и добавление/удаление столбцов.

---

## 8.2.1. Что такое DataFrame

**DataFrame** — табличная структура: **столбцы** с именами (каждый столбец — Series) и **индекс строк** (метки строк, по умолчанию 0, 1, 2, …). Строки и столбцы можно выбирать по меткам и по позициям. См. [Глоссарий](glossary.md).

DataFrame — основной объект для загрузки таблиц из файлов, баз и API, для очистки, фильтрации и агрегации. Импорт: **import pandas as pd**.

---

## 8.2.2. Создание из словаря

**pd.DataFrame(data, index=None, columns=None)** — конструктор. Если **data** — словарь, то **ключи** становятся именами **столбцов**, значения — столбцами (списки или массивы одной длины, либо Series).

```python
import pandas as pd
df = pd.DataFrame({
    "name": ["Alice", "Bob", "Carol"],
    "age": [25, 30, 28],
    "city": ["Moscow", "SPb", "Kazan"]
})
```

Индекс строк по умолчанию — целые от 0 до n-1. Его можно задать аргументом **index**:

```python
df = pd.DataFrame({"x": [1, 2, 3], "y": [4, 5, 6]}, index=["a", "b", "c"])
```

Значения в словаре должны иметь одинаковую длину (или быть совместимы по длине при заданном index); иначе будет ошибка или пропуски (NaN).

---

## 8.2.3. Создание из списка словарей

Каждый элемент списка — **словарь** (одна строка таблицы): ключи — имена столбцов, значения — ячейки строки. Pandas собирает столбцы по ключам; отсутствующие ключи дают NaN.

```python
rows = [
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 30, "city": "SPb"},
    {"name": "Carol", "age": 28}
]
df = pd.DataFrame(rows)
# столбцы name, age, city; у первой строки city — NaN
```

Удобно при разборе JSON-ответов API или логов, когда каждая запись — словарь.

---

## 8.2.4. Загрузка из CSV: read_csv

**pd.read_csv(filepath_or_buffer, sep=',', encoding=None, ...)** загружает таблицу из CSV-файла в DataFrame. Первая строка по умолчанию считается **заголовком** (имена столбцов); следующие строки — данные. См. [§6.3](chapter-06-03.md) про формат CSV.

```python
df = pd.read_csv("data.csv")
```

Файл можно указать путём (строкой) или открытым файловым объектом. Важно задать **encoding**, если файл не в UTF-8: **encoding='utf-8'**, **encoding='cp1251'** и т.д.

**Основные параметры:**

- **sep** — разделитель полей (по умолчанию ','); для файлов с точкой с запятой — **sep=';'**.
- **header** — строка (или номер строки) с заголовками; **header=0** (по умолчанию) — первая строка; **header=None** — нет заголовка, столбцы будут 0, 1, 2, …
- **index_col** — номер столбца или имя столбца, который использовать как индекс строк (например, колонка с id или датой).
- **usecols** — список столбцов для загрузки (по имени или по номеру); остальные не читаются.
- **dtype** — задание типов столбцов (словарь {имя_столбца: тип}).

Пример с параметрами:

```python
df = pd.read_csv("data.csv", encoding="utf-8", sep=";", index_col=0)
```

Результат — DataFrame; столбцы имеют имена из первой строки файла (или 0, 1, … при header=None). Подробнее о типах, пропусках и датах при чтении — в главах 9 и 10.

## 8.2.5. Столбцы и индекс; выбор столбца

**df.columns** — объект с именами столбцов (индекс столбцов). **df.index** — индекс строк. **df.shape** — кортеж (число строк, число столбцов).

**Выбор одного столбца** возвращает **Series** с тем же индексом строк:

**df['имя_столбца']** — передать имя в кавычках. Работает всегда, в том числе когда имя содержит пробелы или совпадает с именем метода.

**df.имя_столбца** — доступ как к атрибуту (только если имя столбца допустимо как идентификатор и не совпадает с методом DataFrame). Для имен с пробелами или цифрами этот способ не подходит; предпочтительнее **df['col']**.

```python
df["age"]    # Series с столбцом age
df.age      # то же, если столбец называется "age"
```

**Список столбцов** даёт подтаблицу (новый DataFrame): **df[['name', 'age']]** — два столбца. Обратите внимание на двойные скобки: **df[['a', 'b']]** — DataFrame из столбцов a и b; **df['a']** — один столбец, Series.

---

## 8.2.6. Кратко: добавление столбца

Новый столбец можно добавить присваиванием: **df['new_col'] = значения** (список, массив или Series той же длины, что и df). Удаление и переименование столбцов — в [§8.3](chapter-08-03.md).

---

## Ключевое

- **DataFrame** — таблица: столбцы (каждый — Series) и индекс строк. Создание: **pd.DataFrame(dict)**, **pd.DataFrame(list_of_dicts)**; загрузка из файла — **pd.read_csv(path, encoding=..., sep=...)**.
- **df.columns** — имена столбцов; **df.index** — индекс строк; **df.shape** — (строки, столбцы).
- **Выбор столбца:** **df['col']** — Series; **df[['col1', 'col2']]** — DataFrame из указанных столбцов. **df.col** — атрибутный доступ, когда имя допустимо.
- read_csv: **encoding**, **sep**, **header**, **index_col**, **usecols** при необходимости.

В [§8.3](chapter-08-03.md) мы разберём выборку строк и ячеек: булева маска, .loc и .iloc для DataFrame, добавление и удаление столбцов.
