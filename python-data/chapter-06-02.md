# §6.2 Текстовые файлы

В [§6.1](chapter-06-01.md) мы разобрали открытие файла и контекстный менеджер with. Теперь — **чтение и запись** текстового содержимого: методы **.read()**, **.readlines()**, **.readline()** для чтения и **.write()** для записи, а также **построчное чтение** больших файлов без загрузки всего в память. В [§6.3](chapter-06-03.md) перейдём к формату CSV и модулю csv.

---

## 6.2.1. Чтение целиком: .read()

Метод **f.read()** читает из файла **всё оставшееся содержимое** и возвращает одну строку (в текстовом режиме). Если файл уже прочитан до конца, последующие вызовы read() возвращают пустую строку **''**.

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
# content — строка со всем содержимым файла
```

Опционально можно передать **размер в символах** (в текстовом режиме): **f.read(n)** прочитает не более n символов и вернёт строку (может быть короче, если до конца файла осталось меньше). Для больших файлов чтение целиком загружает всё в память; если файл очень большой, предпочтительнее читать по строкам или блоками (см. ниже).

---

## 6.2.2. Чтение по строкам: .readlines() и .readline()

**f.readlines()** читает все оставшиеся строки и возвращает **список строк**. Каждый элемент списка — одна строка файла **включая символ перевода строки** (\n) в конце (кроме, возможно, последней строки, если файл не заканчивается \n).

```python
with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
# lines = ["первая строка\n", "вторая строка\n", ...]
```

Чтобы убрать переводы строк при обработке, к каждой строке применяют **.strip()** или **.rstrip('\n')** ([§2.4](chapter-02-04.md)).

**f.readline()** читает **одну** строку (до следующего \n включительно) и возвращает её; в конце файла возвращает пустую строку **''**. Удобно, когда нужно читать по одной строке с дополнительной логикой между вызовами. Для последовательного перебора всех строк чаще используют итерацию по файлу (см. ниже).

---

## 6.2.3. Построчное чтение больших файлов

Файловый объект в текстовом режиме **итерируемый**: в цикле **for line in f** на каждой итерации в **line** попадает следующая строка. Файл при этом **не загружается целиком** в память — строки читаются по мере перебора. Это предпочтительный способ обрабатывать большие логи, дампы и построчные форматы.

```python
with open("large.log", "r", encoding="utf-8") as f:
    for line in f:
        line = line.strip()
        if line.startswith("ERROR"):
            process_error(line)
```

Строка **line** при итерации тоже может содержать завершающий **\n**; при необходимости его убирают **.strip()** или **.rstrip('\n')**.

Такой подход экономит память: одновременно в памяти хранится только текущая строка (и буфер файла). Для файлов в гигабайты чтение всего файла через read() или readlines() может быть недопустимо; построчная обработка или чтение блоками — нормальная практика в пайплайнах данных.

---

## 6.2.4. Запись: .write() и .writelines()

**f.write(string)** записывает строку **string** в файл. Возвращает количество записанных **символов** (в Python 3). Строка записывается «как есть»: символ перевода строки **\n** в строке даёт новую строку в файле; если его не добавить, следующая запись продолжит текущую строку.

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Первая строка\n")
    f.write("Вторая строка\n")
```

**f.writelines(sequence)** принимает последовательность строк и записывает их подряд **без добавления** переводов строк. Если нужны переводы между строками, их нужно включить в сами строки (например, добавлять \n в конец каждой) или записывать строки по одной через write().

```python
lines = ["a\n", "b\n", "c\n"]
with open("out.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

Запись буферизуется: данные могут временно находиться в буфере и попасть на диск при закрытии файла, при вызове **f.flush()** или при достижении размера буфера. Контекстный менеджер with при выходе из блока закрывает файл и сбрасывает буфер.

---

## 6.2.5. Замечания и типичные ошибки

- **Символ новой строки:** при чтении readlines() или в цикле **for line in f** строка обычно содержит \n в конце. Для сравнений и поиска подстрок часто вызывают **.strip()** или **.rstrip('\n')**. При записи нужно явно добавлять **\n**, если нужен перевод строки.
- **Режим 'w' очищает файл** — при открытии на запись предыдущее содержимое теряется. Для дополнения использовать режим **'a'** ([§6.1](chapter-06-01.md)).
- **Кодировка при записи** — задавать **encoding='utf-8'** (или нужную), иначе будет использована кодировка по умолчанию ОС.
- **Один и тот же файл: чтение после записи** — при открытии в режиме 'r+' или 'w+' позиция в файле одна; после записи для чтения с начала может понадобиться **f.seek(0)**. Для простых сценариев «прочитал — обработал — записал в другой файл» удобнее открывать два файла (вход и выход) в одном with.

---

## Ключевое

- **f.read()** — прочитать всё содержимое в одну строку; **f.read(n)** — не более n символов. Для больших файлов не загружать целиком.
- **f.readlines()** — список всех строк (с \n в конце); **f.readline()** — одна строка. Убирать \n при необходимости: **.strip()**, **.rstrip('\n')**.
- **for line in f** — построчное чтение без загрузки всего файла в память; предпочтительно для больших файлов.
- **f.write(string)** — записать строку; \n в строке даёт перевод строки в файле. **f.writelines(sequence)** — записать последовательность строк без добавления \n между ними.
