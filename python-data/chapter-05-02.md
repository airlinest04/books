# §5.2 Словарь (dict)

В [§5.1](chapter-05-01.md) мы разобрали список — упорядоченную последовательность по индексу. **Словарь (dict)** хранит пары **ключ : значение** и даёт доступ по ключу, а не по позиции. Словари удобны для конфигурации, разбора JSON, агрегации по категориям и любых отображений «имя → значение». В этом разделе: создание словаря, доступ по ключу и метод **.get()**, перебор через **.items()**, **.keys()**, **.values()**, изменение и добавление пар. В [§5.3](chapter-05-03.md) рассмотрим кортеж (tuple).

---

## 5.2.1. Создание словаря

**Словарь** задаётся в фигурных скобках: пары **ключ: значение** через запятую. См. [Глоссарий](glossary.md).

```python
empty = {}
person = {"name": "Alice", "age": 30, "city": "Moscow"}
```

Функция **dict()** создаёт словарь из последовательности пар (кортежей или списков из двух элементов) или из именованных аргументов:

```python
dict([("a", 1), ("b", 2)])   # {'a': 1, 'b': 2}
dict(a=1, b=2)               # {'a': 1, 'b': 2}
```

Ключи в одном словаре должны быть **уникальны**; при повторении ключа сохраняется последнее значение. Значения могут быть любого типа; ключи должны быть **хешируемыми** (неизменяемые типы: строки, числа, кортежи из неизменяемых; списки и словари ключами быть не могут). Длина словаря — **len(d)**; проверка наличия ключа — **key in d**, **key not in d** (проверяется только по ключам, не по значениям).

---

## 5.2.2. Доступ по ключу и метод .get()

Доступ к значению по ключу — **d[key]**:

```python
person = {"name": "Alice", "age": 30}
person["name"]   # 'Alice'
person["age"]    # 30
```

Если ключа **нет**, обращение **d[key]** вызывает **KeyError**. Чтобы избежать исключения при неизвестном ключе, используют метод **.get(key, default)**. Он возвращает значение по ключу, а если ключа нет — **default** (если default не указан, возвращается None):

```python
person.get("name")      # 'Alice'
person.get("salary")    # None
person.get("salary", 0) # 0  — значение по умолчанию
```

При разборе данных из API или файлов поля часто отсутствуют; **.get()** позволяет безопасно читать опциональные поля и подставлять значение по умолчанию.

---

## 5.2.3. Изменение и добавление пар

Словарь **изменяемый**. Присваивание **d[key] = value** создаёт новую пару или обновляет значение по существующему ключу:

```python
d = {"a": 1, "b": 2}
d["a"] = 10    # обновление
d["c"] = 3     # добавление новой пары
# d = {'a': 10, 'b': 2, 'c': 3}
```

**Удаление пары:** **del d[key]** — удалить ключ и значение; при отсутствии ключа — KeyError. Метод **d.pop(key, default)** удаляет ключ и возвращает значение; если ключа нет и указан default — возвращает default без исключения; если ключа нет и default не указан — KeyError.

```python
d = {"a": 1, "b": 2}
x = d.pop("b")     # x = 2, d = {'a': 1}
y = d.pop("z", 0)  # ключа 'z' нет, y = 0
```

**d.update(other)** — добавляет в d все пары из другого словаря (или из итерабельного объекта пар); существующие ключи перезаписываются.

---

## 5.2.4. Перебор: .items(), .keys(), .values()

Перебор по умолчанию идёт по **ключам**:

```python
for key in d:
    print(key, d[key])
```

Методы **.keys()**, **.values()**, **.items()** возвращают представления (view) ключей, значений и пар (ключ, значение). Их удобно использовать в циклах:

```python
for key, value in d.items():
    print(key, value)
```

**.items()** даёт пары **(ключ, значение)** — не нужно снова обращаться к d[key]. **.keys()** и **.values()** перебирают ключи и значения по отдельности. Представления отражают текущее состояние словаря: если словарь изменился, это видно при переборе.

Преобразование в список: **list(d.keys())**, **list(d.values())**, **list(d.items())** — когда нужен именно список (например, для индексации или среза).

---

## 5.2.5. Ключи и порядок элементов

**Ключи** должны быть **хешируемыми**: неизменяемые типы (str, int, float, tuple из неизменяемых) подходят; списки и словари — нет. Это связано с внутренней реализацией словаря (хеш-таблица).

Начиная с Python 3.7, словарь **сохраняет порядок вставки** пар: при переборе и при .keys(), .values(), .items() порядок совпадает с порядком добавления. В более старых версиях порядок не гарантировался.

---

## 5.2.6. Типичные ошибки

- **KeyError** при обращении d[key], если ключа нет — использовать **.get(key, default)** или проверку **key in d** перед доступом.
- **Использовать изменяемый тип как ключ** (список, словарь) — TypeError: unhashable type. Ключом может быть, например, кортеж из неизменяемых элементов.
- **Путать ключи и значения** при переборе: по умолчанию `for x in d` перебирает ключи; для пар — **for k, v in d.items()**.

---

## Ключевое

- **Словарь (dict)** — пары ключ: значение; создаётся **{}**, **dict()**; ключи уникальны и хешируемы; порядок вставки сохраняется (Python 3.7+).
- **Доступ:** **d[key]** — значение по ключу, при отсутствии ключа KeyError. **d.get(key, default)** — значение или default (или None), без исключения.
- **Изменение:** **d[key] = value** — добавить или обновить; **del d[key]**, **d.pop(key, default)** — удалить пару. **d.update(other)** — добавить/перезаписать пары из other.
- **Перебор:** **for key in d** — по ключам; **d.items()** — пары (ключ, значение); **d.keys()**, **d.values()** — ключи и значения. **key in d** — проверка наличия ключа.
