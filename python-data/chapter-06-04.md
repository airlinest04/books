# §6.4 JSON

В [§6.3](chapter-06-03.md) мы разобрали CSV. **JSON** (JavaScript Object Notation) — текстовый формат обмена структурированными данными: объекты (словари), массивы (списки), строки, числа, булевы значения и null. Он широко используется в API, конфигурации и хранении данных. Модуль **json** стандартной библиотеки преобразует структуры Python в JSON-строку и обратно; для работы с **файлами** применяют **json.load()** и **json.dump()** ([§4.5](chapter-04-05.md) — кратко loads/dumps для строк). В [§6.5](chapter-06-05.md) перейдём к регулярным выражениям.

---

## 6.4.1. Формат JSON и соответствие типам Python

В JSON допустимы: **объект** (пары "ключ": значение в фигурных скобках), **массив** (значения в квадратных скобках), **строка** (в двойных кавычках), **число**, **true** / **false**, **null**. Ключи объекта — только строки.

Соответствие с типами Python:

| JSON   | Python |
|--------|--------|
| object | dict   |
| array  | list   |
| string | str    |
| number | int, float |
| true / false | True, False |
| null   | None   |

При кодировании в JSON объекты типа datetime, множества и т.п. по умолчанию не поддерживаются — нужно либо преобразовать их в строку/число до вызова dump, либо задать свой encoder. См. [Глоссарий](glossary.md) для термина JSON.

---

## 6.4.2. Чтение: json.load() и json.loads()

**json.load(fp)** читает JSON из **файлового объекта** (открытый файл) и возвращает объект Python (словарь, список и т.д.). Файл должен быть открыт в **текстовом режиме** с корректной кодировкой (обычно **encoding='utf-8'**).

```python
import json
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
# data — dict или list в зависимости от корня JSON
```

**json.loads(s)** разбирает JSON из **строки** (удобно для ответа API, уже полученного как строка):

```python
s = '{"name": "Alice", "age": 30}'
data = json.loads(s)   # {'name': 'Alice', 'age': 30}
```

При неверном JSON (синтаксическая ошибка) выбрасывается **json.JSONDecodeError**. Часто ответы API приходят в виде строки; после **response.text** (библиотека requests, [§10.3](chapter-10-03.md)) вызывают **json.loads(response.text)** или проверяют статус и кодировку перед разбором.

## 6.4.3. Запись: json.dump() и json.dumps()

**json.dump(obj, fp, ...)** записывает объект Python **в файл** (файловый объект fp). Файл открывают на запись в текстовом режиме с нужной кодировкой.

```python
import json
data = {"name": "Alice", "scores": [10, 20, 30]}
with open("output.json", "w", encoding="utf-8") as f:
    json.dump(data, f)
```

**json.dumps(obj, ...)** возвращает **строку** с JSON (для вывода, логирования или отправки по сети):

```python
s = json.dumps(data)   # '{"name": "Alice", "scores": [10, 20, 30]}'
```

**indent** — отступ для «красивого» вывода (удобно для конфигов и отладки):

```python
json.dump(data, f, indent=2)
```

**ensure_ascii=False** — не экранировать не-ASCII символы (кириллица и др. останутся как есть); по умолчанию True, все не-ASCII превращаются в \uXXXX.

```python
json.dumps({"city": "Москва"}, ensure_ascii=False)   # '{"city": "Москва"}'
```

При попытке сериализовать объект, не поддерживаемый по умолчанию (например, datetime, bytes), возникает **TypeError**. Такие значения нужно предварительно преобразовать в строку, число или структуру dict/list, либо реализовать свой **default** (см. документацию).

---

## 6.4.4. Кодировка и работа с файлом

Файл при открытии задаётся с **encoding='utf-8'** ([§6.1](chapter-06-01.md)); модуль json при load/dump использует текстовый поток и не меняет кодировку сам. Для чтения — режим **'r'**, для записи — **'w'**. Контекстный менеджер **with** гарантирует закрытие файла после записи.

При записи больших структур **json.dump()** пишет последовательно в файл; **json.dumps()** формирует всю строку в памяти — для очень больших объектов может быть затратно по памяти.

---

## 6.4.5. Типичные случаи использования

- **Ответ API** — тело ответа (response.text) разбирают через **json.loads()**; результат — словарь или список, дальше обращение по ключам и индексам.
- **Конфигурация** — чтение настроек из config.json через **json.load()**; при необходимости запись обновлённой конфигурации через **json.dump()** с indent.
- **Сохранение промежуточных данных** — список словарей или вложенная структура после обработки записывается в JSON для передачи в другой скрипт или визуализацию.
- **Вложенные структуры** — JSON поддерживает произвольную вложенность (объекты и массивы внутри друг друга); при разборе получаются вложенные dict и list, доступ по ключам и индексам как обычно.

Проверка наличия ключа — **key in data** или **data.get(key)**; при отсутствии ключа **data[key]** даёт KeyError.

---

## Ключевое

- **JSON** — текстовый формат: объекты (dict), массивы (list), строки, числа, true/false, null; соответствие типам Python. Модуль **json** — разбор и сериализация.
- **json.load(f)** — прочитать JSON из файлового объекта; **json.loads(s)** — из строки. Файл открывать в текстовом режиме с **encoding='utf-8'**.
- **json.dump(obj, f)** — записать объект в файл; **json.dumps(obj)** — получить строку. **indent** — форматирование с отступами; **ensure_ascii=False** — не экранировать не-ASCII.
- Нестандартные типы (datetime, bytes и т.п.) перед сериализацией преобразовать в строку/число или использовать default. При ошибке разбора — **json.JSONDecodeError**.
