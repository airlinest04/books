# §4.2 Аргументы

В [§4.1](chapter-04-01.md) мы разобрали определение функции, return и параметры по умолчанию. Теперь — **способы передачи аргументов**: позиционные (по порядку) и именованные (по имени параметра), порядок при вызове и приёмы **\*args** и **\*\*kwargs** для произвольного числа аргументов. В [§4.3](chapter-04-03.md) рассмотрим область видимости переменных.

---

## 4.2.1. Позиционные аргументы

**Позиционные аргументы** передаются в том же порядке, в каком объявлены параметры: первый аргумент — первому параметру, второй — второму и т.д.

```python
def greet(name, greeting):
    return f"{greeting}, {name}!"
greet("Alice", "Hello")   # "Hello, Alice!"
```

Количество аргументов должно совпадать с количеством параметров (если у параметров нет значений по умолчанию). Порядок важен: если переставить аргументы местами, смысл изменится.

---

## 4.2.2. Именованные аргументы

**Именованные аргументы** (keyword arguments) передаются в форме **имя_параметра=значение**. Порядок при вызове может быть любым — параметр определяется по имени:

```python
greet(greeting="Hi", name="Bob")   # "Hi, Bob!"
greet(name="Bob", greeting="Hi")   # то же
```

Именованные аргументы удобны, когда у функции много параметров с умолчанием и нужно изменить только один или несколько: не придётся перечислять все предыдущие.

```python
def process(path, encoding="utf-8", skip_errors=False):
    ...
process("data.csv", skip_errors=True)   # encoding остаётся utf-8
```

Смешивать позиционные и именованные в одном вызове можно: сначала идут позиционные, затем именованные. После первого именованного аргумента все следующие должны быть именованными (иначе будет SyntaxError):

```python
def f(a, b, c):
    return a + b + c
f(1, 2, 3)           # верно
f(1, b=2, c=3)       # верно
f(1, 2, c=3)         # верно
f(a=1, 2, 3)         # SyntaxError: позиционный после именованного
```

---

## 4.2.3. Порядок параметров в определении и при вызове

В **определении** функции порядок такой: обычные параметры, затем параметры с умолчанием, затем (если есть) *args и **kwargs (см. ниже). В **вызове**: сначала позиционные аргументы в порядке параметров, затем именованные в любом порядке. Один и тот же параметр нельзя передать дважды (и позиционно, и по имени).

---

## 4.2.4. *args: произвольное число позиционных аргументов

В списке параметров звёздочка перед именем (**\*args** — имя может быть любым, но по традиции используют args) собирает **все лишние позиционные аргументы** в **кортеж**. Так можно описать функцию, принимающую любое количество позиционных аргументов:

```python
def sum_all(*args):
    return sum(args)
sum_all(1, 2, 3)      # 6
sum_all(1)            # 1
```

Внутри функции `args` — это кортеж из переданных значений. Параметры до *args получают аргументы по позиции как обычно; всё остальное попадает в args.

```python
def headline(prefix, *words):
    return prefix + ": " + " ".join(words)
headline("Result", "one", "two")   # "Result: one two"
```

Обратная операция — **распаковка** при вызове: список или кортеж можно «развернуть» в отдельные аргументы с помощью *:

```python
numbers = [1, 2, 3]
sum_all(*numbers)   # то же, что sum_all(1, 2, 3)
```

Это полезно, когда аргументы заранее собраны в список (например, из конфигурации или из другой функции).

---

## 4.2.5. **kwargs: произвольное число именованных аргументов

Две звёздочки (**\*\*kwargs**) собирают **все лишние именованные аргументы** в **словарь**: ключ — имя параметра, значение — переданное значение.

```python
def report(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")
report(name="Alice", age=30)   # name: Alice, age: 30
```

Порядок объявления в определении: сначала обычные параметры, затем *args (если есть), затем **kwargs. При вызове именованные аргументы, не попавшие в явные параметры, оказываются в kwargs.

Распаковка словаря при вызове — через **:

```python
opts = {"sep": ";", "encoding": "utf-8"}
# передаём как именованные аргументы в функцию, которая их принимает
```

*args и **kwargs часто используют в обёртках и фабриках, когда нужно принять произвольные аргументы и передать их дальше в другую функцию. Для повседневных скриптов обработки данных обычно достаточно явных параметров и нескольких значений по умолчанию.

---

## 4.2.6. Изменяемые объекты как значения по умолчанию

В [§4.1](chapter-04-01.md) было сказано, что не стоит использовать изменяемый объект (список, словарь) в качестве значения по умолчанию. Причина: **значение по умолчанию вычисляется один раз** в момент определения функции, и один и тот же объект используется при всех вызовах. Если внутри функции этот объект изменять (append, pop и т.д.), изменения сохраняются между вызовами:

```python
def add_item(item, items=[]):   # плохо
    items.append(item)
    return items
add_item(1)   # [1]
add_item(2)   # [1, 2]  — тот же список!
```

Правильный приём — использовать None и создавать список внутри тела при первом обращении:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
add_item(1)   # [1]
add_item(2)   # [2]  — каждый вызов получает новый список при items=None
```

То же относится к словарям и другим изменяемым типам.

---

## Ключевое

- **Позиционные аргументы** передаются по порядку параметров; **именованные** — в виде имя=значение, порядок может быть любым. При вызове сначала позиционные, затем именованные; после первого именованного все следующие должны быть именованными.
- **\*args** в определении собирает лишние позиционные аргументы в кортеж; при вызове **\*список** распаковывает последовательность в отдельные позиционные аргументы.
- **\*\*kwargs** собирает лишние именованные аргументы в словарь; при вызове **\*\*словарь** передаёт пары ключ-значение как именованные аргументы.
- Не использовать изменяемые объекты (list, dict) как значения по умолчанию; использовать None и создавать объект внутри функции при необходимости.
