# §5.4 Множество (set)

В [§5.3](chapter-05-03.md) мы разобрали кортеж. **Множество (set)** — неупорядоченная коллекция **уникальных** элементов без повторений. Оно удобно для удаления дубликатов, быстрой проверки вхождения и операций теории множеств (объединение, пересечение, разность). В этом разделе: создание множества, добавление и удаление элементов, операции объединения и пересечения. В [§5.5](chapter-05-05.md) рассмотрим list comprehensions и кратко dict/set comprehensions.

---

## 5.4.1. Создание множества

**Множество** задаётся фигурными скобками с перечислением элементов через запятую **без двоеточий** (в отличие от словаря). См. [Глоссарий](glossary.md).

```python
s = {1, 2, 3}
words = {"apple", "banana", "apple"}   # дубликаты отбрасываются: {'apple', 'banana'}
```

**Пустое множество** нельзя задать как **{}** — это пустой словарь. Используют **set()**:

```python
empty = set()
```

Функция **set(iterable)** создаёт множество из последовательности; дубликаты при этом удаляются:

```python
set([1, 2, 2, 3])   # {1, 2, 3}
set("hello")        # {'h', 'e', 'l', 'o'}
```

Все элементы множества должны быть **хешируемыми** (неизменяемые типы: строки, числа, кортежи). Списки и словари в множество помещать нельзя — TypeError.

---

## 5.4.2. Уникальность и хешируемость

В множестве каждый элемент встречается **не более одного раза**. При создании или добавлении повторяющиеся значения не добавляются заново:

```python
s = {1, 1, 2, 2, 3}
len(s)   # 3
```

Поэтому множество часто используют для **удаления дубликатов** из списка: **list(set(lst))** даёт список уникальных элементов (порядок при этом не сохраняется; если порядок важен, используют цикл с проверкой или dict.fromkeys).

Элементы множества должны быть **хешируемыми**: реализация опирается на хеш-таблицу, и изменяемые объекты (списки, словари, другие множества) не допускаются. Кортежи из неизменяемых элементов допустимы.

---

## 5.4.3. Добавление и удаление элементов

**s.add(x)** — добавить элемент x; если он уже есть, множество не меняется.

```python
s = {1, 2}
s.add(3)   # {1, 2, 3}
s.add(2)   # без изменений
```

**s.remove(x)** — удалить x; если элемента нет — **KeyError**.

**s.discard(x)** — удалить x, если он есть; если нет — ничего не делать, ошибки нет. Удобно, когда неизвестно, есть ли элемент.

**s.pop()** — удалить и вернуть **произвольный** элемент (множество неупорядочено); для пустого множества — KeyError.

**s.clear()** — удалить все элементы.

По индексу к элементу множества обратиться нельзя: нет порядка и нет **s[i]**. Проверка вхождения — **x in s**, **x not in s**; для множества эта операция в среднем очень быстрая (O(1) при типичной реализации). Длина — **len(s)**.

---

## 5.4.4. Операции объединения и пересечения

Множества поддерживают операции теории множеств; результат — новое множество (исходные не меняются, если не использовать варианты методов с присваиванием).

**Объединение** (union) — все элементы, входящие хотя бы в одно множество. Оператор **|** или метод **s.union(other, ...)**:

```python
a = {1, 2, 3}
b = {3, 4, 5}
a | b           # {1, 2, 3, 4, 5}
a.union(b)      # то же
```

**Пересечение** (intersection) — элементы, входящие в оба множества. Оператор **&** или метод **s.intersection(other, ...)**:

```python
a & b           # {3}
a.intersection(b)
```

**Разность** (difference) — элементы первого множества, которых нет во втором. Оператор **-** или метод **s.difference(other)**:

```python
a - b           # {1, 2}
b - a           # {4, 5}
```

**Симметрическая разность** (symmetric difference) — элементы, входящие ровно в одно из множеств (объединение без пересечения). Оператор **^** или метод **s.symmetric_difference(other)**:

```python
a ^ b           # {1, 2, 4, 5}
```

**Подмножество и надмножество:** **s <= other** — s является подмножеством other; **s >= other** — надмножество; **s < other** — строгое подмножество (s <= other и s != other).

---

## 5.4.5. Порядок и перебор

Множество **не упорядочено**: порядок элементов при создании и при итерации не гарантируется (в разных версиях Python и запусках он может отличаться). Перебор — **for x in s**; индексации и срезов нет.

При необходимости **упорядоченного** набора уникальных элементов в Python 3.7+ можно опереться на то, что dict сохраняет порядок ключей: **list(dict.fromkeys(lst))** даёт список уникальных элементов в порядке первого появления.

---

## 5.4.6. Когда использовать множество

- **Удаление дубликатов** из последовательности: **set(lst)** или **list(set(lst))** (если порядок не важен).
- **Быстрая проверка вхождения**: **x in s** в среднем за константное время; для больших коллекций выгоднее множества, чем списки.
- **Операции над наборами значений**: общие элементы двух списков (пересечение), объединение списков без повторов, разность (что есть в одном и нет в другом).

Типичный пример в данных: множество уникальных категорий, идентификаторов или тегов; проверка, входит ли значение в допустимый набор; сведение нескольких столбцов к уникальным комбинациям.

---

## Ключевое

- **Множество (set)** — неупорядоченная коллекция уникальных хешируемых элементов; создаётся **{1, 2, 3}**, **set()** (пустое — только set(), не {}); **set(iterable)** удаляет дубликаты.
- **Добавление и удаление:** **add(x)**, **remove(x)** (KeyError если нет), **discard(x)** (без ошибки), **pop()** (произвольный элемент), **clear()**. Нет индексации; **x in s** — быстрая проверка вхождения.
- **Операции:** **|** (объединение), **&** (пересечение), **-** (разность), **^** (симметрическая разность); методы union, intersection, difference, symmetric_difference. **<=**, **>=** — подмножество, надмножество.
- Порядок элементов не гарантируется. Множество используют для удаления дубликатов, быстрой проверки вхождения и операций над наборами значений.
