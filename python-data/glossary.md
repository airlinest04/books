# Глоссарий

Термины Python и библиотек, используемых в книге.

---

**DataFrame** — табличная структура данных в Pandas: столбцы с именами, индексы строк. См. [§8.2](chapter-08-02.md).

**ETL** (Extract, Transform, Load) — процесс извлечения данных из источников, преобразования и загрузки в хранилище (например, витрину или DWH). См. [§1.1](chapter-01-01.md).

**Jupyter** — среда для интерактивных документов, объединяющих код, вывод (таблицы, графики) и текст; часто используется в аналитике и машинном обучении. См. [§1.3](chapter-01-03.md).

**NumPy** (Numerical Python) — библиотека для многомерных массивов и быстрых численных вычислений; основа для Pandas и Scikit-learn. См. [Глава 7](chapter-07-01.md).

**ndarray** — тип многомерного массива NumPy; однотипные элементы, атрибуты shape, ndim, dtype. См. [§7.1](chapter-07-01.md).

**shape** — атрибут размера: у ndarray — кортеж размеров по осям; у DataFrame Pandas — (число строк, число столбцов). См. [§7.1](chapter-07-01.md), [§8.4](chapter-08-04.md).

**PyPI** (Python Package Index) — публичный репозиторий пакетов Python; pip по умолчанию загружает пакеты с PyPI. См. [§1.4](chapter-01-04.md).

**pip** — стандартный менеджер пакетов Python: установка, обновление и удаление пакетов из PyPI; команды `pip install`, `pip list`, `pip freeze`. См. [§1.4](chapter-01-04.md).

**Pandas** — библиотека для работы с табличными данными (Series и DataFrame): загрузка, очистка, фильтрация, агрегация, слияние. См. [Глава 8](chapter-08-01.md).

**Python** — интерпретируемый язык программирования общего назначения; широко используется для анализа данных, ML и автоматизации пайплайнов. См. [§1.1](chapter-01-01.md).

**REPL** (Read–Eval–Print Loop) — интерактивная оболочка: ввод выражения, вычисление, вывод результата; в Python запускается командой `python` без аргументов. См. [§1.3](chapter-01-03.md).

**SciPy** (Scientific Python) — библиотека научных вычислений поверх NumPy: статистика (scipy.stats), оптимизация (scipy.optimize), линейная алгебра (scipy.linalg) и др. См. [§11.1](chapter-11-01.md).

**Scikit-learn** — библиотека машинного обучения (регрессия, классификация, кластеризация, предобработка); единый API с методами `fit()` и `predict()`. См. [Глава 11](chapter-11-02.md).

**Оценщик** (estimator) — в Scikit-learn объект модели или преобразователя с методами fit(X, y) (обучение) и predict(X) или transform(X); единый интерфейс для всех алгоритмов. См. [§11.2](chapter-11-02.md).

**train_test_split()** — функция sklearn.model_selection: разбиение массивов X и y на обучающую и тестовую выборки; параметры test_size, random_state, stratify. См. [§11.2](chapter-11-02.md).

**MSE** (Mean Squared Error) — средняя квадратичная ошибка регрессии: среднее квадратов (y_true - y_pred); в Scikit-learn — sklearn.metrics.mean_squared_error. См. [§11.3](chapter-11-03.md).

**accuracy** (точность) — в классификации доля правильных предсказаний среди всех объектов; в Scikit-learn — sklearn.metrics.accuracy_score. См. [§11.3](chapter-11-03.md).

**Series** — одномерная структура Pandas с метками индекса. См. [§8.1](chapter-08-01.md).

**.iloc** — доступ к элементам Series/DataFrame по целочисленной позиции (индекс с нуля, срезы). См. [§8.1](chapter-08-01.md), [§8.3](chapter-08-03.md).

**.loc** — доступ к элементам Series/DataFrame по метке индекса; срез по меткам включает обе границы. См. [§8.1](chapter-08-01.md), [§8.3](chapter-08-03.md).

**Интерпретируемый язык** — язык, программы которого выполняются интерпретатором по шагам, без обязательной компиляции в машинный код; к таким языкам относится Python. См. [§1.1](chapter-01-01.md).

**venv** — стандартный модуль Python 3 для создания виртуальных окружений; изолирует пакеты проекта от системного Python. См. [§1.2](chapter-01-02.md).

**Виртуальное окружение** (virtual environment) — изолированный каталог с собственным интерпретатором и набором пакетов; создаётся с помощью `python3 -m venv` и активируется перед работой над проектом. См. [§1.2](chapter-01-02.md).

**Динамическая типизация** — свойство языка, при котором тип переменной не объявляется; переменная ссылается на объект, тип которого определяется в момент выполнения. См. [§2.1](chapter-02-01.md).

**docstring** — строка документации в тройных кавычках сразу после def (или class); описывает назначение функции/класса; доступна через __doc__ и help(). См. [§4.1](chapter-04-01.md).

**Исключение** (exception) — объект, выбрасываемый при ошибке; перехватывается блоком except. Типы: ValueError, TypeError, KeyError, IndexError, OSError/FileNotFoundError и др. См. [§4.6](chapter-04-06.md).

**JSON** (JavaScript Object Notation) — текстовый формат обмена данными: объекты, массивы, строки, числа, true/false, null. Модуль json: json.load(f), json.dump(obj, f) для файлов; json.loads(s), json.dumps(obj) для строк. См. [§6.4](chapter-06-04.md).

**Глобальная переменная** — переменная, объявленная на уровне модуля; видна во всём модуле и внутри функций (чтение без global; для присваивания нужна инструкция global). См. [§4.3](chapter-04-03.md).

**Локальная переменная** — переменная, созданная внутри функции (присваивание или параметр); видна только внутри этой функции. См. [§4.3](chapter-04-03.md).

**Область видимости** (scope) — область кода, в которой имя переменной доступно; в Python различают локальную (внутри функции) и глобальную (уровень модуля). См. [§4.3](chapter-04-03.md).

**Присваивание** — операция связи имени с объектом: `имя = выражение`; результат выражения становится значением переменной. См. [§2.1](chapter-02-01.md).

**Переменная** — имя, связанное с объектом (значением) посредством присваивания; по имени обращаются к значению. См. [§2.1](chapter-02-01.md).

**bool** — встроенный тип логических значений: `True` и `False`. См. [§2.2](chapter-02-02.md).

**Булева маска** — индексация массива (или выборка строк DataFrame) массивом булевых значений (условием); в результат попадают только элементы/строки с True. В NumPy: arr[arr > 0]. В Pandas: df[df['col'] > 0]. См. [§7.2](chapter-07-02.md), [§8.3](chapter-08-03.md).

**Broadcasting** — в NumPy: правила выполнения операций между массивами разной формы (скаляр с массивом, строка с столбцом и т.д.) без явного копирования. См. [§7.3](chapter-07-03.md).

**float** — встроенный тип вещественных чисел с плавающей точкой. См. [§2.2](chapter-02-02.md).

**int** — встроенный тип целых чисел произвольной величины. См. [§2.2](chapter-02-02.md).

**str** — встроенный тип строк (текст). См. [§2.2](chapter-02-02.md), [§2.4](chapter-02-04.md).

**f-строка** (formatted string literal) — строка с префиксом `f`, в которой выражения в фигурных скобках `{}` подставляются в результат. См. [§2.4](chapter-02-04.md).

**Список** (list) — упорядоченная изменяемая последовательность элементов; создаётся [], list(); индексация и срезы; методы append, extend, insert, remove, pop. См. [§5.1](chapter-05-01.md).

**Словарь** (dict) — структура ключ: значение; доступ по ключу, .get(); перебор .items(), .keys(), .values(); ключи хешируемы. См. [§5.2](chapter-05-02.md).

**Кортеж** (tuple) — неизменяемая упорядоченная последовательность; создаётся (), (1,), tuple(); хешируем; распаковка в переменные. См. [§5.3](chapter-05-03.md).

**CSV** (Comma-Separated Values) — текстовый формат табличных данных: строки — записи, поля разделены разделителем (запятая, точка с запятой); кавычки и переносы внутри полей обрабатываются по правилам. Модуль csv — чтение (reader, DictReader) и запись (writer, DictWriter). См. [§6.3](chapter-06-03.md).

**Контекстный менеджер** — объект для использования с инструкцией with; гарантирует выполнение входа и выхода (например, закрытие файла) даже при исключении. См. [§6.1](chapter-06-01.md).

**List comprehension** (списковое включение) — конструкция [выражение for x in последовательность if условие], создающая список за один проход; аналогично dict/set comprehensions. См. [§5.5](chapter-05-05.md).

**Распаковка** — присвоение элементов последовательности нескольким переменным: a, b = (1, 2); используется в for, при возврате из функции. См. [§5.3](chapter-05-03.md).

**Регулярное выражение** (regex) — шаблон для поиска и замены в тексте; в Python — модуль re: search, match, sub, findall; типичные паттерны \d, \s, \w, группы. См. [§6.5](chapter-06-05.md).

**Срез** (slice) — подпоследовательность строки (или другой последовательности): `s[start:end]` или `s[start:end:step]`; граница `end` не включается. См. [§2.4](chapter-02-04.md).

**Метод** — функция, вызываемая в форме `объект.имя_метода(аргументы)`; относится к типу объекта (например, строковые методы .strip(), .split()). См. [§2.4](chapter-02-04.md).

**Модуль** — файл с расширением .py; имя модуля — имя файла без .py. Содержит определения (функции, классы, переменные); подключается через import. См. [§4.4](chapter-04-04.md).

**Множество** (set) — неупорядоченная коллекция уникальных хешируемых элементов; создаётся {}, set(); add, remove, discard, pop; операции |, &, -, ^. См. [§5.4](chapter-05-04.md).

**None** — встроенная константа, единственный объект типа NoneType; обозначает отсутствие значения. Проверка: `x is None`, `x is not None`. См. [§2.5](chapter-02-05.md).

**NoneType** — тип единственного объекта None. См. [§2.5](chapter-02-05.md).

**enumerate()** — встроенная функция: перебирает последовательность и возвращает пары (индекс, элемент). См. [§3.2](chapter-03-02.md).

**range()** — встроенная функция, задающая последовательность целых чисел (например, range(n) — от 0 до n−1); часто используется в цикле for. См. [§3.2](chapter-03-02.md).

**type()** — встроенная функция, возвращающая тип объекта. См. [§2.2](chapter-02-02.md).

**drop** — метод Pandas (Series/DataFrame) для удаления строк или столбцов: df.drop(columns=..., index=...); по умолчанию возвращает новый объект; inplace=True изменяет исходный. См. [§8.3](chapter-08-03.md).

**inplace** — параметр многих методов Pandas (например, drop, fillna): при True метод изменяет объект на месте и возвращает None; при False (по умолчанию) возвращается новый объект. См. [§8.3](chapter-08-03.md).

**NaN** (Not a Number) — в Pandas и NumPy обозначение пропущенного или неопределённого значения (тип float); не равен сам себе, проверка — через pd.isna() / .isna(). См. [§9.1](chapter-09-01.md).

**Пропуск** (missing value) — отсутствующее значение в ячейке таблицы; в Pandas представляется как NaN или None; обнаружение — .isna(), удаление — .dropna(), заполнение — .fillna(). См. [§9.1](chapter-09-01.md).

**isna()** — метод Pandas (Series/DataFrame) и функция pd.isna(): возвращает True там, где значение пропущено (NaN, None). .notna() — обратная маска. См. [§9.1](chapter-09-01.md).

**dropna()** — метод Pandas: удаление строк (или столбцов при axis=1) с пропусками; параметры how ('any'/'all'), subset, inplace. См. [§9.1](chapter-09-01.md).

**fillna()** — метод Pandas: замена пропусков на значение (скаляр или словарь по столбцам); альтернативы — .ffill(), .bfill() для заполнения предыдущим/следующим значением. См. [§9.1](chapter-09-01.md).

**duplicated()** — метод Pandas (Series/DataFrame): возвращает булеву маску строк, считающихся дубликатами ранее встреченных; параметры subset (столбцы для сравнения), keep ('first'/'last'/False). См. [§9.2](chapter-09-02.md).

**drop_duplicates()** — метод Pandas: удаление дубликатов строк; параметры subset, keep, inplace; по умолчанию оставляется первое вхождение. См. [§9.2](chapter-09-02.md).

**astype()** — метод Pandas (Series/DataFrame): приведение типов столбцов к указанному dtype (int64, float64, str, bool и др.); для DataFrame можно передать словарь {столбец: dtype}; параметр errors ('raise', 'ignore', 'coerce'). См. [§9.3](chapter-09-03.md).

**to_datetime()** — функция Pandas (pd.to_datetime): преобразование столбца или последовательности в тип datetime64[ns]; параметры format (формат строки даты), errors ('raise', 'coerce', 'ignore'). См. [§9.3](chapter-09-03.md).

**NaT** (Not a Time) — в Pandas обозначение пропущенного значения для типов datetime64; аналог NaN для дат; появляется при errors='coerce' в pd.to_datetime(). См. [§9.3](chapter-09-03.md).

**groupby()** — метод Pandas: разбиение DataFrame (или Series) на группы по значениям столбца(ов); возвращает объект GroupBy, к которому применяют агрегирующие методы (.sum(), .mean()) или .agg(). См. [§9.4](chapter-09-04.md).

**agg()** (aggregate) — метод объекта GroupBy в Pandas: применение одной или нескольких агрегирующих функций (строка, список, словарь по столбцам); поддержка именованных агрегатов для явных имён результирующих столбцов. См. [§9.4](chapter-09-04.md).

**merge()** — функция Pandas (pd.merge): слияние двух DataFrame по ключу (столбец с общими значениями); параметры on, left_on, right_on, how ('inner', 'left', 'right', 'outer'). См. [§9.5](chapter-09-05.md).

**concat()** — функция Pandas (pd.concat): объединение списка DataFrame или Series по оси axis (0 — по строкам, 1 — по столбцам); параметры join, ignore_index. См. [§9.5](chapter-09-05.md).

**sort_values()** — метод Pandas (Series/DataFrame): сортировка по значениям столбца(ов); параметры by, ascending, na_position, inplace. См. [§9.6](chapter-09-06.md).

**rank()** — метод Pandas (Series/DataFrame): присвоение рангов (порядковых номеров при сортировке); параметр method ('average', 'min', 'max', 'first', 'dense') задаёт правило для совпадающих значений. См. [§9.6](chapter-09-06.md).

**SQLAlchemy** — библиотека Python для работы с реляционными БД: единый API, создание движка (create_engine), выполнение SQL; используется вместе с драйвером СУБД (например, psycopg2 для PostgreSQL). См. [§10.1](chapter-10-01.md).

**create_engine()** — функция SQLAlchemy: создаёт объект Engine (фабрику подключений) по URL подключения (dialect+driver://user:password@host:port/dbname). См. [§10.1](chapter-10-01.md).

**read_sql()** — функция Pandas (pd.read_sql): выполняет SQL-запрос через подключение (движок или соединение) и возвращает результат в виде DataFrame. См. [§10.1](chapter-10-01.md), [§10.2](chapter-10-02.md).

**to_sql()** — метод Pandas (DataFrame): запись содержимого таблицы в БД через подключение (движок или соединение); параметры name (имя таблицы), if_exists ('fail', 'replace', 'append'), index. См. [§10.2](chapter-10-02.md).

**requests** — библиотека Python для HTTP-запросов: requests.get(url), response.status_code, response.json(); установка — pip install requests. См. [§10.3](chapter-10-03.md).

**json_normalize()** — функция Pandas (pd.json_normalize): преобразование вложенных JSON-структур (список словарей или словарь) в плоский DataFrame. См. [§10.3](chapter-10-03.md).

**StandardScaler** — преобразователь Scikit-learn (sklearn.preprocessing): масштабирование признаков к нулевому среднему и единичной дисперсии; fit по обучающей выборке, transform к train и test. См. [§12.2](chapter-12-02.md).

**Утечка целевой переменной** (data leakage, target leakage) — попадание в признаки X информации, напрямую связанной с y или доступной только «в будущем»; приводит к завышенной оценке качества и неработоспособности модели в продакшене. См. [§12.2](chapter-12-02.md).

**cross_val_score()** — функция sklearn.model_selection: кросс-валидация модели — разбиение на cv складок, обучение и оценка на каждой; возвращает массив значений метрики (scoring). См. [§12.3](chapter-12-03.md).

**Переобучение** (overfitting) — ситуация, когда модель слишком подстраивается под обучающую выборку и плохо обобщает на новые данные; признак — метрика на train заметно лучше, чем на test. См. [§12.3](chapter-12-03.md).

**Регуляризация** — штраф за сложность модели (например, за большие веса в линейных моделях); Ridge (L2), Lasso (L1) в Scikit-learn; снижает переобучение. См. [§12.3](chapter-12-03.md).

**Глубокое обучение** (deep learning) — машинное обучение на многослойных нейронных сетях; типично для изображений, текста, речи; требует больших данных и вычислительных ресурсов; фреймворки: Keras, TensorFlow, PyTorch. См. [§13.1](chapter-13-01.md).

**Keras** — высокоуровневый API для построения и обучения нейронных сетей; встроен в TensorFlow (tf.keras); модель из слоёв (Sequential, Dense), compile(), fit(), predict(). См. [§13.2](chapter-13-02.md).

**TensorFlow** — фреймворк для численных вычислений и глубокого обучения (Google); бэкенд для Keras (tf.keras); графы операций, выполнение на CPU/GPU. См. [§13.3](chapter-13-03.md).

**PyTorch** — фреймворк глубокого обучения (императивный стиль, define-by-run); модели nn.Module, явный цикл обучения; распространён в исследованиях и сообществе. См. [§13.3](chapter-13-03.md).
