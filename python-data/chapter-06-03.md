# §6.3 CSV

В [§6.2](chapter-06-02.md) мы разобрали чтение и запись текстовых файлов. **CSV** (Comma-Separated Values) — распространённый текстовый формат табличных данных: строки — записи, поля в строке разделены разделителем (часто запятая или точка с запятой). Модуль **csv** стандартной библиотеки корректно обрабатывает кавычки и переносы строк внутри полей. В этом разделе — **csv.reader**, **csv.writer**, при необходимости **DictReader**/ **DictWriter**, диалекты и кодировки. В [§6.4](chapter-06-04.md) перейдём к JSON.

---

## 6.3.1. Формат CSV и модуль csv

В CSV каждая строка файла — одна запись (строка таблицы); поля разделены **разделителем** (часто **,** или **;**). Первая строка нередко содержит **заголовки** — имена столбцов. Если в поле встречаются разделитель, кавычки или перевод строки, поле заключают в кавычки; внутри кавычек кавычка удваивается. Модуль **csv** учитывает эти правила и избавляет от ручного разбора.

```python
import csv
```

Файл открывают в **текстовом режиме** с нужной кодировкой; при записи CSV на Windows рекомендуют открывать с **newline=''**, чтобы модуль csv сам управлял переводами строк и не появлялись лишние пустые строки. См. [Глоссарий](glossary.md) для термина CSV.

---

## 6.3.2. Чтение: csv.reader()

**csv.reader(fileobject, delimiter=',', ...)** возвращает объект-итератор: при переборе даёт **список полей** для каждой строки. Обычно файл открывают через with и передают в reader:

```python
import csv
with open("data.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)   # row — список строк: ['col1', 'col2', 'col3']
```

Первая строка файла при таком переборе — такая же «строка» (row), как и остальные. Если первая строка — заголовки, её можно прочитать отдельно или пропустить:

```python
with open("data.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    header = next(reader)   # первая строка — заголовки
    for row in reader:
        # row — список значений по порядку столбцов
        process(row)
```

Разделитель по умолчанию — запятая. Для файлов с точкой с запятой (часто в локали с запятой как десятичным разделителем) задают **delimiter=';'**:

```python
reader = csv.reader(f, delimiter=";")
```

---

## 6.3.3. Запись: csv.writer()

**csv.writer(fileobject, delimiter=',', ...)** создаёт объект для записи. Метод **writerow(iterable)** записывает одну строку CSV (поля из списка или кортежа); **writerows(iterable_of_rows)** записывает несколько строк.

```python
import csv
with open("output.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age", "city"])   # заголовки
    writer.writerow(["Alice", 30, "Moscow"])
    writer.writerows([
        ["Bob", 25, "SPb"],
        ["Carol", 28, "Kazan"],
    ])
```

При открытии файла на **запись** в Windows важно передать **newline=''**, иначе между строками могут появиться лишние пустые строки из-за преобразования \n в \r\n. В Linux/macOS newline='' тоже не мешает.

Разделитель задаётся так же, как при чтении: **delimiter=';'** при необходимости.

## 6.3.4. DictReader и DictWriter: доступ по именам столбцов

**csv.DictReader(f, fieldnames=None, ...)** при переборе возвращает не список, а **словарь**: ключи — имена столбцов, значения — соответствующие поля строки. Имена столбцов по умолчанию берутся из **первой строки** файла; при необходимости их можно задать аргументом **fieldnames**.

```python
with open("data.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["age"])   # доступ по имени столбца
        # row — {'name': 'Alice', 'age': '30', 'city': 'Moscow'}
```

Значения в словаре — **строки**; числа и даты при необходимости преобразуют вручную (int, float, datetime и т.д.).

**csv.DictWriter(f, fieldnames, ...)** пишет строки из словарей. При создании нужно передать **fieldnames** — список имён столбцов (порядок определяет порядок полей в файле). **writeheader()** записывает строку заголовков; **writerow(dict)** записывает одну строку (ключи словаря должны совпадать с fieldnames); **writerows(list_of_dicts)** — несколько строк.

```python
with open("out.csv", "w", encoding="utf-8", newline="") as f:
    fieldnames = ["name", "age", "city"]
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerow({"name": "Alice", "age": 30, "city": "Moscow"})
```

В writerow можно передавать числа; DictWriter преобразует их в строки. Пропущенные ключи дадут пустое поле; лишние ключи в словаре игнорируются (или вызывают ошибку в строгом режиме — см. документацию).

## 6.3.5. Диалекты и параметры

**Диалект** в модуле csv — набор настроек: разделитель, символ кавычки, правило обработки кавычек внутри полей и т.д. Стандартный диалект **excel** — запятая, двойные кавычки. Задать разделитель можно и без смены диалекта: **delimiter=','**, **quotechar='"'**.

Для регионов, где в числах используется запятая, файлы часто экспортируют с разделителем **;** (точка с запятой) — тогда при чтении и записи указывают **delimiter=';'**. Кавычки по умолчанию — двойные **"**; если поле содержит запятую или перевод строки, модуль автоматически заключает его в кавычки при записи и корректно разбирает при чтении.

---

## 6.3.6. Кодировки и ограничения

Файл открывают с нужной **encoding** ([§6.1](chapter-06-01.md)): **encoding='utf-8'** для современных данных; для файлов из старых систем может понадобиться **cp1251**, **latin-1** и т.д. Модуль csv не меняет кодировку — она задаётся при open().

**Ограничения формата CSV:** нет единого стандарта (разные разделители, кодировки, представление дат и чисел); большие числа и длинные текстые поля допустимы, но очень большие файлы лучше обрабатывать построчно (reader — итератор). Для сложной структуры, вложенных данных и строгой типизации чаще используют JSON или форматы вроде Parquet; CSV остаётся простым и удобным для обмена таблицами и выгрузок из таблиц и Excel.

---

## Ключевое

- **CSV** — текстовый табличный формат: строки — записи, поля разделены разделителем (часто , или ;); кавычки и переносы внутри полей обрабатываются по правилам RFC. Модуль **csv** разбирает и формирует такие файлы.
- **csv.reader(f)** — итератор по строкам; каждая строка — список полей. **delimiter=';'** для разделителя «точка с запятой». Первую строку (заголовки) при необходимости читают через **next(reader)**.
- **csv.writer(f)** — **writerow(row)**, **writerows(rows)**; при записи на Windows открывать файл с **newline=''**.
- **csv.DictReader(f)** — каждая строка как словарь (ключи — из первой строки или fieldnames). **csv.DictWriter(f, fieldnames)** — **writeheader()**, **writerow(dict)**, **writerows(list_of_dicts)**.
- Кодировка задаётся при **open()** (encoding='utf-8'); диалекты и delimiter/quotechar при необходимости.
