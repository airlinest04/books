# §12.2 Подготовка данных для ML

В [§12.1](chapter-12-01.md) мы обозначили границы книги. Модели Scikit-learn ожидают **числовую матрицу признаков** без пропусков; на практике признаки бывают в разных масштабах или категориальными. В этом разделе — кратко **масштабирование признаков** (StandardScaler, MinMaxScaler), **кодирование категорий** (LabelEncoder, OneHotEncoder, get_dummies) и **типичная ошибка** — утечка целевой переменной. В [§12.3](chapter-12-03.md) разберём кросс-валидацию и переобучение.

## 12.2.1. Масштабирование признаков

Признаки с разным размахом (например, возраст 0–100 и доход 0–1 000 000) могут искажать работу алгоритмов (градиентный спуск, метрики расстояния в k-NN). **Масштабирование** приводит столбцы к сопоставимому диапазону.

**StandardScaler** (sklearn.preprocessing): вычитает среднее и делит на стандартное отклонение по каждому столбцу; после преобразования признаки имеют нулевое среднее и единичную дисперсию. **fit(X_train)** — вычислить среднее и std по обучающей выборке; **transform(X_train)** и **transform(X_test)** — применить те же параметры (тест масштабируется по статистикам train, иначе будет утечка информации из test). Удобно использовать **fit_transform(X_train)** на обучающих данных и отдельно **transform(X_test)** на тестовых.

**MinMaxScaler**: масштабирование в заданный диапазон (по умолчанию [0, 1]): (x - min) / (max - min). Аналогично — fit по train, transform к train и test.

Пайплайн из нескольких шагов (масштабирование → модель) можно объединять через **sklearn.pipeline.Pipeline** (в книге не разбирается); важно лишь не подгонять scaler по тестовой выборке.

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
# затем model.fit(X_train_scaled, y_train), model.predict(X_test_scaled)
```

## 12.2.2. Кодирование категорий

Категориальные признаки (регион, тип товара, «да/нет») нужно превратить в числа. Два подхода:

**Метки классов (целые числа):** **LabelEncoder** (sklearn.preprocessing) сопоставляет каждой категории целое число (0, 1, 2, …). Подходит для **целевой переменной** в классификации (y). Для **признаков** с номинальными категориями без порядка целые числа могут быть восприняты моделью как порядок (1 «больше» 0); тогда предпочтительно one-hot.

**One-hot (бинарные столбцы):** каждая категория — отдельный двоичный признак (1 в своей колонке, 0 в остальных). В Pandas — **pd.get_dummies(df, columns=[...])**; в Scikit-learn — **OneHotEncoder** (sklearn.preprocessing). После one-hot число столбцов растёт (по одному на категорию); для признаков с большим числом уникальных значений иногда используют отбор категорий или эмбеддинги (за рамками книги).

Пропуски в категориальных столбцах перед кодированием нужно заполнить или выделить отдельной категорией; иначе encoder может выдать ошибку или неверно обработать пропуск.

```python
from sklearn.preprocessing import LabelEncoder, OneHotEncoder
# Цель y для классификации:
le = LabelEncoder()
y_encoded = le.fit_transform(y)
```

## 12.2.3. Утечка целевой переменной

**Утечка целевой переменной** (data leakage, target leakage) — когда в признаки **X** попадает информация, которая напрямую связана с **y** или доступна только «в будущем» относительно момента предсказания. Модель тогда получает завышенное качество на тесте, но в реальности такие признаки недоступны.

Примеры: включение в X агрегата по всей выборке (в том числе по тесту), например среднее y по группе; признак «дата ответа» при предсказании «ответит ли клиент» до того, как ответ пришёл; дубликат целевой переменной под другим именем. Как избежать: считать агрегаты только по обучающей выборке (и по времени — только по прошлому); не включать в X то, чего не будет в продакшене в момент предсказания; проверять список признаков на наличие y или производных от него.

Разбиение на train/test до любой предобработки и применение преобразований (scaler, encoder) только по train помогают избежать части утечек; остальное — дисциплина при проектировании признаков.

---

## Ключевое

- **Масштабирование:** StandardScaler или MinMaxScaler; **fit** только по **X_train**, **transform** к train и test (тест не участвует в расчёте среднего и std).
- **Кодирование категорий:** LabelEncoder для меток y; для признаков — OneHotEncoder или pd.get_dummies, чтобы не привносить ложный порядок.
- **Утечка целевой переменной:** в X не должны попадать y, агрегаты по всей выборке (включая test) или «будущая» информация; агрегаты считают только по train (и по прошлому по времени).
