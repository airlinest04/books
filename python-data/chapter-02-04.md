# §2.4 Строки

В [§2.3](chapter-02-03.md) мы разобрали операторы; типы и строки уже упоминались в [§2.2](chapter-02-02.md). Здесь — **полноценная работа со строками**: кавычки и литералы, обращение к символам по индексу и **срезы** (подстроки), а также методы, без которых не обойтись при очистке и разборе данных — `.strip()`, `.split()` — и форматирование: `.format()` и **f-строки**. В [§2.5](chapter-02-05.md) рассмотрим значение `None` и проверку на отсутствие значения.

---

## 2.4.1. Кавычки и литералы строк

Строка (тип **str**) задаётся последовательностью символов в кавычках. Одинарные и двойные кавычки равнозначны; выбор позволяет не экранировать кавычку внутри строки:

```python
s1 = "hello"
s2 = 'world'
s3 = "It's fine"      # апостроф внутри двойных
s4 = 'He said "Hi"'  # кавычки внутри одинарных
```

**Тройные кавычки** (`"""..."""` или `'''...'''`) — многострочные строки; переводы строк сохраняются:

```python
text = """Первая строка.
Вторая строка."""
```

Их же используют для документирующих строк (docstring) в функциях и модулях ([§4.1](chapter-04-01.md)).

**Экранирование:** обратный слэш `\` вводит специальные символы: `\n` — перевод строки, `\t` — табуляция, `\\` — сам слэш, `\'` и `\"` — кавычки внутри строки:

```python
path = "C:\\Users\\data"
line = "Col1\tCol2\tCol3"
```

Строки с префиксом `r` (raw) не интерпретируют обратные слэши как экранирование — удобно для путей и регулярных выражений ([§6.5](chapter-06-05.md)): `r"C:\Users"`.

## 2.4.2. Индексация и срезы

Строка — **последовательность** символов; к ним можно обращаться по индексу. Индексация с нуля: первый символ — индекс 0, второй — 1 и т.д.

**Один символ:** `s[i]` — символ на позиции `i`:

```python
s = "hello"
s[0]   # 'h'
s[1]   # 'e'
s[4]   # 'o'
```

**Отрицательные индексы:** считают с конца: `-1` — последний символ, `-2` — предпоследний:

```python
s[-1]   # 'o'
s[-2]   # 'l'
```

Выход индекса за границы строки вызывает **IndexError**.

**Срез** (slice) — подстрока от индекса `start` до индекса `end` (не включая `end`). Синтаксис: `s[start:end]` или `s[start:end:step]`. См. [Глоссарий](glossary.md).

```python
s = "hello"
s[1:4]   # 'ell'  — символы с индексами 1, 2, 3
s[0:2]   # 'he'
s[:2]    # 'he'   — начало до 2 (start по умолчанию 0)
s[2:]    # 'llo'  — от 2 до конца (end по умолчанию длина строки)
s[:]     # 'hello' — копия всей строки
```

**Шаг (step):** третий параметр задаёт шаг; по умолчанию 1. Отрицательный шаг идёт с конца к началу:

```python
s[::2]    # 'hlo'   — каждый второй символ
s[::-1]   # 'olleh' — строка в обратном порядке
```

Правило: `s[i:j]` — символы с индексами от `i` до `j` не включительно. Пустой срез (например, когда `start >= end`) даёт пустую строку `""`.

## 2.4.3. Длина строки, конкатенация и повторение

**Длина** — встроенная функция **len(s)** возвращает количество символов:

```python
len("hello")   # 5
len("")        # 0
```

**Конкатенация** — сложение строк даёт новую строку:

```python
"Hello, " + "world"   # 'Hello, world'
```

**Повторение** — строка, умноженная на целое число, повторяется указанное число раз:

```python
"ab" * 3   # 'ababab'
```

Строки **неизменяемы**: любая операция, «меняющая» строку, создаёт новый объект. Например, `s = s + "!"` создаёт новую строку и связывает с ней имя `s`.

## 2.4.4. Методы .strip() и .split()

Методы вызывают в форме `строка.имя_метода(аргументы)` (см. [Глоссарий](glossary.md)). При очистке и разборе данных особенно часто нужны два метода.

**.strip()** — удаляет пробельные символы (пробелы, табуляция, переводы строк) с обоих концов строки.

```python
"  hello  \n".strip()   # 'hello'
"\t  data  ".strip()   # 'data'
```

Варианты: **.lstrip()** — только слева, **.rstrip()** — только справа. В **.strip(chars)** можно передать строку символов для удаления (не только пробелы).

**.split()** — разбивает строку по разделителю и возвращает **список** подстрок. По умолчанию разделитель — пробельные символы (пробел, табуляция, перевод строки), при этом несколько подряд идущих пробелов считаются одним разделителем:

```python
"a b c".split()        # ['a', 'b', 'c']
"one two  three".split()  # ['one', 'two', 'three']
```

Явный разделитель передают аргументом:

```python
"a,b,c".split(",")     # ['a', 'b', 'c']
"2024-01-15".split("-") # ['2024', '01', '15']
```

Второй аргумент — максимальное число разбиений: `"a:b:c".split(":", 1)` даёт `['a', 'b:c']`. Списками мы займёмся в [§5.1](chapter-05-01.md); здесь достаточно понимать, что `.split()` возвращает последовательность подстрок, с которой можно дальше работать (индексация, цикл, приведение типов для числовых полей).

**Обратная операция** — собрать строку из списка подстрок: метод **.join()** вызывают у строки-разделителя:

```python
",".join(["a", "b", "c"])   # 'a,b,c'
" ".join(["Hello", "world"]) # 'Hello world'
```

## 2.4.5. Форматирование: .format() и f-строки

Подстановка значений в строку нужна при формировании сообщений, логов и вывода. Два основных способа в современном Python.

**Метод .format():** в строке-шаблоне места подстановки обозначают фигурными скобками `{}`; аргументы метода подставляются по порядку или по имени:

```python
"{} + {} = {}".format(2, 3, 5)           # '2 + 3 = 5'
"{0} and {1}".format("a", "b")           # 'a and b'
"{name}: {value}".format(name="x", value=10)  # 'x: 10'
```

Внутри `{}` можно задать формат числа или выравнивание (например, `{:.2f}` — два знака после запятой для float); подробности — в документации по мини-языку форматирования.

**F-строки** (formatted string literals, с Python 3.6): префикс `f` перед кавычками, внутри `{}` — выражения, которые вычисляются и подставляются в строку. См. [Глоссарий](glossary.md).

```python
name = "Alice"
age = 30
f"{name} is {age} years old"   # 'Alice is 30 years old'
```

В фигурных скобках допустимы выражения, вызовы функций и формат-спецификаторы:

```python
x = 3.14159
f"x = {x:.2f}"   # 'x = 3.14'
f"2 + 2 = {2 + 2}"   # '2 + 2 = 4'
```

Для вывода и логирования f-строки обычно удобнее и читаемее, чем конкатенация или старый стиль с `%`. При работе с данными они часто используются при построении отчётов и сообщений об ошибках.

## 2.4.6. Проверка вхождения и другие полезные методы

**Оператор in** — проверка вхождения подстроки или символа:

```python
"ell" in "hello"   # True
"xyz" in "hello"   # False
```

**Проверка начала и конца:** **.startswith(prefix)** и **.endswith(suffix)** возвращают bool:

```python
"hello".startswith("he")   # True
"data.csv".endswith(".csv")  # True
```

**Замена:** **.replace(old, new)** возвращает новую строку с заменёнными вхождениями:

```python
"spam spam".replace("spam", "egg")   # 'egg egg'
```

**Регистр:** **.lower()**, **.upper()** — строка в нижнем или верхнем регистре; **.capitalize()** — первая буква заглавная. Сравнение строк без учёта регистра часто делают так: `s1.lower() == s2.lower()`.

Для более сложного поиска и замены по шаблону используется модуль **re** ([§6.5](chapter-06-05.md)).

## Ключевое

- **Литералы:** одинарные и двойные кавычки; тройные — многострочные строки; экранирование `\n`, `\t`, `\\`; raw-строки `r"..."`.
- **Индексация:** `s[i]` — символ (индекс с 0); отрицательные индексы — с конца. **Срез:** `s[start:end]` или `s[start:end:step]`; пустой срез при неверных границах даёт `""`.
- **len(s)**, конкатенация `+`, повторение `*`; строки неизменяемы.
- **.strip()** — убрать пробелы с концов; **.split()** — разбить по разделителю (по умолчанию — пробелы) в список; **.join()** — собрать строку из списка.
- **Форматирование:** `.format(...)` с `{}` и f-строки `f"...{выражение}..."`; в f-строках можно задавать формат, например `{x:.2f}`.
- **in**, **.startswith()**, **.endswith()**, **.replace()**, **.lower()** / **.upper()** — типичные операции при очистке и разборе текста.

В [§2.5](chapter-02-05.md) мы разберём значение **None** и проверку на отсутствие значения — это понадобится при работе с пропусками и опциональными результатами.
