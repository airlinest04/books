## 10.3.1. Библиотека requests и GET-запрос

**requests** — популярная библиотека Python для HTTP-запросов. Установка: **pip install requests**.

**requests.get(url, params=None, headers=None, ...)** выполняет GET-запрос по **url** и возвращает объект **Response**. Основные атрибуты и методы:

- **response.status_code** — код ответа (200 — успех, 404 — не найдено, 500 — ошибка сервера и т.д.).
- **response.text** — тело ответа как строка (для любого формата).
- **response.json()** — разбор тела как **JSON**; возвращает объекты Python (dict, list, числа, строки). Если ответ не JSON или битый — выбрасывается исключение.

Параметры запроса в URL можно задать словарём **params**: **requests.get(url, params={'key': 'value'})** — библиотека сама добавит их в URL. Заголовки (например, Authorization, Accept) передают через **headers**.

Перед использованием ответа стоит проверить **status_code** и при ошибке обработать исключение или вывести сообщение.

```python
import requests

url = "https://api.example.com/data"
r = requests.get(url)
if r.status_code == 200:
    data = r.json()   # dict или list в зависимости от API
else:
    raise RuntimeError(f"Request failed: {r.status_code}")
```

## 10.3.2. Разбор JSON и загрузка в DataFrame

Структура JSON-ответа зависит от API. Часто это **список объектов** (список словарей), где каждый словарь — одна запись с полями-ключами. Такой список можно передать в **pd.DataFrame()** напрямую: столбцы — ключи словарей, строки — элементы списка.

Если данные лежат **вложенно** (например, ответ вида **{"results": [ {...}, {...} ]}**), сначала извлекают список: **data = r.json(); rows = data['results']**, затем **df = pd.DataFrame(rows)**.

Для **вложенных структур** внутри каждой записи (объекты или списки в полях) плоская таблица получится не сразу: либо предварительно «развернуть» данные в цикле, либо использовать **pd.json_normalize()**. **pd.json_normalize(data)** превращает список словарей (или один словарь) в DataFrame, при необходимости разворачивая вложенные объекты; имена столбцов образуются из путей (например, **user.name**). Для простого списка словарей без глубокой вложенности достаточно **pd.DataFrame(list)**.

```python
import pandas as pd
import requests

r = requests.get("https://api.example.com/users")
r.raise_for_status()   # исключение при status_code >= 400
data = r.json()
# Если data — список словарей:
df = pd.DataFrame(data)
# Если данные в поле, например data["items"]:
df = pd.DataFrame(data["items"])
# Вложенные поля — pd.json_normalize(data)
```

После загрузки можно применить приёмы из глав 8–9: типы столбцов (.astype(), pd.to_datetime()), пропуски, фильтрация, агрегация.

## Ключевое

- **requests.get(url)** — GET-запрос; **response.status_code**, **response.text**, **response.json()** — код ответа и тело (как строка или разобранный JSON).
- Для загрузки в Pandas: если ответ — **список словарей**, **pd.DataFrame(data)** даёт таблицу; если данные в подключах ответа — сначала извлечь список, затем DataFrame.
- **pd.json_normalize()** — разворот вложенных JSON-структур в плоский DataFrame при необходимости.
