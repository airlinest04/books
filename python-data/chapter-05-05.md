## 5.5.1. Синтаксис: [выражение for элемент in последовательность]

**List comprehension** (списковое включение) — выражение в квадратных скобках, которое создаёт список за один проход по последовательности. Общая форма:

```python
[выражение for элемент in последовательность]
```

Для каждого **элемент**а из **последовательности** вычисляется **выражение**, и результат попадает в новый список. Эквивалентный цикл:

```python
result = []
for элемент in последовательность:
    result.append(выражение)
```

Примеры:

```python
squares = [x ** 2 for x in range(5)]        # [0, 1, 4, 9, 16]
lengths = [len(s) for s in ["a", "bb", "ccc"]]  # [1, 2, 3]
```

Опционально в конце можно добавить **if условие** — в список попадут только те элементы, для которых условие истинно:

```python
[выражение for элемент in последовательность if условие]
```

Пример:

```python
evens = [x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]
```

Условие может использовать переменную цикла и внешние переменные. Порядок чтения: сначала **for**, затем **if** (если есть), затем **выражение** — «для каждого элемента из последовательности, если условие выполняется, добавить выражение в список».

---

## 5.5.2. Несколько циклов и вложенные включения

В одном list comprehension можно указать **несколько for** подряд — они работают как вложенные циклы: для каждого значения первого цикла выполняется полный проход по второму:

```python
[(i, j) for i in range(2) for j in range(2)]
# [(0, 0), (0, 1), (1, 0), (1, 1)]
```

Условие **if** может относиться к последнему циклу или ко всем переменным. Пример: пары, где первый элемент меньше второго:

```python
[(i, j) for i in range(3) for j in range(3) if i < j]
# [(0, 1), (0, 2), (1, 2)]
```

При большом числе вложенных циклов и условий читаемость падает; тогда часто предпочтительнее обычный цикл for с append. Comprehension удобен для одного-двух уровней и простых выражений.

---

## 5.5.3. Dict comprehension и set comprehension

Та же идея — «выражение для каждого элемента с опциональным if» — применяется к **словарю** и **множеству**.

**Dict comprehension:** в фигурных скобках пара **ключ: значение** и цикл (и при необходимости if):

```python
{x: x ** 2 for x in range(5)}   # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

Пример из двух списков (ключи и значения):

```python
keys = ["a", "b", "c"]
values = [1, 2, 3]
d = {k: v for k, v in zip(keys, values)}   # {'a': 1, 'b': 2, 'c': 3}
```

**Set comprehension:** фигурные скобки и выражение без двоеточия — получается множество (уникальные значения):

```python
{x % 3 for x in range(10)}   # {0, 1, 2}
{len(w) for w in ["a", "bb", "a"]}   # {1, 2}
```

Кортежи list/dict/set comprehension не создают «tuple comprehension» — скобки **(x for x in ...)** дают **генератор** (generator), а не кортеж; кортеж из генератора получают **tuple(...)**. Генераторы рассматриваются в продвинутых курсах; здесь достаточно знать, что для списка, словаря и множества есть свой синтаксис включений.

---

## 5.5.4. Когда использовать и читаемость

Comprehensions удобны, когда нужно за один проход **построить список (словарь, множество)** по простому правилу: преобразовать элементы, отфильтровать по условию или скомбинировать несколько циклов в одну короткую конструкцию. В коде обработки данных они часто встречаются при подготовке списков для циклов, при построении словарей-счётчиков или множеств уникальных значений.

При сложной логике (много условий, вложенность, длинные выражения) обычный цикл for с append/update читается проще. Не стоит вкладывать три и более for или писать длинные однострочники в ущерб понятности.

---

## 5.5.5. Типичные ошибки

- **Забыть скобки вокруг пары в dict comprehension:** нужно **{k: v for ...}**, а не **{k, v for ...}** (во втором случае получится set comprehension с кортежами).
- **Путать порядок for и if:** сначала все for (слева направо), затем if, затем выражение. Условие **if** после **for** фильтрует элементы; условие в стиле тернарного выражения в начале — **expr1 if cond else expr2** — допустимо в части «выражение».
- **Использовать comprehension только ради побочного эффекта** (например, печать или вызов функции без использования результата) — технически возможно, но стилистически нежелательно; для побочных эффектов используют обычный цикл for.

---

## Ключевое

- **List comprehension:** **[выражение for x in последовательность]** или с фильтром **[выражение for x in последовательность if условие]** — создаёт список за один проход.
- **Несколько for** подряд — вложенные циклы; **if** фильтрует элементы. Не усложнять: при длинных или многоуровневых конструкциях предпочтительнее обычный цикл.
- **Dict comprehension:** **{ключ: значение for ...}**; **set comprehension:** **{выражение for ...}** (без двоеточия). Кортежа comprehension нет; **(x for x in ...)** — генератор.
- Использовать для простого построения списка/словаря/множества по правилу; не злоупотреблять вложенностью и длинными выражениями.
