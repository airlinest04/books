# §7.2 Индексация и срезы

В [§7.1](chapter-07-01.md) мы разобрали создание массивов NumPy. Теперь — **доступ к элементам**: один индекс, срезы и многомерная индексация **[i, j]**, а также **булева маска** (выборка по условию). В [§7.3](chapter-07-03.md) перейдём к арифметическим операциям и агрегатам.

---

## 7.2.1. Одномерный массив: индекс и срез

Как и у списка ([§5.1](chapter-05-01.md)), у одномерного массива доступны обращение по **индексу** и **срез**.

**Один элемент:** **arr[i]** — элемент с индексом i (с нуля). Отрицательный индекс — с конца: **arr[-1]** — последний элемент.

**Срез:** **arr[start:stop:step]** — подмассив от start до stop (stop не входит) с шагом step. Правила те же, что для списков и строк ([§2.4](chapter-02-04.md)):

```python
import numpy as np
a = np.array([10, 20, 30, 40, 50])
a[0]      # 10
a[-1]     # 50
a[1:4]    # array([20, 30, 40])
a[::2]    # array([10, 30, 50])
```

Результат среза — массив NumPy (подмассив), а не список.

---

## 7.2.2. Многомерные массивы: [i, j] и срезы по осям

У двумерного массива (матрицы) **первый индекс** — строка, **второй** — столбец. Индексация с нуля.

**Один элемент:** **arr[i, j]** — элемент в строке i и столбце j. Запись **arr[i][j]** тоже допустима, но **arr[i, j]** короче и привычнее в NumPy.

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])
m[0, 0]   # 1
m[1, 2]   # 6
```

**Срез по осям:** для каждой оси можно указать индекс (одно число) или срез (start:stop:step). Срез **:** означает «все элементы по этой оси».

**Вся строка i:** **arr[i, :]** или **arr[i]** — строка как одномерный массив.

**Весь столбец j:** **arr[:, j]** — столбец как одномерный массив.

**Подматрица:** **arr[i1:i2, j1:j2]** — прямоугольный фрагмент (строки от i1 до i2-1, столбцы от j1 до j2-1).

```python
m[0, :]    # array([1, 2, 3])  — первая строка
m[:, 1]    # array([2, 5])      — второй столбец
m[0:2, 1:3]  # array([[2, 3], [5, 6]])  — подматрица 2×2
```

Для массивов размерности три и выше индексация обобщается: **arr[i, j, k]** и срезы по каждой оси.

---

## 7.2.3. Срез — это вид (view)

В NumPy срез многомерного массива по умолчанию возвращает **вид (view)** — новый массив, который разделяет данные с исходным. Изменение элементов в срезе **меняет** исходный массив:

```python
a = np.array([1, 2, 3, 4, 5])
b = a[1:4]
b[0] = 100
print(a)   # [  1 100   3   4   5]
```

Чтобы получить **независимую копию**, используют метод **.copy()**:

```python
c = a[1:4].copy()
c[0] = 0   # a не изменится
```

При присваивании в срез (**arr[1:4] = ...**) значения записываются в исходный массив; это ожидаемое поведение при обработке данных (обновление части массива).

## 7.2.4. Булева маска (выборка по условию)

В качестве индекса можно передать **массив булевых значений** той же формы (или совместимой по форме): в результат попадут только те элементы, для которых значение индекса **True**. Такой приём называют **булевой маской** (boolean indexing).

Условие над массивом возвращает массив булевых значений:

```python
a = np.array([1, 5, 3, 8, 2])
a > 3   # array([False,  True, False,  True, False])
```

Подстановка этого массива в индексацию даёт одномерный массив из элементов, удовлетворяющих условию:

```python
a[a > 3]   # array([5, 8])
a[a <= 2]  # array([1, 2])
```

**Присваивание по маске** — заменить только те элементы, где условие истинно:

```python
a[a < 4] = 0
# a станет array([0, 5, 0, 8, 0])
```

Для двумерного массива маска той же формы (2D) даёт одномерный результат — выбранные элементы в порядке обхода по строкам:

```python
m = np.array([[1, 2], [3, 4]])
m[m > 2]   # array([3, 4])
```

Комбинировать условия можно через **&** (И), **|** (ИЛИ), **~** (НЕ); скобки обязательны из-за приоритета операторов: **(arr > 2) & (arr < 5)**.

---

## 7.2.5. Типичные ошибки

- **Выход за границы** — индекс вне диапазона даёт **IndexError**. Для среза границы за пределами массива обрезаются (как у списков), ошибки нет.
- **Путать строку и столбец** — в соглашении NumPy первый индекс — строка, второй — столбец; **arr[i, :]** — строка, **arr[:, j]** — столбец.
- **Изменение среза меняет исходный массив** — если нужна независимая копия, вызывать **.copy()**.
- **Булева маска:** форма маски должна быть совместима с массивом (для поэлементного выбора — та же shape или транслируемая). Разная длина массива и маски даёт ошибку.

---

## Ключевое

- **Одномерный массив:** **arr[i]**, **arr[start:stop:step]** — как у списка. Отрицательные индексы — с конца.
- **Двумерный:** **arr[i, j]** — элемент; **arr[i, :]** или **arr[i]** — строка; **arr[:, j]** — столбец; **arr[i1:i2, j1:j2]** — подматрица.
- **Срез** — по умолчанию вид (view); изменение среза меняет исходный массив. Копия — **arr[...].copy()**.
- **Булева маска:** **arr[условие]** — массив из элементов, где условие истинно; условие — массив bool той же (или совместимой) формы. Присваивание **arr[условие] = значение**. Комбинации условий: **(cond1) & (cond2)**, **|**, **~**.
