# §3.4 Тернарное выражение

В [§3.3](chapter-03-03.md) мы разобрали цикл while, break и continue. Завершаем главу об управляющих конструкциях **тернарным выражением** — компактной записью выбора одного из двух значений в зависимости от условия. Оно не заменяет полноценный if/else с несколькими инструкциями, но удобно при присваивании, в return и при передаче аргументов. В [§4.1](chapter-04-01.md) мы перейдём к определению функций.

---

## 3.4.1. Синтаксис: значение_если_истина if условие else значение_если_ложь

**Тернарное выражение** (условное выражение) в Python записывается так:

```python
значение_при_истине if условие else значение_при_ложи
```

Сначала вычисляется **условие**. Если оно истинно, результатом всего выражения становится **значение_при_истине**; если ложно — **значение_при_ложи**. Вычисляется только одна из двух веток (как в обычном if/else).

Пример:

```python
x = 10
label = "положительное" if x > 0 else "не положительное"
# label будет "положительное"
```

То же через обычный if:

```python
if x > 0:
    label = "положительное"
else:
    label = "не положительное"
```

Тернарная форма короче, когда нужно лишь выбрать одно из двух значений и присвоить его переменной или вернуть.

---

## 3.4.2. Где использовать тернарное выражение

**Присваивание** — выбор значения при инициализации или обновлении переменной:

```python
max_val = a if a > b else b
status = "OK" if error_count == 0 else "ошибки"
```

**return в функции** — возврат одного из двух значений в зависимости от условия:

```python
def abs_value(n):
    return n if n >= 0 else -n
```

**Аргумент при вызове функции** — передача разного значения в зависимости от контекста:

```python
step = 1 if direction == "forward" else -1
process(step)
```

**В списках и других выражениях** — при формировании структур данных (подробнее о списках в [§5.1](chapter-05-01.md), о list comprehensions в [§5.5](chapter-05-05.md)):

```python
labels = ["чётное" if x % 2 == 0 else "нечётное" for x in [1, 2, 3]]
# ['нечётное', 'чётное', 'нечётное']
```

Когда логика сложнее (несколько веток, несколько инструкций в каждой, вложенные условия), лучше писать обычный if/elif/else — читаемость важнее краткости.

---

## 3.4.3. Вложенность и читаемость

Тернарное выражение можно вкладывать в другое тернарное (вместо elif), но это быстро ухудшает читаемость:

```python
# работает, но трудно читать
x = "a" if n == 1 else "b" if n == 2 else "c"
```

Для нескольких вариантов предпочтительнее цепочка if/elif/else или словарь соответствий. Один уровень «условие — два варианта» — норма; вложенные тернарные лучше не использовать без крайней необходимости.

При длинных выражениях в ветках тернарное выражение можно разнести по строкам (скобки или продолжение строки), но если оно не помещается в одну строку, часто проще взять обычный if/else.

---

## 3.4.4. Типичные ошибки

- **Перепутать порядок веток:** в Python сначала идёт значение при истинном условии, затем условие, затем else и значение при ложном. В других языках порядок бывает иной (условие ? истина : ложь); здесь запомнить формулу: **«что если да» if условие else «что если нет»**.

- **Подставить в ветки вызовы с побочными эффектами:** технически допустимо, но путает: в тернарном выражении ожидают выбор значения, а не выполнение действий. Действия (print, изменение глобального состояния) лучше выносить в обычный if/else.

- **Пытаться вставить elif:** в тернарном выражении есть только одна проверка и два исхода. Для трёх и более вариантов — вложенное тернарное (не рекомендуется) или обычный if/elif/else.

---

## Ключевое

- **Тернарное выражение:** `значение_если_истина if условие else значение_если_ложь` — выражение, результат которого одно из двух значений в зависимости от условия. Вычисляется только выбранная ветка.
- Удобно при присваивании, в return, в аргументах вызова и при формировании списков/выражений, когда нужен простой выбор из двух вариантов.
- Вложенные тернарные ухудшают читаемость; для нескольких вариантов лучше if/elif/else. Порядок в Python: сначала «истинная» ветка, потом условие, потом else и «ложная» ветка.
