# §9.2 Дубликаты

В [§9.1](chapter-09-01.md) мы разобрали пропуски: .isna(), .dropna(), .fillna(). Ещё одна типичная задача очистки — **дубликаты строк**: одинаковые или повторяющиеся по ключевым полям записи. В этом разделе: **обнаружение** дубликатов (**.duplicated()**) и **удаление** (**.drop_duplicates()**), в том числе по **подмножеству столбцов** и с выбором, какую копию оставить (первую, последнюю или все помечать как дубликаты). В [§9.3](chapter-09-03.md) перейдём к преобразованию типов (.astype(), pd.to_datetime()).

---

## 9.2.1. .duplicated()

**df.duplicated()** — возвращает **Series** булевых значений (по одной на строку): **True** для строк, которые считаются дубликатами предыдущих, **False** для уникальных. По умолчанию дубликатом считается строка, у которой **все** значения совпадают с какой-то **ранее встреченной** строкой; первое вхождение помечается как False (уникальное).

Параметры:

- **subset** — список имён столбцов; сравнение только по этим столбцам. Остальные столбцы не учитываются. Например, **duplicated(subset=['id'])** — дубликат по полю id.
- **keep** — какую строку считать «первой» и не помечать дубликатом:
  - **keep='first'** (по умолчанию) — первое вхождение уникально, остальные дубликаты;
  - **keep='last'** — последнее вхождение уникально;
  - **keep=False** — все строки с повторяющимся набором значений помечаются как дубликаты (в результате можно оставить только строки, встречающиеся ровно один раз).

Фильтрация: **df[~df.duplicated()]** — оставить только «первые» вхождения (убрать дубликаты, оставив по одному представителю каждой группы).

```python
import pandas as pd
df = pd.DataFrame({"a": [1, 2, 1, 2], "b": [10, 20, 10, 30]})
df.duplicated()           # False, False, True, False (третья = первая по a,b)
df.duplicated(subset=["a"])  # False, False, True, True (дубликаты по a)
df.duplicated(keep="last")   # первое вхождение помечается дубликатом, последнее — нет
df[~df.duplicated()]       # таблица без дубликатов (оставлены первые вхождения)
```

## 9.2.2. .drop_duplicates()

**df.drop_duplicates(subset=None, keep='first', inplace=False)** — возвращает **DataFrame** без дубликатов (или None при inplace=True). Логика совпадает с .duplicated(): по умолчанию сравниваются **все** столбцы, оставляется **первое** вхождение каждой комбинации.

- **subset** — список столбцов, по которым определять дубликаты. Удобно, когда уникальность должна быть только по ключу (например, по id или по (date, user_id)).
- **keep** — 'first' (по умолчанию), 'last' или False. При keep=False удаляются **все** строки, у которых есть дубликат по subset (остаются только строки с уникальным значением ключа).
- **inplace** — при True исходный DataFrame изменяется, метод возвращает None.

После drop_duplicates индексы строк сохраняются; при необходимости сбросить индекс можно вызвать **df.reset_index(drop=True)**.

```python
df.drop_duplicates()                  # убрать полные дубликаты, оставить первые
df.drop_duplicates(subset=["a"])      # по столбцу a — одна строка на каждое значение a
df.drop_duplicates(subset=["a"], keep="last")  # оставить последнее вхождение по a
df.drop_duplicates(subset=["a"], keep=False)   # оставить только строки с уникальным a
```

## 9.2.3. Подмножество столбцов и порядок строк

Часто дубликаты определяют не по всей строке, а по **ключу**: идентификатор, дата+пользователь и т.п. Тогда **subset=['id']** или **subset=['date', 'user_id']** задаёт, по каким столбцам сравнивать. Строки с одинаковыми значениями в subset считаются дубликатами; какая из них остаётся — задаётся **keep**.

Если данные упорядочены по времени, **keep='last'** по ключу часто оставляет актуальную запись (последнее обновление). **keep='first'** — первую встреченную. **keep=False** полезен, когда нужно оставить только строки с **уникальным** ключом и отбросить все повторения (в том числе одиночные дубликаты).

Проверка числа дубликатов перед удалением: **df.duplicated(subset=...).sum()** — сколько строк помечено как дубликаты; **df.drop_duplicates(subset=...).shape** — размер таблицы после удаления.

---

## Ключевое

- **.duplicated()** — булева Series: True для строк-дубликатов (по умолчанию по всем столбцам, первое вхождение — не дубликат).
- **subset** — список столбцов для сравнения; дубликаты определяются только по ним.
- **keep** — 'first' (оставить первое), 'last' (оставить последнее), False (оставить только строки с уникальным ключом, все дубликаты удалить).
- **.drop_duplicates(subset=..., keep=...)** — удаление дубликатов; те же параметры subset и keep; inplace по необходимости.
