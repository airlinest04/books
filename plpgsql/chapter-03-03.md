# §3.3 Цикл LOOP

В [§3.2](chapter-03-02.md) мы разобрали оператор CASE. В этом разделе рассмотрим **цикл LOOP** — безусловный цикл, который повторяется до тех пор, пока не выполнится **EXIT** или **RETURN**. Разберём синтаксис LOOP ... END LOOP, выход по условию (**EXIT WHEN**) и безусловный **EXIT**, приведём примеры. Циклы с условием (WHILE) и с перечислением (FOR) — в [§3.4](chapter-03-04.md); метки циклов и EXIT/CONTINUE с меткой — в [§3.5](chapter-03-05.md). См. [Глоссарий](glossary.md).

---

## 3.3.1. Синтаксис LOOP ... END LOOP

**LOOP** задаёт безусловный цикл: операторы между LOOP и END LOOP выполняются снова и снова, пока управление не передастся наружу оператором **EXIT** или **RETURN** (или пока не возникнет ошибка). Синтаксис (по документации PostgreSQL):

```
[ <<метка>> ]
LOOP
  операторы
END LOOP [ метка ];
```

Метка необязательна; она нужна для выхода из вложенных циклов по имени (EXIT метка) и для CONTINUE (см. §3.5). Без EXIT или RETURN цикл будет выполняться бесконечно. См. [Глоссарий](glossary.md).

Пример минимального цикла с выходом:

```sql
LOOP
  -- что-то делаем
  EXIT WHEN done;   -- выход при истинном условии done
END LOOP;
```

---

## 3.3.2. EXIT и EXIT WHEN

**EXIT** завершает цикл и передаёт управление первому оператору после END LOOP. Две формы:

- **EXIT;** — безусловный выход из **внутреннего** цикла (при вложенных циклах выходит только из того, в котором стоит EXIT).
- **EXIT WHEN логическое_выражение;** — выход только если выражение истинно; иначе выполнение продолжается со следующей итерации. Эквивалент: `IF логическое_выражение THEN EXIT; END IF;`

С опциональной **меткой**: **EXIT метка;** или **EXIT метка WHEN условие;** — выход из цикла (или блока BEGIN) с указанной меткой; используется при вложенных циклах (подробнее §3.5). См. [Глоссарий](glossary.md).

Примеры (по документации PostgreSQL):

```sql
LOOP
  -- вычисления
  IF count > 0 THEN
    EXIT;
  END IF;
END LOOP;

LOOP
  -- вычисления
  EXIT WHEN count > 0;   -- тот же эффект
END LOOP;
```

Условие в EXIT WHEN вычисляется при каждом выполнении EXIT; как только оно становится истинным, цикл завершается.

---

## 3.3.3. Типичный шаблон: цикл с условием выхода

Часто простой LOOP используют, когда условие выхода проверяется **в середине** тела цикла или зависит от нескольких мест. Счётчик или флаг обновляются в теле, а EXIT WHEN проверяет их. См. [Глоссарий](glossary.md).

Пример: повтор до достижения лимита или флага:

```sql
DECLARE
  counter integer := 0;
  max_iter constant integer := 100;
BEGIN
  LOOP
    counter := counter + 1;
    -- какая-то работа
    EXIT WHEN counter >= max_iter;
    -- или выход по другому условию, например:
    -- EXIT WHEN result_found;
  END LOOP;
  RAISE NOTICE 'Выполнено итераций: %', counter;
END;
```

Если условие выхода естественно проверять **в начале** каждой итерации, удобнее цикл **WHILE** (§3.4). Если нужно перебрать диапазон целых или строки запроса — **FOR** (§3.4).

---

## 3.3.4. Метка цикла (кратко)

Перед LOOP можно указать метку: `<<имя>>`. Та же метка может быть указана после END LOOP. Метка нужна, чтобы из вложенного цикла или из вложенного блока выйти сразу во внешний цикл: **EXIT имя_метки;** или **EXIT имя_метки WHEN условие;**. Без метки EXIT выходит только из самого внутреннего цикла. Подробнее и примеры с вложенными циклами — в [§3.5](chapter-03-05.md). См. [Глоссарий](glossary.md).

---

## 3.3.5. Когда использовать простой LOOP

- **LOOP + EXIT WHEN** уместен, когда условие выхода проверяется в середине итерации или в нескольких местах, либо когда логика выхода сложная.
- **WHILE условие LOOP** (§3.4) удобнее, когда проверка одна и выполняется в начале каждой итерации.
- **FOR** (§3.4) — когда нужно перебрать диапазон целых (1..10) или строки результата запроса (FOR rec IN SELECT ...).

Простой LOOP даёт максимальную гибкость, но при «цикле по счётчику» или «по строкам запроса» FOR обычно короче и нагляднее.

---

## Ключевое

- **LOOP ... END LOOP** — безусловный цикл; выход только через EXIT или RETURN (или ошибку).
- **EXIT;** — немедленный выход из текущего (внутреннего) цикла; **EXIT WHEN условие;** — выход при истинном условии.
- **EXIT метка** (и EXIT метка WHEN) — выход из цикла с заданной меткой (при вложенных циклах); подробнее §3.5.
- Типичный шаблон: в теле цикла обновлять переменные и вызывать EXIT WHEN при достижении цели или лимита.
- Выбор между LOOP, WHILE и FOR зависит от того, где проверяется условие и перебирается ли явно диапазон или набор строк.

В [§3.4](chapter-03-04.md) мы разберём циклы WHILE и FOR (по диапазону и по запросу).
