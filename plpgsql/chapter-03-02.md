# §3.2 CASE

В [§3.1](chapter-03-01.md) мы разобрали ветвление с помощью IF. В этом разделе рассмотрим **CASE** — выбор одной из веток по значению (простой CASE) или по условию (CASE с поиском), а также использование CASE как **выражения** (возврат значения) в присваиваниях и запросах. В PL/pgSQL CASE может быть **оператором** (управление потоком выполнения) и **выражением** (результат подставляется в формулу или запрос). Цикл LOOP — в [§3.3](chapter-03-03.md). См. [Глоссарий](glossary.md).

---

## 3.2.1. Простой CASE — выбор по значению

**Простой CASE** сравнивает одно выражение с рядом значений; при первом совпадении выполняется соответствующий блок операторов. Синтаксис (по документации PostgreSQL):

```
CASE выражение_поиска
  WHEN значение [, значение ...] THEN
    операторы
  [ WHEN значение [, значение ...] THEN
    операторы
    ... ]
  [ ELSE
    операторы ]
END CASE;
```

**Выражение_поиска** вычисляется один раз; результат поочерёдно сравнивается с выражениями в каждом WHEN (через равенство). В одном WHEN можно перечислить несколько значений через запятую — при совпадении с любым из них выполняется эта ветка. Если совпадений нет и указан ELSE — выполняется блок ELSE; если ELSE нет — возникает исключение **CASE_NOT_FOUND**. См. [Глоссарий](glossary.md).

Пример:

```sql
CASE x
  WHEN 1, 2 THEN
    msg := 'один или два';
  WHEN 3 THEN
    msg := 'три';
  ELSE
    msg := 'другое значение';
END CASE;
```

Сравнение с NULL в WHEN не сработает (в SQL NULL = NULL даёт NULL), поэтому для проверки на NULL используйте форму CASE по условию (см. ниже) или отдельную ветку с проверкой IS NULL.

---

## 3.2.2. CASE по условию (CASE с поиском)

**CASE по условию** (в документации — searched CASE, «CASE с поиском») не использует одно выражение для сравнения; в каждом WHEN задаётся **логическое выражение**. Выполняется блок первого WHEN, чьё условие истинно. Синтаксис:

```
CASE
  WHEN логическое_выражение THEN
    операторы
  [ WHEN логическое_выражение THEN
    операторы
    ... ]
  [ ELSE
    операторы ]
END CASE;
```

Условия проверяются по порядку; при первом истинном выполняется соответствующий блок и управление переходит после END CASE. Если ни одно условие не истинно и есть ELSE — выполняется ELSE; если ELSE нет — возникает **CASE_NOT_FOUND**. Эта форма эквивалентна IF ... ELSIF ... ELSE с тем отличием, что при отсутствии истинного условия и отсутствии ELSE выдаётся ошибка, а не просто выход. См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL):

```sql
CASE
  WHEN x BETWEEN 0 AND 10 THEN
    msg := 'от нуля до десяти';
  WHEN x BETWEEN 11 AND 20 THEN
    msg := 'от одиннадцати до двадцати';
  ELSE
    msg := 'вне диапазонов';
END CASE;
```

Удобно для проверок на NULL, диапазонов и сложных условий.

---

## 3.2.3. ELSE и исключение CASE_NOT_FOUND

В обеих формах **ELSE** необязателен. Если ни одна ветка WHEN не выбрана (в простом CASE — нет совпадения по значению, в CASE по условию — ни одно условие не истинно) и **ELSE нет**, PL/pgSQL возбуждает исключение **CASE_NOT_FOUND**. Его можно перехватить в блоке EXCEPTION (гл. 4). См. [Глоссарий](glossary.md).

Рекомендация: если по смыслу возможны значения или ситуации, не попавшие ни в один WHEN, либо добавьте ELSE с явной обработкой (например, присваивание по умолчанию или RAISE), либо обрабатывайте CASE_NOT_FOUND в EXCEPTION. Иначе неожиданное значение приведёт к остановке выполнения.

## 3.2.4. CASE как выражение

Кроме оператора CASE (который выполняет один из блоков операторов) в PL/pgSQL и в SQL используется **CASE как выражение**: оно возвращает одно значение и подставляется в присваивание, в SELECT, в другой формуле. Синтаксис такой же, но после THEN и ELSE стоят **выражения** (а не операторы), и вся конструкция даёт значение. В операторе присваивания или в запросе это обычное SQL-выражение. См. [Глоссарий](glossary.md).

Пример в присваивании:

```sql
msg := CASE x
  WHEN 1 THEN 'один'
  WHEN 2 THEN 'два'
  ELSE 'другое'
END;
```

Пример в запросе (фрагмент SELECT):

```sql
SELECT id,
  CASE WHEN status = 'A' THEN 'Активен'
       WHEN status = 'I' THEN 'Неактивен'
       ELSE 'Неизвестно'
  END AS status_text
FROM users;
```

В выражении после THEN и ELSE не может быть операторов (например, присваиваний) — только выражения, возвращающие значение. Точка с запятой после END не ставится, если CASE является частью другого оператора.

---

## 3.2.5. CASE и IF: когда что использовать

- **IF** удобен для одной или двух веток и для сложной логики (несколько операторов в каждой ветке, вложенные проверки).
- **Простой CASE** — когда нужно сопоставить одно значение с набором вариантов (коды, перечисления); запись короче, чем цепочка ELSIF с равенствами.
- **CASE по условию** — когда условия разные (диапазоны, IS NULL, сложные выражения); семантически близок к IF ... ELSIF, но при отсутствии подходящей ветки и ELSE даёт CASE_NOT_FOUND.
- **CASE как выражение** — когда нужно получить одно значение в зависимости от условия (присваивание, RETURN, SELECT); альтернатива цепочке IF/ELSIF с присваиваниями в каждую ветку.

---

## Ключевое

- **Простой CASE** — одно выражение сравнивается с значениями в WHEN; при совпадении выполняется соответствующий блок операторов; при необходимости — ELSE.
- **CASE по условию** — в каждом WHEN логическое выражение; выполняется блок первого истинного WHEN; при отсутствии истинного и отсутствии ELSE — CASE_NOT_FOUND.
- Без **ELSE** и без подходящей ветки возникает исключение **CASE_NOT_FOUND**.
- **CASE как выражение** возвращает значение (THEN и ELSE — выражения) и используется в присваиваниях, RETURN, SELECT.
- Выбор между IF, простым CASE, CASE по условию и CASE-выражением зависит от числа веток, типа условий и того, нужен ли возврат одного значения.

В [§3.3](chapter-03-03.md) мы разберём цикл LOOP и выход из него (EXIT WHEN).
