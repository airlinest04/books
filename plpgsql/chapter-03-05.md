# §3.5 CONTINUE и вложенные циклы

В [§3.4](chapter-03-04.md) мы разобрали циклы WHILE и FOR. В этом разделе рассмотрим **CONTINUE** — переход к следующей итерации цикла — и использование **меток** при **вложенных циклах**: как с помощью EXIT и CONTINUE с меткой выходить из внешнего цикла или переходить к следующей итерации внешнего цикла из внутреннего. Затронем также EXIT из блока BEGIN с меткой. Обработка исключений (EXCEPTION) — с гл. 4. См. [Глоссарий](glossary.md).

---

## 3.5.1. CONTINUE и CONTINUE WHEN

**CONTINUE** прерывает текущую итерацию цикла и передаёт управление **началу следующей** итерации: операторы до конца тела цикла пропускаются, управление переходит к проверке условия (WHILE, FOR) или к следующему шагу перебора. Без метки действует на **внутренний** цикл (при вложенных циклах). Синтаксис (по документации PostgreSQL):

```
CONTINUE [ метка ] [ WHEN логическое_выражение ];
```

**CONTINUE WHEN условие** — переход к следующей итерации только если условие истинно; иначе выполнение продолжается со следующего оператора после CONTINUE. Эквивалент: `IF условие THEN CONTINUE; END IF;` См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL):

```sql
LOOP
  -- вычисления
  EXIT WHEN count > 100;
  CONTINUE WHEN count < 50;
  -- операторы для count в диапазоне [50 .. 100]
END LOOP;
```

CONTINUE применим ко всем типам циклов (LOOP, WHILE, FOR).

---

## 3.5.2. CONTINUE с меткой

Если указана **метка**, CONTINUE переходит к следующей итерации цикла с этой меткой, а не внутреннего. Это нужно при **вложенных циклах**: из внутреннего цикла можно перейти к следующей итерации внешнего, пропуская оставшиеся итерации внутреннего. См. [Глоссарий](glossary.md).

Пример: при определённом условии во внутреннем цикле сразу переходим к следующей итерации внешнего:

```sql
<<outer>>
FOR i IN 1..10 LOOP
  <<inner>>
  FOR j IN 1..10 LOOP
    IF some_condition(i, j) THEN
      CONTINUE outer;   -- следующая пара (i, j), внутренний цикл по j прерывается
    END IF;
    -- работа с (i, j)
  END LOOP;
END LOOP;
```

Без метки `CONTINUE` перевело бы только на следующую итерацию внутреннего цикла (по j).

## 3.5.3. Вложенные циклы и EXIT с меткой

При **вложенных циклах** безымянный **EXIT** выходит только из того цикла, в теле которого он записан (из внутреннего). Чтобы выйти сразу из внешнего цикла, у внешнего цикла задают **метку** и используют **EXIT метка** или **EXIT метка WHEN условие**. См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL, адаптировано):

```sql
<<outer>>
LOOP
  -- вычисления во внешнем цикле
  <<inner>>
  LOOP
    -- при выполнении условия выходим из обоих циклов
    EXIT outer WHEN done;
    EXIT WHEN inner_done;   -- выход только из внутреннего
  END LOOP;
END LOOP;
-- сюда управление попадёт после EXIT outer или после нормального завершения внешнего цикла
```

Метка после END LOOP должна совпадать с меткой перед соответствующим LOOP/WHILE/FOR.

---

## 3.5.4. EXIT из блока BEGIN с меткой

**EXIT** с меткой может указывать не только на цикл, но и на **блок BEGIN ... END** с той же меткой. Тогда управление передаётся первому оператору после этого блока (блок прерывается, как при выходе из цикла). Важно: безымянный **EXIT** в PL/pgSQL **не** связывается с блоком BEGIN — только с циклом. Поэтому для выхода из блока BEGIN обязательно использовать **EXIT метка_блока**. См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL):

```sql
<<ablock>>
BEGIN
  -- вычисления
  IF stocks > 100000 THEN
    EXIT ablock;   -- выход из блока, выполнение продолжается после END
  END IF;
  -- эти операторы не выполнятся, если был EXIT ablock
END;
```

Такой приём удобен, когда нужно раньше времени закончить последовательность операторов внутри блока без введения дополнительного цикла.

---

## Ключевое

- **CONTINUE** — переход к следующей итерации текущего (внутреннего) цикла; **CONTINUE WHEN условие** — только при истинном условии.
- **CONTINUE метка** — переход к следующей итерации цикла с указанной меткой; используется во вложенных циклах.
- При вложенных циклах **EXIT метка** и **EXIT метка WHEN условие** выходят из цикла с этой меткой (в том числе из внешнего).
- **EXIT метка** может указывать на блок **BEGIN ... END** с той же меткой; безымянный EXIT с блоком BEGIN не связывается.

В [§4.1](chapter-04-01.md) мы перейдём к обработке исключений: блок EXCEPTION и переход управления при ошибке.
