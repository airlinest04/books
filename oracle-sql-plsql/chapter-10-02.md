# §10.2 CASE

В [§10.1](chapter-10-01.md) мы разобрали условный оператор IF. **CASE** в PL/SQL — ещё одна форма ветвления: выбор одной из веток по значению выражения (**простой CASE**) или по набору условий (**поисковый CASE**, CASE WHEN). Синтаксис похож на CASE в SQL, но в PL/SQL это оператор с операторами в ветках, а не выражение (хотя в SQL CASE возвращает значение). В этом разделе — оба варианта CASE в PL/SQL и обязательный **END CASE**. Циклы — в [§10.3](chapter-10-03.md). См. [Глоссарий](glossary.md).

---

## 10.2.1. Простой CASE: выбор по значению выражения

**Простой CASE** сравнивает одно выражение с перечисленными значениями и выполняет ветку при первом совпадении. См. [Глоссарий](glossary.md).

Синтаксис:

```plsql
CASE выражение
  WHEN значение1 THEN операторы;
  WHEN значение2 THEN операторы;
  ...
  [ELSE операторы;]
END CASE;
```

**выражение** вычисляется один раз; результат поочерёдно сравнивается с значение1, значение2, ... (через равенство). При первом совпадении выполняется соответствующий блок операторов; затем управление переходит за END CASE. Если совпадений нет, выполняется **ELSE** (если указан); без ELSE при отсутствии совпадения Oracle возбуждает исключение **CASE_NOT_FOUND**. После каждой ветки — точка с запятой; **END CASE** с точкой с запятой обязателен. См. [Глоссарий](glossary.md).

Пример: действие по коду статуса:

```plsql
DECLARE
  v_status   VARCHAR2(10) := 'ACTIVE';
BEGIN
  CASE v_status
    WHEN 'NEW' THEN
      DBMS_OUTPUT.PUT_LINE('Обработка нового');
    WHEN 'ACTIVE' THEN
      DBMS_OUTPUT.PUT_LINE('Активный');
    WHEN 'CLOSED' THEN
      DBMS_OUTPUT.PUT_LINE('Закрыт');
    ELSE
      DBMS_OUTPUT.PUT_LINE('Неизвестный статус');
  END CASE;
END;
/
```

Выведется «Активный». Среда: Oracle PL/SQL.

## 10.2.2. Поисковый CASE (CASE WHEN): выбор по условиям

**Поисковый CASE** (searched CASE) не использует одно общее выражение: в каждой ветке задаётся **отдельное условие** (логическое выражение). Выполняется первая ветка, условие которой истинно. См. [Глоссарий](glossary.md).

Синтаксис:

```plsql
CASE
  WHEN условие1 THEN операторы;
  WHEN условие2 THEN операторы;
  ...
  [ELSE операторы;]
END CASE;
```

Удобно, когда ветки зависят от разных переменных или сложных выражений (диапазоны, комбинации). Пример: категория по баллу и флагу:

```plsql
DECLARE
  v_score   NUMBER := 85;
  v_bonus   BOOLEAN := TRUE;
BEGIN
  CASE
    WHEN v_score >= 90 THEN
      DBMS_OUTPUT.PUT_LINE('Отлично');
    WHEN v_score >= 70 AND v_bonus THEN
      DBMS_OUTPUT.PUT_LINE('Хорошо с бонусом');
    WHEN v_score >= 70 THEN
      DBMS_OUTPUT.PUT_LINE('Хорошо');
    ELSE
      DBMS_OUTPUT.PUT_LINE('Иначе');
  END CASE;
END;
/
```

Здесь при v_score = 85 и v_bonus = TRUE выполнится вторая ветка. См. [Глоссарий](glossary.md).

## 10.2.3. CASE_NOT_FOUND и рекомендации

Если ни одно WHEN не сработало и ветка **ELSE** не задана, в PL/SQL возбуждается предопределённое исключение **CASE_NOT_FOUND**. Чтобы избежать падения при неожиданных значениях, обычно добавляют **ELSE** с обработкой по умолчанию или явно перехватывают CASE_NOT_FOUND в EXCEPTION. См. [Глоссарий](glossary.md).

CASE уместен, когда веток много и они проверяют одно выражение на равенство (простой CASE) или набор независимых условий (искажённый CASE). Для двух-трёх веток IF/ELSIF часто читается проще. Не путайте **оператор CASE** в PL/SQL (с операторами в ветках, END CASE;) с **выражением CASE** в SQL (CASE ... END в SELECT, возвращает значение).

---

## Ключевое

- **CASE** в PL/SQL — оператор ветвления. **Простой CASE**: CASE выражение WHEN значение THEN ... [ELSE ...] END CASE; сравнение по равенству. **Поисковый CASE**: CASE WHEN условие THEN ... [ELSE ...] END CASE; каждое WHEN — своё условие. См. [Глоссарий](glossary.md).
- Выполняется первая подходящая ветка; после неё управление уходит за END CASE. Без ELSE при отсутствии совпадения — исключение **CASE_NOT_FOUND**.
- В каждой ветке — операторы (присваивание, вызовы, другой CASE и т.д.); после THEN и после ELSE — точка с запятой. **END CASE** с точкой с запятой обязателен.
- Оператор CASE в PL/SQL не возвращает значение (в отличие от выражения CASE в SQL).
