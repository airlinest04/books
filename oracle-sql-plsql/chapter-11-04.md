# §11.4 Пакетные процедуры и функции

В [§11.3](chapter-11-03.md) мы разобрали параметры по умолчанию и именованную передачу. Процедуры и функции можно объявлять не только как отдельные объекты (standalone), но и **внутри пакета**. **Пакет** состоит из **спецификации** (объявления подпрограмм и при необходимости публичных переменных, типов, курсоров) и **тела** (реализация подпрограмм). Подпрограммы пакета вызываются с префиксом имени пакета: **имя_пакета.имя_процедуры**(аргументы). В этом разделе — зачем выносить подпрограммы в пакет, минимальная спецификация и тело пакета с одной процедурой или функцией, вызов. Подробнее о пакетах (переменные, курсоры, перегрузка) — в [§12.2](chapter-12-02.md) и [§12.3](chapter-12-03.md). Триггеры — в [§12.1](chapter-12-01.md). См. [Глоссарий](glossary.md).

---

## 11.4.1. Спецификация и тело пакета

**Пакет** (package) — объект схемы Oracle, объединяющий связанные подпрограммы, переменные, типы и курсоры. **Спецификация пакета** (CREATE PACKAGE) — «интерфейс»: объявляются заголовки процедур и функций (имя, параметры, для функции — RETURN тип), а также публичные константы, переменные, типы и курсоры. **Тело пакета** (CREATE PACKAGE BODY) содержит реализацию объявленных подпрограмм (полный код BEGIN...END) и при необходимости приватные объявления. См. [Глоссарий](glossary.md).

Спецификация и тело создаются отдельными командами. Спецификация должна быть создана первой; в теле можно реализовать только то, что объявлено в спецификации (сигнатуры должны совпадать). Подробная структура пакетов — в §12.2; здесь — минимальный пример с одной процедурой. Среда: Oracle Database.

---

## 11.4.2. Минимальный пакет с процедурой и функцией

Пример спецификации с одной процедурой и одной функцией:

```plsql
CREATE OR REPLACE PACKAGE pkg_emp AS
  PROCEDURE show_emp_name(p_emp_id IN employees.employee_id%TYPE);
  FUNCTION get_emp_salary(p_emp_id IN employees.employee_id%TYPE) RETURN NUMBER;
END pkg_emp;
/
```

Тело пакета с реализацией:

```plsql
CREATE OR REPLACE PACKAGE BODY pkg_emp AS
  PROCEDURE show_emp_name(p_emp_id IN employees.employee_id%TYPE) IS
    v_name VARCHAR2(200);
  BEGIN
    SELECT first_name || ' ' || last_name INTO v_name
      FROM employees WHERE employee_id = p_emp_id;
    DBMS_OUTPUT.PUT_LINE(v_name);
  END show_emp_name;

  FUNCTION get_emp_salary(p_emp_id IN employees.employee_id%TYPE) RETURN NUMBER IS
    v_sal NUMBER;
  BEGIN
    SELECT salary INTO v_sal FROM employees WHERE employee_id = p_emp_id;
    RETURN v_sal;
  END get_emp_salary;
END pkg_emp;
/
```

В спецификации — только заголовки (без IS/AS и тела); в теле — полные объявления с IS и реализацией. Имена и сигнатуры в теле должны совпадать со спецификацией. См. [Глоссарий](glossary.md).

## 11.4.3. Вызов пакетной процедуры и функции

Подпрограммы пакета вызываются с префиксом **имя_пакета.** (или схема.имя_пакета.**). См. [Глоссарий](glossary.md).

Примеры:

```plsql
pkg_emp.show_emp_name(100);
v_sal := pkg_emp.get_emp_salary(100);
```

Из другой схемы (при наличии прав): **схема.pkg_emp.show_emp_name(100);** Удаление: **DROP PACKAGE** имя_пакета**;** (удаляет и спецификацию, и тело). **DROP PACKAGE BODY** имя_пакета**;** — удаляет только тело; спецификация остаётся (вызов подпрограмм приведёт к ошибке до пересоздания тела). См. [Глоссарий](glossary.md).

Пакеты позволяют группировать логику по домену (например, pkg_emp, pkg_orders), разделять интерфейс (spec) и реализацию (body), хранить общее состояние между вызовами (пакетные переменные — в §12.2) и перегружать подпрограммы (§12.3). Глава 11 на этом завершается; далее [§12.1](chapter-12-01.md) — триггеры.

---

## Ключевое

- **Пакет** состоит из **спецификации** (CREATE PACKAGE: объявление подпрограмм и публичных объектов) и **тела** (CREATE PACKAGE BODY: реализация подпрограмм). Подпрограммы пакета — «пакетные» процедуры и функции. См. [Глоссарий](glossary.md).
- В спецификации — заголовки процедур и функций (параметры, RETURN для функции); в теле — полная реализация с совпадающими сигнатурами.
- Вызов: **имя_пакета.имя_процедуры**(аргументы); **переменная :=** имя_пакета**.**имя_функции**(аргументы);**
- **DROP PACKAGE** имя — удаление спецификации и тела. **DROP PACKAGE BODY** имя — удаление только тела.

В [§12.1](chapter-12-01.md) мы рассмотрим триггеры: автоматическое выполнение PL/SQL при событиях DML или DDL.
