# §12.1 Триггеры

В [§11.4](chapter-11-04.md) мы разобрали пакетные процедуры и функции. **Триггер** — объект базы данных, привязанный к таблице (или представлению, схеме): при наступлении события (INSERT, UPDATE, DELETE, DDL и т.д.) Oracle автоматически выполняет связанный с триггером блок PL/SQL. Триггеры используют для аудита, проверки данных, поддержания денормализованных полей и другой реакции на изменение данных. В этом разделе — синтаксис **CREATE TRIGGER**, триггеры **BEFORE** и **AFTER**, **FOR EACH ROW**, псевдозаписи **:NEW** и **:OLD**, а также условие **WHEN**. Пакет (структура, переменные) — в [§12.2](chapter-12-02.md). См. [Глоссарий](glossary.md).

---

## 12.1.1. Назначение и типы триггеров

**Триггер** — именованный блок PL/SQL, который выполняется при наступлении определённого события. Чаще всего используются **DML-триггеры** на таблице: срабатывают до или после INSERT, UPDATE или DELETE. Триггер можно задать на **каждую строку** (FOR EACH ROW) или **один раз на оператор** (statement-level). Есть также триггеры DDL (CREATE, ALTER, DROP и т.д.) и триггеры на системные события (подключение, отключение). Здесь рассматриваем DML-триггеры на таблице. См. [Глоссарий](glossary.md).

Типичные применения: проверка и корректировка данных перед записью (BEFORE), запись в таблицу аудита (AFTER), пересчёт итоговых полей. Триггеры усложняют отладку и логику «кто и когда изменил данные»; не стоит злоупотреблять сложной логикой в триггерах. Среда: Oracle Database.

---

## 12.1.2. Синтаксис CREATE TRIGGER (DML)

Упрощённая форма DML-триггера на таблице:

```plsql
CREATE [OR REPLACE] TRIGGER [схема.]имя_триггера
  {BEFORE | AFTER} {INSERT | UPDATE | DELETE} [OR ...]
  ON [схема.]таблица
  [FOR EACH ROW]
  [WHEN (условие)]
  [REFERENCING OLD AS псевдоним_old NEW AS псевдоним_new]
DECLARE
  ...
BEGIN
  ...
END;
/
```

**BEFORE** — выполнить триггер **до** применения изменения (можно изменить :NEW). **AFTER** — после применения (удобно для аудита, :NEW уже записано). События: **INSERT**, **UPDATE**, **DELETE**; можно перечислить через OR (например, INSERT OR UPDATE). **FOR EACH ROW** — триггер вызывается для **каждой затронутой строки**; без него — один раз на весь оператор (statement-level). **WHEN** (условие) — выполнять тело триггера только если условие истинно (только в FOR EACH ROW). См. [Глоссарий](glossary.md). Среда: Oracle Database.

## 12.1.3. :NEW и :OLD (псевдозаписи)

В триггере **FOR EACH ROW** доступны псевдозаписи **:NEW** и **:OLD**, содержащие значения столбцов строки. **:OLD** — значения **до** изменения (для INSERT не определены, для UPDATE и DELETE — старая строка). **:NEW** — значения **после** изменения (для DELETE не определены, для INSERT и UPDATE — новая строка). Обращение к полям: **:NEW.имя_столбца**, **:OLD.имя_столбца**. В триггере **BEFORE** можно присваивать **:NEW.столбец** — изменение попадёт в выполняемую операцию; в AFTER присваивание :NEW не влияет на уже записанные данные. См. [Глоссарий](glossary.md).

Пример: до вставки и обновления заполнять столбец updated_at текущей датой:

```plsql
CREATE OR REPLACE TRIGGER trg_orders_biu
  BEFORE INSERT OR UPDATE ON orders
  FOR EACH ROW
BEGIN
  :NEW.updated_at := SYSDATE;
END;
/
```

В statement-level триггере (без FOR EACH ROW) :NEW и :OLD недоступны. См. [Глоссарий](glossary.md).

---

## 12.1.4. WHEN и отключение триггера

**WHEN** (условие) задаёт фильтр: тело триггера выполняется только для строк, для которых условие истинно. В условии можно использовать :NEW и :OLD. См. [Глоссарий](glossary.md).

Пример: логировать только удаление с определённым статусом:

```plsql
CREATE OR REPLACE TRIGGER trg_orders_audit_del
  AFTER DELETE ON orders
  FOR EACH ROW
  WHEN (OLD.status = 'CANCELLED')
BEGIN
  INSERT INTO orders_audit (action, order_id, audit_time)
  VALUES ('DELETE', :OLD.order_id, SYSDATE);
END;
/
```

**ALTER TRIGGER** имя **DISABLE** — отключить триггер; **ALTER TRIGGER** имя **ENABLE** — включить. **ALTER TABLE** таблица **DISABLE ALL TRIGGERS** — отключить все триггеры таблицы. **DROP TRIGGER** имя — удалить триггер. См. [Глоссарий](glossary.md).

---

## Ключевое

- **Триггер** — блок PL/SQL, выполняемый автоматически при событии (DML: INSERT/UPDATE/DELETE). **CREATE TRIGGER** ... **BEFORE|AFTER** ... **ON** таблица **[FOR EACH ROW]** ... **BEGIN** ... **END;** См. [Глоссарий](glossary.md).
- **BEFORE** — до применения изменения (можно менять :NEW). **AFTER** — после. **FOR EACH ROW** — вызов для каждой строки; в нём доступны **:NEW** и **:OLD** (псевдозаписи со значениями столбцов новой и старой строки).
- **:NEW** — новая строка (INSERT, UPDATE); **:OLD** — старая строка (UPDATE, DELETE). В BEFORE можно присваивать :NEW.столбец.
- **WHEN** (условие) — выполнять тело только при истинном условии. **ALTER TRIGGER** ... **DISABLE|ENABLE**; **DROP TRIGGER** имя.

В [§12.2](chapter-12-02.md) мы рассмотрим пакет подробнее: переменные и константы в спецификации, приватные объекты в теле, инициализация.
