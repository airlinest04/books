# §11.3 Параметры по умолчанию; именованная передача

В [§11.2](chapter-11-02.md) мы разобрали функции и вызов с передачей аргументов по позиции. В PL/SQL параметрам процедур и функций можно задать **значение по умолчанию**; при вызове такие аргументы можно опускать. Кроме того, аргументы можно передавать **по имени** (именованная нотация): параметр **=>** значение, что удобно при большом числе параметров и при пропуске необязательных. В этом разделе — объявление параметра с **:=** значение по умолчанию, **позиционный** и **именованный** вызов, смешанная передача. Пакетные процедуры и функции — в [§11.4](chapter-11-04.md). См. [Глоссарий](glossary.md).

---

## 11.3.1. Значение по умолчанию для параметра

При объявлении параметра можно указать **значение по умолчанию**: параметр **:=** выражение (или константа). Если при вызове соответствующий аргумент не передан (позиционно опущен или не указан в именованной передаче), внутри подпрограммы параметр получит это значение. Параметры с значением по умолчанию обычно размещают **в конце** списка параметров, иначе при позиционном вызове нельзя опустить только их, не передавая аргументы для следующих. См. [Глоссарий](glossary.md).

Пример:

```plsql
CREATE OR REPLACE PROCEDURE log_message (
  p_msg    IN VARCHAR2,
  p_level  IN VARCHAR2 := 'INFO'
) IS
BEGIN
  INSERT INTO app_log (msg, level) VALUES (p_msg, p_level);
END log_message;
/
```

Вызов **log_message('Started')** — p_level получит 'INFO'. Вызов **log_message('Error', 'ERROR')** — p_level будет 'ERROR'. См. [Глоссарий](glossary.md). Среда: Oracle PL/SQL.

## 11.3.2. Позиционная и именованная передача

При **позиционной** передаче аргументы перечисляются в том же порядке, что и параметры: первый аргумент — первому параметру, второй — второму и т.д. Опускать можно только аргументы, соответствующие параметрам с значением по умолчанию, и только в конце (нельзя пропустить второй, передав третий по позиции). См. [Глоссарий](glossary.md).

При **именованной** передаче каждый аргумент задаётся в форме **имя_параметра =>** значение (или выражение). Порядок не важен; можно указать только нужные параметры, остальные получат значения по умолчанию (если заданы). Синтаксис:

```plsql
имя_подпрограммы(имя_параметра1 => значение1, имя_параметра2 => значение2, ...);
```

Пример для log_message:

```plsql
log_message(p_msg => 'Done');                    -- p_level по умолчанию
log_message(p_level => 'WARN', p_msg => 'Check'); -- порядок произвольный
```

Именованная передача удобна при многих параметрах и при частом пропуске необязательных. См. [Глоссарий](glossary.md).

---

## 11.3.3. Смешанная передача

Можно комбинировать позиционные и именованные аргументы: сначала идут позиционные (в порядке параметров), затем именованные. После первого именованного аргумента все следующие должны быть именованными — нельзя «вернуться» к позиционным. См. [Глоссарий](glossary.md).

Пример (процедура с тремя параметрами: a, b, c; у b и c есть значения по умолчанию):

```plsql
proc1(10);                          -- только a
proc1(10, 20);                      -- a, b
proc1(10, p_c => 30);                -- a позиционно, b по умолчанию, c по имени
proc1(p_a => 10, p_c => 30);        -- только a и c по имени, b по умолчанию
```

Неверно: **proc1(10, p_c => 30, 20)** — после именованного p_c позиционный 20 не допускается. См. [Глоссарий](glossary.md).

---

## Ключевое

- **Параметр по умолчанию**: в объявлении параметра **:=** значение (или выражение). При вызове соответствующий аргумент можно не передавать. Обычно такие параметры ставят в конец списка. См. [Глоссарий](glossary.md).
- **Позиционная передача** — аргументы в порядке параметров; пропускать можно только хвост (параметры с умолчанием). **Именованная передача** — имя_параметра **=>** значение; порядок произвольный, можно передавать только нужные параметры.
- При **смешанной** передаче сначала позиционные аргументы, затем именованные; после первого именованного все следующие — только именованные.
- Именованная передача улучшает читаемость вызовов с большим числом параметров и при частом использовании значений по умолчанию.
