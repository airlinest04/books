# §11.1 CREATE PROCEDURE

В [§10.4](chapter-10-04.md) мы завершили главу об управляющих конструкциях. **Процедура** — именованный блок PL/SQL, сохранённый в базе данных; его можно вызывать по имени с передачей аргументов (параметров). В этом разделе — синтаксис **CREATE PROCEDURE**, объявление параметров (**IN**, **OUT**, **IN OUT**), тело процедуры (AS/IS, BEGIN...END) и вызов процедуры из PL/SQL и из SQL*Plus (**EXEC**). Функции (возврат значения) — в [§11.2](chapter-11-02.md). См. [Глоссарий](glossary.md).

---

## 11.1.1. Синтаксис CREATE PROCEDURE

**Процедура** — объект схемы: именованный подпрограмма с списком параметров и телом на PL/SQL. Создаётся командой **CREATE PROCEDURE** (или **CREATE OR REPLACE PROCEDURE** для пересоздания). См. [Глоссарий](glossary.md).

Общая форма:

```plsql
CREATE [OR REPLACE] PROCEDURE [схема.]имя_процедуры
  ( параметр1 [IN | OUT | IN OUT] тип [:= значение_по_умолчанию]
  [, параметр2 ...] )
[AUTHID {CURRENT_USER | DEFINER}]
AS | IS
  [локальные объявления]
BEGIN
  исполняемые операторы;
[EXCEPTION
  обработчики;]
END [имя_процедуры];
```

**OR REPLACE** — пересоздать процедуру, если она уже существует (сохраняются права). Список параметров в скобках; каждый параметр имеет режим **IN** (входной, по умолчанию), **OUT** (выходной, процедура присваивает значение) или **IN OUT** (вход и выход). **AS** и **IS** взаимозаменяемы. После них — необязательная секция объявлений (переменные, курсоры), затем **BEGIN** ... **END**. Имя после END необязательно, но рекомендуется для читаемости. См. [Глоссарий](glossary.md). Среда: Oracle Database.

---

## 11.1.2. Параметры IN, OUT, IN OUT

**IN** — параметр только для входа: вызывающий передаёт значение, внутри процедуры его можно читать, но не изменять (присваивание формально возможно для копии, но не влияет на аргумент вызывающего). По умолчанию параметр считается IN. См. [Глоссарий](glossary.md).

**OUT** — параметр только для выхода: вызывающий передаёт переменную, процедура обязана присвоить ей значение до нормального завершения; начальное значение аргумента внутри процедуры не определено. Используется для возврата результатов (например, код ошибки, количество обработанных строк).

**IN OUT** — вход и выход: вызывающий передаёт переменную, процедура читает и может изменить её; после вызова переменная содержит значение, установленное процедурой.

Пример процедуры с IN и OUT:

```plsql
CREATE OR REPLACE PROCEDURE get_emp_name (
  p_emp_id   IN  employees.employee_id%TYPE,
  p_name     OUT employees.last_name%TYPE
) IS
BEGIN
  SELECT last_name INTO p_name
    FROM employees
   WHERE employee_id = p_emp_id;
END get_emp_name;
/
```

Вызов из блока PL/SQL: передать переменные по позиции или по имени (см. §11.3). См. [Глоссарий](glossary.md).

## 11.1.3. Вызов процедуры

Из **PL/SQL** процедуру вызывают оператором вызова: имя процедуры и список аргументов в скобках. Аргументы — переменные, литералы или выражения (для IN). Для OUT и IN OUT передают только переменные. См. [Глоссарий](glossary.md).

Пример вызова get_emp_name:

```plsql
DECLARE
  v_name   VARCHAR2(100);
BEGIN
  get_emp_name(100, v_name);   -- 100 — IN, v_name — OUT
  DBMS_OUTPUT.PUT_LINE(v_name);
END;
/
```

В **SQL*Plus** и в средах, поддерживающих команду **EXEC** (или **EXECUTE**), процедуру без параметров вызывают так: **EXEC имя_процедуры;** Процедуру с параметрами вызывают через анонимный блок: **EXEC** не поддерживает передачу аргументов напрямую в старом синтаксисе; используют **BEGIN** имя_процедуры**(аргументы); END;** или **CALL** имя_процедуры**(аргументы);** (в зависимости от клиента). См. [Глоссарий](glossary.md).

Пример в SQL*Plus для процедуры с параметрами:

```plsql
VAR v_name VARCHAR2(100);
EXEC get_emp_name(100, :v_name);
PRINT v_name;
```

Удаление процедуры: **DROP PROCEDURE** имя_процедуры**;** Среда: Oracle Database.

---

## Ключевое

- **CREATE [OR REPLACE] PROCEDURE** имя **(** параметры **) AS|IS** ... **BEGIN** ... **END;** — создание процедуры. Параметры: **IN** (вход, по умолчанию), **OUT** (выход), **IN OUT** (вход и выход). См. [Глоссарий](glossary.md).
- **Процедура** не возвращает значение в присваивание (в отличие от функции); результаты передаются через OUT/IN OUT или через глобальное состояние (например, DML).
- Вызов из PL/SQL: **имя_процедуры**(аргументы); для OUT/IN OUT передают переменные. В SQL*Plus: EXEC для процедур без параметров; с параметрами — анонимный блок или CALL.
- **DROP PROCEDURE** имя — удаление процедуры.

В [§11.2](chapter-11-02.md) мы разберём функции (CREATE FUNCTION): возврат значения через RETURN.
