# §9.2 Переменные

В [§9.1](chapter-09-01.md) мы разобрали структуру блока PL/SQL (DECLARE, BEGIN, EXCEPTION, END). Переменные и константы объявляются в секции **DECLARE**; им задаётся тип и при необходимости начальное значение. В этом разделе — объявление переменных, **скалярные типы** (NUMBER, VARCHAR2, DATE, BOOLEAN), **%TYPE** и **%ROWTYPE** (привязка типа к столбцу или строке таблицы), а также константы. Присваивание и выборка в переменные (SELECT INTO) — в [§9.3](chapter-09-03.md). См. [Глоссарий](glossary.md).

---

## 9.2.1. Объявление переменной в DECLARE

Переменная объявляется в секции **DECLARE** в формате:

```plsql
имя_переменной тип [NOT NULL] [:= начальное_значение];
```

**имя_переменной** — идентификатор (буквы, цифры, подчёркивание; не с цифры). **тип** — скалярный тип PL/SQL (NUMBER, VARCHAR2, DATE и т.д.), тип таблицы/курсора или анкерный тип **%TYPE** / **%ROWTYPE**. **NOT NULL** обязывает присвоить значение до использования (при объявлении или в BEGIN). **:=** задаёт начальное значение; без него переменная инициализируется **NULL** (кроме BOOLEAN, у которого по умолчанию NULL, но в условиях он трактуется как FALSE в части контекстов). См. [Глоссарий](glossary.md).

Примеры:

```plsql
DECLARE
  v_count    NUMBER := 0;
  v_name     VARCHAR2(100);
  v_birth    DATE NOT NULL := DATE '1990-01-01';
  v_active   BOOLEAN := TRUE;
BEGIN
  v_count := v_count + 1;
  v_name := 'Test';
  DBMS_OUTPUT.PUT_LINE(v_count || ': ' || v_name);
END;
/
```

Имена переменных принято начинать с префикса (например, `v_` для переменных), чтобы не путать со столбцами таблиц. Среда: Oracle Database (PL/SQL).

## 9.2.2. Скалярные типы PL/SQL

В DECLARE можно использовать те же типы, что и в SQL: **NUMBER**, **VARCHAR2**(size), **CHAR**(size), **DATE**, **TIMESTAMP**, **CLOB**, **BLOB** и др. Размер для VARCHAR2 и CHAR задаётся в байтах или в символах (CHAR). См. [Глоссарий](glossary.md).

**BOOLEAN** — тип только в PL/SQL (в таблицах его нет): значения TRUE, FALSE, NULL. Используется в условиях (IF, WHILE, условия в циклах). Сравнивать с TRUE/FALSE можно; с NULL — через IS NULL.

Для чисел часто используют **NUMBER** без параметров или **BINARY_INTEGER** / **PLS_INTEGER** (целое в диапазоне платформы, эффективнее для счётчиков циклов). Для дат — **DATE** (без времени суток в старом смысле не бывает: DATE в Oracle всегда с временем). См. [Глоссарий](glossary.md).

## 9.2.3. %TYPE: тип по столбцу таблицы

**%TYPE** — анкерный тип: переменная получает тип **столбца таблицы или представления** (или другой переменной). Синтаксис: `имя_переменной таблица.столбец%TYPE` или `переменная%TYPE`. При изменении типа столбца в базе тип переменной при перекомпиляции подстроится автоматически; не нужно дублировать размеры и точность. См. [Глоссарий](glossary.md).

Пример:

```plsql
DECLARE
  v_emp_name   employees.last_name%TYPE;
  v_salary     employees.salary%TYPE;
BEGIN
  -- позже: SELECT last_name, salary INTO v_emp_name, v_salary FROM employees WHERE ...
  NULL;
END;
/
```

Так переменные гарантированно совместимы со столбцами при SELECT INTO и при подстановке в DML. См. [Глоссарий](glossary.md).

---

## 9.2.4. %ROWTYPE: тип по строке таблицы

**%ROWTYPE** — анкерный тип: переменная получает тип **строки таблицы или представления** (или курсора): набор полей с теми же именами и типами, что и столбцы. Синтаксис: `имя_переменной таблица%ROWTYPE` или `курсор%ROWTYPE`. Обращение к полям: **переменная.имя_столбца**. Удобно для хранения одной строки результата запроса без объявления отдельной переменной под каждый столбец. См. [Глоссарий](glossary.md).

Пример:

```plsql
DECLARE
  r_emp   employees%ROWTYPE;
BEGIN
  -- позже: SELECT * INTO r_emp FROM employees WHERE employee_id = 100;
  -- тогда r_emp.employee_id, r_emp.last_name, r_emp.salary и т.д.
  NULL;
END;
/
```

Для одной строки SELECT * INTO record%ROWTYPE — типичный приём; для нескольких строк используют курсор или BULK COLLECT INTO коллекцию записей. См. [Глоссарий](glossary.md).

## 9.2.5. Константы

**Константа** объявляется с ключевым словом **CONSTANT**; значение задаётся при объявлении и далее не меняется. Синтаксис:

```plsql
имя_константы тип CONSTANT := значение;
```

Тип можно задать явно или через %TYPE. Константы используют для магических чисел и строк (лимиты, коды), чтобы не дублировать литералы по коду. См. [Глоссарий](glossary.md).

Пример:

```plsql
DECLARE
  c_max_retry   CONSTANT PLS_INTEGER := 3;
  c_status_ok   CONSTANT VARCHAR2(10) := 'OK';
BEGIN
  -- c_max_retry := 5;  -- ошибка компиляции: константе нельзя присвоить значение
  NULL;
END;
/
```

---

## Ключевое

- Переменные и константы объявляются в **DECLARE**: имя, тип, при необходимости **NOT NULL** и **:= значение**. Константа — с **CONSTANT**. См. [Глоссарий](glossary.md).
- Скалярные типы: NUMBER, VARCHAR2, CHAR, DATE, TIMESTAMP, BOOLEAN (только в PL/SQL) и др. Размер задаётся там, где нужен (VARCHAR2(100) и т.д.).
- **%TYPE** — тип переменной совпадает с типом столбца (таблица.столбец%TYPE). **%ROWTYPE** — переменная-запись с полями как у строки таблицы (таблица%ROWTYPE); обращение: запись.имя_столбца. См. [Глоссарий](glossary.md).
- %TYPE и %ROWTYPE упрощают сопровождение кода при изменении структуры таблиц.
