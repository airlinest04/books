# §3.2 WHERE

В [§3.1](chapter-03-01.md) мы разобрали список столбцов, псевдонимы, выражения и основные функции в SELECT. Чтобы отбирать не все строки таблицы, а только удовлетворяющие условию, используется предложение **WHERE**. В этом разделе рассмотрены **операторы сравнения** (=, <>, <, >, <=, >=), условия **IN**, **BETWEEN**, **LIKE**, проверка на **IS NULL** и **IS NOT NULL**, а также логические операторы **AND**, **OR**, **NOT** и **приоритет** их вычисления. Уникальные строки (DISTINCT) — в [§3.3](chapter-03-03.md). См. [Глоссарий](glossary.md).

---

## 3.2.1. Предложение WHERE и операторы сравнения

**WHERE** задаёт условие отбора строк: в результат попадают только те строки, для которых условие истинно. Условие записывается после FROM и перед GROUP BY, ORDER BY и другими предложениями (если они есть). См. [Глоссарий](glossary.md).

Синтаксис:

```sql
SELECT список_столбцов FROM таблица WHERE условие;
```

**Операторы сравнения:**

| Оператор | Значение |
|----------|----------|
| = | равно |
| <> или != | не равно |
| < | меньше |
| > | больше |
| <= | меньше или равно |
| >= | больше или равно |

Оба варианта «не равно» (<> и !=) в Oracle допустимы. Сравнение с NULL через = или <> **не даёт TRUE и не даёт FALSE** — результат «неизвестно» (UNKNOWN), поэтому такие строки не попадают в выборку. Для проверки на NULL используют **IS NULL** и **IS NOT NULL** (см. подраздел 3.2.5).

Примеры:

```sql
SELECT * FROM products WHERE price > 100;

SELECT id, name FROM products WHERE price <= 50;

SELECT * FROM orders WHERE status = 'CONFIRMED';
```

Сравнивать можно столбцы с литералами, столбцы с выражениями, два столбца. Типы должны быть сравнимы (или неявно приводимы); даты сравниваются в хронологическом порядке.

---

## 3.2.2. IN: вхождение в список

Условие **IN (значение1, значение2, ...)** истинно, если значение выражения **равно одному из** перечисленных. Список задаётся в скобках через запятую; значения — литералы, числа, строки или выражения. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT * FROM products WHERE status IN ('ACTIVE', 'PENDING');

SELECT * FROM orders WHERE customer_id IN (1, 5, 10);
```

**NOT IN (список)** — истинно, если значение **не равно ни одному** из списка. Важно: если в списке есть NULL, то NOT IN может вести себя неочевидно — любое сравнение с NULL даёт UNKNOWN, поэтому условие «столбец NOT IN (a, b, NULL)» для любой строки не будет TRUE (и строка не попадёт в результат). На практике в списке IN/NOT IN стараются не подставлять NULL или используют альтернативы (например, дополнительное условие с IS NULL). См. [Глоссарий](glossary.md).

IN часто используется с подзапросом: **столбец IN (SELECT ...)** — см. [§4.2](chapter-04-02.md).

---

## 3.2.3. BETWEEN: диапазон

Условие **BETWEEN нижняя_граница AND верхняя_граница** истинно, если значение **больше или равно** нижней границе **и меньше или равно** верхней. Границы включаются. Обе границы должны быть совместимых типов (например, обе числа или обе даты). См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT * FROM products WHERE price BETWEEN 10 AND 100;

SELECT * FROM orders WHERE order_date BETWEEN DATE '2025-01-01' AND DATE '2025-01-31';
```

**NOT BETWEEN** — значение строго меньше нижней границы или строго больше верхней. Эквивалент BETWEEN: `значение >= нижняя AND значение <= верхняя`. Для дат удобно использовать BETWEEN с явным приведением строки к дате через TO_DATE.

## 3.2.4. LIKE: сравнение по шаблону

Условие **LIKE шаблон** используется для **частичного совпадения строк**. В шаблоне допустимы спецсимволы: **%** (любое количество любых символов, включая ноль) и **_** (ровно один любой символ). Остальные символы трактуются как обычные. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT * FROM products WHERE name LIKE 'Key%';        -- начинается с Key

SELECT * FROM users WHERE email LIKE '%@company.com';

SELECT * FROM products WHERE code LIKE 'A_B%';       -- A, любой символ, B, потом что угодно
```

Чтобы искать сам символ % или _ в данных, их экранируют. В Oracle для этого задают **ESCAPE символ**: в шаблоне перед % или _ ставится символ экранирования, а в конце условия указывается **ESCAPE 'символ'**. Пример: шаблон `'%\%%' ESCAPE '\'` — строка, содержащая буквальный %.

**NOT LIKE** — истинно, когда строка не совпадает с шаблоном. Сравнение с NULL в LIKE даёт NULL (строка не попадает в результат). Регистр зависит от настроек сравнения символов (collation); для сравнения без учёта регистра часто используют UPPER(столбец) LIKE UPPER('шаблон').

## 3.2.5. IS NULL и IS NOT NULL

В SQL сравнение с NULL (**столбец = NULL**) не даёт TRUE: результат неизвестен (UNKNOWN). Поэтому для проверки «значение пустое» и «значение не пустое» используют специальные условия: **IS NULL** и **IS NOT NULL**. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT * FROM products WHERE price IS NULL;

SELECT * FROM users WHERE phone IS NOT NULL;
```

**IS NULL** истинно только для NULL; **IS NOT NULL** истинно для любого не-NULL значения. Нельзя писать «= NULL» или «<> NULL» для проверки — такие условия не вернут ожидаемых строк. В выражениях (например, NVL) NULL обрабатывают отдельно; в условиях отбора — только через IS NULL / IS NOT NULL.

---

## 3.2.6. AND, OR, NOT и приоритет операторов

Несколько условий объединяют логическими операторами **AND** (все условия истинны) и **OR** (хотя бы одно истинно). **NOT** инвертирует условие. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT * FROM products WHERE price > 10 AND price < 100;

SELECT * FROM orders WHERE status = 'NEW' OR status = 'PENDING';

SELECT * FROM products WHERE NOT (status = 'DISABLED');
```

**Приоритет** (от высшего к низшему): сначала выполняются сравнения и условия (IN, BETWEEN, LIKE, IS NULL), затем **NOT**, затем **AND**, затем **OR**. Поэтому условие `a = 1 AND b = 2 OR c = 3` трактуется как `(a = 1 AND b = 2) OR c = 3`. Чтобы изменить порядок, используют **скобки**:

```sql
SELECT * FROM products WHERE (status = 'ACTIVE' OR status = 'PENDING') AND price < 50;
```

Без скобок пришлось бы учитывать, что AND выше OR; со скобками намерение читается однозначно. Рекомендуется ставить скобки при смешении AND и OR. См. [Глоссарий](glossary.md).

---

## 3.2.7. Комбинированный пример

Запрос с несколькими типами условий:

```sql
SELECT id, name, price
  FROM products
 WHERE status IN ('ACTIVE', 'PENDING')
   AND price BETWEEN 20 AND 200
   AND name LIKE '%Pro%'
   AND description IS NOT NULL;
```

Здесь отбираются продукты со статусом ACTIVE или PENDING, ценой от 20 до 200, с «Pro» в имени и с непустым описанием. Уникальные строки и устранение дубликатов — в [§3.3](chapter-03-03.md).

## 3.2.8. Типичные ошибки при использовании WHERE

- **Писать = NULL вместо IS NULL:** условие `price = NULL` не вернёт строк с пустой ценой; нужно `price IS NULL`.
- **Путать AND и OR без скобок:** `status = 'A' OR status = 'B' AND price > 0` трактуется как `status = 'A' OR (status = 'B' AND price > 0)`. Для «(A или B) и цена > 0» нужны скобки.
- **NOT IN с NULL в списке:** если подзапрос или список содержит NULL, NOT IN может исключить все строки. Избегайте NULL в списке или переформулируйте условие (например, через NOT EXISTS в подзапросе).
- **LIKE без учёта регистра:** в части настроек 'Key%' не совпадёт с 'KEYBOARD'. Используйте UPPER(столбец) LIKE UPPER('Key%') для независимости от регистра.
- **BETWEEN для дат с временем:** BETWEEN '2025-01-01' AND '2025-01-31' может не включить строки с временем 31 января после полуночи (зависит от типа и формата). Для дат на весь день часто используют TRUNC или явные границы с временем.
- **Сравнение строк разной длины и пробелов:** CHAR дополняется пробелами; при сравнении с VARCHAR2 результат может отличаться от ожидаемого. Для единообразия можно использовать TRIM или сравнивать с учётом типа столбца.

## Ключевое

- **WHERE** задаёт условие отбора строк. В результат попадают только строки, для которых условие истинно.
- **Сравнение:** =, <>, !=, <, >, <=, >=. Сравнение с NULL через = / <> не даёт TRUE; для NULL используют **IS NULL** и **IS NOT NULL**.
- **IN (список)** — значение равно одному из списка. **NOT IN** — ни одному (осторожно с NULL в списке).
- **BETWEEN a AND b** — значение в диапазоне [a, b] (границы включаются).
- **LIKE шаблон** — частичное совпадение: **%** — любое число символов, **_** — один символ. Экранирование через ESCAPE. **NOT LIKE** — не совпадает.
- **AND**, **OR**, **NOT** объединяют условия. Приоритет: сравнения и условия (IN, BETWEEN, LIKE, IS NULL), затем NOT, затем AND, затем OR. **Скобки** задают порядок явно.
- Рекомендуется использовать скобки при смешении AND и OR и всегда проверять NULL через IS NULL / IS NOT NULL.

В [§3.3](chapter-03-03.md) мы разберём DISTINCT — как получить уникальные строки в результате запроса.
