# §3.4 Циклы WHILE и FOR

В [§3.3](chapter-03-03.md) мы разобрали безусловный цикл LOOP и выход через EXIT. В этом разделе рассмотрим **WHILE** — цикл с проверкой условия в начале каждой итерации — и **FOR** в двух вариантах: перебор диапазона целых чисел (FOR i IN 1..10) и перебор строк результата запроса (FOR rec IN SELECT ...). CONTINUE и метки при вложенных циклах — в [§3.5](chapter-03-05.md). См. [Глоссарий](glossary.md).

---

## 3.4.1. Цикл WHILE

**WHILE** повторяет блок операторов, пока логическое выражение истинно. Условие проверяется **перед каждой** итерацией: если при входе в цикл оно ложно (или NULL), тело не выполняется ни разу. Синтаксис (по документации PostgreSQL):

```
[ <<метка>> ]
WHILE логическое_выражение LOOP
  операторы
END LOOP [ метка ];
```

См. [Глоссарий](glossary.md).

Примеры (по документации PostgreSQL):

```sql
WHILE amount_owed > 0 AND gift_certificate_balance > 0 LOOP
  -- вычисления по погашению долга
END LOOP;

WHILE NOT done LOOP
  -- работа до установки done := true
END LOOP;
```

WHILE удобен, когда условие продолжения естественно проверять в начале итерации и не требуется явно перебирать диапазон или курсор.

## 3.4.2. FOR по диапазону целых (FOR ... IN ... .. ...)

**FOR** по диапазону целых перебирает значения от нижней границы до верхней (включительно). Синтаксис (по документации PostgreSQL):

```
[ <<метка>> ]
FOR имя IN [ REVERSE ] выражение .. выражение [ BY выражение ] LOOP
  операторы
END LOOP [ метка ];
```

- **имя** — переменная цикла; она объявляется автоматически как **integer** и существует только внутри цикла; внешняя переменная с тем же именем внутри цикла не видна.
- Два выражения задают **нижнюю и верхнюю** границу диапазона; они вычисляются **один раз** при входе в цикл.
- **REVERSE** — перебор в обратном порядке (от верхней границы к нижней, шаг вычитается).
- **BY выражение** — шаг (по умолчанию 1); вычисляется один раз при входе. Без REVERSE шаг прибавляется, с REVERSE — вычитается.

См. [Глоссарий](glossary.md).

Примеры (по документации PostgreSQL):

```sql
FOR i IN 1..10 LOOP
  -- i принимает значения 1, 2, ..., 10
END LOOP;

FOR i IN REVERSE 10..1 LOOP
  -- i принимает значения 10, 9, ..., 1
END LOOP;

FOR i IN REVERSE 10..1 BY 2 LOOP
  -- i принимает значения 10, 8, 6, 4, 2
END LOOP;
```

Если нижняя граница больше верхней (или при REVERSE — наоборот), тело цикла не выполняется ни разу; ошибка не возникает.

---

## 3.4.3. Пустой диапазон и квалификация имени переменной цикла

При **нижняя > верхняя** (без REVERSE) или **верхняя > нижняя** (с REVERSE) цикл не выполняет ни одной итерации. Переменная цикла при этом не инициализируется осмысленным значением для использования после цикла; после END LOOP она уже вне области видимости. См. [Глоссарий](glossary.md).

Если у цикла указана **метка**, к переменной цикла можно обращаться по квалифицированному имени: **метка.имя** (например, для передачи в подпрограмму или вывода).

---

## 3.4.4. FOR по результату запроса (FOR ... IN SELECT ...)

**FOR** по запросу перебирает строки результата запроса; на каждой итерации переменная цикла получает очередную строку. Синтаксис (по документации PostgreSQL):

```
[ <<метка>> ]
FOR цель IN запрос LOOP
  операторы
END LOOP [ метка ];
```

**Цель (target)** — переменная записи (RECORD), переменная строки (%ROWTYPE) или список скалярных переменных через запятую. **Запрос** — любой SQL-команда, возвращающая строки: в основном **SELECT**, а также **INSERT/UPDATE/DELETE/MERGE** с **RETURNING**. См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL, адаптировано):

```sql
FOR mviews IN
  SELECT n.nspname AS mv_schema,
         c.relname AS mv_name,
         pg_catalog.pg_get_userbyid(c.relowner) AS owner
  FROM pg_catalog.pg_class c
  LEFT JOIN pg_catalog.pg_namespace n ON n.oid = c.relnamespace
  WHERE c.relkind = 'm'
  ORDER BY 1
LOOP
  RAISE NOTICE 'Materialized view %.% (owner: %)',
    quote_ident(mviews.mv_schema),
    quote_ident(mviews.mv_name),
    quote_ident(mviews.owner);
  EXECUTE format('REFRESH MATERIALIZED VIEW %I.%I',
    mviews.mv_schema, mviews.mv_name);
END LOOP;
```

Переменные PL/pgSQL в тексте запроса подставляются как параметры; план запроса может кэшироваться. Если цикл прерывается EXIT, последняя присвоенная строка остаётся в переменной цикла после выхода.

---

## 3.4.5. FOR ... IN EXECUTE (динамический запрос)

Форма **FOR цель IN EXECUTE строка_запроса [ USING выражение, ... ] LOOP** перебирает строки запроса, заданного **строкой** (например, собранной в переменной). Запрос планируется при каждой итерации (при входе в цикл); подстановка параметров — через USING. Используется для динамического SQL, когда текст запроса формируется в run time. Подробнее динамический SQL — в гл. 7; здесь достаточно знать, что такая форма существует для перебора результата динамического запроса. См. [Глоссарий](glossary.md).

---

## Ключевое

- **WHILE условие LOOP ... END LOOP** — условие проверяется перед каждой итерацией; при ложном или NULL при входе тело не выполняется.
- **FOR имя IN [ REVERSE ] низ .. верх [ BY шаг ] LOOP** — перебор целых; переменная цикла integer, объявляется автоматически; границы и шаг вычисляются один раз; пустой диапазон — ноль итераций.
- **FOR цель IN запрос LOOP** — перебор строк результата SELECT (или INSERT/UPDATE/DELETE/MERGE RETURNING); цель — RECORD, %ROWTYPE или список переменных; переменные PL/pgSQL в запросе подставляются как параметры.
- **FOR ... IN EXECUTE** — перебор по результату запроса, заданного строкой (динамический SQL); подробнее гл. 7.

В [§3.5](chapter-03-05.md) мы разберём CONTINUE и использование меток при вложенных циклах (EXIT/CONTINUE с меткой).
