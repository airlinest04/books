# §1.4 Первый блок

В [§1.3](chapter-01-03.md) мы разобрали, где выполняется PL/pgSQL: в функциях, процедурах, триггерных функциях и в анонимном блоке DO. В этом разделе мы напишем и выполним **первый анонимный блок** в psql: разберём синтаксис DO, долларовые кавычки, минимальную структуру блока (BEGIN ... END), простой пример с выводом сообщения (RAISE NOTICE) и требования к окружению. Структура блока и объявление переменных подробно рассматриваются в гл. 2; здесь достаточно минимального рабочего примера, чтобы убедиться, что PL/pgSQL у вас выполняется. См. [Глоссарий](glossary.md).

---

## 1.4.1. Синтаксис DO и долларовые кавычки

Оператор **DO** выполняет анонимный блок кода один раз; блок не сохраняется в каталоге БД. По документации PostgreSQL, блок трактуется как тело функции без параметров с возвращаемым типом `void`. Синтаксис:

```sql
DO [ LANGUAGE lang_name ] code
```

Параметр `code` — строка с кодом на процедурном языке. Её нужно передать как **строковый литерал**, как и тело функции в CREATE FUNCTION. Рекомендуется использовать **долларовые кавычки** (dollar quoting): тогда не нужно экранировать одинарные кавычки и обратные слэши внутри кода. Самый частый вариант — пара `$$`: всё между `$$` и `$$` считается телом блока. См. [Глоссарий](glossary.md).

Пример формы оператора:

```sql
DO $$
  -- здесь код на PL/pgSQL
$$;
```

Ключевое слово **LANGUAGE** можно указать до или после блока; по умолчанию используется `plpgsql`, поэтому для PL/pgSQL его часто опускают. Явный вариант:

```sql
DO LANGUAGE plpgsql $$
  -- код
$$;
```

Если внутри блока встречаются сами символы `$$`, используют помеченные долларовые кавычки, например `$body$ ... $body$`, чтобы граница строки была однозначной (подробнее о долларовых кавычках — в документации PostgreSQL, раздел 4.1.2.4).

## 1.4.2. Минимальная структура блока PL/pgSQL

Тело DO (и любое тело функции на PL/pgSQL) должно быть **блоком**. Блок — это структура вида:

```
[ <<метка>> ]
[ DECLARE
    объявления ]
BEGIN
  операторы
END [ метка ];
```

Для первого блока достаточно **минимального варианта**: только `BEGIN` и `END`, между ними — один или несколько операторов, каждый завершается точкой с запятой. Не ставьте точку с запятой сразу после `BEGIN` — это типичная ошибка и приводит к синтаксической ошибке. Точка с запятой нужна после каждого оператора и после вложенных блоков (после `END` вложенного блока), но после конечного `END`, закрывающего весь блок в DO, точку с запятую можно не ставить (завершает оператор сама конструкция `$$;`). См. [§2.1](chapter-02-01.md).

Пример минимального блока:

```sql
DO $$
BEGIN
  NULL;   -- пустой оператор; блок уже валиден
END
$$;
```

Такой блок ничего не делает, но выполняется без ошибки. В следующем подразделе добавим оператор, который выводит сообщение.

## 1.4.3. Пример: вывод сообщения (RAISE NOTICE)

Чтобы увидеть, что блок действительно выполнился, удобно использовать **RAISE NOTICE**: оператор отправляет сообщение в клиент (в psql оно выводится в консоль). Синтаксис для простого случая: `RAISE NOTICE 'текст %', значение;` — символ `%` подставляет следующее значение из списка. Полный пример:

```sql
DO $$
BEGIN
  RAISE NOTICE 'Первый блок PL/pgSQL выполнен.';
END
$$;
```

В psql после выполнения вы увидите что-то вроде:

```
NOTICE:  Первый блок PL/pgSQL выполнен.
DO
```

Строка `DO` — это результат выполнения самого оператора DO (у DO нет возвращаемого значения в виде набора строк). Подробнее о RAISE и уровнях сообщений — в гл. 4; для первых экспериментов достаточно NOTICE.

Можно вывести значение выражения или переменной (переменные введём в гл. 2):

```sql
DO $$
BEGIN
  RAISE NOTICE 'Текущее время: %', now();
END
$$;
```

Функция `now()` возвращает текущие дату и время; они подставятся вместо `%` в сообщении.

## 1.4.4. Выполнение в psql

Чтобы выполнить блок в **psql**:

1. **Подключитесь** к базе данных, в которой установлен язык plpgsql (по умолчанию он есть в каждой созданной базе). Например: `psql -U postgres -d mydb`, или из уже открытой сессии psql переключение на другую базу: `\c mydb`.
2. **Введите оператор DO** целиком: от `DO $$` до `$$;`. Можно вводить построчно; psql будет показывать промпт продолжения (например, `$body$`) до тех пор, пока не увидит закрывающие `$$` и точку с запятой.
3. **Выполните** оператор: нажмите Enter после `$$;`. Сервер выполнит блок и выведет NOTICE (если есть) и строку `DO`.

Если блок многострочный, удобно вводить его в редакторе и вставлять в psql целиком или сохранить в файл и выполнить командой `\i путь/к/файлу.sql`.

Пример сессии (сокращённо):

```text
$ psql -U postgres -d mydb
mydb=# DO $$
BEGIN
  RAISE NOTICE 'Первый блок PL/pgSQL выполнен.';
END
$$;
NOTICE:  Первый блок PL/pgSQL выполнен.
DO
mydb=#
```

Ошибка в синтаксисе (например, точка с запятой после BEGIN) приведёт к сообщению об ошибке от сервера; исправьте блок и выполните снова.

---

## 1.4.5. Требования к окружению

Для выполнения DO с языком plpgsql необходимо:

- **Язык plpgsql установлен** в текущей базе данных. В современных версиях PostgreSQL (начиная с 9.0) он подключается по умолчанию при создании базы; в старых или специально очищенных базах может потребоваться `CREATE EXTENSION plpgsql;` (или эквивалент для вашей версии).
- **Привилегия USAGE** на язык plpgsql у текущей роли (или роль — суперпользователь, если язык недоверенный). Та же привилегия нужна для создания функции на этом языке.

Если при выполнении DO вы получаете ошибку вроде «language "plpgsql" does not exist», установите расширение или подключите язык вручную. Если ошибка «permission denied for language plpgsql», запросите у администратора привилегию USAGE.

В рамках одной транзакции блок DO не может выполнять операторы управления транзакциями (COMMIT/ROLLBACK); они допустимы только если DO выполняется в отдельной транзакции. Для первого блока это не требуется.

---

## Ключевое

- **DO $$ код $$;** — выполнение анонимного блока один раз; код задаётся строковым литералом, рекомендуется долларовые кавычки `$$`.
- Язык по умолчанию — **plpgsql**; при необходимости укажите `LANGUAGE plpgsql` до или после блока.
- Тело блока — структура **BEGIN ... END**; между ними операторы через точку с запятой; не ставить точку с запятой сразу после BEGIN.
- **RAISE NOTICE** выводит сообщение в клиент (в psql — в консоль); удобно для проверки выполнения.
- В psql: подключиться к базе, ввести или вставить DO-блок, выполнить; для установки нужен plpgsql и привилегия USAGE на язык.

В [§2.1](chapter-02-01.md) мы разберём полную структуру блока PL/pgSQL: метки, секция DECLARE и обработка исключений.
