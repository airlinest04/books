# §3.1 Условие IF

В [§2.4](chapter-02-04.md) мы завершили главу о блоках, переменных и присваивании. С этой главы переходим к **управляющим конструкциям** PL/pgSQL: условиям и циклам. В этом разделе разберём **условие IF** — ветвление по логическому выражению: формы IF ... THEN, IF ... THEN ... ELSE и IF ... THEN ... ELSIF ... ELSE, вложенные IF и замечания о NULL в условиях. CASE (выбор по значению или по условию) — в [§3.2](chapter-03-02.md). См. [Глоссарий](glossary.md).

---

## 3.1.1. IF ... THEN ... END IF

Самая простая форма: если логическое выражение истинно, выполняется блок операторов между THEN и END IF; иначе блок пропускается и выполнение продолжается после END IF. Синтаксис (по документации PostgreSQL):

```
IF логическое_выражение THEN
  операторы
END IF;
```

**Логическое выражение** — выражение типа boolean (сравнения, вызовы функций, возвращающих boolean, комбинации через AND, OR, NOT). Каждый оператор внутри блока заканчивается точкой с запятой; после END IF точка с запятой обязательна, так как END IF завершает оператор. См. [Глоссарий](glossary.md).

Пример:

```sql
IF v_user_id <> 0 THEN
  UPDATE users SET email = v_email WHERE user_id = v_user_id;
END IF;
```

Если `v_user_id` не равен 0, выполняется UPDATE; иначе управление переходит к следующему оператору после END IF.

---

## 3.1.2. IF ... THEN ... ELSE ... END IF

Форма с **ELSE** задаёт альтернативный блок: при истинном условии выполняется блок после THEN, при ложном (в том числе при NULL) — блок после ELSE. Синтаксис:

```
IF логическое_выражение THEN
  операторы
ELSE
  операторы
END IF;
```

Выполняется ровно одна из двух веток; затем управление переходит к оператору после END IF. В условии, равном NULL, результат трактуется как «не истина», поэтому выполняется ветка ELSE. См. [Глоссарий](glossary.md).

Пример:

```sql
IF parent_id IS NULL OR parent_id = '' THEN
  RETURN fullname;
ELSE
  RETURN hp_true_filename(parent_id) || '/' || fullname;
END IF;
```

---

## 3.1.3. IF ... THEN ... ELSIF ... ELSE ... END IF

Когда вариантов больше двух, удобна цепочка **ELSIF**: условия проверяются по порядку, выполняется блок первого истинного условия; если ни одно не истинно — блок **ELSE** (если он указан). Синтаксис:

```
IF логическое_выражение THEN
  операторы
[ ELSIF логическое_выражение THEN
  операторы
  [ ELSIF логическое_выражение THEN
    операторы
    ... ]
]
[ ELSE
  операторы ]
END IF;
```

Ключевое слово можно писать **ELSIF** или **ELSEIF**. После срабатывания одной ветки остальные условия не проверяются. См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL):

```sql
IF number = 0 THEN
  result := 'zero';
ELSIF number > 0 THEN
  result := 'positive';
ELSIF number < 0 THEN
  result := 'negative';
ELSE
  -- единственная оставшаяся возможность — number IS NULL
  result := 'NULL';
END IF;
```

Если ELSE нет и ни одно условие не истинно (все ложны или NULL), ни один блок не выполняется; управление переходит после END IF.

---

## 3.1.4. Вложенные IF

Любой из блоков THEN, ELSIF или ELSE может содержать **вложенный IF**: внутри него снова IF ... THEN ... END IF (или с ELSE, ELSIF). Каждый вложенный IF закрывается своим END IF. См. [Глоссарий](glossary.md).

Пример эквивалентной логики — вложенный IF вместо ELSIF:

```sql
IF demo_row.sex = 'm' THEN
  pretty_sex := 'man';
ELSE
  IF demo_row.sex = 'f' THEN
    pretty_sex := 'woman';
  END IF;
END IF;
```

При большом числе вариантов цепочка ELSIF обычно читается и сопровождается проще, чем глубокая вложенность IF. Рекомендуется не злоупотреблять вложенностью и при трёх и более ветках предпочитать ELSIF или CASE ([§3.2](chapter-03-02.md)).

---

## 3.1.5. Условие и значение NULL

Условие в IF должно иметь тип **boolean**. Если выражение даёт **NULL** (например, сравнение с NULL или результат функции NULL), оно не считается истинным: выполняется ветка ELSE (если есть) или блок пропускается. Для явной проверки на NULL используйте **IS NULL** / **IS NOT NULL** или конструкцию **IS DISTINCT FROM**. См. [Глоссарий](glossary.md).

Пример: проверка на NULL перед сравнением:

```sql
IF v_value IS NULL THEN
  RAISE NOTICE 'Значение не задано';
ELSIF v_value = 0 THEN
  RAISE NOTICE 'Ноль';
END IF;
```

Типичная ошибка — писать `IF v_value = NULL`: в SQL сравнение с NULL даёт NULL, а не true, поэтому такая ветка никогда не сработает. Нужно `IF v_value IS NULL`.

---

## Ключевое

- **IF условие THEN ... END IF** — выполнить блок только при истинном условии.
- **IF ... THEN ... ELSE ... END IF** — одна из двух веток выполняется всегда; при NULL в условии выполняется ELSE.
- **IF ... THEN ... ELSIF ... [ ELSIF ... ] [ ELSE ] ... END IF** — первое истинное условие выбирает ветку; ключевое слово ELSIF или ELSEIF; при отсутствии истинного условия выполняется ELSE или ничего.
- Вложенные IF допустимы; при многих ветках предпочтительнее ELSIF или CASE.
- В условиях используйте **IS NULL** / **IS NOT NULL** для проверки на NULL; выражение `= NULL` в условии даёт NULL и не даёт истины.

В [§3.2](chapter-03-02.md) мы разберём оператор CASE: выбор по значению и по условию.
