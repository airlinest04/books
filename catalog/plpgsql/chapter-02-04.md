# §2.4 Константы и параметры

В [§2.3](chapter-02-03.md) мы разобрали присваивание и SELECT ... INTO. В этом разделе закрепим понятие **константы** в DECLARE (переменная, которую нельзя менять после инициализации) и кратко упомянем **параметры** функций и процедур: откуда они появляются в блоке и как к ним обращаться. Подробно создание функций, виды параметров (IN, OUT, INOUT), значения по умолчанию и вызов — в гл. 5; здесь достаточно понимать, что параметры доступны внутри тела как готовые «входные переменные» и что константы задают неизменяемые значения в пределах блока. См. [Глоссарий](glossary.md).

---

## 2.4.1. Константы в DECLARE

**Константа** в PL/pgSQL — это объявление переменной с ключевым словом **CONSTANT**. Такая переменная получает начальное значение при входе в блок (через DEFAULT, := или =) и **не может быть целью присваивания** в теле блока: любая попытка присвоить ей новое значение приводит к ошибке. Смысл константы — дать именованное неизменяемое значение (магическое число, строку, дату) в одном месте и использовать его по имени в операторах. См. [Глоссарий](glossary.md).

Синтаксис тот же, что у переменной, но с CONSTANT и с **обязательным** начальным значением:

```
имя CONSTANT тип [ NOT NULL ] { DEFAULT | := | = } выражение;
```

Без начального значения объявление константы не имеет смысла (и при NOT NULL без значения будет ошибка). Выражение вычисляется при каждом входе в блок, как и для обычной переменной с DEFAULT.

Примеры:

```sql
DECLARE
  max_retries CONSTANT integer := 3;
  app_name CONSTANT text := 'MyApp';
  epoch CONSTANT timestamptz := '1970-01-01 00:00:00+00'::timestamptz;
BEGIN
  -- max_retries := 5;  -- ошибка: присваивание константе запрещено
  IF retry_count > max_retries THEN
    RAISE EXCEPTION 'Превышено число попыток %', max_retries;
  END IF;
END;
```

## 2.4.2. Когда использовать константы

Константы удобны, когда одно и то же значение используется в нескольких местах блока и не должно меняться по ходу выполнения: лимиты повторов, коды состояний, префиксы строк, фиксированные даты. Имя константы делает код читаемым и позволяет изменить значение в одном месте (при следующем входе в блок будет использовано новое выражение инициализации). См. [Глоссарий](glossary.md).

Типичные случаи:

- **Числовые пороги и лимиты:** `max_items CONSTANT int := 100;` — не разбрасывать «100» по коду.
- **Строковые метки и коды:** `status_done CONSTANT varchar(10) := 'DONE';` — единое имя для сравнений и вставок.
- **Временные границы:** константа с датой или интервалом для расчётов и проверок.

Если значение должно быть разным при разных вызовах функции, его задают **параметром**, а не константой.

## 2.4.3. Параметры функций и процедур: откуда они в блоке

Тело функции или процедуры на PL/pgSQL не объявляет параметры в DECLARE — они задаются в определении объекта (**CREATE FUNCTION** или **CREATE PROCEDURE**). Сигнатура функции перечисляет имя, тип и при необходимости режим (IN, OUT, INOUT) и значение по умолчанию. Внутри тела параметры доступны как готовые идентификаторы: по **позиции** — как `$1`, `$2`, … — или по **имени**, если имя указано в CREATE FUNCTION. См. [Глоссарий](glossary.md).

Пример (подробнее гл. 5):

```sql
CREATE FUNCTION discount(amount numeric, rate numeric DEFAULT 0.1)
RETURNS numeric AS $$
BEGIN
  RETURN amount * (1 - rate);
END;
$$ LANGUAGE plpgsql;
```

В теле доступны `amount` (или $1), `rate` (или $2); при вызове `discount(100)` параметр `rate` получит значение по умолчанию 0.1. Для совместимости с существующим кодом можно объявить в DECLARE **алиас** параметра: `имя ALIAS FOR $n;` — тогда внутри блока можно использовать осмысленное имя вместо номера. Параметры нельзя переприсвоить в режиме IN (в некоторых реализациях поведение может отличаться; в PostgreSQL IN-параметры ведут себя как константы в теле). Подробности — в гл. 5.

## 2.4.4. OUT-параметры и возвращаемое значение

Функция может иметь **OUT-** или **INOUT-**параметры: они объявляются в сигнатуре и в теле выступают как переменные, которым присваивают значение; итоговые значения OUT/INOUT возвращаются вызывающему. Функция может также возвращать значение через **RETURNS** (один тип или RECORD/TABLE/SETOF). Процедура не возвращает значение в выражении, но может возвращать несколько результатов через OUT-параметры; вызов — оператором **CALL**. Всё это разбирается в гл. 5 и 6; здесь важно лишь то, что параметры и возвращаемые значения задаются **вне** секции DECLARE блока — в определении функции или процедуры. См. [Глоссарий](glossary.md).

---

## Ключевое

- **Константа** — объявление с CONSTANT и обязательным начальным значением; в теле блока присваивание константе запрещено.
- Константы удобны для именованных неизменяемых значений (лимиты, коды, строки, даты) в пределах одного входа в блок.
- **Параметры** функций и процедур задаются в CREATE FUNCTION / CREATE PROCEDURE; в теле доступны по имени или как $1, $2, …; при необходимости — ALIAS FOR $n.
- OUT/INOUT и возвращаемое значение (RETURNS, CALL) подробно рассматриваются в гл. 5 и 6.
