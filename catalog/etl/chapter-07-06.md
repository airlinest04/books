# §7.6 Сравнительная таблица

В [§7.5](chapter-07-05.md) мы рассмотрели Neoflex Datagram. В этом разделе сводим четыре рассмотренных инструмента — **Talend**, **Informatica**, **Microsoft SSIS**, **Neoflex Datagram** — в сравнительную таблицу по возможностям, экосистеме и целевой аудитории. Сравнение опирается на материал §7.1–7.5 и носит обзорный характер; при выборе инструмента необходимо сверять актуальные версии, лицензии и перечень коннекторов с поставщиками. Этот раздел завершает главу 7; приложения книги — [Глоссарий](glossary.md) и список литературы. См. [Глоссарий](glossary.md).

---

## 7.6.1. Возможности и способ разработки

| Критерий | Talend | Informatica | Microsoft SSIS | Neoflex Datagram |
|----------|--------|-------------|---------------|------------------|
| **Способ разработки** | Визуальная студия, генерация кода (Java) | Визуальный Designer, маппинги и трансформации | Визуальный SSIS Designer (поток управления + поток данных) | Визуальные дизайнеры (трансформации, Workflow), генерация Scala/Python |
| **Коннекторы** | Сотни готовых, Component Kit для своих | Широкий набор к БД, файлам, приложениям | БД (OLE DB, ODBC, ADO.NET), файлы, Azure | CSV, Hive, Kafka, HDFS (ORC, Parquet), RDBMS по JDBC, файлы |
| **Масштаб выполнения** | Параллельное и распределённое выполнение | Масштабируемое выполнение, кластер | SQL Server, при необходимости Azure (ADF, SSIS IR) | Apache Spark, кластеры; оркестрация Airflow/Oozie |
| **Оркестрация** | Встроенные и внешние средства | Workflow в домене, облако IDMC | SQL Server Agent, Azure Data Factory | Внешняя: Airflow или Oozie |
| **Версионирование / CI/CD** | Git, CI/CD в коммерческих версиях | Репозиторий, облако с управлением | .ispac в SSISDB, PowerShell, скрипты развёртывания | Генерация кода в репозиторий, интеграция с Subversion |

## 7.6.2. Экосистема и лицензии

| Критерий | Talend | Informatica | Microsoft SSIS | Neoflex Datagram |
|----------|--------|-------------|----------------|------------------|
| **Платформа / вендор** | Qlik (Talend); облако и on-premise | Informatica; PowerCenter on-premise, IDMC в облаке | Microsoft; в составе SQL Server, Azure | Neoflex; on-premise, облако (в т.ч. Яндекс Облако) |
| **Лицензии** | Коммерческие (Studio, Cloud); открытая Open Studio более не распространяется | Коммерческие, enterprise-ориентированные | В составе лицензии SQL Server / Azure | Коммерческая подписка (по открытым источникам — в т.ч. от объёма потоков) |
| **Экосистема** | Интеграция с облаками, Git, каталог и подготовка данных в платформе | Единая платформа: каталог, качество, MDM, governance | SQL Server, Windows Server, Azure, Visual Studio | Spark, Hadoop, Airflow/Oozie; часть стека Neoflex Reporting Big Data Edition |

## 7.6.3. Целевая аудитория и когда что рассмотреть

| Инструмент | Типичная аудитория | Когда имеет смысл рассмотреть |
|------------|--------------------|------------------------------|
| **Talend** | Команды интеграции и аналитики, нуждающиеся в визуальной разработке и широком наборе коннекторов | Нужны визуальная среда, много коннекторов, готовность к коммерческой лицензии (Qlik/Talend); интеграция в DWH/озеро, миграции, подготовка данных |
| **Informatica** | Крупные организации (enterprise), централизованные команды управления данными | Требования к единой платформе интеграции, качества, каталога и governance; гибридное и облачное развёртывание; бюджет под enterprise-решение |
| **Microsoft SSIS** | Организации на стеке Microsoft (SQL Server, Windows, Azure) | Уже используется SQL Server; нужна тесная интеграция с SQL Server и Azure; развёртывание в ADF или на SQL Server; визуальные пакеты, поток управления и поток данных |
| **Neoflex Datagram** | Организации с фокусом на Big Data и российском стеке, проекты хранилищ и витрин на Spark/Hadoop | Нужны визуальная разработка поверх Spark, генерация Scala/Python, оркестрация Airflow/Oozie; on-premise или российское облако; замена или дополнение западных ETL-платформ |

Сопоставление требований конкретного кейса (источники, объёмы, частота, бюджет, навыки команды, ограничения по платформе) с строками таблицы помогает сузить круг кандидатов; финальный выбор и проверка лицензий — по актуальной информации поставщиков.

## Ключевое

- **Сравнение по возможностям:** все четыре инструмента поддерживают визуальную разработку; различаются среда исполнения (собственный движок, Spark, SQL Server), набор коннекторов, встроенная или внешняя оркестрация и модель лицензирования.
- **Экосистема:** Talend и Informatica — коммерческие платформы с облаком и расширенными возможностями; SSIS — часть экосистемы Microsoft; Datagram — опора на открытые компоненты (Spark, Airflow/Oozie) и российский поставщик.
- **Выбор:** ориентироваться на список источников и целей, масштаб данных, наличие SQL Server/Microsoft-стека, требования к governance и качеству, бюджет и готовность к поддержке; затем сверить с актуальными возможностями и лицензиями выбранных инструментов.
