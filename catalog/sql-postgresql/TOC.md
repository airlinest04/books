## Подробное содержание

### Глава 1. Введение в SQL и среда PostgreSQL

- **1.1 Что такое SQL** — язык запросов к реляционным БД; DDL, DML, DCL; стандарт и диалекты.
- **1.2 Установка и запуск PostgreSQL** — где взять, базовая установка (Linux/Windows/macOS); сервер и клиенты (psql, GUI).
- **1.3 Подключение к базе, создание базы и схемы** — `psql`, команды `\l`, `\c`, `\dt`; CREATE DATABASE, CREATE SCHEMA.
- **1.4 Первый запрос** — SELECT * FROM table; точка с запятой; регистр ключевых слов.
- *Ключевое:* что такое SQL, как подключиться к PostgreSQL. *Задания:* установка, создание базы, выполнение SELECT.

---

### Глава 2. Модель данных: таблицы, столбцы, типы, ключи

- **2.1 Таблицы и столбцы** — CREATE TABLE; имена таблиц и столбцов; кавычки и регистр.
- **2.2 Типы данных в PostgreSQL** — целые (SMALLINT, INTEGER, BIGINT), символы (VARCHAR, TEXT), числа (NUMERIC, REAL), даты и время (DATE, TIMESTAMP), логический (BOOLEAN), JSON и др.
- **2.3 Ограничения столбцов и таблиц** — NOT NULL, DEFAULT, UNIQUE, PRIMARY KEY, CHECK; внешний ключ (FOREIGN KEY) и ссылочная целостность.
- **2.4 Изменение структуры** — ALTER TABLE (ADD, DROP, RENAME столбец/таблицу).
- *Ключевое:* CREATE TABLE, типы, ключи и ограничения. *Задания:* создание таблиц по описанию, добавление ключей.

---

### Глава 3. Выборка данных (SELECT) и фильтрация (WHERE)

- **3.1 SELECT: список столбцов и псевдонимы** — выбор всех столбцов (*) и перечисление; AS для псевдонимов.
- **3.2 Выражения и функции в SELECT** — конкатенация, арифметика, функции (UPPER, LOWER, LENGTH, даты и т.д.).
- **3.3 WHERE: условия отбора** — сравнения (=, <>, <, >, BETWEEN, IN); логические AND, OR, NOT; IS NULL; шаблоны LIKE, ILIKE.
- **3.4 Уникальные значения** — DISTINCT; влияние на производительность.
- *Ключевое:* SELECT, WHERE, выражения. *Задания:* написание запросов с фильтрами по условиям.

---

### Глава 4. Соединение таблиц (JOIN)

- **4.1 Зачем нужны соединения** — связь данных из нескольких таблиц по ключам.
- **4.2 INNER JOIN** — только совпадающие строки; синтаксис ON; несколько JOIN в одном запросе.
- **4.3 LEFT (OUTER) JOIN, RIGHT JOIN, FULL JOIN** — сохранение строк без совпадения; NULL в отсутствующих полях.
- **4.4 Сравнение JOIN и подзапросов** — когда что читаемее и эффективнее.
- **4.5 Соединение таблицы с собой (self-join)** — примеры (иерархия, пары).
- *Ключевое:* INNER, LEFT/RIGHT/FULL JOIN, синтаксис ON. *Задания:* запросы с разными типами JOIN по заданной схеме.

---

### Глава 5. Сортировка, ограничение результатов, пейджинг

- **5.1 ORDER BY** — сортировка по одному и нескольким столбцам; ASC, DESC; NULLS FIRST/LAST.
- **5.2 LIMIT и OFFSET** — ограничение числа строк; пейджинг (страницы); нестабильность при отсутствии ORDER BY.
- **5.3 FETCH FIRST ... ROWS ONLY** — стандартный синтаксис как альтернатива LIMIT.
- *Ключевое:* ORDER BY, LIMIT, OFFSET. *Задания:* выборка N-й страницы с стабильным порядком.

---

### Глава 6. Манипулирование данными: INSERT, UPDATE, DELETE

- **6.1 INSERT** — вставка одной строки и нескольких; указание столбцов; RETURNING.
- **6.2 UPDATE** — обновление по условию WHERE; обновление нескольких столбцов; RETURNING.
- **6.3 DELETE** — удаление по условию; удаление всех строк (TRUNCATE — кратко).
- **6.4 Опасность без WHERE** — как случайно обновить/удалить всё; лучшие практики.
- **6.5 MERGE (UPSERT)** — INSERT ... ON CONFLICT (PostgreSQL); вставка или обновление в одном операторе (PostgreSQL 15+ MERGE — кратко).
- **6.6 Представления** — CREATE VIEW; материализованные представления (MATERIALIZED VIEW, REFRESH); когда использовать.
- **6.7 Массовая загрузка (COPY)** — команда COPY для загрузки и выгрузки данных из файла; форматы.
- *Ключевое:* INSERT, UPDATE, DELETE, RETURNING, VIEW, COPY. *Задания:* сценарии вставки/обновления/удаления по условиям.

---

### Глава 7. Групповые функции и GROUP BY

- **7.1 Агрегатные функции** — COUNT, SUM, AVG, MIN, MAX; поведение с NULL; COUNT(*) vs COUNT(column).
- **7.2 GROUP BY** — группировка по одному и нескольким столбцам; что можно выбирать в SELECT (только столбцы группы и агрегаты).
- **7.3 HAVING** — фильтрация по результатам агрегации (после GROUP BY).
- **7.4 Порядок выполнения** — FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
- *Ключевое:* агрегаты, GROUP BY, HAVING. *Задания:* запросы с группировкой и условиями HAVING.

---

### Глава 8. Ошибки при использовании групповых функций

- **8.1 Столбцы не из GROUP BY в SELECT** — типичная ошибка и сообщение PostgreSQL; как исправить (добавить в GROUP BY или агрегировать).
- **8.2 Фильтрация по агрегату в WHERE** — почему нельзя; перенос в HAVING.
- **8.3 Вложенные агрегаты** — где допустимы (в подзапросе, в выражении для HAVING).
- *Ключевое:* типичные ошибки и их исправление. *Задания:* исправление ошибочных запросов.

---

### Глава 9. Вложенные групповые функции в PostgreSQL

- **9.1 Подзапросы в FROM** — подзапрос как источник данных; псевдоним подзапроса; агрегация по результату подзапроса.
- **9.2 Подзапросы в SELECT и WHERE** — скалярный подзапрос; подзапрос в условии (IN, EXISTS, сравнения).
- **9.3 Вложенные агрегаты** — агрегат от результата агрегации через подзапрос; ограничения стандартного SQL и возможности PostgreSQL.
- *Ключевое:* подзапросы как таблица и как скаляр, вложенная агрегация. *Задания:* запросы с подзапросами и вложенными агрегатами.

---

### Глава 10. Работа с множествами (UNION, INTERSECT, EXCEPT)

- **10.1 UNION и UNION ALL** — объединение результатов двух запросов; совместимость по числу и типам столбцов; дубликаты (UNION убирает, UNION ALL сохраняет).
- **10.2 INTERSECT** — пересечение множеств строк.
- **10.3 EXCEPT** — разность множеств (строки из первого запроса, которых нет во втором).
- **10.4 Порядок выполнения и скобки** — при комбинировании нескольких операций.
- *Ключевое:* синтаксис UNION/INTERSECT/EXCEPT, отличия. *Задания:* запросы на объединение/пересечение/разность наборов.

---

### Глава 11. Транзакции и целостность чтения

- **11.1 Транзакция** — BEGIN, COMMIT, ROLLBACK; неявное завершение в psql.
- **11.2 Целостность чтения** — изоляция от других транзакций; уровень изоляции по умолчанию в PostgreSQL (READ COMMITTED).
- **11.3 Уровни изоляции** — READ COMMITTED, REPEATABLE READ, SERIALIZABLE; кратко про аномалии.
- *Ключевое:* BEGIN/COMMIT/ROLLBACK, уровни изоляции. *Задания:* сценарии с двумя сессиями и разными уровнями изоляции.

---

### Глава 12. Оконные функции

- **12.1 Зачем оконные функции** — расчёт без свёртки строк (в отличие от GROUP BY); каждая строка сохраняется, добавляется результат по «окну».
- **12.2 OVER ()** — окно по всей таблице/результату; PARTITION BY (разбиение на группы); ORDER BY внутри окна.
- **12.3 Ранжирование** — ROW_NUMBER(), RANK(), DENSE_RANK(); NTILE().
- **12.4 Смещение** — LAG(), LEAD(); FIRST_VALUE(), LAST_VALUE().
- **12.5 Агрегаты как оконные** — SUM() OVER (...), AVG() OVER (...); бегущая сумма, скользящее среднее.
- *Ключевое:* OVER, PARTITION BY, ORDER BY; типичные функции. *Задания:* запросы с ранжированием и смещением.

---

### Глава 13. CTE (обобщённые табличные выражения)

- **13.1 Синтаксис WITH ... AS** — именованный подзапрос в начале запроса; несколько CTE через запятую.
- **13.2 Читаемость и поддержка** — замена вложенных подзапросов на CTE.
- **13.3 Рекурсивные CTE** — базовый член и рекурсивный член; примеры (иерархия, числа).
- **13.4 CTE и изменение данных** — INSERT/UPDATE/DELETE с RETURNING и использованием в CTE (PostgreSQL).
- *Ключевое:* WITH ... AS, рекурсия. *Задания:* переписывание запросов с CTE, простой рекурсивный запрос.
