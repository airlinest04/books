# §3.1 SELECT: список столбцов и псевдонимы

В [§1.4](chapter-01-04.md) мы выполнили первый запрос `SELECT * FROM таблица` — выборку всех столбцов. На практике чаще нужны только часть столбцов или столбцы с другими именами в результате. В этом разделе мы разберём **список столбцов** в SELECT: звёздочка и перечисление, **псевдонимы (aliases)** через AS, полные имена столбцов при нескольких таблицах. Выражения и функции в SELECT рассматриваются в [§3.2](chapter-03-02.md); фильтрация через WHERE — в [§3.3](chapter-03-03.md). См. [документацию SELECT](https://www.postgresql.org/docs/current/sql-select.html).

---

## 3.1.1. Звёздочка: все столбцы

Выражение `*` в списке SELECT означает «все столбцы» источника из FROM:

```sql
SELECT * FROM users;
```

Возвращаются все столбцы таблицы `users` в порядке их определения в таблице. Имена столбцов в результате совпадают с именами в таблице.

При нескольких таблицах в FROM (например, при JOIN) `*` даёт все столбцы всех источников:

```sql
SELECT * FROM users JOIN orders ON users.id = orders.user_id;
```

Если в разных таблицах есть столбцы с одинаковым именем, в результате будет несколько столбцов с этим именем; для однозначности нужно использовать полные имена или псевдонимы. Подробнее о JOIN — в [гл. 4](chapter-04-01.md).

---

## 3.1.2. Перечисление столбцов

Вместо `*` можно указать нужные столбцы через запятую:

```sql
SELECT id, name, email FROM users;
```

В результате только эти столбцы и в указанном порядке. Это полезно, когда:

- не все столбцы нужны (меньше данных и трафика);
- порядок столбцов важен для приложения или отчёта;
- нужно избежать лишних столбцов (например, больших текстовых полей).

Порядок столбцов в списке SELECT определяет порядок в результате; он может отличаться от порядка в таблице.

---

## 3.1.3. Псевдонимы столбцов (AS)

Псевдоним задаёт имя столбца в результате. Синтаксис:

```sql
выражение [ AS ] имя_псевдонима
```

Ключевое слово `AS` опционально; в PostgreSQL оба варианта допустимы. См. [документацию](https://www.postgresql.org/docs/current/sql-select.html).

Примеры:

```sql
SELECT id, name AS user_name, email AS user_email FROM users;
SELECT id, name user_name, email user_email FROM users;
```

Оба запроса дают столбцы `user_name` и `user_email` в результате. Без псевдонима столбец называется так же, как в источнике (`name`, `email`).

Псевдоним нужен, когда:

- исходное имя длинное или неудобное;
- столбец — результат выражения или функции (без псевдонима имя может быть пустым или неудачным);
- нужно единообразие имён для приложения или отчёта.

---

## 3.1.4. Псевдоним для выражения

При использовании выражений псевдоним особенно важен — иначе столбец может получить сгенерированное имя или остаться без имени:

```sql
SELECT id, name || ' (' || email || ')' AS full_contact FROM users;
```

Столбец в результате называется `full_contact`. Подробнее о выражениях и функциях (например, `||` для конкатенации) — в [§3.2](chapter-03-02.md).

---

## 3.1.5. Кавычки в псевдонимах

Без кавычек псевдоним приводится к нижнему регистру. Для сохранения регистра, пробелов или спецсимволов используйте двойные кавычки:

```sql
SELECT name AS "User Name", email AS "E-Mail" FROM users;
```

Результат будет содержать столбцы с именами `User Name` и `E-Mail`. При обращении к таким столбцам в ORDER BY, GROUP BY и т.п. нужно использовать те же кавычки. Нестандартные имена усложняют запросы; применять только при необходимости (отчёты, интеграции).

---

## 3.1.6. Полные имена столбцов (таблица.столбец)

При нескольких таблицах в FROM столбец можно указать с именем таблицы:

```sql
SELECT users.id, users.name, orders.total
FROM users
JOIN orders ON users.id = orders.user_id;
```

Формат `таблица.столбец` (или `алиас.столбец`) устраняет неоднозначность, если столбцы с таким именем есть в нескольких таблицах. Подробнее о JOIN — в [§4.2](chapter-04-02.md).

---

## 3.1.7. Псевдонимы таблиц и столбцы

При задании псевдонима таблицы в запросе к её столбцам обращаются по этому псевдониму:

```sql
SELECT u.id, u.name, u.email
FROM users AS u;
```

Ключевое слово `AS` перед псевдонимом таблицы тоже можно опустить:

```sql
SELECT u.id, u.name FROM users u;
```

После объявления псевдонима оригинальное имя таблицы в этом запросе не используется — только псевдоним. Это нужно учитывать при использовании полных имён столбцов.

---

## 3.1.8. Смешение * и отдельных столбцов

В одном SELECT можно комбинировать `*` и явные столбцы, но в целом это не рекомендуется:

```sql
-- Работает, но * разворачивается в список столбцов на этапе разбора
SELECT *, id AS user_id FROM users;
```

При `*` и дополнительных столбцах `id` окажется в результате дважды (как `id` и как `user_id`). Для предсказуемости лучше явно перечислять нужные столбцы.

---

## 3.1.9. Дублирование и порядок столбцов

Один и тот же столбец можно указать несколько раз с разными псевдонимами:

```sql
SELECT id, name, name AS name_copy, id AS user_id FROM users;
```

В результате будет четыре столбца. Такая конструкция используется редко, в основном для отладки или специальных форматов вывода.

Порядок столбцов в списке SELECT полностью задаёт порядок столбцов в результате.

---

## 3.1.10. Сводка синтаксиса

| Конструкция | Пример | Описание |
|-------------|--------|----------|
| Все столбцы | `SELECT *` | Все столбцы источника |
| Список столбцов | `SELECT a, b, c` | Указанные столбцы в заданном порядке |
| Псевдоним | `SELECT a AS x` | Столбец `x` в результате |
| Псевдоним без AS | `SELECT a x` | То же |
| Полное имя | `SELECT t.a` | Столбец `a` из таблицы/алиаса `t` |

---

## 3.1.11. Типичные ошибки

- **Запятая перед FROM:** `SELECT id, name, FROM users` — лишняя запятая после последнего столбца вызывает ошибку.
- **Псевдоним как ключевое слово:** имена вроде `order`, `user`, `select` — ключевые слова; при использовании в качестве псевдонима брать в кавычки: `AS "order"`.
- **Путаница с `*` при JOIN:** `SELECT *` из нескольких таблиц возвращает все столбцы всех таблиц; при совпадении имён столбцов они дублируются. Лучше перечислять нужные столбцы явно.
- **Кавычки в псевдонимах:** псевдоним в кавычках сохраняет регистр; обращаться к нему в дальнейшем нужно с теми же кавычками.

---

## Ключевое

- **\*** — все столбцы источника; при нескольких таблицах — все столбцы всех источников.
- **Явный список** — перечисление столбцов через запятую; порядок в списке задаёт порядок в результате.
- **Псевдоним** — `выражение AS имя` или `выражение имя`; даёт имя столбцу в результате.
- **Полное имя** — `таблица.столбец` (или `алиас.столбец`) при нескольких таблицах.
- **Кавычки** в псевдониме сохраняют регистр и спецсимволы.
- В приложениях и отчётах обычно лучше явно перечислять столбцы, а не использовать `*`.
