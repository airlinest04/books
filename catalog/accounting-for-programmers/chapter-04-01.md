# §4.1 Обороты по дебету и кредиту

В [§3.4](chapter-03-04.md) мы разобрали типовые проводки и корреспонденции. Глава 4 связывает проводки с оборотно-сальдовой ведомостью и балансом: по проводкам считаются **обороты** за период и **сальдо** на дату. В этом разделе вы узнаете, что такое оборот по дебету и оборот по кредиту счёта за период, как они вычисляются из таблицы проводок и как задаются границы периода. Это основа для расчёта сальдо и построения отчётности в DWH.

---

## 4.1.1. Оборот за период: определение

**Оборот по счёту за период** — суммарная величина записей по этому счёту за выбранный интервал времени. Поскольку записи ведутся в двух сторонах (дебет и кредит), отдельно считают **оборот по дебету** и **оборот по кредиту** счёта. См. [Глоссарий](glossary.md).

- **Оборот по дебету счёта X** за период — сумма всех проводок, в которых счёт X указан по дебету (в колонке «дебет-счёт»), и только по тем проводкам, дата которых попадает в период.
- **Оборот по кредиту счёта X** за период — сумма всех проводок, в которых счёт X указан по кредиту (в колонке «кредит-счёт»), за тот же период.

Период задаётся датами начала и конца (например, с 1 по 31 января); включение границ (включительно/исключительно) нужно зафиксировать: обычно «дата проводки >= дата_начала AND дата проводки <= дата_конца» (включительно). Обороты за месяц, квартал, год — основа для оборотно-сальдовой ведомости и для отчёта о движении по счетам; без них нельзя рассчитать конечное сальдо за период (см. [§4.2](chapter-04-02.md)).

---

## 4.1.2. Расчёт оборотов по таблице проводок

В таблице проводок каждая строка содержит: дату, дебет-счёт, кредит-счёт, сумму (и при необходимости организацию, аналитику). Тогда для счёта X:

- **Оборот по дебету счёта X за период** = SUM(amount) по строкам, где account_debit = X и posting_date входит в период.
- **Оборот по кредиту счёта X за период** = SUM(amount) по строкам, где account_credit = X и posting_date входит в период.

Один и тот же счёт в разных проводках может фигурировать то в дебете, то в кредите; каждая проводка учитывается только один раз — в обороте по дебету, если X в дебете, или в обороте по кредиту, если X в кредите. Сумма оборотов по дебету по всем счетам за период равна сумме оборотов по кредиту по всем счетам (следствие двойной записи: каждая проводка даёт одну сумму в дебет одного счёта и одну в кредит другого).

---

## 4.1.3. Пример: обороты по счёту 51 за месяц

Пусть за январь по счёту 51 «Расчётные счета» были проводки:

| Дата | Дебет | Кредит | Сумма |
|------|-------|--------|-------|
| 05.01 | 51 | 62 | 100 000 |
| 10.01 | 60 | 51 | 30 000 |
| 15.01 | 51 | 66 | 200 000 |
| 20.01 | 70 | 51 | 80 000 |
| 25.01 | 51 | 62 | 50 000 |

Оборот по дебету 51 = 100 000 + 200 000 + 50 000 = **350 000** (поступления на счёт). Оборот по кредиту 51 = 30 000 + 80 000 = **110 000** (списания с счёта). Разница оборотов (350 000 − 110 000 = 240 000) при известном начальном сальдо даст конечное сальдо по активному счёту 51 (Ск = Сн + Од − Ок); расчёт сальдо — в [§4.2](chapter-04-02.md).

---

## 4.1.4. Обороты в разрезе аналитики

Если по счёту ведётся аналитика (контрагент, договор, подразделение), обороты можно считать не только по счёту в целом, но и **в разрезе** измерений. Тогда группировка идёт по полям: счёт, контрагент_id (и при необходимости договор_id, подразделение_id), период; в каждой группе — SUM по дебету и SUM по кредиту. См. [§2.3](chapter-02-03.md).

Пример: оборот по дебету счёта 60 по контрагенту A за январь — сумма проводок, где account_debit = 60 (или счёт начинается с 60 при учёте субсчетов), counterparty_id = A и дата в периоде. В витрине оборотов и сальдо строки будут вида: счёт, контрагент, период, оборот_дебет, оборот_кредит, сальдо_начало, сальдо_конец. Без аналитики в проводках такие обороты построить нельзя.

---

## 4.1.5. Период: границы и тип даты

Период задаётся двумя датами: **дата начала** и **дата окончания**. Проводка попадает в период, если дата проводки попадает в интервал [дата_начала; дата_окончания] при включённых границах (стандартный вариант). Важно согласовать с источником учёта:

- **По дате проводки** — дата, на которую операция проведена в учёте (учётная дата).
- **По дате документа** — дата первичного документа; в части систем обороты за период считаются по дате документа, в других — по дате проводки. При несовпадении выгрузки из DWH и отчёта из учётной системы нужно проверить, какая дата использована.

Для отчётности за месяц обычно берут период с первого по последнее число месяца; для квартала — с 1-го по последнее число квартала; для года — с 1 января по 31 декабря. Обороты за «текущий период с начала года» (нарастающим итогом) получают при дата_начала = 1 января отчётного года и дата_конца = текущая дата (или конец отчётного месяца).

---

## 4.1.6. Оборотно-сальдовая ведомость: обороты по всем счетам

**Оборотно-сальдовая ведомость (ОСВ)** за период — отчёт, в котором по каждому счёту (и при необходимости по субсчетам и аналитике) приведены: сальдо на начало периода, оборот по дебету, оборот по кредиту, сальдо на конец периода. Обороты по дебету и по кредиту считаются так, как описано выше; начальное и конечное сальдо — по правилам из [§4.2](chapter-04-02.md). В DWH ОСВ строят как витрину: группировка проводок по счёту (и по аналитике), расчёт оборотов и сальдо по каждой группе. Сверка ОСВ из DWH с ОСВ из учётной системы — один из основных способов проверить корректность загрузки и расчётов.

---

## 4.1.7. Типичные ошибки при расчёте оборотов

- **Включать в оборот проводки не за период:** фильтр по дате обязателен; иначе обороты за «январь» могут включить проводки других месяцев при ошибке в условии.
- **Учитывать одну проводку дважды:** счёт X в одной проводке может быть только либо в дебете, либо в кредите; сумма проводки попадает либо в оборот по дебету X, либо в оборот по кредиту X, но не в оба.
- **Путать оборот по дебету счёта с «суммой всех дебетов в системе»:** оборот по дебету счёта X — только те проводки, где X в дебете; общая сумма дебетов по всем проводкам за период равна общей сумме кредитов и считается по всем строкам без группировки по счёту.
- **Разные границы периода в источнике и в DWH:** если в источнике период «по дате документа», а в DWH считаем «по дате проводки», обороты за один и тот же месяц могут разойтись; нужно унифицировать правило.
- **Игнорировать организацию при многопрофильной выгрузке:** обороты за период должны считаться в разрезе организации (филиала), иначе данные разных юрлиц смешаются.

---

## Ключевое

- **Оборот по дебету счёта за период** — сумма проводок, где этот счёт в колонке «дебет», с датой проводки в периоде. **Оборот по кредиту счёта за период** — сумма проводок, где счёт в колонке «кредит», за тот же период.
- Расчёт по таблице проводок: SUM(amount) WHERE (account_debit = X AND posting_date IN период) — оборот по дебету X; SUM(amount) WHERE (account_credit = X AND posting_date IN период) — оборот по кредиту X.
- Период задаётся датами начала и конца; нужно зафиксировать включение границ и тип даты (дата проводки или дата документа) и согласовать с источником.
- Обороты можно считать в разрезе аналитики (контрагент, договор, подразделение), группируя проводки по счёту и по полям аналитики.
- Оборотно-сальдовая ведомость содержит по каждому счёту сальдо на начало, обороты по дебету и кредиту, сальдо на конец; обороты — основа для расчёта конечного сальдо.
- Сумма оборотов по дебету по всем счетам = сумма оборотов по кредиту по всем счетам (следствие двойной записи).

В [§4.2](chapter-04-02.md) мы разберём сальдо: начальное и конечное, формулы расчёта по активным и пассивным счетам, дебетовое и кредитовое сальдо.
