# §4.2 Сальдо: начальное, конечное

В [§4.1](chapter-04-01.md) мы разобрали обороты по дебету и кредиту счёта за период. Обороты — промежуточный шаг для получения **сальдо**: остатка по счёту на момент времени. В этом разделе вы узнаете, что такое начальное и конечное сальдо, как считается конечное сальдо по активным и пассивным счетам, что такое дебетовое и кредитовое сальдо и как получить сальдо на произвольную дату по проводкам. Это нужно для построения оборотно-сальдовой ведомости и баланса в DWH.

---

## 4.2.1. Сальдо: определение

**Сальдо** (остаток) по счёту — это разница между суммами, записанными по дебету и по кредиту счёта на определённый момент (на дату или на начало/конец периода). В зависимости от того, какая сторона больше, сальдо бывает **дебетовым** (сумма по дебету больше суммы по кредиту) или **кредитовым** (сумма по кредиту больше). На активном счёте нормальное сальдо — дебетовое, на пассивном — кредитовое; на активно-пассивном возможно и то и другое. См. [Глоссарий](glossary.md).

Сальдо на **начало периода** — остаток по счёту на момент непосредственно перед первым днём периода (или на конец предыдущего дня). Сальдо на **конец периода** — остаток на последний момент периода (например, на конец 31 января при периоде «январь»). Конечное сальдо за один период становится начальным сальдо для следующего периода.

---

## 4.2.2. Формулы конечного сальдо по типу счёта

Пусть по счёту за период известны: **Сн** — начальное сальдо, **Од** — оборот по дебету, **Ок** — оборот по кредиту. Конечное сальдо **Ск** зависит от типа счёта (см. [§2.2](chapter-02-02.md)).

**Активный счёт:** начальное сальдо дебетовое (или ноль). Формула:
\[
\text{Ск (дебетовое)} = \text{Сн} + \text{Од} - \text{Ок}.
\]
Если результат отрицательный, по строгой логике активного счёта это ошибка или счёт используется как активно-пассивный.

**Пассивный счёт:** начальное сальдо кредитовое (или ноль). Формула:
\[
\text{Ск (кредитовое)} = \text{Сн} + \text{Ок} - \text{Од}.
\]

**Активно-пассивный счёт:** можно считать отдельно «дебетовое сальдо» и «кредитовое сальдо», либо одно сальдо со знаком: Ск = (Сн_дебет − Сн_кредит) + (Од − Ок); положительное — актив (дебетовое), отрицательное — пассив (кредитовое). В витринах часто хранят два поля: сальдо_дебет и сальдо_кредит.

В коде и в SQL при расчёте сальдо по всем счетам тип счёта берут из справочника плана счетов; без него нельзя выбрать правильную формулу.

---

## 4.2.3. Начальное сальдо: откуда брать

Начальное сальдо на первый день периода — это сальдо на конец предыдущего периода. Варианты получения:

1. **Рекуррентно:** считать сальдо на конец каждого предыдущего периода по проводкам (начиная с «начала времён» или с даты начала учёта), затем конечное сальдо за предыдущий период принять за начальное для текущего. Для длинной истории это может быть трудоёмко без предрасчитанной витрины.
2. **Витрина «сальдо на дату»:** периодически (например, раз в месяц) сохранять срез сальдо по всем счетам на конец дня; начальное сальдо за следующий месяц брать из этого среза. Тогда обороты считают только за текущий период, а начальное сальдо подставляют из среза.
3. **Сальдо на дату «с нуля»:** для произвольной даты сальдо по счёту = сумма проводок по дебету с начала учёта по эту дату включительно минус сумма проводок по кредиту за тот же интервал (для активного счёта); для пассивного — наоборот. Так можно получить сальдо на любую дату без предрасчитанных срезов, но при большом объёме проводок запрос тяжелее.

При загрузке данных из учётной системы источник может отдавать уже рассчитанные «начальные сальдо на период»; тогда их можно загружать в DWH и использовать для проверки своих расчётов или как начальные значения для оборотов за период.

---

## 4.2.4. Сальдо на произвольную дату

**Сальдо на дату D** по счёту — остаток по счёту по состоянию на конец дня D (или на начало дня D+1), то есть по всем проводкам с датой <= D.

Алгоритм для активного счёта X:
- Оборот по дебету по дату D включительно: SUM(amount) WHERE account_debit = X AND posting_date <= D.
- Оборот по кредиту по дату D включительно: SUM(amount) WHERE account_credit = X AND posting_date <= D.
- Сальдо на дату D = Оборот_дебет − Оборот_кредит (для активного счёта).

Для пассивного счёта: Сальдо на дату D = Оборот_кредит − Оборот_дебет. Для активно-пассивного — либо два поля (дебетовое и кредитовое сальдо), либо одна величина со знаком.

Если «начало учёта» не с нуля, а с какой-то даты, в расчёт включают только проводки с датой >= даты начала учёта; при наличии в источнике входящего сальдо на эту дату его нужно прибавить к обороту по дебету (для активного) или по кредиту (для пассивного), в зависимости от стороны входящего сальдо.

---

## 4.2.5. Дебетовое и кредитовое сальдо в отчётах

В оборотно-сальдовой ведомости сальдо показывают в двух колонках: **сальдо по дебету** и **сальдо по кредиту**. По активному счёту в норме заполнена только колонка «дебет» (или «актив»), по пассивному — только «кредит» (или «пассив»). По активно-пассивному счёту могут быть заполнены обе колонки: дебетовое сальдо (актив) в одной колонке, кредитовое (пассив) в другой. В балансе дебетовое сальдо идёт в актив, кредитовое — в пассив; по одному счёту в балансе может быть и та и другая часть (например, по счёту 76 — отдельно дебиторская и отдельно кредиторская задолженность).

При хранении в DWH витрины «обороты и сальдо» удобно иметь поля: сальдо_дебет, сальдо_кредит (или сальдо_начало_дебет, сальдо_начало_кредит, сальдо_конец_дебет, сальдо_конец_кредит). Тогда при построении баланса и отчётов не нужно заново определять знак: дебетовое сальдо — в актив, кредитовое — в пассив.

---

## 4.2.6. Входящее сальдо при первой загрузке

При первой загрузке исторических данных в DWH или при подключении нового источника за период до первой проводки может существовать **входящее сальдо** (остатки на дату начала загрузки). Его нужно либо получить из учётной системы (выгрузка остатков на дату) и загрузить в витрину начальных сальдо, либо смоделировать как «нулевую» проводку или отдельную таблицу входящих остатков. Без входящего сальдо расчёт сальдо по проводкам даст остаток только от операций после даты начала данных; для отчётности за период, включающий дату начала, начальное сальдо должно быть задано. Типичный формат выгрузки входящих остатков: счёт, дата, сальдо_дебет, сальдо_кредит (или одна сумма со знаком и признаком стороны), при необходимости аналитика.

---

## 4.2.7. Типичные ошибки при расчёте сальдо

- **Одна формула для всех счетов:** использовать «Сн + Од − Ок» для пассивных счетов даёт неверное (отрицательное или неверное по смыслу) сальдо; формула должна зависеть от типа счёта из справочника.
- **Не учитывать начальное сальдо:** считать конечное сальдо только как «Од − Ок» без Сн — верно только при нулевом начальном сальдо; для периодов не с начала учёта начальное сальдо обязательно.
- **Путать сальдо на начало и на конец периода:** начальное сальдо периода N = конечное сальдо периода N−1; при построении ОСВ за месяц начальное — на 1-е число, конечное — на последнее число месяца.
- **Считать сальдо на дату без фильтра по дате:** в расчёт должны входить только проводки с датой <= целевой даты; иначе в сальдо попадут будущие проводки.
- **Игнорировать активно-пассивные счета:** хранить только одно поле «сальдо» со знаком — при отнесении к активи/пассиву можно потерять часть (например, показывать только дебиторскую задолженность и терять кредиторскую); лучше хранить дебетовое и кредитовое сальдо отдельно.

---

## Ключевое

- **Сальдо** — остаток по счёту на момент времени; бывает дебетовым (актив) и кредитовым (пассив). Начальное сальдо периода — остаток на начало периода; конечное — на конец периода; конечное за период N становится начальным для периода N+1.
- **Формулы конечного сальдо:** активный счёт Ск = Сн + Од − Ок (дебетовое); пассивный Ск = Сн + Ок − Од (кредитовое). Активно-пассивный — два поля (сальдо по дебету и по кредиту) или одно со знаком. Тип счёта берут из справочника.
- **Начальное сальдо** получают как конечное за предыдущий период, из витрины срезов «сальдо на дату» или пересчётом по всем проводкам с начала учёта по дату начала периода; при первой загрузке — из выгрузки входящих остатков из источника.
- **Сальдо на произвольную дату:** обороты по дебету и по кредиту по проводкам с датой <= D, затем по формулам в зависимости от типа счёта.
- В отчётах и в DWH сальдо удобно хранить в двух полях (сальдо_дебет, сальдо_кредит) для однозначного отнесения к активи и пассиву баланса.
- При расчёте сальдо обязательно: фильтр по дате, учёт начального сальдо, разная формула для активных и пассивных счетов.

В [§4.3](chapter-04-03.md) мы разберём бухгалтерский баланс: актив и пассив, равенство актива и пассива и связь счетов со статьями баланса.
