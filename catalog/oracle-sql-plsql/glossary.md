# Глоссарий: Oracle SQL и PL/SQL

Краткие определения терминов, вводимых в книге. При первом появлении в разделе термин раскрывается в тексте; здесь даётся сводка для справки.

---

**%ROWTYPE** — анкерный тип в PL/SQL: переменная-запись с полями, совпадающими по имени и типу со столбцами строки таблицы/представления или курсора. Обращение: запись.имя_столбца. См. §9.2.

**%TYPE** — анкерный тип в PL/SQL: тип переменной совпадает с типом столбца таблицы/представления или другой переменной. Синтаксис: переменная таблица.столбец%TYPE. См. 
§9.2.

**(+)** — старый синтаксис Oracle для внешнего соединения в WHERE: (+) у столбца таблицы, со стороны которой допускается отсутствие совпадения (LEFT JOIN — (+) справа). 
Рекомендуется использовать JOIN ... ON. См. §4.1.

**ALL / ANY (SOME)** — сравнение с подзапросом, возвращающим несколько значений: ALL — со всеми, ANY — хотя бы с одним. См. §4.2.

**ALTER TABLE** — оператор SQL для изменения структуры таблицы: ADD (столбец), DROP COLUMN, MODIFY (столбец), RENAME COLUMN, ADD CONSTRAINT, DROP CONSTRAINT. См. §2.4.

**BETWEEN a AND b** — условие: значение в диапазоне [a, b] включительно. См. §3.2.

**BLOB** (Binary Large Object) — тип для больших бинарных данных; тот же максимум, что у CLOB. См. §2.2.

**CASE (в PL/SQL)** — оператор ветвления: простой CASE (CASE выражение WHEN значение THEN ...) или поисковый (CASE WHEN условие THEN ...); необязательный ELSE; завершение 
END CASE; при отсутствии совпадения без ELSE — CASE_NOT_FOUND. См. §10.2.

**CHAR [(size)]** — тип символьной строки фиксированной длины; дополняется пробелами; по умолчанию 1, максимум 2000. См. §2.2.

**CHECK** — ограничение: условие (логическое выражение), которому должна удовлетворять каждая строка. Без подзапросов и недетерминированных функций. См. §2.3.

**CLOB** (Character Large Object) — тип для большого символьного текста; максимум (4 ГБ − 1) × размер_блока. См. §2.2.

**COMMIT** — команда завершения транзакции с сохранением всех изменений; после COMMIT откат невозможен. См. §8.1.

**CONNECT** — предопределённая роль Oracle; в 10.2 и позже по сути содержит только CREATE SESSION (и SET CONTAINER в 12.1+). См. §1.2.

**CONNECT BY** — предложение Oracle для иерархического запроса: задаёт связь родитель–потомок. Используется с START WITH (корневые строки) и PRIOR (столбец со стороны 
родителя). См. §7.3.

**Connect descriptor** — описание адреса и службы для подключения (протокол, хост, порт, SERVICE_NAME или SID). См. §1.2.

**CONTINUE** — в PL/SQL (11g+): переход к следующей итерации текущего цикла. CONTINUE WHEN условие — при истинном условии. С меткой — переход к итерации помеченного 
цикла. См. §10.4.

**CREATE SESSION** — привилегия Oracle, дающая право подключаться к базе данных. Минимально необходима для входа. См. §1.2.

**CREATE TABLE** — оператор SQL для создания таблицы в схеме; задаёт имя таблицы и список столбцов с типами данных. См. §2.1.

**CTE** (Common Table Expression) — именованный подзапрос в начале запроса: WITH имя AS (подзапрос). В основном запросе к результату обращаются по имени (как к таблице). 
Несколько CTE — через запятую. См. §7.1.

**CURRVAL** — псевдостолбец последовательности: возвращает последнее значение, выданное NEXTVAL в текущей сессии. Допустим только после хотя бы одного вызова NEXTVAL в 
сессии. См. §2.5.

**DATE** — тип даты и времени в Oracle (7 байт); год, месяц, день, час, минута, секунда; без дробных секунд и часового пояса. См. §2.2.

**DELETE** — оператор SQL для удаления строк из таблицы. Синтаксис: DELETE FROM таблица [WHERE условие]. Без WHERE удаляются все строки. В WHERE допустимы подзапросы. 
DML; откат через ROLLBACK до COMMIT. См. §5.3.

**DISTINCT** — ключевое слово в SELECT: устраняет дубликаты строк в результате; уникальность по всей строке (по всем выбранным столбцам и выражениям). См. §3.3.

**DUAL** — служебная однострочная таблица Oracle для выполнения SELECT выражений без обращения к пользовательским таблицам. См. §3.1.

**Easy Connect** — способ задания подключения к Oracle без tnsnames.ora: строка вида `host[:port][/service_name]`. Подходит для TCP/IP. См. §1.2.

**EXISTS (подзапрос)** — условие: истинно, если подзапрос вернул хотя бы одну строку. NOT EXISTS — истинно, если не вернул ни одной. Часто с коррелированным подзапросом. 
См. §4.2.

**EXPLAIN PLAN** — команда Oracle: построить план выполнения запроса без его выполнения; результат записывается в таблицу планов (PLAN_TABLE). Просмотр: DBMS_XPLAN.
DISPLAY. См. §8.4.

**FETCH FIRST** — предложение Oracle 12c и новее: ограничение числа возвращаемых строк после ORDER BY. Синтаксис: FETCH FIRST n ROWS ONLY (или WITH TIES, или n PERCENT 
ROWS). См. §3.4.

**FOREIGN KEY** — ограничение внешнего ключа: значения столбца(ов) должны совпадать с первичным или уникальным ключом родительской таблицы (или быть NULL). REFERENCES 
задаёт родительскую таблицу и столбцы. ON DELETE CASCADE / SET NULL — поведение при удалении родительской строки. См. §2.3.

**GROUP BY** — предложение SQL: разбиение строк на группы по значениям указанных столбцов или выражений; в списке SELECT допускаются только столбцы из GROUP BY и 
групповые функции. См. §6.1.

**HAVING** — предложение SQL: фильтрация групп после группировки (GROUP BY). В отличие от WHERE фильтрует не отдельные строки, а целые группы. См. §6.1.

**IF (в PL/SQL)** — условный оператор: IF условие THEN операторы [ELSIF условие THEN операторы] [ELSE операторы] END IF; выполняется первая ветка с истинным условием. См. 
§10.1.

**IN (список)** — условие: значение равно одному из перечисленных. NOT IN — не равно ни одному (учёт NULL в списке). См. §3.2.

**INSERT** — оператор SQL для вставки строк в таблицу. INSERT ... VALUES — одна строка; INSERT ... SELECT — вставка из результата запроса (одна или много строк). См. §5.1.

**INTERSECT** — операция над множествами строк: только строки, которые есть в результатах обоих SELECT. См. §7.2.

**IS NULL / IS NOT NULL** — условия проверки на пустое (NULL) или непустое значение. Сравнение с NULL через = или <> не даёт TRUE. См. §3.2.

**JOIN** — соединение таблиц по условию. **INNER JOIN** — только совпадающие строки; **LEFT OUTER JOIN** — все строки левой таблицы, при отсутствии совпадения справа 
NULL; **RIGHT OUTER JOIN** — то же для правой; **FULL OUTER JOIN** — все строки обеих таблиц. Условие задаётся в **ON**. См. §4.1.

**LEVEL** — псевдостолбец в иерархическом запросе Oracle: номер уровня глубины (1 — корень, 2 — потомки первого уровня и т.д.). См. §7.3.

**LIKE шаблон** — условие частичного совпадения строки; % — любое число символов, _ — один символ. ESCAPE для экранирования % и _. См. §3.2.

**LISTAGG** — групповая/оконная функция Oracle: объединяет значения столбца (выражения) из нескольких строк в одну строку с заданным разделителем. LISTAGG(expr, sep) 
WITHIN GROUP (ORDER BY ...). См. §6.3.

**LOB** (Large Object) — общее название типов больших объектов в Oracle: CLOB, BLOB, NCLOB, BFILE. См. §2.2.

**LOWER(строка)** — функция Oracle: возвращает строку в нижнем регистре. См. §3.1.

**MERGE** — оператор SQL (DML) для слияния данных: по условию ON для каждой строки источника выполняется либо UPDATE в целевой таблице (WHEN MATCHED), либо INSERT (WHEN 
NOT MATCHED). Используется для загрузки и синхронизации (upsert). См. §5.4.

**MINUS** — операция над множествами строк: строки из первого SELECT, которых нет во втором. Порядок запросов важен. См. §7.2.

**NEXTVAL** — псевдостолбец последовательности: возвращает следующее значение и сдвигает счётчик. Обращение: имя_последовательности.NEXTVAL. Используется в INSERT и 
SELECT. См. §2.5.

**NOT NULL** — ограничение: столбец не может содержать NULL. Объявляется только в строке столбца (inline). См. §2.3.

**NTH_VALUE** — оконная функция Oracle: возвращает значение выражения из N-й строки в окне (по ORDER BY в OVER). NTH_VALUE(expr, n) [FROM FIRST | FROM LAST]. См. §6.3.

**NUMBER [(p [, s])]** — тип данных Oracle для чисел с точностью p (1–38) и масштабом s (-84..127). Без параметров — произвольная точность в пределах хранения. См. §2.2.

**NVL(выражение, значение_если_NULL)** — функция Oracle: возвращает второй аргумент, если первый NULL, иначе первый. См. §3.1.

**NVL2(выражение, если_не_NULL, если_NULL)** — функция Oracle: возвращает второй аргумент при не-NULL первом, иначе третий. См. §3.1.

**OFFSET** — в предложении ограничения строк (Oracle 12c+): пропустить указанное число строк перед FETCH FIRST. Записывается перед FETCH FIRST после ORDER BY. См. §3.4.

**ON** — предложение в JOIN: задаёт условие соединения таблиц (например, table1.col = table2.col). См. §4.1.

**Oracle Database** — реляционная СУБД корпорации Oracle; серверная система хранения и обработки данных, поддержка SQL и PL/SQL. См. §1.1.

**Oracle Net** (ранее SQL*Net) — сетевой протокол/слой Oracle для установления соединения между клиентом и сервером Oracle Database (хост, порт, service name / SID).

**Oracle Net Listener** (listener) — процесс на сервере, принимающий входящие подключения клиентов по сети и перенаправляющий их к экземпляру базы данных. По умолчанию 
слушает порт 1521. См. §1.2.

**Oracle SQL Developer** — бесплатная графическая среда разработки Oracle для выполнения SQL и PL/SQL, просмотра объектов схемы, отладки. См. §1.1.

**OVER** — предложение оконной функции: задаёт партиции (PARTITION BY), порядок (ORDER BY) и при необходимости кадр (ROWS/RANGE BETWEEN). См. §6.2.

**PARTITION BY** (в окне) — в предложении OVER: разбиение строк на партиции; оконная функция вычисляется отдельно внутри каждой партиции. См. §6.2.

**PL/SQL** — процедурное расширение SQL в Oracle: блоки с DECLARE, BEGIN, EXCEPTION, END; переменные, условия, циклы; процедуры, функции, триггеры, пакеты. Выполняется на 
сервере. См. §9.1.

**PRIMARY KEY** — ограничение первичного ключа: уникальность и запрет NULL для столбца(ов); в таблице один. Oracle создаёт уникальный индекс. См. §2.3.

**READ COMMITTED** — уровень изоляции: видны только закоммиченные данные других транзакций; грязное чтение исключено; возможны неповторяемое и фантомное чтение. См. §8.2.

**RESOURCE** — предопределённая роль Oracle: привилегии на создание объектов в своей схеме (CREATE TABLE, CREATE SEQUENCE, CREATE PROCEDURE и др.) и UNLIMITED TABLESPACE. 
См. §1.2.

**RETURNING INTO** — предложение в INSERT/UPDATE/DELETE (в PL/SQL): возвращает значения указанных столбцов вставленной/обновлённой/удалённой строки в переменные. Для 
нескольких строк — BULK COLLECT INTO. См. §5.1.

**ROLLBACK** — команда отмены текущей транзакции: все незакоммиченные изменения отменяются. См. §8.1.

**ROWNUM** — псевдостолбец Oracle: порядковый номер строки в наборе результатов (1, 2, …). Присваивается до ORDER BY. Используется для ограничения числа строк (WHERE 
ROWNUM <= N). Для «топ-N по сортировке» до 12c — подзапрос с ORDER BY и ROWNUM снаружи. См. §3.4.

**SAVEPOINT** — именованная точка внутри транзакции. ROLLBACK TO SAVEPOINT имя откатывает все изменения после этой точки, не завершая транзакцию. См. §8.3.

**SELECT** — оператор SQL для выборки данных из таблиц и представлений; возвращает набор строк (result set). Минимальная форма: SELECT * FROM имя_таблицы; Список 
столбцов, выражения, псевдонимы, функции — §3.1. См. §1.4.

**SELECT INTO** — в PL/SQL: выполнить SELECT и поместить ровно одну строку результата в перечисленные переменные (или в запись %ROWTYPE). При нуле строк — NO_DATA_FOUND, 
при нескольких — TOO_MANY_ROWS. См. §9.3.

**SERIALIZABLE** — уровень изоляции: транзакция видит снимок данных на момент своего начала; неповторяемое и фантомное чтение исключены; при конфликте записи — ORA-08177. 
См. §8.2.

**Service name** — имя службы (службы подключения) в Oracle Net; используется в строке подключения при подключении к базе (в т.ч. через listener). См. §1.1, §1.2.

**SID** (System Identifier) — идентификатор экземпляра Oracle; в ряде конфигураций используется для подключения вместо service name.

**SQL*Plus** — консольный клиент Oracle для выполнения SQL и PL/SQL, запуска скриптов, вывода результатов в терминал. См. §1.1.

**START WITH** — предложение иерархического запроса Oracle: условие отбора корневых строк, с которых начинается обход дерева. См. §7.3.

**TIMESTAMP [(p)]** — тип даты и времени с дробными секундами (p — 0–9 цифр). Варианты: WITH TIME ZONE, WITH LOCAL TIME ZONE. См. §2.2.

**TNS** (Transparent Network Substrate) / локальный способ имён — задание подключения через сетевое имя и файл tnsnames.ora, где имя сопоставлено с connect descriptor. 
См. §1.2.

**tnsnames.ora** — файл конфигурации Oracle Net с сетевыми именами и соответствующими connect descriptor (хост, порт, SERVICE_NAME или SID). См. §1.2.

**TO_CHAR** — функция Oracle: преобразование даты/времени или числа в строку по заданному формату. См. §3.1.

**TO_DATE(строка [, формат])** — функция Oracle: преобразование строки в тип DATE по формату. Рекомендуется указывать формат явно. См. §3.1.

**TRUNCATE TABLE** — команда DDL: полная очистка таблицы (все строки удаляются без условия WHERE). Обычно не откатывается; освобождает место; быстрее DELETE при полной 
очистке. См. §5.3.

**UNION** — операция над множествами строк: объединение результатов двух SELECT с удалением дубликатов. Оба запроса должны иметь одинаковое число совместимых по типу 
столбцов. См. §7.2.

**UNION ALL** — объединение результатов двух SELECT без удаления дубликатов. См. §7.2.

**UNIQUE** — ограничение уникальности значений в столбце(ах); NULL допускается. См. §2.3.

**UPDATE** — оператор SQL для изменения значений столбцов в существующих строках таблицы. Синтаксис: UPDATE таблица SET столбец = выражение [WHERE условие]. В SET 
допустим скалярный подзапрос; в WHERE — подзапросы (IN, EXISTS и т.д.). См. §5.2.

**UPPER(строка)** — функция Oracle: возвращает строку в верхнем регистре. См. §3.1.

**USER_* / ALL_* / DBA_*** ** — префиксы имён представлений словаря данных: USER_* — объекты своей схемы; ALL_* — объекты, доступные текущему пользователю (есть столбец 
OWNER); DBA_* — все объекты базы (требуются привилегии DBA). См. §1.3.

**VARCHAR** — устаревший/не рекомендуемый в Oracle тип; документация рекомендует использовать VARCHAR2. Семантика VARCHAR может измениться в будущих версиях. См. §2.2.

**VARCHAR2 (size [BYTE|CHAR])** — тип символьной строки переменной длины; size до 4000 (STANDARD) или 32767 (EXTENDED). Рекомендуемый тип для текста переменной длины в 
Oracle. См. §2.2.

**WHERE** — предложение SQL, задающее условие отбора строк в SELECT, UPDATE, DELETE. В результат попадают только строки, для которых условие истинно. См. §3.2.

**WITH** — предложение SQL для объявления CTE: WITH имя AS (подзапрос) [, имя2 AS (...)] основной_запрос. См. §7.1.

**Автономная транзакция** — транзакция подпрограммы PL/SQL, независимая от транзакции вызывающего. Задаётся PRAGMA AUTONOMOUS_TRANSACTION; COMMIT/ROLLBACK внутри не 
затрагивают основную транзакцию. См. §13.4.

**Блок PL/SQL** — минимальная единица выполнения PL/SQL: необязательная секция DECLARE, обязательные BEGIN и END, необязательная EXCEPTION. Анонимный блок не сохраняется 
в базе; именованный — в процедуре, функции, триггере, пакете. См. §9.1.

**Блок данных (data block, Oracle block)** — минимальная единица ввода-вывода в Oracle; размер задаётся параметром DB_BLOCK_SIZE (часто 4 KB или 8 KB).

**Встроенное представление (inline view)** — подзапрос в предложении FROM; результат подзапроса используется как источник строк (как таблица). В Oracle для такого 
подзапроса обязателен псевдоним. См. §4.3.

**Групповые функции** (агрегатные функции) — функции, вычисляемые по набору строк (по группе): COUNT, SUM, AVG, MIN, MAX и др. В SELECT с GROUP BY допустимы только 
столбцы из GROUP BY и групповые функции. См. §6.1.

**Идентификатор (identifier)** — имя объекта (таблицы, столбца, представления и т.д.) в Oracle. Некавычковый — хранится в верхнем регистре, до 30 байт; кавычковый — в 
двойных кавычках, сохраняет регистр. См. §2.1.

**Именованная передача параметров** — вызов процедуры/функции с указанием аргументов в виде имя_параметра => значение; порядок произвольный, можно опускать параметры с 
значением по умолчанию. См. §11.3.

**Исключение (exception)** — в PL/SQL: условие ошибки, прерывающее выполнение; перехват в секции EXCEPTION (WHEN имя THEN ... WHEN OTHERS THEN ...). Предопределённые: 
NO_DATA_FOUND, TOO_MANY_ROWS и др. Пользовательское: DECLARE имя EXCEPTION; RAISE имя; PRAGMA EXCEPTION_INIT — привязка к коду ORA. См. §13.3.

**Кавычковый идентификатор (quoted identifier)** — идентификатор в двойных кавычках; сохраняет точный регистр; при обращении к объекту кавычки обязательны. См. §2.1.

**Каталог данных (data dictionary)** — системные таблицы и представления Oracle с метаданными о базе (объекты, столбцы, привилегии и т.д.). Доступ через представления 
USER_*, ALL_*, DBA_*. См. §1.3.

**Коррелированный подзапрос** — подзапрос, ссылающийся на столбцы внешнего запроса; логически выполняется для каждой строки внешней таблицы. См. §4.2.

**Курсор (cursor)** — в PL/SQL: указатель на результат запроса SELECT для построчного чтения. Явный курсор: DECLARE CURSOR ... IS SELECT ... ; OPEN; FETCH INTO ... ; 
CLOSE. Атрибуты: %NOTFOUND, %FOUND, %ROWCOUNT. См. §13.1.

**Курсорная переменная (REF CURSOR)** — переменная типа REF CURSOR (например, SYS_REFCURSOR): запрос привязывается в runtime через OPEN переменная FOR SELECT ... ; FETCH 
и CLOSE как у явного курсора. Можно передавать в подпрограммы. См. §13.2.

**Материализованное представление** — объект Oracle, хранящий результат запроса как данные; обновляется по REFRESH (COMPLETE, FAST, FORCE; ON DEMAND или ON COMMIT). 
Используется для ускорения тяжёлых запросов при допустимой задержке актуальности. См. §7.4.

**Ограничение (constraint)** — правило целостности данных в Oracle: NOT NULL, PRIMARY KEY, UNIQUE, CHECK, FOREIGN KEY. Задаётся в CREATE TABLE или ALTER TABLE; можно 
именовать через CONSTRAINT имя. См. §2.3.

**Оконная функция** — функция с предложением OVER, задающим окно (набор строк) для расчёта. Строки не группируются: каждая строка результата сохраняется и получает 
значение функции по своему окну. См. §6.2.

**Пакет (package)** — объект схемы Oracle: спецификация (CREATE PACKAGE) с объявлением подпрограмм и публичных объектов и тело (CREATE PACKAGE BODY) с реализацией. Вызов 
подпрограмм: имя_пакета.имя_процедуры(аргументы). См. §11.4, §12.2.

**Перегрузка (в пакете)** — в одном пакете несколько процедур или функций с одним именем и разными сигнатурами (число или типы параметров). При вызове выбирается версия 
по фактическим аргументам. В standalone-подпрограммах перегрузка недоступна. См. §12.3.

**Подзапрос (subquery)** — вложенный запрос SELECT в скобках внутри другого запроса. В WHERE возвращает значения для сравнения (скаляр, список для IN, предикат для 
EXISTS). См. §4.2.

**Пользователь (user)** — учётная запись для входа в Oracle Database; владелец одноимённой схемы и объектов в ней. См. §1.1.

**Последовательность (sequence)** — объект схемы, генерирующий последовательные числовые значения (NEXTVAL, CURRVAL); часто используется для первичных ключей. Создаётся 
через CREATE SEQUENCE. См. §1.3, §2.5.

**Представление (VIEW)** — именованный сохранённый запрос SELECT; при обращении выполняется запрос над базовыми таблицами, результат возвращается как «виртуальная 
таблица». CREATE VIEW ... AS подзапрос; WITH READ ONLY, WITH CHECK OPTION. См. §1.3, §7.4.

**Привилегия (privilege)** — право выполнять определённое действие в Oracle (подключиться, создать таблицу, выбрать из таблицы и т.д.). См. §1.2.

**Процедура (procedure)** — именованная подпрограмма PL/SQL, сохранённая в базе: CREATE PROCEDURE имя (параметры IN/OUT/IN OUT) AS ... BEGIN ... END; вызывается по имени 
с передачей аргументов; не возвращает значение в выражение. См. §11.1.

**Псевдоним (alias)** — имя для столбца или выражения в результате запроса. Задаётся через AS или сразу после выражения; с пробелами/регистром — в двойных кавычках. См. 
§3.1.

**Псевдоним таблицы (table alias)** — короткое имя таблицы в запросе (например, o для orders); используется для однозначного указания столбца: псевдоним.столбец. См. §4.1.

**Роль (role)** — именованный набор привилегий; пользователю выдают роль, и он получает все входящие в неё привилегии. См. §1.2.

**СУБД** — система управления базами данных.

**Сегмент (segment)** — объект хранения в Oracle (таблица, индекс и т.п.), занимающий место в табличном пространстве; состоит из одного или нескольких экстентов.

**Синоним (synonym)** — альтернативное имя для объекта (таблицы, представления, последовательности и т.д.); может ссылаться на объект своей или другой схемы. См. §1.3.

**Скалярный подзапрос** — подзапрос, возвращающий ровно одно значение (одна строка, один столбец). Используется в сравнениях в WHERE (=, <, > и т.д.) и в списке SELECT 
как столбец. При нескольких строках — ошибка. См. §4.2, §4.4.

**Строка подключения (connect string)** — параметры, задающие, куда подключаться: хост, порт, имя службы (или сетевое имя из tnsnames.ora). См. §1.2.

**Схема (schema)** — совокупность объектов базы данных (таблицы, представления, процедуры и т.д.), принадлежащих одному пользователю. В Oracle имя схемы совпадает с 
именем пользователя-владельца. См. §1.1.

**Таблица (table)** — объект схемы для хранения данных в виде строк и столбцов; основной объект реляционной модели. См. §1.3, гл. 2.

**Табличное пространство (tablespace)** — логический контейнер для хранения сегментов (таблиц, индексов и др.); физически данные хранятся в одном или нескольких файлах 
данных (data files). См. §1.1.

**Транзакция** — логическая единица работы в Oracle: последовательность операторов SQL, которая завершается COMMIT (сохранить изменения) или ROLLBACK (отменить). Свойства 
ACID. См. §8.1.

**Триггер (trigger)** — объект базы данных: блок PL/SQL, выполняемый автоматически при событии (DML: INSERT/UPDATE/DELETE на таблице). CREATE TRIGGER ... BEFORE|AFTER ... 
ON таблица [FOR EACH ROW]; в строковом триггере доступны :NEW и :OLD. См. §12.1.

**Уровень изоляции** — настройка, определяющая, какие изменения других транзакций видит текущая сессия. В Oracle: READ COMMITTED (по умолчанию, без грязного чтения), 
SERIALIZABLE (снимок на начало транзакции). См. §8.2.

**Файл данных (data file)** — файл на диске, в котором Oracle хранит данные табличного пространства (логические сегменты, экстенты, блоки).

**Функция (function, в PL/SQL)** — именованная подпрограмма PL/SQL с RETURN тип: возвращает одно значение через RETURN выражение в теле; вызывается как выражение в PL/SQL 
и при соблюдении ограничений — в SQL. См. §11.2.

**Цикл (в PL/SQL)** — LOOP (с EXIT/EXIT WHEN), WHILE условие LOOP, FOR счетчик IN [REVERSE] низ..верх LOOP, FOR запись IN (курсор) LOOP. Завершение — END LOOP. См. §10.3.

**Экстент (extent)** — совокупность логически последовательных блоков данных Oracle, выделенных для хранения данных одного сегмента (например, таблицы).
