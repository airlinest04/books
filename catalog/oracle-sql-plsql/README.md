## Подробное содержание

### Часть I. Oracle SQL с нуля

#### Глава 1. Среда Oracle: введение и основные объекты

- **1.1 Экосистема Oracle** — СУБД Oracle Database; схемы (schema), пользователи, табличные пространства; клиенты (SQL*Plus, SQL Developer, др.).
- **1.2 Подключение к базе** — строка подключения, имя службы (service name); роли и привилегии.
- **1.3 Основные объекты** — таблицы, представления (views), синонимы (synonyms), последовательности (sequences); каталог данных (data dictionary) — обзор представлений USER_*, ALL_*, DBA_*.
- **1.4 Первый запрос** — SELECT в SQL*Plus/SQL Developer; выполнение и форматирование вывода.
- *Ключевое:* схема, пользователь, объекты, первый SELECT. *Задания:* подключение, просмотр объектов схемы.

#### Глава 2. Модель данных и типы в Oracle

- **2.1 CREATE TABLE** — имена таблиц и столбцов; кавычки и регистр.
- **2.2 Типы данных** — NUMBER, VARCHAR2, CHAR, DATE, TIMESTAMP, CLOB, BLOB; различие VARCHAR и VARCHAR2.
- **2.3 Ограничения** — NOT NULL, PRIMARY KEY, UNIQUE, CHECK, FOREIGN KEY; именование ограничений.
- **2.4 ALTER TABLE** — добавление/удаление столбцов и ограничений; изменение типа (ограничения).
- **2.5 Последовательности (SEQUENCE)** — NEXTVAL, CURRVAL; использование для первичных ключей.
- *Ключевое:* типы Oracle, ключи, последовательности. *Задания:* создание таблиц и последовательностей.

#### Глава 3. Выборка и фильтрация (SELECT, WHERE)

- **3.1 SELECT** — список столбцов, псевдонимы (AS), выражения; функции (UPPER, LOWER, TO_CHAR, TO_DATE, NVL и др.).
- **3.2 WHERE** — сравнения, IN, BETWEEN, LIKE; AND, OR, NOT; IS NULL; приоритет операторов.
- **3.3 DISTINCT** — уникальные строки.
- **3.4 Специфика Oracle** — ROWNUM (псевдостолбец); ограничение числа строк до 12c; в 12c — FETCH FIRST, OFFSET.
- *Ключевое:* SELECT, WHERE, типичные функции Oracle. *Задания:* запросы с фильтрами и функциями.

#### Глава 4. Соединение таблиц (JOIN) и подзапросы

- **4.1 INNER JOIN, LEFT/RIGHT/FULL OUTER JOIN** — синтаксис ON; (+) в старом синтаксисе Oracle (кратко).
- **4.2 Подзапросы в WHERE** — скалярный подзапрос; IN, EXISTS, сравнения с подзапросом.
- **4.3 Подзапросы в FROM** — подзапрос как таблица; псевдоним.
- **4.4 Подзапросы в SELECT** — скалярный подзапрос в списке столбцов (одна строка, один столбец).
- *Ключевое:* JOIN, подзапросы в WHERE/FROM/SELECT. *Задания:* многотабличные запросы и подзапросы.

#### Глава 5. Манипулирование данными (INSERT, UPDATE, DELETE)

- **5.1 INSERT** — вставка одной и нескольких строк; вставка из подзапроса (INSERT ... SELECT); RETURNING INTO (в PL/SQL).
- **5.2 UPDATE** — обновление по WHERE; подзапрос в SET и в WHERE.
- **5.3 DELETE** — удаление по условию; TRUNCATE (кратко).
- **5.4 MERGE** — вставка или обновление в одном операторе (upsert); синтаксис и типичное применение.
- *Ключевое:* INSERT, UPDATE, DELETE, MERGE. *Задания:* сценарии DML и MERGE.

#### Глава 6. Агрегация, группировка, оконные функции

- **6.1 Групповые функции** — COUNT, SUM, AVG, MIN, MAX; GROUP BY; HAVING.
- **6.2 Оконные функции** — OVER (PARTITION BY ... ORDER BY ...); ROW_NUMBER, RANK, DENSE_RANK; LAG, LEAD; агрегаты как оконные.
- **6.3 Специфичные для Oracle** — NVL, NVL2, DECODE; аналитические функции (кратко список).
- *Ключевое:* GROUP BY, HAVING, OVER. *Задания:* агрегация и оконные функции по сценариям.

#### Глава 7. CTE, множества, сложные запросы

- **7.1 WITH (CTE)** — WITH name AS (SELECT ...) SELECT ...; несколько CTE; рекурсивные запросы (CONNECT BY — кратко как альтернатива).
- **7.2 UNION, UNION ALL, INTERSECT, MINUS** — операции над наборами строк; MINUS как аналог EXCEPT.
- **7.3 Иерархические запросы** — CONNECT BY, START WITH, LEVEL (кратко).
- **7.4 Представления и материализованные представления** — CREATE VIEW; CREATE MATERIALIZED VIEW; REFRESH; когда использовать.
- *Ключевое:* WITH, UNION/INTERSECT/MINUS, представления. *Задания:* запросы с CTE и множествами.

#### Глава 8. Транзакции и целостность в Oracle

- **8.1 Транзакции** — явный COMMIT, ROLLBACK; неявный COMMIT при DDL в некоторых клиентах.
- **8.2 Уровни изоляции** — READ COMMITTED по умолчанию; SERIALIZABLE и другие; блокировки строк.
- **8.3 SAVEPOINT** — сохранение точки отката; частичный ROLLBACK.
- **8.4 План выполнения запроса** — EXPLAIN PLAN; чтение плана; индексы и полный скан таблицы; когда смотреть план.
- *Ключевое:* COMMIT, ROLLBACK, SAVEPOINT, EXPLAIN PLAN. *Задания:* сценарии с двумя сессиями и откатом.

### Часть II. PL/SQL с нуля

#### Глава 9. Введение в PL/SQL: блоки, переменные, типы

- **9.1 Структура блока** — DECLARE, BEGIN, EXCEPTION, END; анонимный блок и выполнение.
- **9.2 Переменные** — объявление с типом; типы: NUMBER, VARCHAR2, DATE, BOOLEAN; %TYPE, %ROWTYPE.
- **9.3 Присваивание и SELECT INTO** — := ; SELECT ... INTO ... FROM ... ; одна строка и обработка NO_DATA_FOUND/TOO_MANY_ROWS.
- *Ключевое:* блок, переменные, %TYPE, %ROWTYPE. *Задания:* анонимные блоки с переменными.

#### Глава 10. Управляющие конструкции: условия и циклы

- **10.1 IF / ELSIF / ELSE** — условия; вложенность.
- **10.2 CASE** — простой и поисковый CASE.
- **10.3 Циклы** — LOOP ... EXIT WHEN; WHILE; FOR по диапазону (FOR i IN 1..10); FOR по курсору (FOR rec IN (SELECT ...)).
- **10.4 CONTINUE, EXIT с меткой** — вложенные циклы.
- *Ключевое:* IF, CASE, LOOP, FOR. *Задания:* логика с ветвлениями и циклами.

#### Глава 11. Процедуры и функции в PL/SQL

- **11.1 CREATE PROCEDURE** — параметры IN, OUT, INOUT; тело; вызов CALL.
- **11.2 CREATE FUNCTION** — возвращаемый тип; RETURN; вызов в SQL.
- **11.3 Параметры по умолчанию; именованная передача** — вызов с указанием имён параметров.
- **11.4 Пакетные процедуры и функции** — объявление в спецификации пакета, тело в теле пакета (см. гл. 12).
- *Ключевое:* PROCEDURE, FUNCTION, IN/OUT. *Задания:* написание процедур и функций.

#### Глава 12. Триггеры и пакеты (packages)

- **12.1 Триггеры** — BEFORE/AFTER, FOR EACH ROW/STATEMENT; события INSERT, UPDATE, DELETE; :NEW, :OLD; создание триггерной процедуры и привязка триггера.
- **12.2 Пакет (package)** — спецификация (объявление процедур, функций, типов, констант) и тело (реализация); зачем пакеты (инкапсуляция, перегрузка, состояние сессии).
- **12.3 Перегрузка в пакете** — несколько процедур/функций с одним именем и разными сигнатурами.
- *Ключевое:* триггеры :NEW/:OLD; структура пакета. *Задания:* триггер; простой пакет с процедурой и функцией.

#### Глава 13. Курсоры и обработка исключений

- **13.1 Явные курсоры** — объявление CURSOR; OPEN, FETCH, CLOSE; цикл FOR по курсору.
- **13.2 Курсорные переменные** — REF CURSOR; открытие для разных запросов.
- **13.3 Обработка исключений** — EXCEPTION блок; WHEN NO_DATA_FOUND, WHEN TOO_MANY_ROWS, WHEN OTHERS; PRAGMA EXCEPTION_INIT; RAISE_APPLICATION_ERROR.
- **13.4 Транзакции в PL/SQL** — COMMIT/ROLLBACK внутри процедуры; лучшие практики.
- *Ключевое:* курсоры, EXCEPTION, RAISE_APPLICATION_ERROR. *Задания:* процедура с курсором и обработкой ошибок.
