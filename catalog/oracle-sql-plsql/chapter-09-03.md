# §9.3 Присваивание и SELECT INTO

В [§9.2](chapter-09-02.md) мы разобрали объявление переменных и типы (%TYPE, %ROWTYPE). Чтобы записать в переменную значение, используют **присваивание** (оператор **:=**) или **SELECT INTO** — выборку одной строки запроса напрямую в переменные. В этом разделе — синтаксис присваивания, **SELECT INTO** для одной строки (скаляры и запись %ROWTYPE), исключения **NO_DATA_FOUND** и **TOO_MANY_ROWS**. Условия (IF, CASE) и циклы — в [главе 10](chapter-10-01.md). См. [Глоссарий](glossary.md).

---

## 9.3.1. Присваивание :=

В PL/SQL присваивание выполняется оператором **:=** (двоеточие и знак равенства). Слева — переменная (или поле записи), справа — выражение: константа, другая переменная, вызов функции, результат подзапроса и т.д. Тип выражения должен быть совместим с типом переменной (или приводим неявно). См. [Глоссарий](glossary.md).

Примеры:

```plsql
v_count := 0;
v_name := 'Smith';
v_total := v_price * v_qty;
v_birth := SYSDATE - 365;
r_emp.salary := r_emp.salary * 1.1;   -- поле записи
```

Оператор сравнения «равно» в условиях — **=** (один знак); в присваивании — только **:=**. Среда: Oracle PL/SQL.

## 9.3.2. SELECT INTO: одна строка в переменные

**SELECT INTO** — оператор PL/SQL: выполняется запрос SELECT, и **ровно одна** строка результата помещается в перечисленные переменные (или в одну переменную типа %ROWTYPE). Запрос должен возвращать не более одной строки; иначе Oracle вызовет исключение. См. [Глоссарий](glossary.md).

Синтаксис:

```plsql
SELECT список_столбцов_или_*
  INTO список_переменных
  FROM таблица [WHERE условие] [и другие предложения];
```

Количество и порядок выражений в SELECT должны совпадать с количеством и порядком переменных в INTO; типы должны быть совместимы. Пример выбора по первичному ключу:

```plsql
DECLARE
  v_name   employees.last_name%TYPE;
  v_sal    employees.salary%TYPE;
BEGIN
  SELECT last_name, salary
    INTO v_name, v_sal
    FROM employees
   WHERE employee_id = 100;
  DBMS_OUTPUT.PUT_LINE(v_name || ': ' || v_sal);
END;
/
```

Если условие WHERE гарантирует одну строку (уникальный ключ), SELECT INTO безопасен. Для одной строки в запись:

```plsql
DECLARE
  r_emp   employees%ROWTYPE;
BEGIN
  SELECT * INTO r_emp FROM employees WHERE employee_id = 100;
  DBMS_OUTPUT.PUT_LINE(r_emp.last_name || ', ' || r_emp.salary);
END;
/
```

См. [Глоссарий](glossary.md). Среда: Oracle PL/SQL.

## 9.3.3. NO_DATA_FOUND и TOO_MANY_ROWS

**SELECT INTO** требует ровно одной строки результата. Если запрос **не вернул ни одной** строки, Oracle возбуждает исключение **NO_DATA_FOUND**. Если вернулось **больше одной** строки — **TOO_MANY_ROWS**. Оба прерывают выполнение блока, если нет обработчика в секции EXCEPTION. См. [Глоссарий](glossary.md).

Типичная обработка: при поиске по ключу «может не найтись» перехватывают NO_DATA_FOUND и выполняют альтернативную логику (сообщение, значение по умолчанию, выход). TOO_MANY_ROWS обычно указывает на ошибку в условии (ожидали одну строку, условие не уникально) — нужно ужесточить WHERE или использовать курсор и взять первую строку осознанно.

Пример обработки NO_DATA_FOUND:

```plsql
DECLARE
  v_name   employees.last_name%TYPE;
BEGIN
  SELECT last_name INTO v_name FROM employees WHERE employee_id = 99999;
  DBMS_OUTPUT.PUT_LINE(v_name);
EXCEPTION
  WHEN NO_DATA_FOUND THEN
    DBMS_OUTPUT.PUT_LINE('Сотрудник не найден');
END;
/
```

Если employee_id = 99999 нет в таблице, выполнение перейдёт в EXCEPTION, будет выведено «Сотрудник не найден». См. [Глоссарий](glossary.md).

## Ключевое

- **Присваивание** в PL/SQL: переменная **:=** выражение. Для сравнения в условиях используется **=**, не :=. См. [Глоссарий](glossary.md).
- **SELECT INTO** — выборка **одной** строки запроса в переменные (или в запись %ROWTYPE). Запрос должен возвращать ровно одну строку; список столбцов и переменных по порядку и типу должны совпадать. См. [Глоссарий](glossary.md).
- **NO_DATA_FOUND** — запрос не вернул ни одной строки. **TOO_MANY_ROWS** — вернулось больше одной строки. Обрабатывают в EXCEPTION (WHEN NO_DATA_FOUND / WHEN TOO_MANY_ROWS).
- Для нескольких строк используют курсор (FETCH в цикле) или BULK COLLECT INTO коллекцию — темы последующих глав.

В [§10.1](chapter-10-01.md) мы начнём главу об управляющих конструкциях: условия IF, ELSIF, ELSE.
