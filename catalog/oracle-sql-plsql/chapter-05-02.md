# §5.2 UPDATE

В [§5.1](chapter-05-01.md) мы разобрали вставку строк (INSERT). Оператор **UPDATE** изменяет значения столбцов в существующих строках таблицы. В этом разделе рассмотрим синтаксис **UPDATE ... SET**, условие **WHERE** (какие строки обновлять), **подзапрос в SET** (скалярное значение для присваивания) и **подзапрос в WHERE** (отбор обновляемых строк). DELETE и TRUNCATE — в [§5.3](chapter-05-03.md). См. [Глоссарий](glossary.md).

---

## 5.2.1. Синтаксис UPDATE ... SET ... WHERE

Общая форма:

```sql
UPDATE имя_таблицы [псевдоним]
   SET столбец1 = выражение1 [, столбец2 = выражение2, ...]
 [WHERE условие];
```

**SET** задаёт присваивание: каждому перечисленному столбцу — значение выражения (константа, другой столбец, вызов функции, скалярный подзапрос). Можно обновить один или несколько столбцов в одной команде. **WHERE** указывает, **какие строки** обновлять: только те, для которых условие истинно. Если WHERE опущен, обновляются **все строки** таблицы. См. [Глоссарий](glossary.md).

Пример: обновить цену и статус у одного товара по id:

```sql
UPDATE products SET price = 24.99, status = 'PROMO' WHERE id = 10;
```

Пример без WHERE (осторожно — затронет всю таблицу):

```sql
UPDATE products SET updated_at = SYSDATE;
```

Все строки products получат текущую дату в столбце updated_at. Перед выполнением UPDATE без WHERE убедитесь, что это намеренно; в production обычно сначала проверяют количество строк (SELECT COUNT(*) ... с тем же условием) или используют транзакцию с последующим ROLLBACK для проверки.

## 5.2.2. Выражения в SET

В SET справа от знака равенства может стоять не только константа, но и **выражение**: арифметика, конкатенация строк, функции, ссылка на другой столбец той же таблицы. Выражение вычисляется для каждой обновляемой строки. См. [Глоссарий](glossary.md).

Примеры:

```sql
-- увеличить цену на 10%
UPDATE products SET price = price * 1.1 WHERE category_id = 1;

-- обновить из другого столбца и функции
UPDATE orders SET total = quantity * unit_price, updated_at = SYSDATE WHERE order_id = 100;
```

Тип выражения должен быть совместим с типом столбца. При необходимости используйте TO_CHAR, TO_DATE, TO_NUMBER и т.д.

---

## 5.2.3. Подзапрос в SET

В SET можно подставить значение из **скалярного подзапроса** (одна строка, один столбец). Подзапрос выполняется для каждой обновляемой строки; если он коррелирован (ссылается на столбцы обновляемой таблицы), то для каждой строки может возвращаться своё значение. См. [Глоссарий](glossary.md).

Пример: установить в orders столбец customer_name равным имени клиента из таблицы customers по customer_id:

```sql
UPDATE orders o
   SET customer_name = (SELECT name FROM customers c WHERE c.customer_id = o.customer_id)
 WHERE o.order_date >= DATE '2025-01-01';
```

Подзапрос коррелированный: o.customer_id берётся из текущей строки orders. Он должен возвращать не более одной строки (уникальный customer_id в customers). Если вернётся ноль строк, в столбец подставится NULL. Если несколько строк — ошибка ORA-01427.

## 5.2.4. Подзапрос в WHERE

Условие **WHERE** может содержать подзапросы: **IN (подзапрос)**, **EXISTS**, сравнение со скалярным подзапросом и т.д. Тогда обновляются только те строки, которые удовлетворяют этому условию. См. [Глоссарий](glossary.md) и [§4.2](chapter-04-02.md).

Пример: обновить статус заказов только у клиентов из Москвы:

```sql
UPDATE orders
   SET status = 'PENDING_REVIEW'
 WHERE customer_id IN (SELECT customer_id FROM customers WHERE city = 'Moscow');
```

Другой пример — обновить цену товаров до средней по категории (скалярный подзапрос в SET, зависящий от категории текущей строки):

```sql
UPDATE products p
   SET price = (SELECT AVG(price) FROM products p2 WHERE p2.category_id = p.category_id)
 WHERE category_id = 1;
```

Здесь в SET — коррелированный скалярный подзапрос; в WHERE — обычное условие по столбцу. Подзапросы в WHERE позволяют отбирать строки по сложным условиям (существование в другой таблице, сравнение с агрегатом и т.д.).

## 5.2.5. Псевдоним таблицы при UPDATE

Если в SET или WHERE используются подзапросы или выражения с ссылкой на обновляемую таблицу, таблицу часто задают с **псевдонимом** после имени таблицы. Тогда в подзапросе и в условиях обращение к столбцам идёт через этот псевдоним. См. [Глоссарий](glossary.md).

Пример (уже использовался выше):

```sql
UPDATE orders o
   SET customer_name = (SELECT name FROM customers c WHERE c.customer_id = o.customer_id)
 WHERE o.order_id BETWEEN 1 AND 100;
```

Псевдоним o однозначно указывает на таблицу orders при корреляции в подзапросе.

## 5.2.6. Типичные ошибки при использовании UPDATE

- **Забыть WHERE:** обновляются все строки таблицы. В production это часто недопустимо. Перед выполнением проверьте условие (например, выполните SELECT с тем же WHERE и посмотрите число строк).
- **Подзапрос в SET возвращает несколько строк:** скалярный подзапрос должен возвращать не более одной строки. Иначе ORA-01427. Обеспечьте уникальность (условие по первичному ключу, агрегат).
- **Подзапрос в SET возвращает несколько столбцов:** в SET можно подставить только одно значение на столбец. Подзапрос должен возвращать один столбец.
- **Циклические зависимости в SET:** не задавайте SET a = b, b = a в одной команде — порядок присваивания может быть неочевиден. Лучше обновить в два шага через временную переменную или использовать подзапрос/выражение, не зависящее от обновляемого столбца в той же строке.
- **Обновление по неверному ключу:** убедитесь, что условие WHERE однозначно определяет нужные строки (например, по первичному ключу). Иначе можно обновить лишние строки или не обновить нужные.
- **Транзакция:** UPDATE выполняется в рамках транзакции; для фиксации изменений нужен COMMIT. До COMMIT другие сессии не видят изменения (при уровне изоляции по умолчанию).

---

## Ключевое

- **UPDATE таблица SET столбец = выражение [, ...] [WHERE условие]** — изменить значения столбцов в строках, удовлетворяющих WHERE. Без WHERE обновляются **все** строки таблицы.
- В SET можно указывать константы, выражения, ссылки на другие столбцы, **скалярный подзапрос**. Подзапрос должен возвращать одну строку и один столбец.
- **Подзапрос в WHERE** ограничивает набор обновляемых строк (IN, EXISTS, сравнение с подзапросом и т.д.).
- **Коррелированный подзапрос в SET** может зависеть от текущей строки обновляемой таблицы; для однозначности используют псевдоним таблицы.
- Перед массовым UPDATE проверяйте условие WHERE (SELECT с тем же WHERE); после изменения выполняйте COMMIT для сохранения.

В [§5.3](chapter-05-03.md) мы разберём оператор DELETE: удаление строк по условию и кратко TRUNCATE.
