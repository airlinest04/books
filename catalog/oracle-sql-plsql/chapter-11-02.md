# §11.2 CREATE FUNCTION

В [§11.1](chapter-11-01.md) мы разобрали процедуры. **Функция** — именованная подпрограмма PL/SQL, которая **возвращает одно значение** (скаляр или составной тип) через оператор **RETURN**. Функцию можно вызывать в выражениях PL/SQL и в SQL (SELECT, WHERE и т.д.), если она удовлетворяет ограничениям «SQL-функции». В этом разделе — синтаксис **CREATE FUNCTION**, объявление типа возврата (**RETURN** тип), оператор **RETURN** значение в теле, вызов в PL/SQL и в SQL, а также **DROP FUNCTION**. Параметры по умолчанию и именованная передача — в [§11.3](chapter-11-03.md). См. [Глоссарий](glossary.md).

---

## 11.2.1. Синтаксис CREATE FUNCTION

**Функция** — объект схемы: подпрограмма с списком параметров (только **IN**; в чистой функции OUT/IN OUT не используют для возврата результата — только RETURN), типом возвращаемого значения и телом, в котором хотя бы один путь выполнения должен выполнить **RETURN** выражение. См. [Глоссарий](glossary.md).

Общая форма:

```plsql
CREATE [OR REPLACE] FUNCTION [схема.]имя_функции
  ( параметр1 [IN] тип [:= значение_по_умолчанию]
  [, параметр2 ...] )
  RETURN тип_возврата
[AUTHID {CURRENT_USER | DEFINER}]
[DETERMINISTIC | PARALLEL_ENABLE ...]
AS | IS
  [локальные объявления]
BEGIN
  исполняемые операторы;
  RETURN выражение;   -- хотя бы один RETURN
[EXCEPTION
  обработчики;]
END [имя_функции];
```

**RETURN** тип_возврата — обязательная часть заголовка: тип значения, которое возвращает функция (NUMBER, VARCHAR2, DATE, %TYPE и т.д.). В теле должен быть выполнен хотя бы один **RETURN** выражение; тип выражения должен совместим с объявленным типом возврата. Выполнение RETURN завершает функцию (управление возвращается вызывающему). См. [Глоссарий](glossary.md). Среда: Oracle Database.

## 11.2.2. RETURN в теле функции

В исполняемой части (BEGIN) и в обработчиках (EXCEPTION) функция должна вернуть значение через **RETURN** выражение**;** Если по какому-то пути выполнения RETURN не выполнится (например, ветка без RETURN), при вызове может возникнуть ошибка или неопределённое поведение. Обычно в каждой ветке, ведущей к выходу из функции, пишут RETURN. См. [Глоссарий](glossary.md).

Пример: функция, возвращающая полное имя сотрудника по id:

```plsql
CREATE OR REPLACE FUNCTION get_emp_full_name (
  p_emp_id IN employees.employee_id%TYPE
) RETURN VARCHAR2
IS
  v_name VARCHAR2(200);
BEGIN
  SELECT first_name || ' ' || last_name
    INTO v_name
    FROM employees
   WHERE employee_id = p_emp_id;
  RETURN v_name;
EXCEPTION
  WHEN NO_DATA_FOUND THEN
    RETURN NULL;   -- или другой вариант по умолчанию
END get_emp_full_name;
/
```

Функция возвращает VARCHAR2; при отсутствии строки обрабатывается NO_DATA_FOUND и возвращается NULL. См. [Глоссарий](glossary.md).

## 11.2.3. Вызов функции в PL/SQL и в SQL

В **PL/SQL** функцию вызывают в любом месте, где допустимо выражение: справа в присваивании, в условии IF, в параметрах другой подпрограммы, в DBMS_OUTPUT.PUT_LINE и т.д. См. [Глоссарий](glossary.md).

Пример:

```plsql
DECLARE
  v_name VARCHAR2(200);
BEGIN
  v_name := get_emp_full_name(100);
  DBMS_OUTPUT.PUT_LINE(v_name);
  IF get_emp_full_name(200) IS NULL THEN
    DBMS_OUTPUT.PUT_LINE('Сотрудник не найден');
  END IF;
END;
/
```

В **SQL** (SELECT, WHERE, ORDER BY и т.д.) пользовательскую функцию можно вызывать, если она подчиняется правилам «чистоты»: не изменяет состояние базы (нет DML в теле при вызове из запроса в общем случае), детерминирована при необходимости (DETERMINISTIC). См. [Глоссарий](glossary.md).

Пример вызова в SELECT:

```sql
SELECT employee_id, get_emp_full_name(employee_id) AS full_name
  FROM employees
 WHERE department_id = 10;
```

Ограничения: в SQL нельзя вызывать функции с параметрами OUT/IN OUT; функция не должна выполнять DDL или изменять пакетное состояние в контексте запроса. Подробности — в документации Oracle. **DROP FUNCTION** имя_функции**;** — удаление функции. Среда: Oracle Database.

## Ключевое

- **CREATE [OR REPLACE] FUNCTION** имя **(** параметры **) RETURN** тип **AS|IS** ... **BEGIN** ... **RETURN** выражение**;** ... **END;** — создание функции. Параметры обычно только IN. В теле обязателен хотя бы один выполнимый RETURN. См. [Глоссарий](glossary.md).
- **Функция** возвращает одно значение; вызов используется как выражение. В отличие от процедуры, не вызывается отдельным оператором ради побочных эффектов (хотя побочные эффекты в теле возможны, для использования в SQL их избегают).
- Вызов в PL/SQL: переменная **:=** имя_функции**(аргументы);** или в условии, в выражении. В SQL — в SELECT, WHERE и т.д., с ограничениями на «чистоту» функции.
- **DROP FUNCTION** имя — удаление функции.

В [§11.3](chapter-11-03.md) мы разберём параметры по умолчанию и именованную передачу аргументов (вызов по имени параметра).
