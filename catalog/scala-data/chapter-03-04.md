# §3.4 Циклы while и do-while

В [§3.3](chapter-03-03.md) мы разобрали цикл for и for-comprehension. **while** и **do-while** — императивные циклы, которые выполняют тело **пока условие истинно**. В идиоматичном Scala они используются редко: предпочтительны for, рекурсия и методы коллекций (map, fold). Тем не менее while нужен при чтении до маркера, низкоуровневых сценариях и при портировании Java-кода. В [§4.1](chapter-04-01.md) начнём главу о функциях и методах.

---

## 3.4.1. Синтаксис while

Цикл **while** записывается так:

```scala
while (условие) {
  тело_цикла
}
```

Условие должно иметь тип Boolean. Перед каждой итерацией оно проверяется; если истинно, выполняется тело. Цикл завершается, когда условие становится ложным. Если условие ложно при первом входе, тело не выполнится ни разу.

Пример:

```scala
var n = 0
while (n < 3) {
  println(n)
  n += 1
}
// выведет: 0, 1, 2
```

Здесь требуется **var**: переменная, участвующая в условии, должна обновляться в теле, иначе цикл может стать бесконечным.

---

## 3.4.2. do-while (Scala 2)

Цикл **do-while** выполняет тело **хотя бы один раз**, затем проверяет условие:

```scala
var n = 0
do {
  println(n)
  n += 1
} while (n < 3)
```

В **Scala 3** синтаксис `do ... while` удалён. Вместо него используют `while` с блоком в условии:

```scala
var n = 0
while ({
  println(n)
  n += 1
  n < 3
}) ()
```

Для большинства задач достаточно обычного while; do-while встречается редко.

## 3.4.3. break и continue

В Scala **нет** встроенных операторов `break` и `continue`. Вместо них используют:

1. **Рекурсию** или **функции высшего порядка** — for с yield, find, takeWhile и т.д. Часто «поиск с досрочным выходом» переписывают через `find` или рекурсию.
2. **scala.util.control.Breaks** — объект для имитации break:

```scala
import scala.util.control.Breaks._

breakable {
  for (x <- List(1, 2, 3, 4, 5)) {
    if (x == 4) break
    println(x)
  }
}
// выведет: 1, 2, 3
```

`break` внутри `breakable` выбрасывает исключение, которое перехватывается и выходит из блока. Это обходной путь; в новом коде лучше обходиться без break.

**continue** в Scala обычно заменяют фильтром в for или `if` в теле:

```scala
for (x <- List(1, -2, 3, -4, 5) if x > 0) {
  println(x)
}
```

## 3.4.4. Когда использовать while

В Scala while применяют редко. Типичные случаи:

- **Чтение до маркера** — из файла, потока или ввода, пока не встретится условие выхода.
- **Низкоуровневые императивные алгоритмы** — портирование кода из Java или C, мутация массива по индексам.
- **Узкие места производительности** — в горячих участках while может быть быстрее, чем создание промежуточных коллекций (хотя преждевременная оптимизация не рекомендуется).
- **Взаимодействие с Java** — циклы, построенные на изменяемых переменных и побочных эффектах.

В большинстве случаев предпочтительны:

- **for** и **for-comprehension** — перебор коллекций, фильтрация, преобразования;
- **map, filter, fold** — декларативная работа с коллекциями ([§4.5](chapter-04-05.md), [§5.5](chapter-05-05.md));
- **рекурсия** — когда нужен явный «досрочный» выход или сложное состояние.

---

## 3.4.5. Бесконечный цикл и типичные ошибки

**Бесконечный цикл** возникает, когда условие while никогда не становится ложным. Частая причина — не обновляется переменная в условии:

```scala
var n = 0
while (n < 5) {
  println(n)
  // забыли n += 1
}
```

Прервать выполнение в терминале — Ctrl+C.

**Намеренный бесконечный цикл** `while (true)` с выходом через `Breaks.break` или return допустим, когда условие выхода удобнее проверить внутри тела. Главное — гарантировать, что выход когда-нибудь произойдёт.

**Рекомендация:** при появлении while в коде проверьте, нельзя ли заменить его на for, find, takeWhile или рекурсию — такой код обычно проще понимать и тестировать.

---

## Ключевое

- **while (условие) { тело }** — выполнять тело пока условие истинно; условие проверяется перед каждой итерацией. Требует var для обновления переменных в условии.
- **do-while** — в Scala 2 выполняется хотя бы один раз; в Scala 3 удалён, вместо него используют while с блоком в условии.
- В Scala **нет break и continue**; аналог break — `scala.util.control.Breaks`; continue обычно заменяют фильтром в for.
- В идиоматичном Scala while используется редко; предпочтительны for, методы коллекций и рекурсия.
