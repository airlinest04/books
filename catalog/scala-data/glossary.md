# Глоссарий

Термины Scala и экосистемы данных, используемых в книге.

---

## A

**Apache Spark** — платформа распределённой обработки больших данных; изначально написана на Scala; поддерживает batch, streaming, SQL, ML. См. [§1.1](chapter-01-01.md).

---

## C

**case class** — неизменяемая модель данных; компилятор автоматически добавляет equals, hashCode, toString, copy и apply (создание без new); удобен в pattern matching. См. [§6.3](chapter-06-03.md).

**class** — объявление класса в Scala: шаблон для создания объектов. Параметры конструктора с val/var становятся полями; экземпляр создают через new Имя(...). См. [§6.1](chapter-06-01.md).

**CSV** (Comma-Separated Values) — текстовый формат табличных данных: строки — записи, поля разделены разделителем (запятая или точка с запятой). Простой парсинг — split; для полной поддержки кавычек и спецсимволов — библиотеки. См. [§7.3](chapter-07-03.md).

---

## D

**DataFrame** — в Spark таблица со схемой; по сути Dataset[Row]. Создание: spark.read.csv/json, createDataFrame. Операции: select, filter, groupBy. См. [§8.1](chapter-08-01.md), [§8.3](chapter-08-03.md).

**Dataset** — типизированный API Spark: распределённая коллекция с известным типом элементов (например, `Dataset[User]`); объединяет типобезопасность RDD с оптимизациями Catalyst. См. [§8.3](chapter-08-03.md).

---

## E

**Either[E, A]** — значение Left(error) или Right(result); для возврата доменной ошибки вместо исключения. См. [§9.3](chapter-09-03.md).

**ETL** (Extract, Transform, Load) — процесс извлечения данных из источников, преобразования и загрузки в целевое хранилище (витрина, DWH). См. [§1.1](chapter-01-01.md).

---

## F

**flatMap** — метод коллекций и Option: применяет функцию A => Collection[B] (или A => Option[B]) и объединяет результаты в одну коллекцию; «разворачивает» вложенность. См. [§5.4](chapter-05-04.md), [§5.5](chapter-05-05.md).

**for-comprehension** — цикл for с yield: создаёт новую коллекцию из результатов выражения для каждого элемента (с учётом фильтров); эквивалентен цепочкам map, flatMap, withFilter. См. [§3.3](chapter-03-03.md).

---

## I

**implicit** (неявный) — механизм Scala для автоматической подстановки аргументов и преобразований. **spark.implicits._** вносит Encoders для case class, синтаксис $"column" и др. для работы с Dataset/DataFrame. См. [§8.5](chapter-08-05.md).

---

## J

**JDK** (Java Development Kit) — комплект разработчика Java: компилятор javac, среда выполнения и утилиты; необходим для компиляции и запуска Scala. См. [§1.2](chapter-01-02.md).

**JVM** (Java Virtual Machine) — виртуальная машина Java; среда выполнения байт-кода, на которой работают Java, Scala, Kotlin и другие языки. См. [§1.1](chapter-01-01.md).

---

## L

**List** — неизменяемая упорядоченная последовательность в Scala; односвязный список. Создание: List(1,2,3), Nil. Операции: head, tail, :: (cons), :::, ++. См. [§5.1](chapter-05-01.md).

---

## M

**Map** — коллекция пар ключ–значение; по умолчанию неизменяема. Создание: Map("a" -> 1). Доступ: .get (Option), .getOrElse. Добавление: +. См. [§5.2](chapter-05-02.md).

**match** — выражение сопоставления с образцом: проверка значения на соответствие образцам (case) и выполнение соответствующей ветки; поддерживает guard (if) и связывание переменных. См. [§3.2](chapter-03-02.md).

**Metals** — language server для Scala: автодополнение, навигация, диагностика; работает в VS Code, Vim, Emacs и других редакторах. См. [§1.3](chapter-01-03.md).

**mutable.Set** — изменяемая версия Set; операции +=, -=, add, remove изменяют множество на месте. Импорт из scala.collection.mutable. См. [§5.3](chapter-05-03.md).

---

## N

**None** — подтип Option, обозначающий отсутствие значения. См. [§2.5](chapter-02-05.md).

---

## O

**object** (объект) — singleton в Scala: один экземпляр; методы — ObjectName.method(). Используется для точки входа (main), утилит.

**Option[T]** — тип для опционального значения: либо `Some(x)` (значение есть), либо `None` (значения нет). Безопасное извлечение — `.getOrElse(default)`; цепочки — `.map`, `.flatMap`; удобная запись — for-comprehension. См. [§2.5](chapter-02-05.md), [§5.4](chapter-05-04.md).

---

## P

**PrintWriter** — java.io.PrintWriter для записи текста в файл: println, print, write; конструктор (path, charset) для кодировки; требуется close() или Using.resource. См. [§7.2](chapter-07-02.md).

---

## R

**RDD** (Resilient Distributed Dataset) — базовый абстрактный тип в Spark: распределённая неизменяемая коллекция с отложенным вычислением. См. [§8.2](chapter-08-02.md).

**REPL** (Read–Eval–Print Loop) — интерактивная оболочка Scala: ввод выражения, вычисление, вывод результата; запускается командой `scala` без аргументов. См. [§1.2](chapter-01-02.md).

---

## S

**s-интерполяция** — подстановка переменных и выражений в строку: `s"$name"`, `s"${expr}"`; префикс `s` перед кавычками. См. [§2.4](chapter-02-04.md).

**sbt** (Scala Build Tool) — инструмент сборки для проектов на Scala: управление зависимостями, компиляция, тесты; стандарт для Spark jobs и библиотек. См. [§1.2](chapter-01-02.md).

**Scala** (Scalable Language) — язык программирования для JVM, сочетающий объектно-ориентированный и функциональный стиль; компилируется в байт-код Java. См. [§1.1](chapter-01-01.md).

**scala-cli** — утилита для запуска Scala-скриптов и однострочников без настройки проекта; поддерживает REPL и упаковку в JAR. См. [§1.2](chapter-01-02.md).

**scalac** — компилятор Scala: преобразует исходный код (.scala) в байт-код JVM (.class). См. [§1.2](chapter-01-02.md).

**Set** — неизменяемая коллекция уникальных элементов без повторений; порядок не гарантируется. Создание: Set(1,2,3), Set.empty. Операции: contains, +, -, | (union), & (intersect), diff. Элементы должны быть хешируемыми. См. [§5.3](chapter-05-03.md).

**Some** — подтип Option, оборачивающий значение. `Some(42)` — Option с числом 42. См. [§2.5](chapter-02-05.md).

**Source** — объект scala.io.Source для чтения текстовых файлов: fromFile(path), getLines(), mkString; требуется явное закрытие (close) или Using.resource. См. [§7.1](chapter-07-01.md).

**SparkSession** — точка входа в Spark SQL; создаётся через builder (appName, master, getOrCreate); используется для создания DataFrame, Dataset, чтения файлов. См. [§8.1](chapter-08-01.md).

---

## T

**trait** (трейт) — механизм описания интерфейса и смешиваемого поведения; класс наследует через extends и with; может содержать абстрактные и реализованные методы. См. [§6.4](chapter-06-04.md).

**Try[T]** — контейнер для вычисления, которое может выбросить исключение: Success(x) или Failure(exception). Обработка: match, getOrElse, recover. См. [§9.3](chapter-09-03.md).

---

## U

**Unit** — тип «отсутствия значения» в Scala; единственное значение — `()`. Используется как возвращаемый тип для процедур (например, println). См. [§2.2](chapter-02-02.md).

---

## V

**val** — объявление неизменяемого значения: имя связывается с результатом выражения один раз; повторное присваивание запрещено. Рекомендуется по умолчанию. См. [§2.1](chapter-02-01.md).

**var** — объявление изменяемой переменной: допускается повторное присваивание; тип не меняется. См. [§2.1](chapter-02-01.md).

**varargs** (повторяющиеся параметры) — параметр вида `x: T*`, принимающий произвольное число аргументов типа T; внутри имеет тип Seq[T]. См. [§4.2](chapter-04-02.md).

---

## η

**η-преобразование** (eta-expansion) — автоматическое преобразование метода в функцию при передаче в контекст, ожидающий функцию; `method` превращается в `x => method(x)`. См. [§4.4](chapter-04-04.md).

---

## А

**Анонимная функция** (lambda) — функция без имени: `(x: Int) => x * 2`; подчёркивание `_` — плейсхолдер для параметра. Передаётся в map, filter и другие методы. См. [§4.3](chapter-04-03.md).

---

## И

**Иммутабельность** (immutability) — неизменяемость: значение или структура данных не может быть изменена после создания; в Scala по умолчанию используются val и неизменяемые коллекции. См. [§1.1](chapter-01-01.md), [§6.5](chapter-06-05.md).

---

## О

**Объект-компаньон** — object с тем же именем, что и class, в одном файле; фабричные методы (apply), утилиты; доступ к приватным членам класса. См. [§1.4](chapter-01-04.md), [§6.2](chapter-06-02.md).

---

## С

**Сериализация** — преобразование объектов в формат для хранения или передачи (JSON, байты); обратная операция — десериализация. В Scala: circe/json4s для JSON; Spark — Kryo для RDD, Encoders для Dataset. См. [§7.4](chapter-07-04.md).

**Статическая типизация** — свойство языка, при котором типы переменных и выражений проверяются на этапе компиляции; ошибки типов обнаруживаются до выполнения. См. [§1.1](chapter-01-01.md).

---

## Ф

**Функция высшего порядка** — функция или метод, принимающий другую функцию как аргумент или возвращающий функцию. Примеры: map, filter, foldLeft. См. [§4.5](chapter-04-05.md).

---

## Ч

**Чистая функция** — функция без побочных эффектов; для одних и тех же аргументов всегда возвращает один и тот же результат. Упрощает тестирование и рассуждения о коде. См. [§6.5](chapter-06-05.md).
