## Подробное содержание

### Глава 1. Scala как язык для данных: зачем и среда

- **1.1 Зачем Scala в данных** — нативная поддержка в Spark (Spark написан на Scala); производительность и выразительность; статическая типизация и иммутабельность.
- **1.2 Установка** — JDK; установка Scala (sbt или scala-cli); проверка scala и scalac в командной строке.
- **1.3 Инструменты** — sbt (сборка и зависимости); IDE (IntelliJ IDEA с плагином Scala) или VS Code; REPL для экспериментов.
- **1.4 Первая программа** — объект с методом main; компиляция и запуск; скрипт в REPL.
- *Ключевое:* зачем Scala, установка, первый запуск. *Задания:* установить среду, вывести «Hello» из программы и из REPL.

---

### Глава 2. Синтаксис: переменные, типы, операторы

- **2.1 Значения и переменные** — val (неизменяемое) и var (изменяемое); рекомендация предпочитать val.
- **2.2 Основные типы** — Int, Long, Double, Float, Boolean, Char, String; вывод типа; приведение .toInt, .toDouble и т.д.
- **2.3 Операторы** — арифметические, сравнения, логические; операторы как методы (a + b как a.+(b)).
- **2.4 Строки** — интерполяция s"$name"; многострочные строки (тройные кавычки); методы .length, .split, .toInt.
- **2.5 Option и null** — отсутствие значения: Option[T], Some(x), None; безопасное извлечение .getOrElse; избегание null.
- *Ключевое:* val/var, типы, строки, Option. *Задания:* выражения со строками и Option.

---

### Глава 3. Управляющие конструкции: условия и циклы

- **3.1 Условие if** — if (условие) ... else ...; if возвращает значение (выражение); блоки в фигурных скобках.
- **3.2 Сопоставление с образцом (match)** — match { case значение => ... }; case с условием (guard); замена цепочки if-else.
- **3.3 Цикл for** — for (i <- 1 to 10); for по коллекции; фильтр for (x <- col if условие); yield для создания коллекции (for-comprehension).
- **3.4 Циклы while и do-while** — когда использовать; редко в идиоматичном Scala.
- *Ключевое:* if как выражение, match, for и for-comprehension. *Задания:* переписать условия через match; for-comprehension для списка.

---

### Глава 4. Функции и методы

- **4.1 Определение функции** — def имя(параметры): тип = тело; явный возвращаемый тип для публичных API.
- **4.2 Параметры** — по умолчанию; именованные аргументы; повторяющиеся параметры (varargs).
- **4.3 Анонимные функции** — (x: Int) => x * 2; передача в методы (map, filter).
- **4.4 Методы и функции** — метод принадлежит классу/объекту; функция — значение; преобразование метода в функцию (η-преобразование).
- **4.5 Функции высшего порядка** — map, filter, foldLeft; примеры на коллекциях.
- *Ключевое:* def, анонимные функции, map/filter. *Задания:* написать функции и использовать их в map/filter.

---

### Глава 5. Коллекции: List, Map, Set, Option

- **5.1 List** — создание List(1, 2, 3); голова и хвост head, tail; конкатенация :: и :::; неизменяемость; типы List[A].
- **5.2 Map** — создание Map("a" -> 1); доступ .get (возвращает Option); .getOrElse; обновление и добавление +; неизменяемые по умолчанию.
- **5.3 Set** — уникальные элементы; основные операции; неизменяемый и mutable.Set.
- **5.4 Option** — повторение: Some/None; .map, .flatMap, .getOrElse; for-comprehension над Option.
- **5.5 Общие операции** — .size, .isEmpty, .contains; .map, .flatMap, .filter, .foreach; .foldLeft, .reduce; преобразование в список .toList.
- *Ключевое:* List, Map, Set, Option; map, flatMap, filter. *Задания:* обработка списков и мап; цепочки Option.

---

### Глава 6. Объектно-ориентированный и функциональный стиль

- **6.1 Классы** — class Имя(параметры конструктора); поля и методы; создание экземпляра new Имя(...).
- **6.2 Объекты (singleton)** — object Имя; методы и поля объекта; объект-компаньон для класса (то же имя).
- **6.3 Case-классы** — case class: автоматические equals, hashCode, toString; создание без new; использование в pattern matching.
- **6.4 Трейты (traits)** — описание интерфейса и смешиваемого поведения; with для примеси; пример трейта для «логируемого» поведения.
- **6.5 Иммутабельность и чистые функции** — предпочтение неизменяемых структур; функции без побочных эффектов; связь с надёжностью и тестированием.
- *Ключевое:* class, object, case class, trait; иммутабельность. *Задания:* описать case class для сущности данных; трейт с методом.

---

### Глава 7. Работа с данными: файлы, потоки, сериализация

- **7.1 Чтение файлов** — Source.fromFile; построчное чтение .getLines(); кодировка; использование ресурса и закрытие (или using).
- **7.2 Запись файлов** — java.io.PrintWriter или scala.io; запись построчно.
- **7.3 Парсинг CSV/простой текстовый формат** — разбиение строк .split; обработка заголовка; преобразование в case class или Map.
- **7.4 Сериализация** — сериализация в JSON (библиотека circe или json4s — кратко); сериализация для Spark (Kryo, Encoders).
- *Ключевое:* Source, запись, парсинг строк, сериализация. *Задания:* прочитать CSV и преобразовать в список case class; записать результат.

---

### Глава 8. Связь Scala со Spark (при необходимости)

- **8.1 Spark на Scala** — SparkSession; создание DataFrame; типичный контекст: скрипты и jobs на Scala для Spark.
- **8.2 RDD и типы** — RDD как распределённая коллекция; типизированные RDD (RDD[(String, Int)]); методы map, filter, reduceByKey в Scala.
- **8.3 Dataset API** — типизированный Dataset[T]; Encoders для case class; связь с DataFrame (Dataset[Row]).
- **8.4 Зависимости и сборка** — добавление spark-core, spark-sql в sbt; пример минимального job и запуск через spark-submit.
- **8.5 Неявные преобразования (implicit)** — spark.implicits._; автоматические Encoders для case class; зачем нужны при работе с Dataset/DataFrame в Scala.
- *Ключевое:* SparkSession, RDD/Dataset в Scala, sbt-зависимости, implicits. *Задания:* написать простой Spark job на Scala (чтение, преобразование, запись).

### Глава 9. Типовые паттерны для ETL и пайплайнов

- **9.1 Конфигурация и параметры** — загрузка конфига (файл, переменные окружения); case class для конфигурации; передача путей и опций в job.
- **9.2 Цепочка преобразований** — последовательность шагов (read → transform1 → transform2 → write); композиция функций или вызов по шагам; обработка ошибок (Option, Try).
- **9.3 Обработка ошибок** — Try[T], Success, Failure; Either для возврата ошибки или результата; логирование и повтор.
- **9.4 Тестируемость** — выделение чистых функций преобразования; тесты на малых примерах данных (ScalaTest или minitest — кратко); моки для внешних вызовов.
- **9.5 Логирование** — выбор библиотеки (slf4j, logback); логирование в ETL-пайплайне (старт/конец шага, ошибки).
- *Ключевое:* конфиг, цепочка шагов, Try/Either, тесты. *Задания:* оформить простой ETL как цепочку с конфигом и обработкой ошибок.
