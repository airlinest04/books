# §4.3 Анонимные функции

В [§4.2](chapter-04-02.md) мы разобрали параметры по умолчанию и varargs. **Анонимные функции** (lambda, функциональные литералы) — функции без имени, которые задают выражением и часто передают в другие методы (map, filter и т.д.). В Scala они записываются компактно и широко используются при работе с коллекциями. В [§4.4](chapter-04-04.md) рассмотрим различие между методами и функциями как значениями.

---

## 4.3.1. Синтаксис: (параметры) => тело

Анонимная функция имеет вид:

```scala
(параметр1: Тип1, параметр2: Тип2, ...) => выражение
```

Слева от `=>` — параметры (с типами или без, если тип выводится); справа — тело (одно выражение или блок в фигурных скобках).

Примеры:

```scala
(x: Int) => x * 2
(s: String) => s.length
(a: Int, b: Int) => a + b
```

Типы параметров можно опустить, если компилятор выводит их из контекста (например, при передаче в `map`):

```scala
val list = List(1, 2, 3)
list.map((x) => x * 2)   // List(2, 4, 6)
list.map(x => x * 2)     // то же, скобки вокруг одного параметра опциональны
```

---

## 4.3.2. Сокращённая запись с подчёркиванием

Когда параметр используется в теле **один раз**, можно заменить его на **подчёркивание** `_`:

```scala
list.map(_ * 2)      // эквивалентно list.map(x => x * 2)
list.filter(_ > 0)   // эквивалентно list.filter(x => x > 0)
```

`_` — плейсхолдер для единственного параметра. Он должен входить в выражение, а не стоять отдельно: `_ * 2` — корректно, одиночное `_` в контексте `map` может трактоваться иначе (частичное применение).

Для **нескольких параметров** каждое вхождение `_` обозначает следующий по порядку параметр:

```scala
list.reduce(_ + _)   // эквивалентно (a, b) => a + b
```

`_ + _` — два параметра, первый и второй. Использовать `_` при более сложных выражениях нужно аккуратно: при неоднозначности компилятор выдаст ошибку; в таких случаях лучше писать явную функцию `(a, b) => ...`.

---

## 4.3.3. Сохранение в переменную

Анонимную функцию можно сохранить в `val` и вызывать:

```scala
val double = (x: Int) => x * 2
double(5)   // 10
```

Тип такой переменной — функция, например `Int => Int` (принимает Int, возвращает Int). Функции — значения первого класса; их можно передавать, возвращать и хранить. Подробнее — в [§4.4](chapter-04-04.md).

---

## 4.3.4. Передача в map и filter

Методы коллекций часто принимают функцию как аргумент. **map** применяет функцию к каждому элементу и возвращает новую коллекцию:

```scala
List(1, 2, 3).map(x => x * 2)   // List(2, 4, 6)
List(1, 2, 3).map(_ * 2)        // то же
```

**filter** оставляет только элементы, для которых функция возвращает true:

```scala
List(1, 2, 3, 4, 5).filter(x => x % 2 == 0)   // List(2, 4)
List(1, 2, 3, 4, 5).filter(_ % 2 == 0)        // то же
```

Эти методы — примеры **функций высшего порядка** ([§4.5](chapter-04-05.md)); анонимные функции естественно передаются в них.

---

## 4.3.5. Многострочное тело

Тело анонимной функции может быть блоком в фигурных скобках:

```scala
list.map { x =>
  val doubled = x * 2
  doubled + 1
}
```

При блоке параметры и `=>` задают вход; значением является последнее выражение в блоке.

---

## 4.3.6. Типичные ошибки

- **Слишком общая запись с `_`** — при неоднозначности (например, несколько `_` в сложном выражении) компилятор может не понять порядок параметров; используйте явные параметры.
- **Один `_` для identity** — `list.map(_)` не работает как «вернуть элемент»; используйте `identity`: `list.map(identity)` или `list.map(x => x)`.
- **Смешение `=>` и `->`** — `=>` в функции, `->` для пары (например, в Map); не путать.

---

## Ключевое

- **Анонимная функция:** `(параметры) => тело`; типы параметров опциональны при выводе.
- **Подчёркивание `_`** — плейсхолдер: `_ * 2` эквивалентно `x => x * 2`; `_ + _` — двум параметрам. Работает, когда параметр используется один раз.
- Функции — значения: можно сохранять в `val`, передавать в методы (map, filter) и возвращать из методов.
- **map** и **filter** принимают функцию; анонимные функции передаются в них постоянно.

В [§4.4](chapter-04-04.md) мы разберём разницу между методами (def) и функциями как значениями, а также преобразование метода в функцию.
