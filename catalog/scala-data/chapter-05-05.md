# §5.5 Общие операции коллекций

В [§5.4](chapter-05-04.md) мы углубили работу с Option. Завершаем главу о коллекциях сводкой **общих операций**, доступных List, Map, Set и другим коллекциям: проверка размера и вхождения, преобразования (map, flatMap, filter), свёртка (foldLeft, reduce) и преобразование в список. Эти методы — основа пайплайнов обработки данных. В [§6.1](chapter-06-01.md) начнём главу об объектно-ориентированном и функциональном стиле: классы и объекты. См. [Глоссарий](glossary.md).

---

## 5.5.1. size, isEmpty, length

Методы **size** и **length** возвращают количество элементов. **isEmpty** — пуста ли коллекция:

```scala
List(1, 2, 3).size      // 3
List(1, 2, 3).isEmpty   // false
List.empty[Int].isEmpty // true

Map("a" -> 1, "b" -> 2).size   // 2 (число пар)
Set(1, 2, 2, 3).size           // 3 (уникальных элементов)
```

Для List **size** и **length** эквивалентны; для Map и Set — число записей или элементов.

---

## 5.5.2. contains

**contains(elem)** — есть ли элемент в коллекции. Семантика зависит от типа:

- **List, Set:** проверка вхождения элемента `elem`;
- **Map:** `contains(key)` — есть ли такой ключ.

```scala
List(1, 2, 3).contains(2)   // true
Set(1, 2, 3).contains(5)    // false
Map("a" -> 1).contains("a") // true
Map("a" -> 1).contains("b") // false
```

У Map есть также **isDefinedAt(key)** — то же, что `contains(key)`. Для Set проверка `contains` в среднем O(1); для List — O(n).

---

## 5.5.3. map — преобразование каждого элемента

**map(f)** применяет функцию к каждому элементу и возвращает новую коллекцию того же вида:

```scala
List(1, 2, 3).map(_ * 2)        // List(2, 4, 6)
Set(1, 2, 3).map(_.toString)    // Set("1", "2", "3")
```

Для **Map** итерация идёт по парам `(ключ, значение)`. Функция получает кортеж `(K, V)`; результат map — коллекция (часто Map, если возвращать пары):

```scala
Map("a" -> 1, "b" -> 2).map { case (k, v) => (k, v * 2) }
// Map("a" -> 2, "b" -> 4)

Map("a" -> 1, "b" -> 2).map(_._2)   // List(1, 2) — только значения
```

Для преобразования только значений без изменения ключей удобен **mapValues** (создаёт view):

```scala
Map("a" -> 1, "b" -> 2).view.mapValues(_ * 2).toMap   // Map("a" -> 2, "b" -> 4)
```

---

## 5.5.4. flatMap — преобразование с «развёртыванием»

**flatMap(f)** применяет функцию `A => IterableOnce[B]` и объединяет результаты в одну коллекцию:

```scala
List(1, 2, 3).flatMap(x => List(x, x * 2))   // List(1, 2, 2, 4, 3, 6)
List("ab", "cd").flatMap(_.toList)           // List(a, b, c, d)

Set(1, 2).flatMap(x => Set(x, x + 10))       // Set(1, 2, 11, 12)
```

Типичное применение — обработка Option внутри коллекции: функция возвращает Option, flatMap «разворачивает» и отбрасывает None:

```scala
val opts = List(Some(1), None, Some(3))
opts.flatMap(x => x)   // List(1, 3)
// или короче:
opts.flatten           // List(1, 3)
```

Связь с for-comprehension: `for (x <- col; y <- f(x)) yield g(x, y)` эквивалентно `col.flatMap(x => f(x).map(y => g(x, y)))`.

---

## 5.5.5. filter и withFilter

**filter(p)** возвращает коллекцию только тех элементов, для которых предикат `p` истинен:

```scala
List(1, 2, 3, 4, 5).filter(_ % 2 == 0)   // List(2, 4)
Set(1, 2, 3).filter(_ > 1)               // Set(2, 3)

Map("a" -> 1, "b" -> 2, "c" -> 3).filter { case (_, v) => v > 1 }
// Map("b" -> 2, "c" -> 3)
```

**filterNot(p)** — обратная операция. **withFilter(p)** — ленивый фильтр для цепочек; при последовательных map/flatMap элементы отфильтровываются по пути, без создания промежуточной коллекции.

---

## 5.5.6. foreach — побочные эффекты

**foreach(f)** применяет функцию `A => Unit` к каждому элементу ради побочных эффектов (вывод, запись). Возвращает `Unit`:

```scala
List(1, 2, 3).foreach(println)
Map("a" -> 1, "b" -> 2).foreach { case (k, v) => println(s"$k -> $v") }
```

Для создания новой коллекции используют map; для эффектов — foreach.

---

## 5.5.7. foldLeft и reduce

**foldLeft(z)(op)** сворачивает коллекцию в одно значение, применяя бинарный оператор `(acc, elem) => acc` слева направо с начальным значением `z`:

```scala
List(1, 2, 3, 4, 5).foldLeft(0)(_ + _)   // 15
List("a", "b", "c").foldLeft("")(_ + _)  // "abc"
```

**reduce(op)** — то же без начального значения; в качестве аккумулятора берётся первый элемент. Для пустой коллекции — исключение:

```scala
List(1, 2, 3, 4, 5).reduce(_ + _)   // 15
List.empty[Int].reduce(_ + _)       // UnsupportedOperationException
```

**reduceOption** возвращает Option: `Some(result)` или `None` для пустой коллекции:

```scala
List(1, 2, 3).reduceOption(_ + _)   // Some(6)
List.empty[Int].reduceOption(_ + _) // None
```

foldLeft и reduce рассмотрены подробнее в [§4.5](chapter-04-05.md).

---

## 5.5.8. Преобразование в список: toList

**toList** превращает коллекцию в `List`:

```scala
Set(1, 2, 3).toList      // List (порядок не гарантирован)
Map("a" -> 1).toList     // List(("a", 1))
(1 to 5).toList          // List(1, 2, 3, 4, 5)
```

Аналогично: **toSet**, **toVector**, **toArray** — преобразование в нужный тип коллекции. Для Map `toList` даёт список пар `(K, V)`.

---

## 5.5.9. Цепочки и пайплайны

Методы объединяют в цепочки; результат каждого вызова — коллекция, к которой применяется следующий метод:

```scala
List(1, 2, 3, 4, 5, 6)
  .filter(_ % 2 == 0)
  .map(_ * 2)
  .foldLeft(0)(_ + _)
// 2*2 + 4*2 + 6*2 = 4 + 8 + 12 = 24
```

Пример с Map — отбор пар, преобразование, свёртка:

```scala
Map("a" -> 10, "b" -> 20, "c" -> 30)
  .filter { case (_, v) => v >= 20 }
  .view.mapValues(_ / 10).toMap
  .toList
  .map { case (k, v) => s"$k:$v" }
// List("b:2", "c:3")
```

Такие пайплайны — основа обработки данных: фильтрация записей, преобразование полей, агрегация.

## 5.5.10. Сводная таблица

| Метод | Назначение |
|-------|------------|
| size, length | Число элементов |
| isEmpty | Пуста ли коллекция |
| contains | Проверка вхождения (для Map — по ключу) |
| map(f) | Преобразование каждого элемента |
| flatMap(f) | Преобразование + объединение результатов |
| filter(p) | Отбор по предикату |
| foreach(f) | Побочные эффекты для каждого элемента |
| foldLeft(z)(op) | Свёртка с начальным значением |
| reduce(op) | Свёртка без начального значения |
| toList | Преобразование в List |

---

## Ключевое

- **size**, **isEmpty**, **contains** — общие для List, Map, Set. У Map `contains` проверяет ключ.
- **map** — преобразование каждого элемента; для Map итерация по парам (ключ, значение).
- **flatMap** — преобразование с «развёртыванием»; удобен для Option (flatten) и вложенных структур.
- **filter** — отбор по предикату; **foreach** — побочные эффекты.
- **foldLeft(z)(op)**, **reduce(op)** — свёртка в одно значение; reduce на пустой коллекции — исключение; **reduceOption** возвращает Option.
- **toList** — преобразование в List. Методы объединяют в пайплайны: filter → map → foldLeft.
