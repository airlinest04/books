# §5.2 Map

В [§5.1](chapter-05-01.md) мы разобрали List. **Map** — коллекция пар **ключ → значение**; доступ по ключу, а не по индексу. В Scala Map по умолчанию **неизменяем**: добавление и обновление создают новую структуру. В этом разделе: создание, доступ через `.get` (Option), `.getOrElse`, добавление и обновление через `+`. В [§5.3](chapter-05-03.md) рассмотрим Set. См. [Глоссарий](glossary.md).

---

## 5.2.1. Создание Map

Map создают из пар ключ–значение. Оператор **->** образует пару `(ключ, значение)`:

```scala
val map = Map("a" -> 1, "b" -> 2, "c" -> 3)
val empty: Map[String, Int] = Map.empty
```

Эквивалентная запись через кортежи: `Map(("a", 1), ("b", 2))`. Тип `Map[K, V]` — ключи типа K, значения типа V. Ключи должны быть уникальными; при дублировании сохраняется последнее значение.

```scala
Map("x" -> 1, "x" -> 2)   // Map(x -> 2)
```

---

## 5.2.2. Доступ по ключу: get и getOrElse

Метод **.get(key)** возвращает **Option[V]**: `Some(value)` при наличии ключа, `None` при отсутствии. В отличие от прямого доступа по индексу, это не выбрасывает исключение.

```scala
val m = Map("a" -> 1, "b" -> 2)
m.get("a")   // Some(1)
m.get("z")   // None
```

**getOrElse(key, default)** возвращает значение по ключу или `default`, если ключа нет:

```scala
m.getOrElse("a", 0)   // 1
m.getOrElse("z", 0)   // 0
```

При разборе данных из файлов и API поля часто отсутствуют; `getOrElse` даёт безопасное чтение с запасным значением.

**Прямой доступ m(key)** — при отсутствии ключа выбрасывает исключение. Использовать только когда ключ гарантированно есть, иначе предпочтительны `get` или `getOrElse`.

---

## 5.2.3. Добавление и обновление: оператор +

Для **неизменяемого** Map операции добавления и обновления возвращают **новый** Map; исходный не меняется.

**Добавление пары:** `map + (key -> value)`:

```scala
val m = Map("a" -> 1, "b" -> 2)
val m2 = m + ("c" -> 3)   // Map(a -> 1, b -> 2, c -> 3)
// m по-прежнему Map(a -> 1, b -> 2)
```

**Обновление:** если ключ уже есть, `+` перезаписывает значение:

```scala
val m3 = m + ("a" -> 10)   // Map(a -> 10, b -> 2)
```

Метод **updated(key, value)** делает то же: `m.updated("c", 3)`.

**Удаление:** оператор `-` удаляет ключ:

```scala
m - "a"   // Map(b -> 2)
```

**Несколько пар:** `map + (k1 -> v1, k2 -> v2)` или цепочка `map + (k1 -> v1) + (k2 -> v2)`.

---

## 5.2.4. Проверка ключей и обход

**contains(key)** — есть ли ключ в Map. **keys** — итератор по ключам. **values** — по значениям. **toList** — список пар `(key, value)`.

```scala
val m = Map("a" -> 1, "b" -> 2)
m.contains("a")    // true
m.contains("z")    // false
m.keys.toList      // List(a, b)
m.values.toList    // List(1, 2)
```

**Перебор пар:**

```scala
for ((k, v) <- m) println(s"$k -> $v")
m.foreach { case (k, v) => println(s"$k -> $v") }
```

## 5.2.5. mutable.Map (изменяемый Map)

Если нужны изменения на месте, используют **scala.collection.mutable.Map**:

```scala
import scala.collection.mutable

val m = mutable.Map("a" -> 1, "b" -> 2)
m("c") = 3         // добавление
m("a") = 10        // обновление
m -= "b"           // удаление
m.getOrElseUpdate("d", 4)   // получить или вычислить и сохранить
```

По умолчанию `Map` в Scala — **immutable**; для мутабельности явно указывают `mutable.Map`. В идиоматичном Scala предпочитают неизменяемые структуры; mutable.Map применяют при необходимости (например, кэш, накопление в цикле).

---

## 5.2.6. Преобразование из коллекции пар

Список пар можно превратить в Map через **.toMap**:

```scala
List(("a", 1), ("b", 2)).toMap   // Map(a -> 1, b -> 2)
```

Обратное — **.toList** у Map даёт список пар.

---

## 5.2.7. Типичные ошибки

- **m(key) при отсутствии ключа** — исключение; используйте `get` или `getOrElse`.
- **Забыть, что Map неизменяем** — `m + ("x" -> 1)` не меняет `m`; результат нужно присвоить переменной.
- **Ключи должны быть хешируемыми** — неизменяемые типы подходят; изменяемые (например, List) — нет.

---

## Ключевое

- **Map** — коллекция пар ключ → значение; создание: `Map("a" -> 1, "b" -> 2)`, `Map.empty`.
- **.get(key)** возвращает `Option[V]`; **.getOrElse(key, default)** — значение или default. Прямой доступ `m(key)` при отсутствии ключа — исключение.
- **Добавление/обновление:** `map + (key -> value)`; **удаление:** `map - key`. Неизменяемый Map; операции возвращают новый Map.
- **mutable.Map** — изменяемая версия; присваивание по ключу, `-=`, `getOrElseUpdate`.

В [§5.3](chapter-05-03.md) мы разберём Set: коллекцию уникальных элементов.
