# §4.1 Определение функции

В [§3.4](chapter-03-04.md) мы разобрали циклы while и do-while. Теперь переходим к **функциям и методам**: они позволяют выделить повторяющуюся логику в отдельный блок с именем, параметрами и возвращаемым значением. В этом разделе — синтаксис **def**, параметры с типами, возвращаемый тип и отсутствие явного return. В [§4.2](chapter-04-02.md) рассмотрим параметры по умолчанию, именованные аргументы и varargs.

---

## 4.1.1. Синтаксис def

Функция (метод) определяется ключевым словом **def**, именем, списком параметров с типами и телом:

```scala
def имя(параметр1: Тип1, параметр2: Тип2): ВозвращаемыйТип = тело
```

**Параметры** — в круглых скобках, каждый с указанием типа. **Возвращаемый тип** — после скобок, через двоеточие; может выводиться компилятором, но для публичного API рекомендуется указывать явно. Тело — выражение или блок в фигурных скобках.

Пример:

```scala
def add(a: Int, b: Int): Int = a + b
def greet(name: String): String = s"Hello, $name!"
```

**Вызов** — имя и аргументы в скобках:

```scala
add(2, 3)           // 5
greet("Alice")      // "Hello, Alice!"
```

Методы в Scala определяются внутри **object**, **class** или **trait**. Для скриптов и примеров код обычно помещают в object:

```scala
object Main {
  def add(a: Int, b: Int): Int = a + b
  def main(args: Array[String]): Unit =
    println(add(2, 3))
}
```

---

## 4.1.2. Возврат значения: последнее выражение

В Scala **нет** ключевого слова `return` в обычном коде. Значение функции — значение **последнего выражения** в теле. Если тело — один блок `{ ... }`, возвращается результат последнего выражения в блоке:

```scala
def add(a: Int, b: Int): Int = {
  val sum = a + b
  sum
}
```

Или короче:

```scala
def add(a: Int, b: Int): Int = a + b
```

Ключевое слово `return` существует, но его используют только для досрочного выхода из метода. В идиоматичном Scala предпочитают структурировать код так, чтобы «выход» был через последнее выражение; `return` усложняет контроль потока и может нарушить семантику вложенных функций.

---

## 4.1.3. Вывод возвращаемого типа

Компилятор может **вывести** возвращаемый тип по телу:

```scala
def add(a: Int, b: Int) = a + b   // тип результата — Int
```

Для публичных методов и библиотечного API **рекомендуется указывать тип явно**: это документирует контракт, помогает при рефакторинге и упрощает чтение. Для коротких приватных вспомогательных методов вывод типа допустим.

---

## 4.1.4. Процедуры: Unit

Методы, которые не возвращают осмысленное значение (только побочные эффекты — вывод, запись и т.д.), имеют возвращаемый тип **Unit** ([§2.2](chapter-02-02.md)):

```scala
def log(msg: String): Unit = {
  println(msg)
}
```

Тип `Unit` можно опустить — компилятор выведет его для тел с `println` и подобными вызовами. Явное указание `Unit` подчёркивает, что метод — процедура:

```scala
def log(msg: String): Unit = println(msg)
```

---

## 4.1.5. Блок как тело

Тело метода может быть **блоком** в фигурных скобках. Значение блока — значение последнего выражения:

```scala
def max(a: Int, b: Int): Int = {
  val result = if (a > b) a else b
  result
}
```

Промежуточные `val` и выполняемые инструкции (с побочными эффектами) допустимы; возвращается только последнее выражение. Если последнее выражение — `println(...)`, тип будет Unit.

---

## 4.1.6. Отсутствие параметров

Метод без параметров объявляют с пустыми скобками:

```scala
def getDefaultName(): String = "unknown"
getDefaultName()
```

В Scala методы могут быть объявлены **без скобок** — `def name: Type`. Разница: `def name()` — метод с пустым списком аргументов, вызывается как `name()`; `def name` — метод без параметров, вызывается как `name` (без скобок). Для методов с побочными эффектами принято использовать `()`; для вычисления «свойства» — без скобок. Подробнее — в [§4.4](chapter-04-04.md).

---

## 4.1.7. ScalaDoc

Документацию к методу пишут в виде **ScalaDoc** — комментарий `/** ... */` непосредственно перед объявлением:

```scala
/** Возвращает сумму двух целых чисел. */
def add(a: Int, b: Int): Int = a + b

/**
 * Форматирует имя и возраст.
 * @param name имя
 * @param age возраст
 * @return строка вида "Name (age)"
 */
def formatPerson(name: String, age: Int): String =
  s"$name ($age)"
```

ScalaDoc используется для генерации документации (например, scaladoc) и отображается в IDE при наведении на метод.

---

## 4.1.8. Типичные ошибки

- **Забыть тип параметра** — в def параметры должны иметь тип: `def f(x: Int)` корректно, `def f(x)` — только если тип выводится из контекста (редко для параметров).
- **Путать `=` и `:`** — возвращаемый тип после двоеточия, тело после `=`.
- **Ожидать return** — в Scala возвращается последнее выражение; явный return обычно не нужен.
- **Процедура без Unit** — если последнее выражение — `println` или подобное, результат Unit; при необходимости явно укажите `: Unit`.

---

## Ключевое

- **def имя(параметры: типы): ВозвращаемыйТип = тело** — определение метода; параметры с типами, возвращаемый тип опционален, но рекомендуется для публичного API.
- **Возврат** — значение последнего выражения в теле; явный `return` обычно не используется.
- **Unit** — тип для процедур (методов без осмысленного возвращаемого значения).
- Блок `{ ... }` как тело; значение блока — последнее выражение. **ScalaDoc** — документация в `/** ... */` перед объявлением.

В [§4.2](chapter-04-02.md) мы разберём параметры по умолчанию, именованные аргументы и повторяющиеся параметры (varargs).
