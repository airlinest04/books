## Подробное содержание

### Глава 1. Введение в MPP и Greenplum

- **1.1 Зачем MPP-СУБД** — масштабирование «по горизонтали»; разделение данных и запросов между узлами; отличия от SMP; когда MPP уместен (аналитика, DWH, петабайты).
- **1.2 Что такое Greenplum** — MPP-СУБД на базе PostgreSQL; история (Greenplum Inc., Pivotal, VMware); open source и коммерческие версии; связь с Apache MADlib.
- **1.3 Связь с PostgreSQL** — Greenplum как форк PostgreSQL; совместимость SQL; что изменено под MPP (распределение, типы таблиц, план выполнения).
- **1.4 Сценарии использования** — DWH и витрины; пакетная аналитика; стриминг (Kafka); интеграция с Hadoop и облаком.
- *Ключевое:* MPP, Greenplum, сценарии использования. *Задания:* определить, когда Greenplum уместен по сравнению с PostgreSQL.

---

### Глава 2. Архитектура Greenplum

- **2.1 Master и Standby Master** — Master: точка входа, планировщик запросов, распределение плана; Standby Master для отказоустойчивости; failover.
- **2.2 Сегменты (Segment nodes)** — каждый сегмент — экземпляр PostgreSQL; хранение части данных; primary и mirror сегменты.
- **2.3 Interconnect** — сеть между Master и Segments; передача данных при JOIN и агрегации; типы соединений (UDP, TCP); настройки.
- **2.4 Поток выполнения запроса** — от клиента к Master; построение плана; рассылка по сегментам; сбор результатов; motion-операции.
- *Ключевое:* Master, Segment, Interconnect, поток запроса. *Задания:* объяснить, как запрос распределяется по сегментам.

---

### Глава 3. Установка и инициализация

- **3.1 Требования к окружению** — ОС (Linux), CPU, RAM, диск; сеть; пользователь gpadmin; SSH без пароля между узлами.
- **3.2 Установка Greenplum** — где взять дистрибутив; установка RPM/DEB; распаковка бинарников; переменные окружения (GPHOME, PATH).
- **3.3 Конфигурация и gpinitsystem** — файл конфигурации; hostfile; создание данных на сегментах; gpinitsystem; создание кластера.
- **3.4 Первый запуск и проверка** — gpstart; psql; проверка gp_segment_configuration; простой запрос.
- *Ключевое:* gpinitsystem, gpstart, проверка кластера. *Задания:* развернуть тестовый кластер на одной или нескольких машинах.

### Глава 4. Управление кластером

- **4.1 gpstart и gpstop** — запуск и остановка кластера; graceful vs immediate; gpstop -u (reload config).
- **4.2 Отказоустойчивость: gprecoverseg** — восстановление упавших сегментов; mirror-сегменты; балансировка.
- **4.3 Утилиты администратора** — gpstate, gpconfig, gpcheck; просмотр конфигурации; изменение параметров.
- **4.4 Мониторинг и логи** — расположение логов; анализ ошибок; интеграция с внешним мониторингом.
- *Ключевое:* gpstart, gpstop, gprecoverseg, утилиты. *Задания:* симулировать сбой сегмента и восстановление.

---

### Глава 5. Типы таблиц

- **5.1 Heap-таблицы** — по умолчанию; row-oriented; подходят для OLTP-подобных сценариев; UPDATE/DELETE.
- **5.2 Append-Optimized (AO)** — оптимизация для bulk-вставки; сжатие; AO row vs AO columnar.
- **5.3 Колоночное хранение (AO Columnar)** — хранение по столбцам; выгода для аналитических запросов; сжатие; когда использовать.
- **5.4 Выбор типа таблицы** — heap vs AO vs columnar; сценарии (загрузка сырых данных, витрины, аналитика).
- *Ключевое:* heap, AO, AO columnar, сжатие. *Задания:* создать таблицы разных типов и сравнить производительность.

---

### Глава 6. Распределение и партиционирование

- **6.1 DISTRIBUTED BY: выбор ключа распределения** — как данные распределяются по сегментам; hash-распределение по столбцу(ам); влияние на JOIN.
- **6.2 Равномерное распределение (DISTRIBUTED RANDOMLY)** — круглые столбцы; когда использовать; распределение по столбцам.
- **6.3 Партиционирование (PARTITION BY)** — разбиение больших таблиц; partition pruning; RANGE, LIST.
- **6.4 Партиционирование по диапазону и списку** — RANGE (даты, числа); LIST (регион, статус); подпартиции.
- *Ключевое:* DISTRIBUTED BY, PARTITION BY, partition pruning. *Задания:* спроектировать распределение и партиционирование для DWH-слоёв.

### Глава 7. SQL в Greenplum

- **7.1 Совместимость с PostgreSQL** — что работает как в PostgreSQL (SELECT, JOIN, CTE, оконные функции); ограничения и отличия.
- **7.2 Особенности диалекта** — расширения для MPP; системные представления (gp_*); функции Greenplum.
- **7.3 Массовая загрузка (COPY, gpload)** — COPY для быстрой загрузки из файла; gpload для ETL; форматы (CSV, TEXT); параллельная загрузка.
- **7.4 Представления и материализованные представления** — CREATE VIEW; MATERIALIZED VIEW; REFRESH; использование в DWH.
- *Ключевое:* совместимость с PostgreSQL, COPY, gpload, VIEW. *Задания:* загрузка данных через COPY; создание витрин.

### Глава 8. Оптимизация запросов

- **8.1 EXPLAIN и EXPLAIN ANALYZE** — чтение плана; Seq Scan, Index Scan; motion (Gather Motion, Redistribute Motion, Broadcast Motion); cost.
- **8.2 Статистика и ANALYZE** — важность статистики; ANALYZE; autovacuum; настройка выборки.
- **8.3 Типичные узкие места** — data skew; broadcast vs redistribute; лишние motion; перераспределение.
- **8.4 Профилирование и настройка** — настройки GUC; work_mem, statement_mem; gp_resqueue; профилирование медленных запросов.
- *Ключевое:* EXPLAIN ANALYZE, motion, skew, ANALYZE. *Задания:* оптимизировать медленный запрос по плану.

### Глава 9. Внешние данные (PXF)

- **9.1 Protocol eXtension Framework (PXF)** — доступ к внешним источникам без загрузки в Greenplum; архитектура PXF.
- **9.2 Доступ к HDFS и облачным хранилищам** — connectors; S3, Azure Blob, HDFS; настройка.
- **9.3 Форматы: Parquet, ORC, Avro** — чтение колоночных форматов; predicate pushdown; выбор формата.
- **9.4 External tables** — CREATE EXTERNAL TABLE; LOCATION; запросы к внешним данным как к обычным таблицам.
- *Ключевое:* PXF, external table, Parquet, ORC. *Задания:* создать external table к файлам в HDFS/S3.
