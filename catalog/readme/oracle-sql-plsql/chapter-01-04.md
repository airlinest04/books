# §1.4 Первый запрос

В [§1.3](chapter-01-03.md) мы рассмотрели основные объекты схемы — таблицы, представления, синонимы, последовательности — и научились смотреть их список в словаре данных. Теперь выполним **первый запрос SELECT**: выберем данные из таблицы в SQL*Plus и в SQL Developer, разберём, как отправлять запрос на выполнение и как настроить **форматирование вывода**, чтобы результат был читаемым. Этого достаточно, чтобы закрыть введение в среду Oracle; детальный разбор синтаксиса SELECT, списка столбцов, фильтрации (WHERE) и функций — в [главе 3](chapter-03-01.md). См. [Глоссарий](glossary.md).

## 1.4.1. Базовый SELECT: выборка из таблицы

**SELECT** — оператор SQL для выборки данных. Минимальная форма запроса «все столбцы из одной таблицы»:

```sql
SELECT * FROM имя_таблицы;
```

Звёздочка (`*`) означает «все столбцы таблицы»; `FROM имя_таблицы` задаёт источник данных. Результат — набор строк (набор результатов, result set): столько строк, сколько удовлетворяет запросу (пока без условия — все строки таблицы), и столько столбцов, сколько их в таблице. Точка с запятой в конце завершает оператор; в большинстве клиентов именно она запускает выполнение. См. [Глоссарий](glossary.md).

Пример для учебной схемы (если в базе есть таблица `HR.EMPLOYEES` и вам выдана привилегия SELECT):

```sql
SELECT * FROM HR.EMPLOYEES;
```

Либо из своей схемы, если у вас уже есть таблица:

```sql
SELECT * FROM user_tables;
```

Это запрос к представлению словаря данных: вы получите список своих таблиц. Выбор конкретных столбцов, псевдонимы, выражения и условия WHERE мы разберём в главе 3; здесь важно понять: **SELECT ... FROM ... ;** — это запрос на чтение данных, он не меняет данные в базе.

## 1.4.2. Выполнение запроса в SQL*Plus

В **SQL*Plus** вы вводите запрос с клавиатуры (или вставляете из буфера) и завершаете строку с точкой с запятой. После нажатия Enter SQL*Plus может переносить длинные строки на следующую строку (признак продолжения — `2` или `3` в начале строки); выполнение начинается только после ввода точки с запятой и нажатия Enter.

Альтернатива точке с запятой — **слэш на новой строке**: ввести запрос (можно без `;`), нажать Enter и на следующей строке ввести одну кнопку `/` и Enter. SQL*Plus выполнит последний введённый SQL-оператор (буфер текущего оператора). Для PL/SQL-блоков слэш используется как разделитель выполнения блока (подробнее в части II книги).

Порядок действий:

1. Запустить SQL*Plus и подключиться (например, `sqlplus user@host:1521/ORCL`).
2. Ввести запрос, например: `SELECT * FROM user_tables;`
3. Нажать Enter. Запрос выполнится; результат выведется в консоль.

Если запрос вернул много столбцов или длинные значения, вывод может «съезжать» или переноситься неудобно. Ниже мы настроим форматирование. Выполнение скрипта из файла: в SQL*Plus выполнить `@путь/к/файлу.sql` или `START путь/к/файлу.sql`.

## 1.4.3. Выполнение запроса в SQL Developer

В **SQL Developer** запрос вводят в **редакторе листа (Worksheet)**. Откройте соединение (двойной щелчок или «Connect»), затем откройте лист для этого соединения (иконка «Open SQL Worksheet» или контекстное меню соединения). Введите или вставьте запрос в окно редактора.

Способы выполнения:

- **Выполнить текущий оператор:** установите курсор внутрь нужного оператора и нажмите **Ctrl+Enter** (или кнопка «Run Statement»). Выполнится только тот оператор, в котором находится курсор. Результат отображается во вкладке «Query Result» в виде сетки (строки и столбцы).
- **Выполнить весь скрипт:** нажмите **F5** (или кнопка «Run Script»). Выполняются все операторы в окне по порядку; вывод идёт в панель «Script Output» в текстовом виде, как в SQL*Plus. Точка с запятой разделяет операторы.

Рекомендуется для одного запроса: курсор в запросе и **Ctrl+Enter** — результат в сетке, удобно просматривать и экспортировать. Для скрипта из нескольких команд (например, несколько SELECT и вывод в консоль) — **F5**.

После выполнения во вкладке «Query Result» можно прокручивать строки, менять ширину столбцов перетаскиванием границ заголовков, копировать ячейки. Количество выбранных строк отображается внизу панели.

## 1.4.4. Форматирование вывода

### SQL*Plus

По умолчанию SQL*Plus выводит данные в фиксированном формате: ширина столбца определяется длиной заголовка или данными, длина строки вывода ограничена (часто 80 символов), после каждых N строк выводится заголовок (разделитель страницы). При широких таблицах или длинных значениях вывод трудно читать. Основные команды настройки (действуют до конца сессии или до изменения снова):

**Ширина строки вывода и размер «страницы»:**

```text
SET LINESIZE 200
SET PAGESIZE 50
```

`LINESIZE` — максимальное число символов в одной строке вывода (перенос длинных столбцов или обрезка зависят от настроек столбцов). `PAGESIZE` — сколько строк выводить между повторениями заголовка столбцов; 0 отключает разбиение на страницы и заголовки между блоками (удобно для вывода в файл).

**Ширина и перенос конкретного столбца:**

```text
COLUMN имя_столбца FORMAT A30
```

`A30` — символьный столбец шириной 30 символов. Для чисел используют формат вроде `COLUMN sal FORMAT 99999.99`. Имя столбца задаётся так, как он отображается в заголовке (обычно в верхнем регистре). Сбросить настройки столбца: `COLUMN имя_столбца CLEAR`.

**Отключение переноса строк в ячейке (wrap):**

```text
SET WRAP OFF
```

Длинные значения тогда обрежутся по ширине столбца (если задана через COLUMN) или по LINESIZE. Для «длинных» столбцов часто задают `COLUMN ... FORMAT A40` или нужную ширину.

Пример настройки перед запросом к таблице с длинными именами:

```text
SET LINESIZE 200
SET PAGESIZE 100
COLUMN table_name FORMAT A30
SELECT table_name, tablespace_name FROM user_tables;
```

### SQL Developer

В SQL Developer вывод в сетке «Query Result» настраивается через интерфейс: ширина столбцов меняется перетаскиванием границ заголовков; можно включить перенос текста в ячейке (правый щелчок по заголовку или настройки отображения). Сохранение результата в файл: правый щелчок по сетке — Export — выбрать формат (CSV, Excel, Insert и т.д.). Для скриптового вывода (F5) формат задаётся настройками панели «Script Output» и глобальными настройками приложения.

## 1.4.5. Типичные ошибки при первом запросе

- **Забыть точку с запятой в SQL*Plus:** без `;` или `/` SQL*Plus считает, что запрос не закончен, и ждёт продолжения. В SQL Developer при выполнении одним оператором (Ctrl+Enter) точка с запятой не обязательна, но для стиля и для Run Script (F5) её лучше ставить.
- **Обращение к несуществующей таблице или без прав:** «ORA-00942: table or view does not exist» — либо таблица в другой схеме (нужен префикс `схема.таблица` и привилегия SELECT), либо имя набрано с ошибкой. Имена в Oracle по умолчанию в верхнем регистре; кавычки в именах разбираются в §2.1.
- **Путать Run Statement (Ctrl+Enter) и Run Script (F5) в SQL Developer:** первый выполняет один оператор и даёт результат в сетке; второй выполняет весь текст как скрипт и выводит в Script Output. Для одного SELECT удобнее Ctrl+Enter.
- **Ожидать изменения данных от SELECT:** SELECT только читает данные; вставка, обновление и удаление выполняются операторами INSERT, UPDATE, DELETE (глава 5).
- **Не учитывать LINESIZE и ширину столбцов в SQL*Plus:** при большом числе или длинных столбцах вывод «наезжает» или не помещается. Задайте SET LINESIZE и при необходимости COLUMN ... FORMAT.

## Ключевое

- **SELECT * FROM имя_таблицы;** — выборка всех столбцов из таблицы; результат — набор строк. SELECT не изменяет данные.
- **SQL*Plus:** ввод запроса, завершение `;` или на новой строке `/`; выполнение скрипта — `@файл.sql`. Форматирование: SET LINESIZE, SET PAGESIZE, COLUMN ... FORMAT, SET WRAP OFF.
- **SQL Developer:** запрос в Worksheet; **Ctrl+Enter** — выполнить текущий оператор, результат в сетке; **F5** — выполнить скрипт, вывод в Script Output. Ширина столбцов и экспорт — через интерфейс результата.
- Для читаемого вывода в SQL*Plus задайте LINESIZE, PAGESIZE и при необходимости формат столбцов (COLUMN). В SQL Developer настройте ширину столбцов в сетке или экспортируйте в файл.
