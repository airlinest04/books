# §10.4 CONTINUE, EXIT с меткой

В [§10.3](chapter-10-03.md) мы разобрали циклы LOOP, WHILE и FOR. **EXIT** и **EXIT WHEN** прерывают цикл (выход из текущего цикла). **CONTINUE** переходит к **следующей итерации** того же цикла, пропуская остаток тела. При **вложенных циклах** выход или переход только из внутреннего цикла по умолчанию затрагивает именно его; чтобы выйти из внешнего или продолжить итерацию внешнего, используют **метки циклов** и **EXIT метка** / **CONTINUE метка**. В этом разделе — синтаксис CONTINUE и CONTINUE WHEN, повтор EXIT и применение меток. Глава 10 на этом завершается; далее [глава 11](chapter-11-01.md): процедуры и функции. См. [Глоссарий](glossary.md).

---

## 10.4.1. CONTINUE и CONTINUE WHEN

**CONTINUE** — оператор PL/SQL: прерывает текущую итерацию цикла и передаёт управление на начало **следующей** итерации (или на проверку условия в WHILE/FOR). Остаток тела цикла после CONTINUE не выполняется. См. [Глоссарий](glossary.md).

**CONTINUE WHEN** условие — выполнить CONTINUE только если условие истинно; иначе выполнение идёт дальше. Удобно для пропуска «неподходящих» значений без вложенного IF.

Синтаксис:

```plsql
CONTINUE;           -- немедленный переход к следующей итерации
CONTINUE WHEN условие;
```

Пример: вывести только чётные числа от 1 до 10:

```plsql
BEGIN
  FOR i IN 1..10 LOOP
    CONTINUE WHEN MOD(i, 2) != 0;   -- пропустить нечётные
    DBMS_OUTPUT.PUT_LINE(i);
  END LOOP;
END;
/
```

CONTINUE и CONTINUE WHEN появились в Oracle 11g. В более ранних версиях ту же логику реализуют через IF и GOTO или переструктурирование условия. См. [Глоссарий](glossary.md). Среда: Oracle 11g и новее.

## 10.4.2. EXIT и EXIT WHEN (напоминание)

**EXIT** без аргументов выходит из **текущего** (внутреннего) цикла. **EXIT WHEN** условие — выход при истинном условии. Уже использовались в §10.3 в базовом LOOP. Вложенный цикл: EXIT прерывает только тот LOOP/WHILE/FOR, в теле которого он записан. См. [Глоссарий](glossary.md).

Пример: поиск в двумерной сетке — при нахождении нужного значения выйти из обоих циклов. Без метки пришлось бы использовать флаговую переменную и проверять её во внешнем цикле. С меткой — см. ниже.

## 10.4.3. Метка цикла и EXIT/CONTINUE с меткой

**Метка** — идентификатор, помечающий цикл; записывается в угловых скобках перед LOOP: **<<имя_метки>>**. Тот же идентификатор указывается после **END LOOP** (для читаемости): **END LOOP имя_метки;** См. [Глоссарий](glossary.md).

**EXIT** метка **[WHEN условие]** — выход из цикла с указанной меткой (может быть внешний при вложенности). **CONTINUE** метка **[WHEN условие]** — переход к следующей итерации цикла с указанной меткой. Так из внутреннего цикла можно выйти сразу из внешнего или перейти к следующей итерации внешнего. См. [Глоссарий](glossary.md).

Пример: выход из вложенных циклов по метке:

```plsql
<<outer>>
FOR i IN 1..3 LOOP
  FOR j IN 1..3 LOOP
    DBMS_OUTPUT.PUT_LINE(i || ',' || j);
    EXIT outer WHEN i = 2 AND j = 2;   -- выйти из обоих циклов
  END LOOP;
END LOOP outer;
```

Без метки **EXIT** вышло бы только из внутреннего FOR. С **EXIT outer** управление переходит сразу за **END LOOP outer**. См. [Глоссарий](glossary.md).

---

## Ключевое

- **CONTINUE** — переход к следующей итерации текущего цикла (остаток тела пропускается). **CONTINUE WHEN** условие — то же при истинном условии. Oracle 11g+. См. [Глоссарий](glossary.md).
- **EXIT** и **EXIT WHEN** выходят из текущего цикла; во вложенных — только из того, в теле которого стоят.
- **Метка цикла**: **<<имя>>** перед LOOP; **EXIT** имя **[WHEN условие]** и **CONTINUE** имя **[WHEN условие]** — выход или переход к итерации цикла с этой меткой (в т.ч. внешнего при вложенности).
- END LOOP может заканчиваться именем метки: **END LOOP** имя_метки**;** — для ясности при длинных блоках.
