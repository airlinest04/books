# §3.1 SELECT

В [§2.5](chapter-02-05.md) мы завершили главу о модели данных и последовательностях. В [§1.4](chapter-01-04.md) уже выполнялся простой запрос **SELECT * FROM таблица**. Теперь разберём **SELECT** подробнее: как выбирать не все столбцы, а нужный **список столбцов**, как задавать **псевдонимы (AS)** для столбцов и выражений, как использовать **выражения** (арифметика, конкатенация), а также основные **функции** Oracle: **UPPER**, **LOWER**, **TO_CHAR**, **TO_DATE**, **NVL**. Фильтрацию строк по условию (WHERE) рассмотрим в [§3.2](chapter-03-02.md). См. [Глоссарий](glossary.md).

---

## 3.1.1. Список столбцов

Вместо звёздочки (*) в SELECT можно перечислить **столбцы через запятую** — в результате появятся только они и в указанном порядке:

```sql
SELECT id, name, price FROM products;
```

Имена столбцов задаются так, как они определены в таблице (обычно в верхнем регистре, если созданы без кавычек). Столбец из другой схемы указывается с префиксом: `SELECT owner, table_name FROM all_tables`. Один и тот же столбец можно указать несколько раз — в наборе результатов будет несколько колонок с одинаковыми данными. См. [Глоссарий](glossary.md).

---

## 3.1.2. Псевдонимы (AS)

Заголовок колонки в результате по умолчанию совпадает с именем столбца или с видом выражения. Чтобы задать другое имя заголовка (например, для отчёта или для удобства в приложении), используют **псевдоним (alias)**. Синтаксис:

```sql
выражение_или_столбец [AS] псевдоним
```

Ключевое слово **AS** необязательно; псевдоним можно писать сразу после выражения или столбца. Если псевдоним содержит пробелы, спецсимволы или нужно сохранить регистр — его заключают в **двойные кавычки**. Без кавычек Oracle приводит псевдоним к верхнему регистру. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT id AS product_id, name AS product_name FROM products;

SELECT id product_id, name product_name FROM products;   -- то же без AS

SELECT price * 1.2 AS "Price with VAT" FROM products;   -- кавычки для пробела и регистра
```

В PL/SQL и в подзапросах псевдонимы используются для обращения к колонкам результата по имени.

## 3.1.3. Выражения в SELECT

В списке SELECT можно указывать не только столбцы, но и **выражения**: константы, арифметику, конкатенацию строк и вызовы функций. Результат выражения — это вычисленное значение для каждой строки.

**Арифметика:** операторы +, -, *, / для чисел. Приоритет как в математике; скобки задают порядок. Деление на NULL даёт NULL. Пример:

```sql
SELECT name, price, price * 0.9 AS discount_price FROM products;
```

**Конкатенация строк:** в Oracle символ **||** объединяет строки. Пример:

```sql
SELECT 'Product: ' || name || ', price: ' || price AS info FROM products;
```

Если один из операндов не символьный (например, число или дата), Oracle неявно преобразует его в строку по правилам сессии (для даты — NLS_DATE_FORMAT). Для явного формата даты используют TO_CHAR (см. ниже). **Литералы** (константы) в запросе: строки в одинарных кавычках, числа без кавычек. См. [Глоссарий](glossary.md).

---

## 3.1.4. Функции UPPER и LOWER

**UPPER(строка)** возвращает строку в **верхнем регистре**, **LOWER(строка)** — в **нижнем**. Аргумент — символьное выражение (столбец, литерал, результат другой функции). См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT UPPER(name) AS name_upper, LOWER(name) AS name_lower FROM products;

SELECT * FROM users WHERE LOWER(login) = 'admin';   -- сравнение без учёта регистра
```

Функция **INITCAP(строка)** возвращает строку с первой буквой каждого слова в верхнем регистре, остальными в нижнем (удобно для имён и заголовков). NULL передаётся в функцию и возвращается как NULL (если не обрабатывается отдельно, например через NVL).

---

## 3.1.5. TO_CHAR и TO_DATE: форматирование и разбор дат

В Oracle дата хранится внутренне без «формата»; при выводе в символьный вид и при вводе из строки используется формат. **TO_CHAR** преобразует дату (или число) в строку по заданному формату; **TO_DATE** преобразует строку в дату по формату. См. [Глоссарий](glossary.md).

**TO_CHAR(datetime [, формат [, nls_param]])** — дата/время в строку. Элементы формата (по документации Oracle): DD — день, MM — месяц, YYYY — год, MON — краткое имя месяца, HH24 — часы (0–23), MI — минуты, SS — секунды. Пример:

```sql
SELECT TO_CHAR(created_at, 'DD.MM.YYYY HH24:MI') AS created_formatted FROM orders;
```

Если формат не указан, используется NLS_DATE_FORMAT сессии. Явный формат делает запрос предсказуемым при любых настройках.

**TO_DATE(строка [, формат [, nls_param]])** — строка в дату. Формат должен соответствовать строке. Пример:

```sql
SELECT TO_DATE('15.02.2025', 'DD.MM.YYYY') FROM DUAL;
```

Рекомендуется **всегда указывать формат** в TO_DATE, чтобы не зависеть от NLS настроек (иначе строка '02-15-2025' может трактоваться по-разному). **DUAL** — служебная однострочная таблица Oracle для вычисления выражений без обращения к своим таблицам (SELECT выражение FROM DUAL). См. [Глоссарий](glossary.md).

**TO_CHAR** для чисел позволяет задать формат вывода (знаки, разделители, количество знаков после запятой), например TO_CHAR(1234.5, '9999.99').

## 3.1.6. NVL: подстановка значения вместо NULL

Если столбец или выражение может быть NULL, а в результате нужно показать другое значение (например, 0 или '-'), используют **NVL(выражение, значение_если_NULL)**. Функция возвращает второй аргумент, если первый равен NULL, иначе — первый. Оба аргумента могут быть любого типа; типы должны быть совместимы (или приводимы). См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT name, NVL(price, 0) AS price FROM products;        -- вместо NULL вывести 0

SELECT name, NVL(TO_CHAR(comments), '-') AS comments FROM products;
```

**NVL2(выражение, значение_если_не_NULL, значение_если_NULL)** — три аргумента: если первое не NULL, возвращается второе, иначе третье. Удобно, когда нужно два разных подставляемых значения. См. [Глоссарий](glossary.md).

```sql
SELECT name, NVL2(price, 'Yes', 'No') AS has_price FROM products;
```

**COALESCE(expr1, expr2, ...)** возвращает первое не-NULL значение из списка; удобно для выбора первого «заполненного» из нескольких столбцов.

## 3.1.7. Пример запроса с несколькими элементами

Сводный пример: список столбцов, псевдонимы, выражение, функции.

```sql
SELECT id,
       UPPER(name) AS name_upper,
       price,
       NVL(price, 0) * 1.2 AS price_with_vat,
       TO_CHAR(created_at, 'YYYY-MM-DD') AS created_date
  FROM products;
```

Здесь: исходные id и price; имя в верхнем регистре с псевдонимом; вычисление «цена с НДС» с подстановкой 0 вместо NULL; дата в формате год-месяц-день. Условие отбора строк (WHERE) добавим в [§3.2](chapter-03-02.md).

## 3.1.8. Типичные ошибки при использовании SELECT и функций

- **Путать одинарные и двойные кавычки:** строковые литералы и форматы дат — в **одинарных** кавычках. Двойные кавычки в Oracle — для идентификаторов (имена столбцов, псевдонимы с пробелами/регистром).
- **Забыть формат в TO_DATE:** строка '2025-02-15' при разных NLS может трактоваться как 15 февраля или как неверная дата. Всегда указывайте формат: TO_DATE('2025-02-15', 'YYYY-MM-DD').
- **Сравнивать строки с учётом регистра без подготовки:** сравнение name = 'Admin' не найдёт 'ADMIN' или 'admin'. Используйте UPPER(name) = 'ADMIN' или LOWER(name) = 'admin' (и тогда литерал в одном регистре).
- **Ожидать от NVL изменение самой таблицы:** NVL только подменяет значение в результате запроса; данные в таблице не меняются.
- **Арифметика с NULL:** любая операция с NULL даёт NULL (например, price + NULL, 10 * NULL). Для «трактовать NULL как 0» используйте NVL(price, 0) в выражении.
- **Псевдоним с пробелом без кавычек:** `AS Price With VAT` будет воспринято как три отдельных слова и вызовет ошибку. Нужно `AS "Price With VAT"`.

## Ключевое

- В **SELECT** перечисляют столбцы через запятую или выражения. Порядок столбцов в списке задаёт порядок в результате.
- **Псевдоним:** выражение **AS** псевдоним или выражение псевдоним. Для пробелов и спецсимволов — псевдоним в двойных кавычках.
- **Выражения:** арифметика (+, -, *, /), конкатенация строк (**||**), вызовы функций. Литералы: строки в одинарных кавычках.
- **UPPER(строка)** / **LOWER(строка)** — приведение к верхнему/нижнему регистру. **INITCAP** — первые буквы слов с заглавной.
- **TO_CHAR(datetime, формат)** — дата в строку. **TO_DATE(строка, формат)** — строка в дату. Формат задавать явно (DD.MM.YYYY, YYYY-MM-DD и т.д.).
- **NVL(выражение, значение_если_NULL)** — подстановка вместо NULL. **NVL2(выражение, если_не_NULL, если_NULL)** — два варианта подстановки. **COALESCE** — первое не-NULL из списка.
- **DUAL** — служебная таблица для SELECT выражений без своих таблиц.

В [§3.2](chapter-03-02.md) мы разберём предложение WHERE: сравнения, IN, BETWEEN, LIKE, AND, OR, NOT, IS NULL и приоритет операторов.
