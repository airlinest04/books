# §10.3 Циклы

В [§10.2](chapter-10-02.md) мы разобрали CASE. В PL/SQL для повторения блока операторов используются **циклы**. Есть три формы: **базовый LOOP** (с выходом через EXIT или EXIT WHEN), **WHILE** (проверка условия перед каждой итерацией) и **FOR** (цикл по диапазону чисел или по курсору). В этом разделе — синтаксис всех трёх и типичные примеры. CONTINUE и EXIT с меткой — в [§10.4](chapter-10-04.md). См. [Глоссарий](glossary.md).

---

## 10.3.1. Базовый LOOP и EXIT WHEN

**LOOP** — цикл без встроенного условия: тело выполняется снова и снова, пока не сработает **EXIT** или **EXIT WHEN условие**. EXIT прерывает цикл немедленно; EXIT WHEN проверяет условие и при истине выходит из цикла. Без EXIT цикл был бы бесконечным. См. [Глоссарий](glossary.md).

Синтаксис:

```plsql
LOOP
  операторы;
  EXIT WHEN условие;   -- или EXIT; при выполнении условия
END LOOP;
```

Пример: вывод чисел от 1 до 5:

```plsql
DECLARE
  v_i   PLS_INTEGER := 1;
BEGIN
  LOOP
    DBMS_OUTPUT.PUT_LINE(v_i);
    EXIT WHEN v_i >= 5;
    v_i := v_i + 1;
  END LOOP;
END;
/
```

Условие выхода можно поставить в начале тела (тогда возможна нулевая итерация) или в конце (как выше). **END LOOP** с точкой с запятой обязателен. См. [Глоссарий](glossary.md). Среда: Oracle PL/SQL.

---

## 10.3.2. WHILE: цикл с условием в начале

**WHILE** проверяет условие **перед** каждой итерацией: если условие ложно с самого начала, тело не выполнится ни разу. См. [Глоссарий](glossary.md).

Синтаксис:

```plsql
WHILE условие LOOP
  операторы;
END LOOP;
```

Пример: тот же вывод 1..5:

```plsql
DECLARE
  v_i   PLS_INTEGER := 1;
BEGIN
  WHILE v_i <= 5 LOOP
    DBMS_OUTPUT.PUT_LINE(v_i);
    v_i := v_i + 1;
  END LOOP;
END;
/
```

Условие должно со временем стать ложным (или внутри тела быть EXIT), иначе цикл будет бесконечным. См. [Глоссарий](glossary.md).

---

## 10.3.3. FOR: цикл по диапазону чисел

**FOR** в числовом варианте задаёт счётчик в заданном диапазоне: цикловая переменная последовательно принимает значения от нижней границы до верхней (включительно). Границы вычисляются один раз при входе в цикл. См. [Глоссарий](glossary.md).

Синтаксис:

```plsql
FOR счетчик IN [REVERSE] нижняя_граница .. верхняя_граница LOOP
  операторы;
END LOOP;
```

**счётчик** — необъявленная переменная (нельзя объявлять в DECLARE с тем же именем в этом блоке); тип неявно PLS_INTEGER. Диапазон задаётся двумя целочисленными выражениями через **..** (две точки). **REVERSE** — перебор от верхней границы к нижней (убывание). После END LOOP счётчик недоступен (область видимости — только тело цикла). См. [Глоссарий](glossary.md).

Пример:

```plsql
BEGIN
  FOR i IN 1..5 LOOP
    DBMS_OUTPUT.PUT_LINE(i);
  END LOOP;
  -- REVERSE:
  FOR j IN REVERSE 1..3 LOOP
    DBMS_OUTPUT.PUT_LINE('j=' || j);  -- 3, 2, 1
  END LOOP;
END;
/
```

Если нижняя граница больше верхней (без REVERSE), тело не выполнится. С REVERSE при нижняя > верхняя — тоже ноль итераций. Среда: Oracle PL/SQL.

---

## 10.3.4. FOR по курсору (кратко)

**FOR** может перебирать строки курсора без явного OPEN, FETCH, CLOSE: цикл сам открывает курсор, на каждой итерации помещает следующую строку в запись (или переменные), по окончании закрывает курсор. См. [Глоссарий](glossary.md).

Синтаксис (упрощённо):

```plsql
FOR запись IN (SELECT ... FROM ...) LOOP
  -- запись.столбец1, запись.столбец2
END LOOP;
```

Или: **FOR запись IN имя_курсора LOOP** — если курсор объявлен в DECLARE. Подробнее курсоры рассматриваются в последующих главах; здесь достаточно знать, что FOR по выборке — удобная форма обхода результата запроса. См. [Глоссарий](glossary.md).

---

## Ключевое

- **LOOP** ... **END LOOP** — базовый цикл; выход через **EXIT** или **EXIT WHEN** условие. **WHILE** условие **LOOP** ... **END LOOP** — проверка перед каждой итерацией. См. [Глоссарий](glossary.md).
- **FOR** счетчик **IN** [REVERSE] низ..верх **LOOP** ... **END LOOP** — цикл по диапазону целых; счётчик не объявляют, границы вычисляются один раз.
- FOR по курсору: **FOR** запись **IN** (SELECT ...) **LOOP** — обход строк запроса без явного OPEN/FETCH/CLOSE.
- Каждый цикл завершается **END LOOP** с точкой с запятой. Бесконечный цикл возможен, если условие выхода никогда не выполняется.

В [§10.4](chapter-10-04.md) мы разберём CONTINUE и EXIT с меткой: переход на следующую итерацию и выход из вложенных циклов.
