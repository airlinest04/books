# §10.1 IF / ELSIF / ELSE

В [§9.3](chapter-09-03.md) мы разобрали присваивание и SELECT INTO. Управляющие конструкции задают ветвление и повторение кода. **IF** проверяет условие (логическое выражение) и выполняет одну из веток в зависимости от результата. В этом разделе — синтаксис **IF ... THEN**, **ELSIF** и **ELSE**, вложенный IF, а также типичные ошибки (ELSE IF вместо ELSIF, пропуск END IF). CASE — в [§10.2](chapter-10-02.md). См. [Глоссарий](glossary.md).

---

## 10.1.1. Синтаксис IF ... THEN ... END IF

Условный оператор в PL/SQL имеет вид:

```plsql
IF условие THEN
  операторы;
[ELSIF условие2 THEN
  операторы;]
[ELSIF условие3 THEN
  операторы;]
...
[ELSE
  операторы;]
END IF;
```

**условие** — логическое выражение (сравнение, вызов функции, возвращающей BOOLEAN, комбинация через AND/OR/NOT). Если условие истинно (TRUE), выполняется блок после **THEN**; затем управление переходит за **END IF**. Если ложно (FALSE или NULL), проверяется следующее **ELSIF** (если есть); если ни одно ELSIF не истинно, выполняется блок **ELSE** (если есть). Блоков ELSIF может быть несколько. **END IF** с точкой с запятой обязателен. См. [Глоссарий](glossary.md).

Пример: проверка по числу и вывод сообщения:

```plsql
DECLARE
  v_score   NUMBER := 75;
BEGIN
  IF v_score >= 90 THEN
    DBMS_OUTPUT.PUT_LINE('Отлично');
  ELSIF v_score >= 70 THEN
    DBMS_OUTPUT.PUT_LINE('Хорошо');
  ELSIF v_score >= 50 THEN
    DBMS_OUTPUT.PUT_LINE('Удовлетворительно');
  ELSE
    DBMS_OUTPUT.PUT_LINE('Неудовлетворительно');
  END IF;
END;
/
```

Здесь при v_score = 75 выполнится ветка ELSIF v_score >= 70 и выведется «Хорошо». Среда: Oracle PL/SQL.

## 10.1.2. ELSIF и ELSE

**ELSIF** (пишется слитно, без пробела и без второго E в «ELSE») — следующая проверка, если предыдущее IF/ELSIF ложно. Порядок проверок сверху вниз; выполняется только первая истинная ветка, остальные не проверяются. **ELSE** — ветка «во всех остальных случаях» (когда все IF и ELSIF ложны); может быть только одна и обычно идёт последней перед END IF. См. [Глоссарий](glossary.md).

Типичная ошибка: написать **ELSE IF** (два слова) вместо **ELSIF**. В PL/SQL нет конструкции ELSE IF — будет трактоваться как ELSE с вложенным IF, и потребуется лишний END IF. Другая ошибка — забыть **END IF** у внешнего IF при вложенных условиях; каждый IF должен иметь свой END IF.

---

## 10.1.3. Вложенный IF

Внутри ветки IF/ELSIF/ELSE можно писать любой код, в том числе другой **IF ... END IF**. Вложенность не ограничена. Для читаемости глубоко вложенные условия иногда выносят в отдельные процедуры или переписывают через CASE. См. [Глоссарий](glossary.md).

Пример вложенной проверки:

```plsql
IF v_dept_id = 10 THEN
  IF v_salary > 5000 THEN
    DBMS_OUTPUT.PUT_LINE('Старший сотрудник отдела 10');
  ELSE
    DBMS_OUTPUT.PUT_LINE('Сотрудник отдела 10');
  END IF;
ELSE
  DBMS_OUTPUT.PUT_LINE('Другой отдел');
END IF;
```

---

## Ключевое

- **IF** условие **THEN** операторы **[ELSIF** условие **THEN** операторы **]** ... **[ELSE** операторы **] END IF;** — условное ветвление. Выполняется первая ветка с истинным условием; если ни одна не истинна — ветка ELSE (если есть). См. [Глоссарий](glossary.md).
- Пишется **ELSIF** (одно слово), не ELSE IF. Каждому IF соответствует один **END IF** (с точкой с запятой).
- Условие — логическое выражение (TRUE/FALSE/NULL); в PL/SQL NULL в условии трактуется как «ложно» при проверке на истинность.
- Вложенный IF допускается; каждый вложенный блок завершается своим END IF.

В [§10.2](chapter-10-02.md) мы разберём CASE: выбор по значению выражения или по условиям (CASE expression / CASE WHEN).
