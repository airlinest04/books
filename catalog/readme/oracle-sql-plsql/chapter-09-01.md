# §9.1 Структура блока

В [§8.4](chapter-08-04.md) мы завершили часть I — Oracle SQL. **PL/SQL** — процедурное расширение SQL в Oracle: в нём пишут блоки кода с переменными, условиями, циклами, вызовами SQL и обработкой ошибок; из блоков строят процедуры, функции, триггеры и пакеты. Вся эта логика выполняется на сервере. В этом разделе — **структура блока PL/SQL**: секции **DECLARE**, **BEGIN**, **EXCEPTION**, **END**; анонимный блок и минимальный пример. Переменные и типы — в [§9.2](chapter-09-02.md). См. [Глоссарий](glossary.md).

---

## 9.1.1. Что такое блок PL/SQL

**Блок PL/SQL** — минимальная исполняемая единица: последовательность объявлений (опционально), исполняемых операторов и обработчиков исключений. Блок может быть **анонимным** (написан в скрипте или приложении, выполняется и не сохраняется в базе как объект) или входить в состав **именованного** объекта — процедуры, функции, триггера, тела пакета. См. [Глоссарий](glossary.md).

Структура:

```plsql
[DECLARE
  объявления переменных, курсоров, типов и т.д.]
BEGIN
  исполняемые операторы (присваивание, SQL, вызовы, условия, циклы);
[EXCEPTION
  обработчики исключений]
END;
[/]
```

**DECLARE** — необязательная секция: локальные переменные, константы, курсоры, локальные типы. Если объявлений нет, секцию DECLARE опускают. **BEGIN ... END** — обязательная секция: здесь выполняется код. **EXCEPTION** — необязательная: перехват ошибок; если её нет, необработанное исключение прерывает блок и передаётся вызывающему. Точка с запятой после **END** обязательна; в SQL*Plus после блока часто ставят слэш **/** на отдельной строке, чтобы отправить блок на выполнение. См. [Глоссарий](glossary.md). Среда: Oracle Database (PL/SQL Engine).

---

## 9.1.2. Минимальный блок и первый пример

Самый короткий блок — только BEGIN и END, без операторов (пустой исполняемый блок) или с одним оператором. Пример: вывести сообщение в буфер (в SQL*Plus/SQL Developer его покажет команда вывода):

```plsql
BEGIN
  DBMS_OUTPUT.PUT_LINE('Hello, PL/SQL');
END;
/
```

**DBMS_OUTPUT.PUT_LINE** — встроенная процедура пакета DBMS_OUTPUT: выводит строку в буфер сессии. Чтобы увидеть вывод в SQL*Plus, нужно выполнить **SET SERVEROUTPUT ON** до запуска блока. В SQL Developer вывод обычно включается по умолчанию или в настройках окна. См. [Глоссарий](glossary.md).

Пример с секцией DECLARE (объявление переменной и её использование в BEGIN) будет в [§9.2](chapter-09-02.md); здесь важно запомнить порядок: DECLARE → BEGIN → [EXCEPTION] → END;

## 9.1.3. Секция EXCEPTION

В секции **EXCEPTION** перечисляют обработчики: по имени исключения (например, NO_DATA_FOUND, DUP_VAL_ON_INDEX) или **WHEN OTHERS** — «любая ошибка». При возникновении исключения в BEGIN управление переходит в соответствующий WHEN; после обработчика выполнение блока заканчивается (или выполняется код в обработчике, затем выход). Если подходящего обработчика нет, исключение «всплывает» наверх (вызывающему блоку или клиенту). См. [Глоссарий](glossary.md).

Пример: обработать ситуацию «строка не найдена» при выборке в переменную (SELECT INTO — в §9.3):

```plsql
BEGIN
  -- какой-то код, например SELECT INTO
  NULL;  -- заглушка
EXCEPTION
  WHEN NO_DATA_FOUND THEN
    DBMS_OUTPUT.PUT_LINE('Данные не найдены');
  WHEN OTHERS THEN
    DBMS_OUTPUT.PUT_LINE('Ошибка: ' || SQLERRM);
END;
/
```

**SQLERRM** — встроенная функция: текст сообщения об ошибке. Детали исключений и RAISE — в главах о процедурах и обработке ошибок. Сейчас достаточно понимать, что EXCEPTION — это «хвост» блока для перехвата ошибок.

## Ключевое

- **Блок PL/SQL** состоит из необязательной секции **DECLARE**, обязательной **BEGIN ... END** и необязательной **EXCEPTION**. Точка с запятой после END обязательна. См. [Глоссарий](glossary.md).
- **PL/SQL** — процедурное расширение SQL в Oracle; выполняется на сервере. Анонимный блок не сохраняется в базе; именованные блоки — в процедурах, функциях, триггерах, пакетах.
- Минимальный исполняемый блок: BEGIN ... END; с выводом — DBMS_OUTPUT.PUT_LINE; в SQL*Plus перед выполнением — SET SERVEROUTPUT ON.
- В EXCEPTION обрабатывают исключения (WHEN имя_исключения или WHEN OTHERS); без обработчика исключение передаётся вызывающему.

В [§9.2](chapter-09-02.md) мы введём переменные: объявление в DECLARE, типы (скалярные, %TYPE, %ROWTYPE), константы.
