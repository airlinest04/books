## Подробное содержание

### Глава 1. Введение в Spark: зачем и когда использовать

- **1.1 Ограничения MapReduce** — много итераций — много проходов по диску; неудобно для интерактивных запросов и сложной логики.
- **1.2 Идея Spark** — вычисления в памяти (in-memory); общий абстрактный слой (RDD, затем DataFrame); одна платформа для пакетной обработки, SQL, стриминга (и ML).
- **1.3 Когда выбирать Spark** — большие объёмы данных, необходимость итераций или сложных преобразований; интеграция с HDFS, объектными хранилищами, DWH.
- **1.4 Языки и API** — Scala, Python (PySpark), Java, R; в книге фокус на PySpark.
- *Ключевое:* in-memory, универсальность, когда использовать Spark. *Задания:* обосновать выбор Spark для заданного сценария.

---

### Глава 2. Архитектура Spark: RDD, DAG, драйвер и исполнители

- **2.1 Драйвер и исполнители (executors)** — драйвер запускает приложение и строит граф; исполнители на узлах кластера выполняют задачи и хранят данные в памяти/диске.
- **2.2 RDD (Resilient Distributed Dataset)** — неизменяемая распределённая коллекция; создание из данных или преобразований; ленивое выполнение (lazy evaluation).
- **2.3 DAG и этапы (stages)** — граф направленных ациклических графов операций; разбиение на стадии по границам shuffle; задачи (tasks) внутри стадии.
- **2.4 Трансформации и действия** — трансформации (map, filter, groupBy) возвращают RDD/DataFrame и не выполняются сразу; действия (count, collect, write) запускают вычисление.
- **2.5 Кластерные режимы** — standalone, YARN, Kubernetes, локальный режим (для разработки).
- **2.6 Отладка и мониторинг** — Spark UI (stages, tasks, shuffle); логи драйвера и исполнителей; типичные причины медленной работы (skew, избыточный shuffle).
- *Ключевое:* драйвер/исполнители, RDD, DAG, lazy evaluation, UI. *Задания:* объяснить, какие операции вызовут shuffle; посмотреть DAG в UI.

---

### Глава 3. Spark SQL и DataFrame API

- **3.1 DataFrame** — табличная абстракция со схемой; унифицированный API поверх RDD; оптимизация через Catalyst.
- **3.2 Создание DataFrame** — из RDD с заданной схемой; из источников (read); из SparkSession.createDataFrame.
- **3.3 Spark SQL** — регистрация DataFrame как временной таблицы; запросы SQL через spark.sql(); подзапросы и соединения.
- **3.4 Каталог и метаданные** — базы данных, таблицы, представления; интеграция с Hive Metastore (внешние таблицы).
- *Ключевое:* DataFrame, Spark SQL, схема. *Задания:* создать DataFrame и выполнить SQL-запрос.

---

### Глава 4. Связь с хранилищами данных и большими данными

- **4.1 Чтение и запись** — форматы: Parquet, ORC, JSON, CSV; опции сжатия и партиционирования.
- **4.2 HDFS и объектные хранилища** — пути hdfs://, s3a://; настройка доступа к S3/совместимым хранилищам.
- **4.3 Партиционирование при записи** — partitionBy(столбец); каталоговая структура; влияние на последующие чтения и фильтрацию.
- **4.4 Интеграция с DWH и витринами** — выгрузка в таблицы (JDBC); чтение из БД; использование Spark как этапа ETL перед загрузкой в DWH.
- *Ключевое:* форматы, партиционирование, JDBC. *Задания:* прочитать данные из файла и записать в партиционированном виде; выгрузить в БД.

### Глава 5. PySpark: среда и основы

- **5.1 Установка и запуск** — PySpark через pip; переменные окружения (SPARK_HOME, PYSPARK_PYTHON); запуск локально pyspark.
- **5.2 SparkSession** — точка входа; создание spark = SparkSession.builder.getOrCreate(); конфигурация (память, число ядер).
- **5.3 DataFrame в PySpark** — создание из списка словарей или из файла; просмотр схемы .printSchema(), .show(); выбор столбцов и фильтрация.
- **5.4 Сравнение с Pandas** — синтаксис похож (select, filter, groupBy); распределённое выполнение; когда использовать .toPandas() (малые результаты).
- *Ключевое:* SparkSession, создание DataFrame в PySpark. *Задания:* настроить среду, загрузить данные, вывести схему и выборку.

### Глава 6. Работа с данными в PySpark: чтение, преобразование, запись

- **6.1 Чтение** — spark.read.format("parquet").load(path); .csv(), .json(); опции header, schema, sep.
- **6.2 Выборка и фильтрация** — .select(), .filter() / .where(); добавление столбца .withColumn(); переименование .withColumnRenamed(); удаление .drop().
- **6.3 Типы данных и приведение** — .cast(); типы из pyspark.sql.types (IntegerType, StringType, TimestampType и др.).
- **6.4 Запись** — .write.format(...).save(); режимы overwrite, append; партиционирование .partitionBy().
- **6.5 Обработка пропусков** — .na.fill(), .na.drop(); стратегии.
- **6.6 Кэширование и партиции** — .cache() и .persist(); когда кэшировать (повторное использование); coalesce и repartition; выбор числа партиций.
- *Ключевое:* read/write, select, filter, withColumn, partitionBy, cache. *Задания:* пайплайн чтения → преобразования → записи с партициями.

### Глава 7. Агрегации, окна, соединения в PySpark

- **7.1 Группировка и агрегация** — .groupBy(); .agg(); встроенные функции sum, count, avg, min, max; именованные агрегаты.
- **7.2 Оконные функции** — Window.partitionBy().orderBy(); row_number(), rank(), dense_rank(); lag, lead; агрегаты over окно.
- **7.3 Соединения** — .join(other, on, how); inner, left, right, full; по одному и нескольким столбцам; broadcast join (кратко).
- **7.4 Уникальные значения и дубликаты** — .distinct(); .dropDuplicates([cols]).
- *Ключевое:* groupBy/agg, Window, join. *Задания:* запросы с группировкой, окнами и join; сравнение с эквивалентным SQL.

### Глава 8. Spark Streaming (при необходимости)

- **8.1 Микропакетная обработка** — Structured Streaming: поток как «бесконечная» таблица; триггеры (например, раз в N секунд); вывод в консоль, файл или внешнюю систему.
- **8.2 Источники и приёмники** — чтение из Kafka, файлового каталога (новые файлы); запись в Kafka, консоль, паркет.
- **8.3 Агрегации в потоке** — группировка по окну времени (window); watermark для отложенных данных.
- **8.4 Границы главы** — только введение; детали — в специализированных материалах.
- *Ключевое:* Structured Streaming, микропакеты, окна. *Задания:* простой поток чтения из каталога и вывода агрегата (по желанию).
