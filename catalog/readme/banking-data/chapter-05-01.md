# §5.1 Основные формы отчётности в ЦБ

Часть II книги посвящена **регуляторной отчётности на практике**. В этом разделе — обзор **основных форм отчётности**, представляемых кредитными организациями в Банк России: баланс, отчётность по рискам, ликвидности и другим направлениям; **назначение** форм и **связь с бухгалтерскими данными**. Конкретные номера и актуальные указания ЦБ задаются нормативными актами Банка России; список источников — в [Список литературы](../../banking-data/sources.md). Здесь фиксируем типы форм и принципы, важные для инженера данных. См. [Глоссарий](glossary.md).

***

## 5.1.1. Зачем банку отчитываться перед ЦБ

Банк России как регулятор запрашивает у кредитных организаций данные для надзора за устойчивостью банковской системы, за достаточностью капитала и резервов, за ликвидностью и рисками. На основе отчётности ЦБ оценивает состояние банка, выявляет нарушения и назначает меры. Для банка своевременная и корректная сдача форм — обязанность; ошибки и просрочки влекут санкции. Для инженера данных и разработчиков отчётность означает: наличие **источников данных** (бухучёт, витрины, операционки), **маппинг** полей формы на эти источники, **пайплайн** подготовки и проверок, **сверка** с бухгалтерией. См. [§5.2](chapter-05-02.md), [§5.3](chapter-05-03.md), [§6.1](chapter-06-01.md).

***

## 5.1.2. Баланс и отчётность, опирающаяся на бухучёт

**Бухгалтерский баланс** банка — отчёт о состоянии активов и пассивов на дату; строится на основе остатков по счетам плана счетов кредитной организации. Многие формы ЦБ прямо или косвенно опираются на данные бухучёта: остатки по счетам, обороты за период, расшифровки по видам операций. См. [§1.4](chapter-01-04.md), книгу «Бухгалтерия для программистов» ([../accounting-for-programmers/](../accounting-for-programmers/)).

Связь форм с бухгалтерскими данными:

* **Баланс (форма по учёту в ЦБ):** остатки по счетам на отчётную дату; структура отчёта соответствует или сопоставляется с планом счетов. Источник — бухгалтерская система: остатки по каждому счёту на дату. См. [§4.3](chapter-04-03.md), [§5.3](chapter-05-03.md).
* **Отчёт о прибылях и убытках (ОПУ), отчёт о движении денежных средств:** обороты по счетам доходов/расходов, по счетам денежных средств за период. Источник — проводки (обороты) из бухучёта за отчётный период.
* **Расшифровки к балансу:** детализация статей по срокам, контрагентам, валютам; часть данных берётся из бухучёта (аналитика по счетам), часть — из операционных систем и витрин (например, разбивка ссудной задолженности по срокам и категориям качества). См. [§1.3](chapter-01-03.md), [§1.4](chapter-01-04.md), [§4.2](chapter-04-02.md).

Для подготовки таких форм в данных должны быть: план счетов, проводки за период, остатки на отчётную дату; связь «продукт — счёт» для расшифровок по продуктам. См. [§4.3](chapter-04-03.md), [§5.3](chapter-05-03.md).

***

## 5.1.3. Отчётность по рискам и резервам

ЦБ запрашивает данные о **кредитных рисках**, **качестве ссудного портфеля** и **резервах на потери**. Эти формы опираются не только на бухучёт (остатки по счетам ссудной задолженности и резервов), но и на **продуктовые данные** и расчёты. См. [§1.3](chapter-01-03.md), [§1.4](chapter-01-04.md), [§4.2](chapter-04-02.md).

Необходимые данные:

* **Остатки ссудной задолженности** по видам (физлица, юрлица, продукты), по валютам, по срокам; источник — бухучёт (остатки по счетам) или витрина «портфель кредитов» при наличии сверки с бухучётом.
* **Категории качества ссуд** и **резервы на возможные потери:** расчёт по положению ЦБ (DPD, категории, проценты резерва); источник — витрина «портфель» или «просрочка» с полями DPD, категория качества, сумма резерва; сверка с остатком по счёту резерва в бухучёте. См. [§1.3](chapter-01-03.md), [§6.2](chapter-06-02.md).
* **Расшифровки** по сегментам, по срокам просрочки, по видам обеспечения — из операционных систем и витрин (договоры, продукты, расчёты DPD и категорий).

Конкретные формы и состав показателей задаются указаниями ЦБ; для инженера данных важно: цепочка «события по кредитам → расчёт остатка, DPD, категории, резерва → витрины → форма» и сверка с бухучётом по счетам. См. [§5.3](chapter-05-03.md), [§6.1](chapter-06-01.md).

***

## 5.1.4. Отчётность по ликвидности и платёжной системе

ЦБ контролирует **ликвидность** банков и участие в **платёжной системе**. Формы по ликвидности отражают активы и обязательства по срокам, потоки платежей, выполнение нормативов. Формы по платёжной системе — объёмы и суммы переводов, участие в системе Банка России и др. См. [§3.1](chapter-03-01.md), [§3.4](chapter-03-04.md).

Источники данных:

* **Бухучёт:** остатки по корреспондентским счетам, по привлечённым средствам, по размещённым средствам с разбивкой по срокам; обороты по счетам за период.
* **Платёжная система:** данные о проведённых платежах (объёмы, суммы, валюты), выписки по корсчетам; сверка с внутренними данными по платежам и проводкам. См. [§3.4](chapter-03-04.md), [§4.4](chapter-04-04.md).
* **Витрины платежей:** агрегаты за период по направлениям, валютам, платёжным системам для заполнения показателей по переводам. См. [§4.2](chapter-04-02.md), [§5.3](chapter-05-03.md).

Связь с бухгалтерскими данными: остатки и обороты по корсчетам в формах должны совпадать с данными бухучёта и с выписками ЦБ; данные по платежам — с витринами и операционными системами. См. [§6.2](chapter-06-02.md).

***

## 5.1.5. Другие направления отчётности

Помимо баланса, рисков и ликвидности ЦБ может запрашивать отчётность по:

* **Операциям с ценными бумагами, валютой, драгметаллами:** остатки и обороты по соответствующим счетам и операциям; источники — бухучёт и операционные системы учёта операций.
* **Структуре капитала и достаточности капитала:** данные из бухучёта и расчётных модулей по нормативам.
* **ПОД/ФТ (противодействие отмыванию и финансированию терроризма):** объёмы операций, отчётность по подозрительным сделкам; связь с данными по клиентам и операциям. См. главу 7.
* **Прочие тематические формы** по указаниям ЦБ.

Для каждого направления в банке определяются источники данных (бухучёт, витрины, операционки), маппинг полей формы и регламент подготовки. См. [§5.3](chapter-05-03.md), [§6.1](chapter-06-01.md). Актуальный перечень форм и указаний — в нормативных актах Банка России и в [Список литературы](../../banking-data/sources.md).

## 5.1.6. Сводка: типы форм и связь с данными

| Направление                  | Типичное содержание форм                                           | Основные источники данных                                                               |
| ---------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| Баланс и отчётность по учёту | Остатки по счетам на дату, обороты за период                       | Бухучёт (остатки, проводки), план счетов                                                |
| Риски и резервы              | Ссудная задолженность по категориям качества, резервы, расшифровки | Витрины «портфель», «просрочка»; бухучёт (счета ссуд, резервов); расчёт DPD и категорий |
| Ликвидность                  | Активы и обязательства по срокам, нормативы                        | Бухучёт, расчётные модули                                                               |
| Платёжная система            | Объёмы и суммы переводов, участие в системе                        | Витрины платежей, бухучёт (корсчета), выписки ЦБ                                        |
| Прочие                       | По указаниям ЦБ                                                    | Бухучёт, операционки, витрины                                                           |

Общий принцип: **формы ЦБ опираются на бухгалтерские данные** (остатки, обороты по счетам) и на **продуктовые данные и витрины** (кредиты, карты, платежи) при необходимости расшифровок и показателей, которые в бухучёте не хранятся в разрезе (например, DPD, категория качества по каждому договору). Сверка между витринами и бухучётом обязательна. См. [§4.3](chapter-04-03.md), [§6.2](chapter-06-02.md).

## 5.1.7. Типичные ошибки

* **Подставлять в форму данные только из витрины без сверки с бухучётом:** если форма дублирует или детализирует баланс, остатки и обороты должны совпадать с бухучётом; расхождение ведёт к ошибке в отчётности и риску санкций.
* **Игнорировать версионность форм:** ЦБ меняет формы и указания; при изменении состава полей или правил расчёта маппинг и пайплайн нужно обновлять; старые сданные отчёты хранить в версии, соответствующей форме на дату сдачи. См. [§5.4](chapter-05-04.md).
* **Нет единого реестра «форма — источник — ответственный»:** без реестра сложно поддерживать маппинг и воспроизводить заполнение формы при смене людей или систем; реестр и документация маппинга обязательны. См. [§5.3](chapter-05-03.md).

***

## Ключевое

* **Формы отчётности в ЦБ** — инструмент надзора; банк обязан сдавать их в срок и без ошибок. Для инженера данных важны источники, маппинг полей и пайплайн подготовки.
* **Баланс и отчётность по учёту** строятся на остатках и оборотах по счетам из бухучёта; план счетов и проводки — базовый источник.
* **Отчётность по рискам и резервам** опирается на витрины «портфель» и «просрочка» (остаток, DPD, категория, резерв) и на бухучёт (счета ссуд и резервов); необходима сверка.
* **Ликвидность и платёжная система:** остатки по корсчетам, обороты по платежам; источники — бухучёт, витрины платежей, выписки ЦБ.
* Общий принцип: формы связаны с **бухгалтерскими данными** и с **витринами по продуктам**; сверка витрин с бухучётом обязательна. Актуальный перечень форм — в указаниях ЦБ и в [Список литературы](../../banking-data/sources.md).

В [§5.2](chapter-05-02.md) мы разберём сроки и периодичность сдачи: ежедневно, ежемесячно, ежеквартально; календарь сдачи и последствия нарушения сроков.
