# §5.5 Инструменты

В [§5.4](chapter-05-04.md) мы разобрали цвет и доступность. Принципы визуализации ([§5.1](chapter-05-01.md)–[§5.4](chapter-05-04.md)) применимы независимо от инструмента; выбор инструмента зависит от задачи, источника данных и того, кто будет строить и смотреть графики. В этом разделе — краткий **обзор категорий** инструментов визуализации: BI-инструменты, библиотеки программирования (в т.ч. matplotlib, Seaborn), специализированные средства; и связь с книгами серии по Python и BI. Конкретные продукты и версии не перечисляем детально — они меняются; важны типы инструментов и критерии выбора.

---

## 5.5.1. BI-инструменты

**BI-инструменты** (Business Intelligence) — платформы для построения отчётов и дашбордов, подключения к хранилищам и витринам данных ([§1.3](chapter-01-03.md)), перетаскивания полей и настройки графиков через интерфейс без кода. Типичные возможности: множество типов диаграмм, фильтры, срезы по времени и размерностям, обновление по расписанию, раздача отчётов по правам доступа.

**Когда уместны:** регулярные отчёты и дашборды для бизнеса; аудитория смотрит готовые экраны и фильтрует данные; данные уже в DWH или витринах; аналитик или владелец отчёта не обязан писать код. BI-инструменты хорошо подходят для **коммуникационной** визуализации ([§5.1](chapter-05-01.md)) и для мониторинга KPI ([§6.4](chapter-06-04.md)).

**Ограничения:** тонкая настройка оформления (шрифты, точное положение элементов, доступность) может быть ограничена; для нестандартных типов графиков или для воспроизводимой аналитической пайплайны (скрипт от данных до графика) чаще используют библиотеки программирования. Связь с темами BI и хранилищ данных — в соответствующих книгах серии.

---

## 5.5.2. Библиотеки программирования (Python: matplotlib, Seaborn и др.)

**Библиотеки визуализации в коде** позволяют строить графики программно: данные подготавливаются в коде (Pandas, NumPy), график генерируется вызовами функций. Это даёт полный контроль над типом графика, оформлением и воспроизводимостью (скрипт или ноутбук можно повторить на новых данных).

**Типичные инструменты в экосистеме Python:**

- **matplotlib** — базовая библиотека для построения двумерных графиков; гибкая, но для сложных сюжетов требует много настроек. Часто используется как «движок» для других библиотек.
- **Seaborn** — надстройка над matplotlib, удобна для статистических сюжетов (распределения, ящики с усами, тепловые карты корреляций); разумные дефолты оформления.
- **Plotly** (в т.ч. через pandas или отдельно) — интерактивные графики (зум, подсказки при наведении); удобно для разведки и для веб-дашбордов.

**Когда уместны:** разведочный анализ в Jupyter; публикация графиков в отчётах и статьях из одного пайплайна (данные → анализ → график); нестандартные типы визуализации; требование воспроизводимости и версионирования кода. Подробнее работа с данными и визуализацией в Python — в книге серии «Python для данных».

---

## 5.5.3. Специализированные инструменты

**Специализированные** — инструменты под узкую задачу или тип данных.

- **Визуализация для веба (D3.js и аналоги):** кастомные интерактивные визуализации, встраиваемые в веб-приложения; требуют разработки на JavaScript или использования обёрток.
- **Географические карты:** отображение данных на карте (регионы, точки); в BI-инструментах часто есть встроенные карты; в Python — библиотеки для карт и геоданных.
- **Визуализация графов и сетей:** узлы и рёбра; специализированные библиотеки и приложения.
- **Профилирование и отчёты по качеству данных:** инструменты, генерирующие отчёты по метрикам из [§3.2](chapter-03-02.md)–[§3.4](chapter-03-04.md); часть из них интегрируется в пайплайны (см. [§3.5](chapter-03-05.md)).

Выбор зависит от задачи: для обычных бизнес-графиков достаточно BI или Python-библиотек; для нестандартной интерактивности или карт — специализированные решения.

---

## 5.5.4. Когда что использовать: ориентиры

| Задача | Типичный выбор |
|--------|-----------------|
| Регулярные дашборды и отчёты для бизнеса, данные из DWH | BI-инструмент |
| Разведка в ноутбуке, воспроизводимый пайплайн «данные → график» | Python (matplotlib, Seaborn, Plotly) |
| Интерактивный график для презентации или веба | Plotly или специализированные веб-библиотеки |
| Нестандартный тип графика, полный контроль над оформлением | Библиотеки программирования (Python, R и др.) |
| Карты, графы, нишевые форматы | Специализированные инструменты |

Один и тот же принцип «тип данных → тип графика» ([§5.2](chapter-05-02.md)) и правила читаемости и доступности ([§5.3](chapter-05-03.md), [§5.4](chapter-05-04.md)) применяются во всех инструментах; инструмент лишь даёт способ реализации.

---

## 5.5.5. Связь с другими книгами серии

- **«Python для данных»:** подготовка данных (Pandas), построение графиков (matplotlib, Seaborn, при необходимости Plotly), интеграция визуализации в аналитический пайплайн и в отчёты (Jupyter, экспорт в файлы).
- **Книги по BI и хранилищам данных:** подключение BI-инструментов к DWH и витринам, проектирование дашбордов и раздача отчётов; визуализация в этой книге даёт принципы, а инструменты BI — реализацию в корпоративной среде.

В этой книге мы не учим синтаксису конкретной библиотеки; мы задаём критерии выбора типа графика, оформления и доступности, которые можно применить в любом выбранном инструменте.

---

## Ключевое

- **BI-инструменты** — отчёты и дашборды, подключение к DWH, интерфейс без кода; уместны для регулярной отчётности и мониторинга.
- **Библиотеки программирования (Python):** matplotlib, Seaborn, Plotly — разведка, воспроизводимые пайплайны, полный контроль над оформлением; детали — в книге «Python для данных».
- **Специализированные:** веб (D3 и др.), карты, графы — под узкие задачи.
- Выбор инструмента — под задачу (дашборд vs разведка vs публикация), источник данных и требования к воспроизводимости. Принципы визуализации ([§5.1](chapter-05-01.md)–[§5.4](chapter-05-04.md)) едины для всех инструментов.

В [§6.1](chapter-06-01.md) мы перейдём к главе 6 — представлению результатов и сторителлингу: аудитория и цель, кому и зачем показываем результат и как один набор данных может порождать разные истории для разных ролей.
