## Подробное содержание

### Глава 1. Arenadata DB и его место в экосистеме

* **1.1 Что такое Arenadata DB** — российский дистрибутив MPP-СУБД на основе Greenplum; предназначение для DWH и аналитики; хранение и обработка до десятков петабайт.
* **1.2 Связь с Greenplum и Greengage** — основа Arenadata DB — Greenplum; история: Greenplum open source, закрытие Broadcom; Greengage как open source fork (Apache 2.0); Arenadata DB на базе Greengage с ADB 6.29.0 (2025).
* **1.3 Экосистема Arenadata** — Arenadata Cluster Manager (ADCM), Arenadata DB Control, Arenadata DB Backup Manager; дополнительные инструменты и интеграции; документация на русском языке.
* **1.4 Когда выбирать Arenadata** — российский рынок; импортозамещение; поддержка и локализация; связь с Greenplum-книгой.
* _Ключевое:_ Arenadata DB, Greengage, экосистема, сценарии выбора. _Задания:_ определить, когда Arenadata предпочтительнее «сырого» Greenplum.

### Глава 2. Компоненты Arenadata

* **2.1 Arenadata Cluster Manager (ADCM)** — автоматизированное развёртывание и управление кластерами; web-интерфейс; конфигурация хостов, сегментов; мониторинг состояния.
* **2.2 Arenadata DB Control** — мониторинг запросов в реальном времени; просмотр выполняемых запросов; метрики производительности; управление сессиями.
* **2.3 Arenadata DB Backup Manager** — управление резервным копированием; полный и инкрементальный бэкап; расписание; восстановление.
* **2.4 Дополнительные инструменты** — утилиты Arenadata; интеграции; документация и поддержка.
* _Ключевое:_ ADCM, DB Control, Backup Manager. _Задания:_ описать роли каждого компонента.
