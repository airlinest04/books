## 7.3.1. Поэлементные арифметические операции

Операторы **+**, **-**, **\***, **/**, **\*\*** и т.д. применяются к массивам **поэлементно** (element-wise): операция выполняется для каждой пары соответствующих элементов. Массивы должны быть **одинаковой формы** (или совместимой по правилам broadcasting — см. ниже).

```python
import numpy as np
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
a + b    # array([11, 22, 33])
a * b    # array([10, 40, 90])
b / a    # array([10., 10., 10.])
```

Для **двумерных** массивов то же самое — сложение, вычитание, умножение и деление по элементам:

```python
m = np.array([[1, 2], [3, 4]])
m * 2    # array([[2, 4], [6, 8]])  — см. broadcasting ниже
m + m    # array([[2, 4], [6, 8]])
```

Результат — новый массив; исходные не меняются. Тип результата (int/float) определяется правилами Python и типами операндов.

## 7.3.2. Broadcasting

**Broadcasting** (распространение) — правила NumPy, позволяющие выполнять операции между массивами **разной формы** без явного копирования данных. Упрощённо: размерности по краям дополняются единицами, затем по осям, где размер равен 1 или массивы совпадают, операция выполняется. См. [Глоссарий](glossary.md).

**Скаляр и массив:** скаляр «распространяется» на все элементы массива:

```python
a = np.array([1, 2, 3])
a + 10      # array([11, 12, 13])
a * 2       # array([2, 4, 6])
```

**Строка (1, n) и столбец (m, 1):** при сложении/умножении строка дублируется по строкам, столбец — по столбцам, в результате матрица (m, n):

```python
row = np.array([[1, 2, 3]])      # shape (1, 3)
col = np.array([[10], [20]])     # shape (2, 1)
row + col    # array([[11, 12, 13], [21, 22, 23]])
```

Это часто используют для центрирования (вычесть среднее по столбцу) или нормализации: массив (n,) при операции с матрицей (m, n) ведёт себя как (1, n) и распространяется по строкам. Подробные правила (сравнение размеров осей справа налево, 1 и равенство) описаны в документации NumPy; для типичных случаев достаточно «скаляр + массив» и «строка + столбец».

При несовместимых формах (например, (2, 3) и (2, 4)) возникает **ValueError: operands could not be broadcast**.

## 7.3.3. Агрегирующие функции: sum, mean, min, max

Агрегаты сводят массив (или его часть по оси) к одному значению. Основные функции в **np.** и как методы массива **arr.sum()**, **arr.mean()** и т.д.

**np.sum(arr)** — сумма всех элементов. **np.mean(arr)** — среднее арифметическое. **np.min(arr)** и **np.max(arr)** — минимум и максимум.

```python
a = np.array([1, 2, 3, 4, 5])
np.sum(a)    # 15
np.mean(a)   # 3.0
np.min(a)   # 1
np.max(a)   # 5
```

Эквивалентно: **a.sum()**, **a.mean()**, **a.min()**, **a.max()**. Для пустого массива sum даёт 0, mean — NaN (или предупреждение); min/max на пустом массиве вызывают ошибку.

---

## 7.3.4. Параметр axis: агрегация по осям

Для многомерного массива по умолчанию агрегат считается **по всем элементам**. Параметр **axis** задаёт **ось**, вдоль которой выполняется свёртка: эта ось «исчезает» в результате, остальные размеры сохраняются.

**Двумерный массив (матрица):** ось **axis=0** — по строкам (вниз), ось **axis=1** — по столбцам (вправо). Иначе: при **axis=0** агрегируем по первому индексу (строкам), результат — по столбцам; при **axis=1** агрегируем по второму индексу (столбцам), результат — по строкам.

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])
m.sum()           # 21  — сумма всех
m.sum(axis=0)     # array([5, 7, 9])  — сумма по столбцам (по каждой колонке)
m.sum(axis=1)     # array([6, 15])    — сумма по строкам (по каждой строке)
m.mean(axis=0)    # array([2.5, 3.5, 4.5])  — среднее по столбцам
```

Память: **axis=0** — «складываем по нулевой оси» (строка за строкой), получаем один вектор размера (число столбцов); **axis=1** — по столбцам, получаем вектор размера (число строк). Для массивов большей размерности axis указывает, по какой оси свёртка.

**axis=None** (по умолчанию для части функций) — агрегация по всем элементам, результат — скаляр.

---

## 7.3.5. Другие агрегаты и методы

**np.prod(arr)** — произведение всех элементов (или по оси). **np.std(arr)** — стандартное отклонение, **np.var(arr)** — дисперсия. Все они поддерживают параметр **axis**.

**np.argmin(arr)**, **np.argmax(arr)** — **индекс** минимального и максимального элемента (в плоском виде или по оси). Полезно, когда нужно не значение, а позиция.

Для булевых массивов **np.sum()** считает число True (True как 1, False как 0). **np.any()** и **np.all()** — есть ли хотя бы один True и все ли True (в том числе по axis).

---

## Ключевое

- **Поэлементные операции** — +, -, *, /, ** над массивами одной (или совместимой) формы; результат — массив.
- **Broadcasting** — операции между массивами разной формы: скаляр распространяется на весь массив; строка (1, n) и столбец (m, 1) дают матрицу (m, n). Несовместимые формы — ValueError.
- **Агрегаты:** **np.sum**, **np.mean**, **np.min**, **np.max** (и методы .sum(), .mean() и т.д.). По умолчанию — по всем элементам.
- **axis** — ось свёртки: для 2D **axis=0** — по строкам (результат по столбцам), **axis=1** — по столбцам (результат по строкам). **axis=None** — по всем элементам, скаляр.
