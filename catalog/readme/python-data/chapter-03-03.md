# §3.3 Цикл while

В [§3.2](chapter-03-02.md) мы разобрали цикл for — перебор последовательности. **Цикл while** выполняет блок кода **пока условие истинно**; число итераций заранее может быть неизвестно. В этом же разделе — операторы **break** (досрочный выход из цикла) и **continue** (переход к следующей итерации). В [§3.4](chapter-03-04.md) рассмотрим тернарное выражение.

---

## 3.3.1. Синтаксис while

Цикл while записывается так:

```python
while условие:
    блок_тела_цикла
```

Сначала проверяется **условие**. Если оно истинно, выполняется блок; затем условие проверяется снова. Цикл завершается, когда условие становится ложным. Если условие ложно уже при первом входе, блок не выполнится ни разу.

Пример — счётчик до заданного значения:

```python
n = 0
while n < 3:
    print(n)
    n = n + 1
# выведет: 0, 1, 2
```

Здесь важно, что внутри блока переменная `n` меняется; иначе условие `n < 3` никогда не стало бы ложным и цикл выполнялся бы бесконечно.

**Отступы** задают тело цикла так же, как у if и for: все инструкции с одинаковым отступом под `while условие:` входят в блок.

---

## 3.3.2. Когда использовать while вместо for

**for** удобен, когда есть готовая последовательность (список, строка, range) или известно число проходов. **while** — когда число итераций заранее неизвестно и цикл должен идти «пока что-то выполняется» или «пока не выполнится условие выхода».

Типичные случаи для while:

- Чтение из файла или ввод пользователя **до маркера** (например, до пустой строки или до слова «конец»).
- Ожидание события или проверка состояния (в скриптах и пайплайнах — пока очередь не пуста, пока не пришёл ответ).
- Итерации численного метода или поиска, где остановка определяется условием (например, «пока разница между шагами больше порога»).

Пример: читать числа с клавиатуры, пока не введён ноль (в реальном коде источник может быть файлом или API):

```python
total = 0
while True:
    x = int(input("Введите число (0 — выход): "))
    if x == 0:
        break
    total += x
print("Сумма:", total)
```

Здесь выход из цикла выполняется через **break** внутри условия — см. ниже.

---

## 3.3.3. Оператор break

**break** — выход из цикла (for или while) **немедленно**. Управление передаётся первой инструкции после цикла. Обычно break стоит внутри условия: «если выполнилось то-то — выходим».

Пример: поиск первого чётного числа в списке:

```python
for x in [1, 3, 5, 6, 7]:
    if x % 2 == 0:
        print("Найдено:", x)
        break
else:
    print("Чётных нет")
```

Блок **else** у цикла for (или while) выполняется только если цикл **завершился нормально**, то есть не по break. Если break сработал, блок else не выполняется.

Ещё пример — выход из «бесконечного» while по условию (как в примере с вводом чисел выше): цикл `while True` идёт до тех пор, пока внутри не выполнится break.

---

## 3.3.4. Оператор continue

**continue** — переход к **следующей итерации** цикла без выполнения оставшегося кода в теле. Условие цикла (в while) или следующий элемент (в for) обрабатываются как обычно; просто текущий проход прерывается.

Пример: обработать только положительные числа, отрицательные пропустить:

```python
for x in [1, -2, 3, -4, 5]:
    if x < 0:
        continue
    print(x)   # выведет 1, 3, 5
```

То же можно записать через `if x >= 0: print(x)` без continue; continue полезен, когда при «плохом» значении нужно пропустить много кода внизу по телу цикла и не увеличивать вложенность условий.

В цикле while после continue снова проверяется условие; если оно истинно, выполняется следующая итерация. Нужно следить, чтобы не пропустить обновление переменных, от которых зависит условие, иначе возможен бесконечный цикл.

---

## 3.3.5. Бесконечный цикл и типичные ошибки

**Бесконечный цикл** — когда условие while никогда не становится ложным. Частая причина: забыли изменить переменную, входящую в условие, или логика обновления неверна.

Пример ошибки:

```python
n = 0
while n < 5:
    print(n)
    # забыли n = n + 1  — n всегда 0, цикл не закончится
```

Прервать выполнение программы в терминале можно сочетанием **Ctrl+C**.

**Намеренный бесконечный цикл** `while True` с выходом через break — нормальный приём, когда условие выхода удобнее проверить внутри тела (ввод до маркера, ожидание события). Главное — гарантировать, что break когда-нибудь выполнится при корректных данных.

**break и continue** действуют только на **ближайший** цикл. Если циклы вложенные, break во внутреннем цикле выходит только из него; внешний продолжает работу.

---

## Ключевое

- **while условие:** — выполнять блок пока условие истинно; перед каждой итерацией условие проверяется заново. В теле нужно обновлять переменные так, чтобы условие могло стать ложным (или использовать break).
- **break** — немедленный выход из цикла (for или while); управление переходит к коду после цикла. Блок **else** у цикла выполняется только если цикл завершился без break.
- **continue** — переход к следующей итерации, остаток тела текущей итерации пропускается. В while после continue снова проверяется условие.
- while уместен, когда число итераций неизвестно (ввод до маркера, ожидание события). Бесконечный цикл из-за необновляемого условия — типичная ошибка; `while True` с break — допустимый паттерн при явном выходе по условию внутри тела.
