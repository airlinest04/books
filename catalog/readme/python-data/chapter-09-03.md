# §9.3 Преобразование типов

В [§9.2](chapter-09-02.md) мы разобрали дубликаты: .duplicated(), .drop_duplicates(). Столбцы в DataFrame после загрузки из CSV или API часто имеют неверный тип: числа в виде строк, даты в виде текста. В этом разделе — **преобразование типов** столбцов: метод **.astype()** для приведения к int, float, str, bool и функция **pd.to_datetime()** для перевода в тип даты-времени. В [§9.4](chapter-09-04.md) перейдём к группировке и агрегации (groupby(), .agg()).

---

## 9.3.1. .astype()

**s.astype(dtype)** (для Series) и **df.astype(dtype)** (для DataFrame) возвращают новый объект с приведёнными типами. **dtype** — целевой тип: строка или объект типа NumPy/Pandas ('int64', 'float64', 'str', 'bool', 'Int64' для целых с пропусками и т.д.). Для DataFrame можно передать **словарь {имя_столбца: dtype}** — тогда преобразуются только указанные столбцы, остальные без изменений.

Типичные целевые типы:

- **'int64'**, **'float64'** — целые и вещественные числа; если в столбце есть нечисловые строки или пропуски, преобразование может вызвать ошибку или потребовать **errors='coerce'** (см. ниже).
- **'str** или **'object'** — строковое представление; числа и даты превращаются в текст.
- **'bool'** — логический тип; непустые нечисловые строки часто трактуются как True.

Исходный объект не изменяется; для изменения на месте нужно присвоить результат обратно: **df['col'] = df['col'].astype('int64')** или **df = df.astype({...})**.

```python
import pandas as pd
df = pd.DataFrame({"a": ["1", "2", "3"], "b": [1.5, 2.5, 3.5]})
df["a"].astype("int64")    # Series с целыми 1, 2, 3
df.astype({"a": "int64", "b": "int64"})  # a и b — целые
df["b"].astype("str")      # строки "1.5", "2.5", "3.5"
```

## 9.3.2. Ошибки при преобразовании

Если значение нельзя привести к целевому типу (например, строка "abc" к int), по умолчанию **.astype()** выбрасывает исключение. Параметр **errors**:

- **errors='raise'** (по умолчанию) — при первой же ошибке вызывается исключение.
- **errors='ignore'** — при ошибке исходное значение остаётся без изменений (в текущих версиях Pandas может возвращать копию без преобразования).
- **errors='coerce'** — неконвертируемые значения заменяются на **NaN** (для числовых типов) или на **pd.NaT** (для datetime). Удобно для «грязных» данных: после преобразования можно отфильтровать или заполнить пропуски.

Для столбцов с пропусками и смешанным содержимым часто используют **errors='coerce'**, затем **.fillna()** или **.dropna()** по этому столбцу.

```python
s = pd.Series(["1", "2", "x", "4"])
s.astype("int64", errors="coerce")  # 1, 2, NaN, 4
```

## 9.3.3. pd.to_datetime()

Даты и время в файлах часто приходят как строки ('2024-01-15', '15.01.2024' и т.д.). **pd.to_datetime(arg, format=None, errors='raise')** преобразует **arg** (столбец, Series, список, скаляр) в тип **datetime64[ns]**.

- **arg** — столбец DataFrame (df['col']), Series или список строк/дат.
- **format** — строка формата (например, '%Y-%m-%d', '%d.%m.%Y'); если задан, разбор быстрее и однозначнее. Для распространённых ISO-подобных форматов Pandas часто угадывает формат сам.
- **errors** — 'raise' (по умолчанию), 'coerce' (неразбираемые → NaT), 'ignore' (вернуть исходные данные).

Результат — Series с dtype **datetime64[ns]**; его можно присвоить обратно в столбец: **df['date'] = pd.to_datetime(df['date'])**. После преобразования доступны атрибуты **.dt.year**, **.dt.month**, **.dt.day** и другие для извлечения компонент даты.

**pd.to_datetime()** для столбца с датами в одном формате:

```python
df = pd.DataFrame({"date_str": ["2024-01-15", "2024-02-20", "2024-03-10"]})
df["date"] = pd.to_datetime(df["date_str"])
# столбец date — datetime64[ns]
df["date"].dt.year   # 2024, 2024, 2024
df["date"].dt.month  # 1, 2, 3
```

Если формат нестандартный, лучше задать **format**:

```python
pd.to_datetime(["15.01.2024", "20.02.2024"], format="%d.%m.%Y")
```

Для смешанных или неверных записей — **errors='coerce'**: неразбираемые значения станут **pd.NaT** (Not a Time), аналог NaN для дат.

---

## Ключевое

- **.astype(dtype)** — приведение типа Series или DataFrame; для DataFrame можно передать словарь **{столбец: dtype}**. Типы: 'int64', 'float64', 'str', 'bool' и др.
- **errors='coerce'** в .astype() — неконвертируемые значения превращаются в NaN; удобно для очистки «грязных» столбцов.
- **pd.to_datetime(arg, format=..., errors=...)** — преобразование в datetime64[ns]; **format** задаёт формат строки даты; **errors='coerce'** даёт NaT для неразбираемых значений. У результата — доступ к компонентам через **.dt** (year, month, day и т.д.).
