# §9.4 Группировка и агрегация

В [§9.3](chapter-09-03.md) мы разобрали преобразование типов: .astype(), pd.to_datetime(). Частая задача анализа — **свести таблицу к сводке по группам**: например, сумма продаж по регионам или среднее по категориям. В Pandas это делается через **groupby()** и агрегирующие функции (**.sum()**, **.mean()**, **.count()** и др.) или через **.agg()** — с одной или несколькими функциями и при необходимости **именованными** результатами. В [§9.5](chapter-09-05.md) рассмотрим слияние таблиц: merge() и concat.

---

## 9.4.1. groupby()

**df.groupby(by, axis=0)** разбивает DataFrame на **группы** по одинаковым значениям столбца (или нескольких столбцов) **by**. **by** — имя столбца (строка), список имён столбцов, Series или массив той же длины, что и df; можно также передать функцию от индекса. Результат — объект **DataFrameGroupBy** (или SeriesGroupBy при группировке Series): он не является таблицей, а описывает разбиение; к нему применяют агрегирующие методы или .agg().

По умолчанию **axis=0** — группировка по строкам (столбцы в by задают ключ группы). Строки с одинаковым значением ключа попадают в одну группу; затем по каждой группе вычисляют агрегат (сумму, среднее, количество и т.д.).

```python
import pandas as pd
df = pd.DataFrame({"region": ["A", "A", "B", "B"], "sales": [10, 20, 15, 25], "quantity": [1, 2, 1, 3]})
gb = df.groupby("region")
# gb — объект DataFrameGroupBy; группы: A (2 строки), B (2 строки)
```

---

## 9.4.2. Одна агрегирующая функция

К объекту GroupBy можно применить агрегирующий метод — он будет вычислен **по каждой группе** по каждому столбцу (где это применимо). Результат — DataFrame (или Series), в котором **индекс** — уникальные значения ключа группировки, столбцы — исходные числовые столбцы (или один столбец при выборе столбца до агрегации).

Типичные методы: **.sum()**, **.mean()**, **.median()**, **.min()**, **.max()**, **.count()** (число непустых значений), **.std()**, **.var()**. Нечисловые столбцы при этом обычно пропускаются (или для .count() учитываются).

Если нужна агрегация только по одному столбцу, сначала выбирают столбец: **df.groupby('key')['col'].sum()** — получится Series с ключом в индексе и суммой по col в каждой группе.

```python
df.groupby("region").sum()      # сумма sales по регионам (A: 30, B: 40)
df.groupby("region")["sales"].mean()  # среднее sales по регионам
df.groupby("region").count()   # число строк в каждой группе
```

---

## 9.4.3. .agg() — одна и несколько функций

**grouped.agg(func)** или **grouped.aggregate(func)** применяет к каждой группе одну или несколько агрегирующих функций. **func** может быть:

- **Строка имени функции** — 'sum', 'mean', 'count', 'min', 'max' и т.д.; применяется ко всем подходящим столбцам.
- **Список функций** — например **['sum', 'mean']**; для каждого столбца будет несколько результатов, в столбцах появятся многоуровневые имена (sum, mean).
- **Словарь {столбец: функция или список функций}** — задаёт, какую функцию применить к какому столбцу. Например, **agg({'sales': 'sum', 'quantity': 'mean'})**.

Итог — DataFrame (или Series) с индексом по ключу группировки и столбцами в зависимости от переданных функций.

```python
df.groupby("region").agg("sum")
df.groupby("region").agg(["sum", "mean"])   # по каждому столбцу — sum и mean
df.groupby("region").agg({"sales": ["sum", "mean"]})             # один столбец — две функции
df.groupby("region").agg({"sales": "sum", "quantity": "mean"})  # разным столбцам — разные функции
```

Для одного столбца и одной функции удобно также: **df.groupby('key')['col'].agg('sum')**.

## 9.4.4. Именованные агрегаты

Чтобы задать **имена результирующих столбцов** явно (вместо автоматических 'sum', 'mean' и т.д.), в **.agg()** используют **именованные агрегаты**: кортеж **(имя_столбца, функция)** передаётся как именованный аргумент с именем нового столбца. Синтаксис: **.agg(новое_имя=('исходный_столбец', 'функция'))**. Для нескольких агрегатов по одному столбцу — несколько таких пар; для одного столбца с одной функцией — один именованный аргумент.

Именованные агрегаты делают результат читаемым и удобным для дальнейшего использования (например, экспорт или построение графиков).

```python
df.groupby("region").agg(
    total_sales=("sales", "sum"),
    avg_sales=("sales", "mean"),
)
# столбцы: total_sales, avg_sales; индекс — region
```

Если группировка по нескольким столбцам — **df.groupby(['region', 'year']).agg(...)** — индекс будет мультииндексом (region, year).

---

## Ключевое

- **df.groupby(by)** — разбиение таблицы на группы по значениям столбца(ов) **by**; результат — объект GroupBy, к нему применяют агрегацию.
- Агрегирующие методы: **.sum()**, **.mean()**, **.count()**, **.min()**, **.max()** и др.; выбор столбца до агрегации: **df.groupby('key')['col'].sum()**.
- **.agg(func)** — одна функция (строка), список функций или словарь {столбец: функция/список}; задаёт, что считать по каждой группе.
- **Именованные агрегаты** — **.agg(имя_столбца=('исходный_столбец', 'функция'))** — явные имена результирующих столбцов.

В [§9.5](chapter-09-05.md) разберём слияние таблиц: merge() по ключу, типы join (inner, left, right, outer) и concat по строкам или столбцам.
