# §11.1 SciPy

В [§10.3](chapter-10-03.md) мы разобрали HTTP-запросы и загрузку JSON в DataFrame. **SciPy** (Scientific Python) — библиотека научных вычислений поверх **NumPy**: статистика, оптимизация, линейная алгебра, обработка сигналов, численное интегрирование и др. В этом разделе — краткий **обзор** основных модулей (статистика, оптимизация, линейная алгебра) и когда SciPy уместен в анализе данных. Подробное изучение выходит за рамки книги; далее мы сфокусируемся на **Scikit-learn** для машинного обучения ([§11.2](chapter-11-02.md), [§11.3](chapter-11-03.md)).

---

## 11.1.1. Что такое SciPy

**SciPy** опирается на **NumPy** (массивы, типы данных) и добавляет алгоритмы из численной математики и прикладной статистики. Установка: **pip install scipy**. Импорт по подмодулям: **scipy.stats**, **scipy.optimize**, **scipy.linalg** и т.д.

Типичные области: статистические тесты и распределения, минимизация функций (подбор параметров, регрессия «вручную»), решение линейных систем и разложения матриц, интерполяция, Фурье-анализ. В анализе данных SciPy чаще используют для **углублённой аналитики** (проверка гипотез, оценка распределений, кастомная оптимизация), тогда как базовую агрегацию и визуализацию делают в Pandas и NumPy.

---

## 11.1.2. Статистика (scipy.stats)

Модуль **scipy.stats** содержит распределения вероятностей, описательную статистику и статистические тесты.

**Распределения:** у каждого распределения есть методы **pdf** (плотность), **cdf** (функция распределения), **ppf** (квантиль), **rvs** (случайная выборка). Пример: **scipy.stats.norm** — нормальное распределение; **norm.mean()**, **norm.std()**; **norm.cdf(x)** — P(X ≤ x); **norm.ppf(0.95)** — 0.95-квантиль.

**Описательная статистика:** **scipy.stats.describe(sample)** — число наблюдений, min, max, среднее, дисперсия, асимметрия, эксцесс. Для сравнения с теоретическим распределением — критерии согласия (например, **normaltest**).

**Тесты:** **ttest_ind**, **mannwhitneyu**, **chi2_contingency** и др. — проверка гипотез о средних, распределениях, таблицах сопряжённости. Тесты возвращают статистику и p-value; интерпретация требует понимания статистики.

Для быстрой сводки по данным в Pandas обычно хватает .describe() и визуализации; scipy.stats нужен, когда требуются точные квантили распределений, тесты или симуляции.

## 11.1.3. Оптимизация (scipy.optimize)

Модуль **scipy.optimize** — минимизация (и максимизация через смену знака) функций одной или многих переменных.

**minimize(fun, x0, method=..., bounds=...)** — общая минимизация: **fun** — целевая функция, **x0** — начальное приближение, **method** — алгоритм ('BFGS', 'L-BFGS-B', 'Nelder-Mead' и др.), **bounds** — ограничения на переменные. Возвращает объект с полями **x** (решение), **fun** (значение функции), **success** (успех сходимости).

**curve_fit(f, xdata, ydata, p0=...)** — подбор параметров функции **f(x, *params)** по данным (xdata, ydata); по сути минимизация суммы квадратов невязок. Удобно для кастомных регрессионных кривых (экспонента, логарифм и т.д.), когда готовой модели в Scikit-learn нет.

Для типовой регрессии и классификации проще использовать Scikit-learn ([§11.2](chapter-11-02.md)); scipy.optimize — когда нужна своя целевая функция или ограничения.

## 11.1.4. Линейная алгебра (scipy.linalg)

Модуль **scipy.linalg** расширяет **numpy.linalg**: решение линейных систем, разложения (LU, Cholesky, QR, SVD), обращение матриц. Функции часто принимают и возвращают массивы NumPy.

**scipy.linalg.solve(A, b)** — решение системы **Ax = b** (A — матрица, b — вектор). **inv(A)** — обратная матрица (по возможности лучше решать систему, чем явно обращать). **svd**, **eig** — сингулярное разложение и собственные значения.

В анализе данных линейная алгебра «напрямую» встречается в методах снижения размерности (PCA), линейной регрессии «из формул» и в кастомных моделях; в книге мы используем готовые реализации в Scikit-learn.

---

## 11.1.5. Когда использовать SciPy

**В рамках этой книги** SciPy даётся обзорно: читатель должен знать, что такая библиотека есть и для чего её подмодули. Углублённое изучение статистики и оптимизации — отдельная тема.

**Имеет смысл обращаться к SciPy**, когда: нужны статистические тесты или квантили распределений (scipy.stats); подгонка нестандартной кривой по данным (scipy.optimize.curve_fit); своя задача минимизации с ограничениями; разложения матриц или решение линейных систем (scipy.linalg). Для регрессии и классификации по табличным данным следующий шаг — **Scikit-learn** ([§11.2](chapter-11-02.md)).

---

## Ключевое

- **SciPy** — библиотека научных вычислений поверх NumPy: статистика, оптимизация, линейная алгебра, сигналы и др.
- **scipy.stats** — распределения (norm, t, chi2…), описательная статистика (describe), тесты (ttest_ind и др.).
- **scipy.optimize** — минимизация функций (minimize), подгонка кривых (curve_fit).
- **scipy.linalg** — решение линейных систем (solve), разложения (SVD, LU и др.).
- В книге SciPy — обзор; для машинного обучения по табличным данным переходим к Scikit-learn.

В [§11.2](chapter-11-02.md) разберём обзор API Scikit-learn: оценщики (fit, predict), выбор модели и разбиение данных (train_test_split).
