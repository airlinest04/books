# §8.4 Базовые атрибуты и методы

В [§8.3](chapter-08-03.md) мы разобрали выборку строк и ячеек, .loc/.iloc и добавление/удаление столбцов. Чтобы быстро **просмотреть** таблицу и её структуру, в Pandas есть атрибуты **.shape**, **.dtypes** и методы **.head()**, **.tail()**, **.info()**, **.describe()**. В [§9.1](chapter-09-01.md) перейдём к очистке данных: пропуски (.isna(), .fillna(), .dropna()).

---

## 8.4.1. .head() и .tail()

**df.head(n=5)** — возвращает **первые n строк** DataFrame (по умолчанию 5). Удобно для беглого просмотра после загрузки файла или фильтрации.

**df.tail(n=5)** — возвращает **последние n строк**. Полезно для проверки конца таблицы или данных, упорядоченных по времени.

Оба метода возвращают новый DataFrame (подтаблицу); исходный объект не изменяется. Для Series работают аналогично: **s.head(n)**, **s.tail(n)**.

```python
import pandas as pd
df = pd.DataFrame({"a": range(10), "b": range(10, 20)})
df.head(3)   # строки 0, 1, 2
df.tail(2)   # строки 8, 9
```

---

## 8.4.2. .shape

**df.shape** — атрибут (не метод): кортеж **(число_строк, число_столбцов)**. Аналогично **ndarray.shape** в NumPy. Позволяет быстро проверить размер таблицы после загрузки или фильтрации.

```python
df.shape   # (10, 2) — 10 строк, 2 столбца
len(df)    # 10 — число строк (длина индекса)
```

---

## 8.4.3. .dtypes

**df.dtypes** — **Series**, в котором индекс — имена столбцов, значения — типы данных каждого столбца (dtype). Типы могут быть: int64, float64, object (часто строки или смешанный тип), bool, datetime64 и др. По .dtypes видно, какие столбцы числовые, какие текстовые; это важно перед агрегацией и преобразованием типов (см. [§9.3](chapter-09-03.md)).

```python
df.dtypes
# a    int64
# b    int64
# dtype: object
```

---

## 8.4.4. .info()

**df.info()** — метод, который **выводит в консоль** сводку о таблице (ничего не возвращает, возвращаемое значение — None). Содержит:

- тип индекса и диапазон меток;
- для каждого столбца: имя, число **непустых** значений (non-null count) и dtype;
- использование памяти.

По non-null count легко увидеть **пропуски**: если число не совпадает с числом строк, в столбце есть отсутствующие значения (NaN). Подробнее о пропусках — в [§9.1](chapter-09-01.md).

```python
df.info()
# <class 'pandas.core.frame.DataFrame'>
# RangeIndex: 10 entries, 0 to 9
# Data columns (total 2 columns):
#  #   Column  Non-Null Count  Dtype
# ---  ------  --------------  -----
#  0   a       10 non-null     int64
#  1   b       10 non-null     int64
# dtypes: int64(2)
# memory usage: ...
```

## 8.4.5. .describe()

**df.describe()** — возвращает **DataFrame** со сводной **статистикой по числовым столбцам**: count (число непустых), mean, std, min, 25%, 50%, 75%, max. Процентили (25%, 50%, 75%) — квартили. Столбцы с типом object по умолчанию не включаются. Подходит для быстрой оценки размаха и распределения числовых данных.

Включить все столбцы (в том числе нечисловые) можно аргументом **include='all'**; для нечисловых столбцов будут count, unique, top (самое частое значение), freq.

```python
df.describe()
#               a          b
# count  10.00000  10.00000
# mean    4.50000  14.50000
# std     2.87228   2.87228
# min     0.00000  10.00000
# 25%     2.25000  12.25000
# 50%     4.50000  14.50000
# 75%     6.75000  16.75000
# max     9.00000  19.00000
```

---

## Ключевое

- **.head(n)**, **.tail(n)** — первые или последние n строк (по умолчанию n=5); результат — DataFrame.
- **.shape** — кортеж (число строк, число столбцов).
- **.dtypes** — Series с типами столбцов (int64, float64, object и т.д.).
- **.info()** — вывод в консоль: индекс, столбцы, non-null count, dtype, память; по non-null видно пропуски.
- **.describe()** — сводная статистика по числовым столбцам (count, mean, std, min, квартили, max).

В [§9.1](chapter-09-01.md) мы разберём работу с пропусками: .isna(), .fillna(), .dropna() и стратегии заполнения.
