# §2.1 Переменные и присваивание

В [§1.4](chapter-01-04.md) мы настроили окружение и установили пакеты. Теперь переходим к синтаксису Python. Этот раздел открывает главу о переменных, типах и операторах: мы разберём, как связать имя с значением (присваивание), почему в Python не нужно объявлять тип переменной (динамическая типизация) и что происходит при повторном присваивании. В [§2.2](chapter-02-02.md) мы рассмотрим основные типы данных — целые и вещественные числа, строки и булевы значения.

---

## 2.1.1. Присваивание: имя = значение

**Переменная** в Python — это имя, связанное с некоторым объектом (значением). Связь создаётся операцией **присваивания**: слева от знака `=` указывают имя, справа — выражение, результат которого станет значением переменной. См. [Глоссарий](glossary.md).

Синтаксис:

```python
имя = выражение
```

Примеры:

```python
x = 10
name = "Alice"
temperature = 36.6
```

Интерпретатор вычисляет правую часть и связывает полученное значение с именем слева. После этого по имени можно обращаться к значению:

```python
x = 10
print(x)   # 10
print(x + 5)   # 15
```

В одной строке можно присвоить одно и то же значение нескольким переменным:

```python
a = b = 0
```

Сначала вычисляется правая часть (здесь `0`), затем это значение присваивается и `a`, и `b`. Несколько имён слева и несколько выражений справа (распаковка) мы рассмотрим в главе о структурах данных ([§5.3](chapter-05-03.md)).

**Имена переменных** должны удовлетворять правилам языка: буквы (в том числе Unicode), цифры и символ подчёркивания `_`; имя не может начинаться с цифры. Регистр учитывается: `total` и `Total` — разные имена. По соглашению (PEP 8) имена переменных пишут в нижнем регистре, слова разделяют подчёркиванием, например `user_name`, `item_count`. Зарезервированные слова (например, `if`, `for`, `def`) использовать в качестве имён нельзя.

## 2.1.2. Динамическая типизация

В Python **тип значения не задаётся при присваивании**. Тип определяется самим объектом: число `10` имеет тип `int`, строка `"hello"` — тип `str`. Переменная же лишь ссылается на объект; у неё нет «собственного» типа, зафиксированного в коде. Такой подход называют **динамической типизацией**: одна и та же переменная может в разное время ссылаться на объекты разных типов. См. [Глоссарий](glossary.md).

Следствия:

- Не нужно (и нельзя в стандартном синтаксисе) писать «переменная x типа int». Достаточно присвоить значение: `x = 10`.
- Проверка типов выполняется во время выполнения программы: если вы передадите в функцию значение не того типа, который она ожидает, ошибка возникнет в момент вызова, а не при компиляции. В [§2.2](chapter-02-02.md) мы познакомимся с функцией `type()`, которая возвращает тип объекта.
- Код остаётся коротким и гибким; за строгую согласованность типов при сложных проектах отвечают аннотации типов (type hints) и инструменты статического анализа — они выходят за рамки этой книги.

Для работы с данными динамическая типизация удобна: один и тот же скрипт может обрабатывать столбцы с разными типами, а тип переменной определяется содержимым (число, строка, список, DataFrame и т.д.).

## 2.1.3. Повторное присваивание

Имя можно использовать многократно: новое присваивание **перезаписывает** связь имени с объектом. Переменная начинает ссылаться на новое значение; предыдущее значение при этом никуда не «перезаписывается» в памяти — на него просто перестаёт ссылаться это имя (и если на него больше нет ссылок, сборщик мусора может освободить память).

Пример:

```python
x = 5
print(x)   # 5
x = 10
print(x)   # 10
x = "text"
print(x)   # text
```

Сначала `x` ссылается на целое число, затем на другое целое, затем на строку. Изменение типа при повторном присваивании в Python допустимо; для читаемости кода обычно стараются не менять тип одной и той же переменной без необходимости.

**Увеличение значения на основе текущего** — типичный паттерн:

```python
count = 0
count = count + 1   # теперь count равно 1
count = count + 1   # теперь 2
```

Сокращённая запись такого присваивания — операторы `+=`, `-=` и т.д. — будет рассмотрена в [§2.3](chapter-02-03.md).

## 2.1.4. Присваивание и объекты: на что ссылается имя

В Python все данные представлены **объектами**. Присваивание не «копирует» значение в ячейку с именем переменной, а связывает имя с объектом в памяти. Несколько имён могут ссылаться на один и тот же объект; тогда изменение изменяемого объекта (например, списка) через одно имя будет видно и по другому имени. С неизменяемыми типами (числа, строки, кортежи) такой путаницы не возникает: «изменить» их можно только присвоив переменной новый объект. Подробнее об изменяемости мы поговорим в главе о структурах данных ([§5.1](chapter-05-01.md), [§5.2](chapter-05-02.md)); здесь важно зафиксировать: присваивание связывает имя с объектом, повторное присваивание перенаправляет имя на другой объект.

---

## Ключевое

- **Присваивание:** `имя = выражение` — вычисляется правая часть, результат связывается с именем слева; по имени далее обращаются к значению.
- **Имена:** буквы, цифры, `_`; не начинаются с цифры; регистр учитывается; стиль PEP 8 — нижний регистр, слова через подчёркивание.
- **Динамическая типизация:** тип не объявляется; тип имеет объект, переменная — только ссылка на объект; одна переменная может ссылаться на объекты разных типов в разное время.
- **Повторное присваивание:** новое присваивание тому же имени перенаправляет его на новый объект; предыдущее значение при этом не изменяется — меняется только то, на что ссылается имя.
