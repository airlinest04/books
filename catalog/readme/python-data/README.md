## Подробное содержание

### Часть I. Python с нуля

#### Глава 1. Python как язык для работы с данными: среда и инструменты

* **1.1 Зачем Python для данных** — экосистема библиотек (NumPy, Pandas, Scikit-learn); интерпретируемый язык, читаемость.
* **1.2 Установка Python** — установка с python.org или пакетным менеджером; версия 3.x; виртуальное окружение (venv).
* **1.3 Запуск кода** — интерактивная оболочка (REPL), запуск файла .py; Jupyter Notebook/Lab (кратко) для интерактивного анализа.
* **1.4 Установка пакетов** — pip; pip install numpy pandas; requirements.txt.
* _Ключевое:_ установка, venv, pip. _Задания:_ создать окружение и установить пакеты.

#### Глава 2. Синтаксис Python: переменные, типы, операторы

* **2.1 Переменные и присваивание** — имя = значение; динамическая типизация; повторное присваивание.
* **2.2 Основные типы** — int, float, str, bool; проверка типа type(); приведение int(), float(), str().
* **2.3 Операторы** — арифметические (+, -, \*, /, //, %); сравнения (==, !=, <, >); логические (and, or, not).
* **2.4 Строки** — кавычки; индексация и срезы s\[i], s\[start:end]; методы .strip(), .split(), .format() и f-строки.
* **2.5 None** — отсутствие значения; проверка на None.
* _Ключевое:_ типы, операторы, строки. _Задания:_ простые вычисления и работа со строками.

#### Глава 3. Управляющие конструкции: условия и циклы

* **3.1 Условие if / elif / else** — отступы; вложенность.
* **3.2 Цикл for** — for x in последовательность; range(); перебор элементов списка и строки.
* **3.3 Цикл while** — условие; break и continue.
* **3.4 Тернарное выражение** — x if условие else y.
* _Ключевое:_ if, for, while, break/continue. _Задания:_ задачи на ветвления и циклы.

#### Глава 4. Функции и модули

* **4.1 Определение функции** — def имя(параметры):; return; параметры по умолчанию.
* **4.2 Аргументы** — позиционные и именованные; \*args, \*\*kwargs (кратко).
* **4.3 Область видимости** — локальные и глобальные переменные; не изменять глобальные без global (лучшие практики).
* **4.4 Модули** — import module; from module import name; **name** == '**main**' при запуске файла.
* **4.5 Стандартная библиотека** — os, sys, datetime, json (кратко для последующих глав).
* **4.6 Обработка исключений** — try/except; типы исключений (ValueError, KeyError, IOError); обрабатывать и пробрасывать; зачем в пайплайнах данных и при работе с API/файлами.
* _Ключевое:_ def, return, import, try/except. _Задания:_ написание функций и разбиение кода на модули.

#### Глава 5. Структуры данных: списки, словари, кортежи, множества

* **5.1 Список (list)** — создание \[], индексация, срезы; методы append, extend, insert, remove, pop; список как изменяемый тип.
* **5.2 Словарь (dict)** — пары ключ: значение; доступ по ключу; .get(); перебор .items(), .keys(), .values(); изменение и добавление.
* **5.3 Кортеж (tuple)** — неизменяемая последовательность; распаковка; когда использовать вместо списка.
* **5.4 Множество (set)** — уникальные элементы; добавление, удаление; операции объединения и пересечения.
* **5.5 List comprehensions** — \[выражение for x in ... if условие]; кратко dict/set comprehensions.
* _Ключевое:_ list, dict, tuple, set; срезы и методы. _Задания:_ задачи на коллекции и comprehensions.

#### Глава 6. Чтение и запись данных (файлы, форматы)

* **6.1 Открытие файла** — open(), контекстный менеджер with; режимы 'r', 'w', 'a'; кодировка encoding='utf-8'.
* **6.2 Текстовые файлы** — чтение .read(), .readlines(); запись .write(); построчное чтение больших файлов.
* **6.3 CSV** — модуль csv; reader, writer; диалекты; ограничения и кодировки.
* **6.4 JSON** — json.load(), json.dump(); чтение и запись структур данных.
* **6.5 Регулярные выражения** — модуль re; поиск (search, match) и замена (sub) при очистке текстовых полей; типичные паттерны для данных (кратко).
* _Ключевое:_ with open(), csv, json, re. _Задания:_ чтение CSV/JSON, извлечение полей и сохранение результата.

### Часть II. NumPy и Pandas

#### Глава 7. NumPy: массивы и вычисления

* **7.1 Создание массивов** — np.array(); np.zeros(), np.ones(), np.arange(); форма shape и размерность ndim.
* **7.2 Индексация и срезы** — один индекс, срезы; многомерные массивы \[i, j]; булева маска.
* **7.3 Операции** — поэлементные арифметические операции; broadcasting; агрегаты np.sum(), np.mean(), np.min(), np.max() по оси axis.
* **7.4 Формы и преобразования** — reshape, ravel; конкатенация массивов.
* _Ключевое:_ ndarray, shape, срезы, агрегаты. _Задания:_ создание массивов, вычисления, агрегация по осям.

#### Глава 8. Pandas: Series и DataFrame

* **8.1 Series** — одномерная структура с индексами; создание из списка и dict; доступ .loc, .iloc; атрибут .index.
* **8.2 DataFrame** — создание из dict, из списка словарей, из CSV; столбцы и индексы; выбор столбца df\['col'], df.col.
* **8.3 Выборка строк и ячеек** — булева маска df\[df\['col'] > 0]; .loc\[], .iloc\[]; добавление и удаление столбцов.
* **8.4 Базовые атрибуты и методы** — .head(), .tail(), .info(), .describe(); .shape, .dtypes.
* _Ключевое:_ Series, DataFrame, .loc, .iloc. _Задания:_ загрузка таблицы, выборка и просмотр.

#### Глава 9. Очистка, преобразование и агрегация в Pandas

* **9.1 Пропуски** — .isna(), .fillna(), .dropna(); стратегии заполнения.
* **9.2 Дубликаты** — .duplicated(), .drop\_duplicates(); по подмножеству столбцов.
* **9.3 Преобразование типов** — .astype(); преобразование дат pd.to\_datetime().
* **9.4 Группировка и агрегация** — groupby(); .agg(); одна и несколько агрегирующих функций; именованные агрегаты.
* **9.5 Слияние таблиц** — merge() по ключу; типы join (inner, left, right, outer); concat по строкам/столбцам.
* **9.6 Сортировка и ранжирование** — sort\_values(); rank().
* _Ключевое:_ очистка, groupby, merge. _Задания:_ пайплайн очистки и агрегации по кейсу.

#### Глава 10. Связь с базами данных и API

* **10.1 Подключение к БД** — библиотеки sqlalchemy, psycopg2 (PostgreSQL); создание движка и чтение read\_sql().
* **10.2 Запросы и результат в DataFrame** — SELECT в read\_sql; параметризованные запросы; запись в таблицу to\_sql() (кратко).
* **10.3 HTTP-запросы** — библиотека requests; GET; разбор JSON-ответа и загрузка в DataFrame.
* _Ключевое:_ read\_sql, requests, JSON в DataFrame. _Задания:_ выгрузка из БД в DataFrame; запрос к API и разбор ответа.

#### Глава 11. SciPy и Scikit-learn: введение

* **11.2 Scikit-learn: обзор API** — оценщики (estimators): fit(), predict(); выбор модели и разбиение данных (train\_test\_split).
* **11.3 Пример: регрессия и классификация** — одна модель регрессии (LinearRegression) и одна классификации (LogisticRegression или дерево); метрики (MSE, accuracy).
* _Ключевое:_ fit/predict, train\_test\_split, одна-две модели. _Задания:_ обучить модель по готовому набору, посчитать метрику.

#### Глава 12. Машинное обучение: объём и границы книги

* **12.1 Что покрыто в серии** — основы в этой книге; углубление — отдельные курсы/книги; связь с книгой «Анализ данных и визуализация» (прогнозная аналитика).
* **12.2 Подготовка данных для ML** — масштабирование признаков; кодирование категорий; типичные ошибки (утечка целевой переменной).
* **12.3 Валидация и переобучение** — кросс-валидация (cross\_val\_score); переобучение и регуляризация (кратко).

#### Глава 13. Обзор фреймворков: TensorFlow, Keras, PyTorch

* **13.1 Когда нужны глубокие нейросети** — задачи (распознавание образов, NLP и т.д.); отличие от классического ML.
* **13.2 Keras** — высокоуровневый API; последовательная модель; пример простой сети (плотные слои); компиляция и обучение.
* **13.3 TensorFlow и PyTorch** — кратко: TensorFlow как бэкенд для Keras; PyTorch — императивный стиль; когда что выбирать.
* _Ключевое:_ обзор возможностей; один пример на Keras. _Задания:_ запустить пример обучения простой модели (по желанию).
