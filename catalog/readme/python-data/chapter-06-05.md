# §6.5 Регулярные выражения

В [§6.4](chapter-06-04.md) мы разобрали JSON. Завершаем главу о файлах и форматах **регулярными выражениями** (regex): они задают **шаблоны** для поиска и замены в тексте и полезны при очистке полей (телефоны, коды, лишние пробелы, извлечение фрагментов). В Python за это отвечает модуль **re**. В разделе — **re.search()**, **re.match()**, **re.sub()** и кратко типичные паттерны для данных. В [§7.1](chapter-07-01.md) мы начнём Часть II: NumPy и создание массивов.

---

## 6.5.1. Модуль re и зачем нужны regex при очистке данных

**Регулярное выражение** — строка-шаблон, описывающая множество строк: например, «одна или более цифр», «пробелы в начале и конце», «последовательность букв и цифр». Модуль **re** по такому шаблону ищет вхождения в тексте и может выполнять замену. См. [Глоссарий](glossary.md).

При очистке данных regex используют, когда простых методов строк (.strip(), .split(), in) недостаточно: нормализация телефонов (оставить только цифры), удаление всего кроме цифр из поля «код», проверка формата (например, почтовый индекс), извлечение части строки по шаблону. Слишком сложную логику лучше разбивать на шаги или ограничивать область применения regex, чтобы шаблоны оставались читаемыми.

```python
import re
```

Шаблоны часто задают **сырыми строками** **r"..."**, чтобы обратный слэш \ не интерпретировался как экранирование в Python ([§2.4](chapter-02-04.md)).

## 6.5.2. Поиск: re.search() и re.match()

**re.search(pattern, string)** ищет **первое** вхождение шаблона **в любом месте** строки. Возвращает объект **Match** при успехе или **None**, если совпадений нет.

```python
import re
m = re.search(r"\d+", "Price: 123 rub")
if m:
    print(m.group())   # 123
```

**m.group()** — подстрока, совпавшая с шаблоном целиком; **m.start()**, **m.end()** — начальный и конечный индексы вхождения.

**re.match(pattern, string)** ищет совпадение **только с начала** строки. Если шаблон должен совпасть с начала (например, «строка начинается с цифры»), удобен match; для поиска в любом месте — search.

```python
re.match(r"\d+", "123 abc")   # совпадение с "123"
re.match(r"\d+", "abc 123")   # None — в начале нет цифр
re.search(r"\d+", "abc 123")  # совпадение с "123"
```

Для проверки «есть ли в строке шаблон» часто пишут **if re.search(pattern, s):**.

---

## 6.5.3. Замена: re.sub()

**re.sub(pattern, repl, string, count=0)** возвращает строку, в которой **все** вхождения шаблона заменены на **repl**. **repl** может быть строкой или функцией (принимает объект Match, возвращает строку). **count** — максимальное число замен (0 — все).

```python
import re
s = "  spaces   here  "
re.sub(r"\s+", " ", s).strip()   # "spaces here" — схлопнуть пробелы
re.sub(r"\D", "", "+7 (999) 123-45-67")   # "79991234567" — оставить только цифры
```

В **repl** можно использовать ссылки на **группы** (части шаблона в круглых скобках): **\1**, **\2** — первая, вторая группа. Например, поменять местами две части: **re.sub(r"(\w+), (\w+)", r"\2 \1", "Last, First")** даёт "First Last".

## 6.5.4. Типичные паттерны для данных

Краткий набор элементов синтаксиса, достаточный для простой очистки:

| Паттерн | Значение |
|---------|----------|
| **\d**  | одна цифра |
| **\D**  | один не-цифровой символ |
| **\s**  | пробельный символ (пробел, табуляция, \n) |
| **\S**  | не пробел |
| **\w**  | буква, цифра или _ (зависит от локали/флага) |
| **\W**  | не \w |
| **[0-9]** | одна цифра (то же, что \d в ASCII) |
| **[a-zA-Z]** | одна буква латиницы |
| **.**   | любой символ кроме перевода строки (с флагом re.DOTALL — любой) |
| **+**   | предыдущий элемент один или более раз |
| **\***  | ноль или более раз |
| **?**   | ноль или один раз |
| **{n}** | ровно n раз |
| **(...)** | группа (для извлечения или подстановки в sub) |

Примеры:

- **r"\d+"** — одна или более цифр (число).
- **r"\s+"** — один или более пробельных символов подряд (схлопнуть в один пробел через sub).
- **r"^\s+|\s+$"** — пробелы в начале или в конце строки (можно удалить через sub в пустую строку; или использовать .strip()).
- **r"[A-Za-z0-9]+"** — последовательность букв и цифр.
- **r"(\d{3})-(\d{2})-(\d{2})"** — группы для даты в виде 123-45-67 (извлечь через m.group(1), m.group(2)).

Флаг **re.IGNORECASE** (или **re.I**) — поиск без учёта регистра. Передаётся последним аргументом в search/match/sub или в **re.compile(pattern, re.I)**.

## 6.5.5. re.compile() и сырые строки

При многократном использовании одного и того же шаблона его компилируют: **re.compile(pattern)** возвращает объект с методами **.search(s)**, **.match(s)**, **.sub(repl, s)** и т.д. Это немного эффективнее и удобнее, когда один шаблон применяется ко многим строкам.

```python
pat = re.compile(r"\d+")
pat.findall("a1b22c")   # ['1', '22']
```

**re.findall(pattern, string)** возвращает **список всех** непересекающихся совпадений (каждое — строка или кортеж групп, если в шаблоне есть группы).

Шаблоны с обратным слэшем (например, **\d**, **\s**) в Python удобно задавать сырыми строками **r"..."**, иначе нужно удваивать слэш: **"\\d"**.

---

## Ключевое

- **Регулярное выражение** — шаблон для поиска и замены в тексте. Модуль **re**; шаблоны часто в сырых строках **r"..."**.
- **re.search(pattern, string)** — первое вхождение в любом месте; возвращает Match или None. **re.match(pattern, string)** — совпадение только с начала строки. **m.group()** — совпавшая подстрока.
- **re.sub(pattern, repl, string)** — заменить все вхождения на repl; repl может быть строкой с **\1**, **\2** (группы). **count** — максимум замен.
- Типичные элементы: **\d**, **\s**, **\w**, **+**, **\***, **?**, **(...)** группы. **re.findall()** — все совпадения; **re.compile()** — компиляция шаблона при многократном использовании.
