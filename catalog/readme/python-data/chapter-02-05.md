# §2.5 None

В [§2.4](chapter-02-04.md) мы разобрали строки и их методы. Завершаем главу о типах и операторах значением **None** — единственным объектом типа `NoneType`, которое в Python обозначает **отсутствие значения**. Оно встречается как результат функций без явного return, как значение по умолчанию аргументов и при работе с опциональными данными; важно уметь корректно проверять «есть ли значение» и не путать None с нулём или пустой строкой. В [§3.1](chapter-03-01.md) мы перейдём к условиям if/elif/else.

---

## 2.5.1. Что такое None

**None** — встроенная константа, единственный экземпляр типа **NoneType**. Она обозначает отсутствие осмысленного значения: «ничего не вернулось», «значение не задано», «опциональный результат отсутствует». См. [Глоссарий](glossary.md).

В коде None записывают без кавычек:

```python
x = None
```

Тип переменной после такого присваивания — `NoneType`:

```python
type(None)   # <class 'NoneType'>
```

None не равен числу нуль, не равен пустой строке и не равен пустому списку. Это отдельный объект-маркер «значения нет»:

```python
None == 0        # False
None == ""       # False
None == []       # False
```

Использовать None в арифметике нельзя — это приведёт к ошибке TypeError. Не следует подменять им 0 или "" там, где ожидается число или строка: для «пустого» числового или строкового значения используют 0 или ""; None — именно для случаев «значение не определено» или «результат отсутствует».

---

## 2.5.2. Когда появляется None

**Функция без return или без значения после return.** Если функция не выполняет инструкцию `return` или выполняет `return` без выражения, она возвращает None:

```python
def say_hello():
    print("Hello")

result = say_hello()   # выведет Hello
print(result)         # None
```

**Значение по умолчанию аргумента.** Необязательные параметры часто инициализируют None, чтобы потом отличить «аргумент не передан» от «передано какое-то значение» ([§4.2](chapter-04-02.md)).

**Методы и операции, означающие «не найдено».** Например, метод словаря **.get(key, default)** возвращает None по умолчанию, если ключа нет и второй аргумент не указан:

```python
d = {"a": 1}
d.get("b")   # None
d.get("b", 0)   # 0  — явное значение по умолчанию
```

В данных и API часто поля при отсутствии значения приходят как null (в JSON) или пропуск; при разборе в Python их нередко представляют как None. В Pandas пропуски в таблицах обозначаются особым значением (NaN), но при работе со списками и словарями None — типичный маркер «значения нет».

---

## 2.5.3. Проверка на None

Проверять, равно ли значение None, принято операторами **is** и **is not**, а не **==** и **!=**. Причина: в Python существует только один объект None; проверка по идентичности (тот же ли это объект в памяти) семантически точнее и соответствует рекомендациям (PEP 8).

**Рекомендуемый способ:**

```python
if x is None:
    print("значение не задано")

if x is not None:
    print("значение задано")
```

**Почему не == None:** выражение `x == None` технически работает (None сравнивается с самим собой и даёт True), но стиль кода предписывает использовать `is None`. Выражение `x is None` читается однозначно: «переменная x ссылается на объект None».

**Типичная ошибка:** подставить None в условие и ожидать «ложь». None в логическом контексте действительно считается ложным:

```python
bool(None)   # False
if None:
    pass     # этот блок не выполнится
```

Но для явной проверки «значение отсутствует» всегда пишут `if x is None` или `if x is not None`, а не полагаются на «ложность» — иначе путаются с 0, "" или пустым списком, которые тоже ложны, но не означают «нет значения».

---

## 2.5.4. None и работа с данными

При разборе файлов, ответов API или результатов запросов к базе поля могут отсутствовать. В таких случаях в программе часто хранят None и перед использованием проверяют:

```python
value = row.get("optional_field")   # может быть None
if value is not None:
    process(value)
else:
    use_default()
```

При выводе или записи в файл None обычно преобразуют в строку явно, иначе получится строка `"None"`:

```python
x = None
print(str(x))   # "None"
# при необходимости подставить пустую строку или прочерк:
print(x if x is not None else "")
```

В таблицах Pandas пропуски представляются как NaN (Not a Number); проверка и замена пропусков рассматриваются в [§9.1](chapter-09-01.md). На уровне обычных типов Python None остаётся стандартным способом обозначить «значения нет».

---

## Ключевое

- **None** — единственный объект типа NoneType; обозначает отсутствие значения. Не равен 0, "" или []; в арифметике использовать нельзя.
- None возвращают функции без return (или с `return` без выражения); его используют как значение по умолчанию аргументов и как маркер «не найдено» (например, dict.get() без второго аргумента).
- **Проверка:** писать `if x is None` и `if x is not None`, а не `== None`. В логическом контексте None считается ложным, но для явной проверки на отсутствие значения всегда используют `is None` / `is not None`.
- При работе с данными None часто обозначает отсутствующее поле; перед использованием проверяют `is not None`; при выводе при необходимости подставляют пустую строку или другое значение.
