# §8.1 Series

В [§7.4](chapter-07-04.md) мы завершили главу о NumPy. Теперь — **Pandas**: библиотека для табличных данных и рядов. **Series** — одномерная структура с **метками индекса** (labels): у каждого значения есть не только позиция, но и имя (индекс), по которому можно обращаться. В этом разделе: создание Series из списка и словаря, доступ по позиции (**.iloc**) и по метке (**.loc**), атрибуты **.index** и **.values**. В [§8.2](chapter-08-02.md) рассмотрим DataFrame — таблицу из столбцов и строк.

---

## 8.1.1. Что такое Series

**Series** — одномерный массив с **индексом**: каждому элементу соответствует **метка** (label). По смыслу это столбец таблицы или временной ряд: значения и их подписи (даты, идентификаторы, категории). См. [Глоссарий](glossary.md).

Импорт Pandas по соглашению:

```python
import pandas as pd
```

Series объединяет массив значений (внутри — NumPy ndarray) и индекс (метки). Обращаться к элементам можно **по позиции** (как в массиве) и **по метке индекса** — в этом отличие от обычного списка или массива NumPy.

---

## 8.1.2. Создание Series: из списка и из словаря

**pd.Series(data, index=None)** — конструктор Series. **data** — последовательность значений (список, массив NumPy, другой Series); **index** — необязательный список (или массив) меток той же длины.

**Из списка** — индекс по умолчанию целочисленный (0, 1, 2, …):

```python
import pandas as pd
s = pd.Series([10, 20, 30, 40])
# 0    10
# 1    20
# 2    30
# 3    40
# dtype: int64
```

**Явный индекс** — передать список меток:

```python
s = pd.Series([10, 20, 30], index=["a", "b", "c"])
# a    10
# b    20
# c    30
# dtype: int64
```

**Из словаря** — ключи становятся метками индекса, значения — элементами Series. Порядок элементов в Series совпадает с порядком ключей в словаре (в Python 3.7+ порядок вставки сохраняется):

```python
pd.Series({"x": 1, "y": 2, "z": 3})
# x    1
# y    2
# z    3
# dtype: int64
```

Можно передать **index** при создании из словаря: тогда в Series попадут только ключи из index, отсутствующим будет присвоено NaN (пропуск). Подробнее о пропусках — в [§9.1](chapter-09-01.md).

## 8.1.3. Доступ по позиции: .iloc

**.iloc** (integer location) — доступ **по целочисленной позиции** (как у списка или массива): с нуля, срезы в формате start:stop:step.

**Один элемент:** **s.iloc[i]** — значение на позиции i.

**Срез:** **s.iloc[start:stop]** или **s.iloc[start:stop:step]** — подмножество Series (новая Series с теми же метками индекса у выбранных элементов).

```python
s = pd.Series([10, 20, 30, 40], index=["a", "b", "c", "d"])
s.iloc[0]     # 10
s.iloc[-1]    # 40
s.iloc[1:3]   # b    20, c    30  (Series из двух элементов)
```

Обращение **s[i]** для целочисленного i может совпадать с обращением по индексу: если метки индекса — целые числа 0, 1, 2, …, то **s[0]** даст первый элемент. При нецелочисленных метках **s[0]** трактуется как доступ **по метке** (и может быть KeyError, если метки 0 нет). Чтобы однозначно обращаться по позиции, используют **.iloc**.

---

## 8.1.4. Доступ по метке индекса: .loc

**.loc** (label location) — доступ **по метке индекса** (и срезы по меткам: включаются обе границы, если они есть в индексе).

**Один элемент:** **s.loc[label]** — значение с меткой label. Если метки нет — **KeyError**.

**Срез по меткам:** **s.loc[start_label:end_label]** — все элементы от метки start_label до end_label **включительно** (в отличие от среза по позиции, где stop не входит). Порядок определяется порядком меток в индексе.

```python
s = pd.Series([10, 20, 30, 40], index=["a", "b", "c", "d"])
s.loc["a"]       # 10
s.loc["b":"d"]   # b 20, c 30, d 40  — все три входят
s.loc["c"]       # 30
```

Для списка меток **s.loc[["a", "c"]]** возвращает Series с выбранными метками (fancy indexing). Присваивание **s.loc["a"] = 100** изменяет значение по этой метке.

---

## 8.1.5. Атрибуты .index и .values

**.index** — объект индекса (тип Index): метки всех элементов. Итерируемый; можно преобразовать в список **list(s.index)**. Проверка наличия метки: **"a" in s.index** или **"a" in s** (для Series проверка in идёт по индексу).

**.values** — массив NumPy с значениями Series (без меток). Удобно, когда нужны «голые» числа для передачи в NumPy или другие функции.

```python
s.index    # Index(['a', 'b', 'c', 'd'])
s.values   # array([10, 20, 30, 40])
len(s)     # 4
```

**.shape** — кортеж размеров (для Series — (n,)).

---

## 8.1.6. Кратко: арифметика и выравнивание по индексу

При арифметических операциях между двумя Series Pandas **выравнивает** их **по меткам индекса**: складываются (или умножаются и т.д.) элементы с **одинаковыми метками**; если метка есть только в одном Series, в результате для неё будет NaN. Это важное отличие от NumPy (где операции поэлементны по позиции). Подробнее арифметика и пропуски встретятся в следующих главах; здесь достаточно знать, что обращение к элементам — через **.loc** (по метке) и **.iloc** (по позиции).

---

## Ключевое

- **Series** — одномерная структура Pandas: значения + индекс (метки). Создание: **pd.Series(list)** или **pd.Series(dict)**; опционально **index=**.
- **.iloc[i]** — доступ по **позиции** (целое число, срезы); **.loc[label]** — по **метке индекса**; срез .loc включает обе границы.
- **.index** — объект индекса (метки); **.values** — массив NumPy значений. **in s** проверяет наличие метки в индексе.
- При арифметике двух Series выравнивание идёт по меткам индекса; отсутствующие метки дают NaN.
