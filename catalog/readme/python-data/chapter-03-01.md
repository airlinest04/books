# §3.1 Условие if / elif / else

В [§2.5](chapter-02-05.md) мы разобрали None и проверку на отсутствие значения. Теперь переходим к **управляющим конструкциям**: в зависимости от результата условия программа может выполнять разные участки кода. В этом разделе — условие **if**, ветка **else** и цепочка **elif**, а также правила отступов и вложенность. В [§3.2](chapter-03-02.md) рассмотрим цикл for.

---

## 3.1.1. Синтаксис if: условие и блок

Условие записывают так:

```python
if условие:
    инструкции_блока
```

После выражения **условия** обязательно ставится **двоеточие**. Следующие строки, которые должны выполняться при истинном условии, образуют **блок** и выделяются **отступом** (обычно 4 пробела). Все инструкции с одинаковым отступом под строкой `if условие:` входят в этот блок; первая строка с меньшим отступом (или конец файла) завершает блок.

Пример:

```python
x = 10
if x > 0:
    print("x положительное")
    print("проверка выполнена")
print("эта строка выполнится всегда")
```

Здесь при `x > 0` выполняются две строки с отступом, затем всегда выполняется последняя строка без отступа. Если условие ложно, блок под if пропускается.

**Условие** — любое выражение, результат которого в логическом контексте интерпретируется как истина или ложь: сравнения (`==`, `<`, `!=` и т.д.), логические выражения (`and`, `or`, `not`), вызовы функций, возвращающих bool, а также объекты, которые считаются «правдивыми» или «ложными» (см. ниже).

## 3.1.2. Ветка else и цепочка elif

**else** — ветка «во всех остальных случаях». Синтаксис:

```python
if условие:
    блок_если_истина
else:
    блок_если_ложь
```

Выполняется только один из блоков: если условие истинно — первый, иначе — второй.

**elif** (сокращение от «else if») — проверка следующего условия, если предыдущие не выполнились. Можно объединять несколько условий подряд:

```python
if x > 0:
    print("положительное")
elif x < 0:
    print("отрицательное")
else:
    print("ноль")
```

Интерпретатор проверяет условия по порядку; выполняется блок при первом истинном условии. Если ни одно не истинно, выполняется блок после **else** (если он есть). Блоков elif может быть несколько; else — не более одного и только в конце цепочки.

Пример с несколькими elif:

```python
score = 75
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
```

## 3.1.3. Отступы и блоки

В Python **отступы задают структуру кода**: не фигурные скобки, а пробелы (или табуляция) в начале строки. Все строки одного блока должны иметь **одинаковый** отступ; смешивать пробелы и табуляцию в одном файле не рекомендуется — возможны ошибки (Python 3 обычно выдаёт предупреждение).

Рекомендация (PEP 8): **4 пробела** на уровень вложенности.

**Типичные ошибки:**

- Забыть двоеточие после условия — синтаксическая ошибка.
- Поставить отступ только у части инструкций блока — следующая строка без отступа завершит блок раньше времени; логическая ошибка.
- Неправильный отступ у elif/else — elif и else должны быть на одном уровне с соответствующим if, а не внутри блока if:

```python
if x > 0:
    print("ok")
elif x < 0:   # тот же уровень отступа, что и if
    print("minus")
else:
    print("zero")
```

Пустой блок (когда по синтаксису что-то должно быть, но делать нечего) заполняют инструкцией **pass**:

```python
if condition:
    pass   # заглушка, потом допишете логику
```

## 3.1.4. Вложенные условия

Внутри блока if (или else, elif) может стоять ещё один if — получаются **вложенные условия**:

```python
x = 10
y = 5
if x > 0:
    if y > 0:
        print("оба положительные")
    else:
        print("x положительное, y — нет")
else:
    print("x не положительное")
```

Читаемость при большой вложенности падает; часто логику можно упростить, объединив условия через **and** / **or** или переписав цепочку elif:

```python
if x > 0 and y > 0:
    print("оба положительные")
elif x > 0:
    print("x положительное, y — нет")
else:
    print("x не положительное")
```

При работе с данными условия нередко проверяют несколько полей (значение в диапазоне, не пустая строка, не None); важно не увлекаться глубокой вложенностью и выносить сложные проверки в переменные или функции.

## 3.1.5. «Правдивость» значений в условиях

В условии после if можно писать не только сравнения и логические выражения, но и один объект. В таком случае используется его **булево представление** (truthiness): объект считается «ложным» (условие не выполнится) или «истинным» (условие выполнится).

**Считаются ложными (False):**

- `None`
- `False`
- Число ноль: `0`, `0.0`
- Пустые последовательности и коллекции: `""`, `[]`, `()`, `{}`
- Объекты, у которых определён специальный метод `__bool__` или `__len__` и они возвращают False или 0

**Считаются истинными (True):** практически всё остальное — любое ненулевое число, непустая строка, непустой список, непустой словарь и т.д.

Примеры:

```python
if []:
    print("не выведется")
if [1, 2]:
    print("выведется")
if "":
    print("не выведется")
if "hello":
    print("выведется")
```

Проверка на пустоту списка или строки часто пишется просто `if items:` (есть элементы) или `if not items:` (пусто). Для явной проверки на None по-прежнему используют `if x is None` ([§2.5](chapter-02-05.md)), чтобы не смешивать «нет значения» с нулём или пустой строкой.

---

## Ключевое

- **if условие:** — после условия ставится двоеточие; блок задаётся отступами (обычно 4 пробела). Выполняется только при истинном условии.
- **else** — ветка «иначе»; выполняется, когда условие if (и все elif выше) ложно. **elif** — следующая проверка в цепочке; первое истинное условие определяет выполняемый блок.
- Отступы задают принадлежность к блоку; смешивать пробелы и табуляцию не следует. Пустой блок — инструкция **pass**.
- Вложенные if допустимы; при сложной логике лучше объединять условия через and/or или переписывать в цепочку elif.
- В условиях используются «правдивые» и «ложные» значения: пустые последовательности и 0 — ложны, непустые и ненулевые — истинны; для проверки на None используют `is None` / `is not None`.
