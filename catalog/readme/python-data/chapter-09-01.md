# §9.1 Пропуски

В [§8.4](chapter-08-04.md) мы разобрали .info() и по non-null count увидели, что в столбцах могут быть **пропуски** — отсутствующие значения. В Pandas они представляются как **NaN** (Not a Number) или, в некоторых контекстах, как **None**. В этом разделе: **обнаружение** пропусков (**.isna()**, **.notna()**), **удаление** строк или столбцов с пропусками (**.dropna()**) и **заполнение** пропусков (**.fillna()**) с разными стратегиями. В [§9.2](chapter-09-02.md) рассмотрим дубликаты строк (.duplicated(), .drop_duplicates()).

---

## 9.1.1. Что такое пропуски в Pandas

**Пропуск** (missing value) — ячейка, для которой значение неизвестно или не задано. В Pandas для этого используется в основном **NaN** (тип float); при чтении из CSV пустые ячейки и строки вроде "NA", "null" при определённых настройках тоже превращаются в NaN. В столбцах типа object могут встречаться и **None** (Python). Функции и методы Pandas обычно трактуют и NaN, и None как отсутствующее значение.

NaN не равен сам себе: **float('nan') == float('nan')** даёт False. Поэтому для проверки «это пропуск?» в Pandas используют **.isna()** / **pd.isna()**, а не сравнение с NaN.

---

## 9.1.2. .isna() и .notna()

**df.isna()** — возвращает **DataFrame** той же формы, что и df, с булевыми значениями: True там, где в исходной таблице пропуск (NaN или None), False — где значение есть. Для одного столбца: **df['col'].isna()** — Series булевых значений.

**df.notna()** — обратная маска: True, где значение **есть**, False — где пропуск. Удобно для фильтрации «оставить только строки с заполненным полем»: **df[df['col'].notna()]**.

**pd.isna(obj)** — функция: принимает скаляр, Series или DataFrame; возвращает True/False или маску. **pd.notna(obj)** — то же с обратной логикой.

```python
import pandas as pd
import numpy as np
df = pd.DataFrame({"a": [1, np.nan, 3], "b": [10, 20, np.nan]})
df.isna()
#        a      b
# 0  False  False
# 1   True  False
# 2  False   True
df["a"].notna()   # 0 True, 1 False, 2 True
df[df["a"].notna()]  # строки, где a не пропущен
```

## 9.1.3. .dropna()

**df.dropna()** — удаляет **строки**, в которых есть хотя бы один пропуск. По умолчанию возвращает новый DataFrame; **inplace=True** изменяет исходный.

- **how='any'** (по умолчанию) — удалить строку, если в ней есть хотя бы один пропуск.
- **how='all'** — удалить строку только если **все** её ячейки — пропуски.
- **subset** — список столбцов; учитываются пропуски только в этих столбцах. Например, **dropna(subset=['col1', 'col2'])** удаляет строки, где пропуск в col1 или col2.
- **axis=1** — удалять **столбцы**, в которых есть пропуски (по умолчанию axis=0 — строки).

При массовом удалении строк теряются данные; часто разумнее заполнять пропуски (.fillna()) или удалять только по ключевым полям (subset).

```python
df.dropna()                    # строки без единого пропуска
df.dropna(how="all")           # только строки, целиком пустые
df.dropna(subset=["a"])        # строки, где в столбце a нет пропуска
df.dropna(axis=1)              # столбцы, в которых нет пропусков
```

## 9.1.4. .fillna() и стратегии заполнения

**df.fillna(value, inplace=False)** — заменяет пропуски на указанное значение. **value** может быть скаляром (одно и то же для всех пропусков) или словарём **{имя_столбца: значение}** — тогда в каждом столбце свои заполнители. Возвращает новый DataFrame (или None при inplace=True).

**Частые стратегии:**

- **Константа:** **fillna(0)**, **fillna('')** — все пропуски заменить на 0 или пустую строку. Подходит, когда смысл «нет значения» кодируется константой.
- **Среднее/медиана по столбцу:** **df['col'].fillna(df['col'].mean())** или **fillna(df.mean())** — заполнить числовые столбцы средними по столбцу. Так сохраняется масштаб и не теряются строки.
- **Продолжение предыдущего значения (forward fill):** **fillna(method='ffill')** или **fillna(method='pad')** — взять значение из предыдущей строки (по индексу). Удобно для временных рядов или повторяющихся категорий.
- **Продолжение следующего значения (backward fill):** **fillna(method='bfill')** — взять значение из следующей строки.

Для **method='ffill'** и **method='bfill'** можно задать **limit=N** — заполнить не более N подряд идущих пропусков в каждом столбце.

Заполнение может искажать распределение и выводы; выбор стратегии зависит от предметной области (временной ряд, опросы, справочники).

```python
df.fillna(0)                           # все пропуски — ноль
df.fillna({"a": 0, "b": df["b"].mean()})  # по столбцам
df.fillna(method="ffill")               # предыдущее значение (устаревший синтаксис)
# В новых версиях Pandas вместо method используют ffill()/bfill():
df.ffill()                             # forward fill
df.bfill()                             # backward fill
df.ffill(limit=1)                      # не более 1 пропуска подряд
```

В современных версиях Pandas предпочтительно использовать методы **df.ffill()** и **df.bfill()** вместо **fillna(method='ffill'/'bfill')**, так как аргумент method в fillna помечен как устаревающий.

---

## Ключевое

- **Пропуски** в Pandas — в основном **NaN** (и иногда None); проверка — через **.isna()** / **.notna()**, не через сравнение с NaN.
- **.isna()**, **.notna()** — маска True/False по пропускам; **df[df['col'].notna()]** — выбор строк с заполненным полем.
- **.dropna()** — удаление строк (или столбцов при axis=1) с пропусками; **how='any'** / **'all'**, **subset** — по каким столбцам смотреть.
- **.fillna(value)** — заменить пропуски на константу или словарь по столбцам; **ffill()** / **bfill()** — заполнение предыдущим/следующим значением; для числовых столбцов часто используют среднее по столбцу.
