## 8.3.1. Булева маска: выборка строк по условию

Условие над столбцом даёт **Series** булевых значений (по одной на строку). Передача этой Series в индексацию DataFrame **df[маска]** возвращает только те **строки**, для которых маска истинна. Результат — новый DataFrame (подтаблица).

```python
import pandas as pd
df = pd.DataFrame({"a": [1, 2, 3, 4, 5], "b": [10, 20, 30, 40, 50]})
df[df["a"] > 2]      # строки, где a больше 2
df[df["a"] <= 3]     # строки, где a не больше 3
```

**Комбинация условий:** использовать **&** (И), **|** (ИЛИ), **~** (НЕ); скобки обязательны из-за приоритета операторов:

```python
df[(df["a"] > 1) & (df["a"] < 5)]   # 1 < a < 5
df[(df["a"] == 2) | (df["a"] == 4)] # a равно 2 или 4
```

**Проверка на вхождение в множество:** **df['col'].isin([значения])** — булева Series; подходит для фильтрации по списку категорий или идентификаторов.

```python
df[df["a"].isin([2, 4])]   # строки, где a равно 2 или 4
```

Маска должна быть той же длины, что и DataFrame; индексы выравниваются по меткам строк, поэтому порядок строк в результате сохраняется и соответствует исходному индексу.

## 8.3.2. .loc: строки и столбцы по меткам

Для DataFrame **.loc** принимает один или два аргумента: **df.loc[строки, столбцы]**. Оба могут быть одной меткой, списком меток или срезом по меткам. Обращение **по метке индекса** строк и **по имени** столбцов.

**Все строки, один столбец:** **df.loc[:, 'col']** — столбец 'col' (Series). Двоеточие означает «все строки».

**Одна строка, все столбцы:** **df.loc['метка_строки']** или **df.loc['метка_строки', :]** — строка как Series (индекс — имена столбцов).

**Одна ячейка:** **df.loc['метка_строки', 'имя_столбца']**.

**Подтаблица:** **df.loc[список_строк, список_столбцов]** или срезы по меткам. Срез по меткам **включает** конечную метку (в отличие от среза по позиции в iloc).

```python
df = pd.DataFrame({"x": [1, 2, 3], "y": [4, 5, 6]}, index=["a", "b", "c"])
df.loc["a", "x"]     # 1  — одна ячейка
df.loc["a"]          # строка a (Series)
df.loc["a":"b", "x"] # строки a, b, столбец x (срез по меткам включает b)
df.loc[["a", "c"], ["x", "y"]]  # подтаблица 2×2
```

Присваивание: **df.loc[маска, 'col'] = значение** — изменить ячейки в столбце 'col' только для строк, где маска истинна.

## 8.3.3. .iloc: строки и столбцы по позициям

**.iloc** — доступ по **целочисленной позиции** (с нуля). **df.iloc[строки, столбцы]**; строки и столбцы — индекс, срез или список индексов.

**Одна строка:** **df.iloc[i]** или **df.iloc[i, :]** — i-я строка (по порядку в таблице).

**Один столбец:** **df.iloc[:, j]** — j-й столбец.

**Одна ячейка:** **df.iloc[i, j]**.

**Срез:** **df.iloc[0:2, 1:3]** — строки 0 и 1, столбцы 1 и 2 (граница stop не входит, как у срезов в Python).

```python
df.iloc[0]       # первая строка
df.iloc[:, 0]    # первый столбец
df.iloc[0:2, [0, 1]]  # первые две строки, первые два столбца
```

.iloc не использует метки индекса и имена столбцов — только порядковые номера. Удобно для скриптов, когда позиция фиксирована (например, «первый столбец — дата»).

## 8.3.4. Добавление и удаление столбцов

**Добавление столбца** — присваиванием: **df['new_col'] = значения**. Справа — список, массив NumPy или Series той же длины, что и df (или совместимый по индексу; при несовпадении индексов будут NaN). Новый столбец появляется в конце (порядок столбцов можно менять выбором списка столбцов при присваивании или через .reindex).

**Удаление столбцов** — метод **df.drop(columns=..., axis=1)**. Аргумент **columns** — имя столбца (строка) или список имён. По умолчанию **drop** возвращает **новый** DataFrame, не изменяя исходный. Чтобы изменить исходный объект, передают **inplace=True** (тогда метод возвращает None).

```python
df.drop(columns="col_to_remove")           # новый DataFrame без столбца
df.drop(columns=["a", "b"])               # без столбцов a и b
df.drop("col_name", axis=1)               # то же (axis=1 — по столбцам)
```

**Удаление строк** — **df.drop(index=метки)** или **df.drop(метки, axis=0)**; метки — одна или список. Аналогично **inplace=True** для изменения на месте.

---

## 8.3.5. Присваивание и копия

Присваивание в ячейку или столбец **изменяет** исходный DataFrame (если не создавать копию явно). Примеры: **df.loc[0, 'col'] = 10**; **df['col'] = df['col'] * 2**; **df.loc[маска, 'col'] = 0**.

Чтобы получить независимую копию таблицы для экспериментов, используют **df.copy()**. Изменение копии не затронет исходный DataFrame.

---

## Ключевое

- **Булева маска строк:** **df[df['col'] > 0]** — подтаблица из строк, где условие истинно. Комбинации: **(cond1) & (cond2)**, **|**, **~**. **df['col'].isin([...])** — проверка вхождения в список.
- **.loc[строки, столбцы]** — по меткам индекса и именам столбцов; срез по меткам включает конечную. **.iloc[строки, столбцы]** — по целочисленным позициям; срезы как в Python (stop не входит).
- **Добавление столбца:** **df['new_col'] = значения**. **Удаление:** **df.drop(columns=имя или список, inplace=...)**; строки — **df.drop(index=..., axis=0)**.
- Присваивание меняет исходный DataFrame; копия — **df.copy()**.
