# §5.1 Список (list)

В [§4.6](chapter-04-06.md) мы разобрали обработку исключений. Теперь переходим к **структурам данных**: списки, словари, кортежи и множества — основа для хранения и перебора данных в Python. **Список (list)** — упорядоченная изменяемая последовательность элементов произвольного типа. В этом разделе: создание списка, индексация и срезы, методы добавления и удаления элементов и то, чем список отличается от неизменяемых последовательностей (например, строк). В [§5.2](chapter-05-02.md) рассмотрим словарь (dict).

---

## 5.1.1. Создание списка

**Список** задаётся в квадратных скобках; элементы перечисляются через запятую. См. [Глоссарий](glossary.md).

```python
empty = []
numbers = [1, 2, 3]
mixed = [1, "hello", 3.14, True]
```

Тип — **list**. Функция **list()** создаёт список из другой последовательности (строка — список символов, range — список чисел, итератор):

```python
list("abc")        # ['a', 'b', 'c']
list(range(3))     # [0, 1, 2]
```

Списки могут быть вложенными (список списков — например, таблица или матрица):

```python
matrix = [[1, 2], [3, 4]]
```

Длина списка — **len(lst)**; проверка вхождения — **x in lst**, **x not in lst**.

---

## 5.1.2. Индексация и срезы

Как и у строк ([§2.4](chapter-02-04.md)), у списка доступны обращение по индексу и срезы. Индексация с нуля; отрицательные индексы — с конца.

```python
lst = [10, 20, 30, 40]
lst[0]    # 10
lst[-1]   # 40
lst[1:3]  # [20, 30]  — срез даёт новый список
lst[:2]   # [10, 20]
lst[::2]  # [10, 30]  — каждый второй
```

**Отличие от строк:** срез списка создаёт **новый список** (копию подпоследовательности); у строк срез создаёт новую строку. Кроме того, список можно **изменять по индексу** — см. ниже.

---

## 5.1.3. Список как изменяемый тип

Список — **изменяемый** (mutable) тип: содержимое можно менять без создания нового объекта. Присваивание по индексу меняет элемент на заданной позиции:

```python
lst = [1, 2, 3]
lst[1] = 20   # теперь [1, 20, 3]
```

**Срез в левой части присваивания** заменяет участок списка на элементы из правой части (итерабельного объекта):

```python
lst = [1, 2, 3, 4]
lst[1:3] = [20, 30]   # [1, 20, 30, 4]
lst[1:3] = [100]      # [1, 100, 4]  — два элемента заменены одним
```

Несколько имён могут ссылаться на **один и тот же список**; тогда изменение по одному имени видно по другому:

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4]  — a и b указывают на один список
```

Чтобы получить **копию** списка, используйте срез **lst[:]** или **list(lst)** или метод **lst.copy()** (см. ниже). Для вложенных списков копия получается «поверхностной» — вложенные объекты не копируются; для полной копии — модуль **copy** и **copy.deepcopy()**.

---

## 5.1.4. Добавление элементов: append, extend, insert

**lst.append(x)** — добавить один элемент **в конец** списка. Метод изменяет список и возвращает None.

```python
lst = [1, 2]
lst.append(3)   # [1, 2, 3]
```

**lst.extend(iterable)** — добавить в конец списка **все элементы** другой последовательности (списка, строки, range и т.д.):

```python
lst = [1, 2]
lst.extend([3, 4])   # [1, 2, 3, 4]
```

Разница с **append**: `lst.append([3, 4])` даст `[1, 2, [3, 4]]` — один элемент-список; **extend** «разворачивает» последовательность и добавляет её элементы.

**lst.insert(i, x)** — вставить элемент **x** на позицию **i**; существующие элементы с индексом >= i сдвигаются вправо.

```python
lst = [1, 2, 3]
lst.insert(1, 99)   # [1, 99, 2, 3]
```

Конкатенация **+** создаёт **новый** список, не изменяя исходные: `[1, 2] + [3, 4]` → `[1, 2, 3, 4]`. Оператор **+=** для списка ведёт себя как extend (добавляет элементы в конец текущего списка).

---

## 5.1.5. Удаление элементов: remove, pop

**lst.remove(x)** — удалить **первое** вхождение значения **x**. Если элемента нет — **ValueError**. Метод ничего не возвращает (вернее, возвращает None).

```python
lst = [1, 2, 2, 3]
lst.remove(2)   # [1, 2, 3]  — удалено первое вхождение 2
```

**lst.pop(i)** — удалить и **вернуть** элемент с индексом **i**. Если индекс не указан, удаляется и возвращается **последний** элемент (pop()).

```python
lst = [10, 20, 30]
x = lst.pop(1)   # x = 20, lst = [10, 30]
y = lst.pop()    # y = 30, lst = [10]
```

**del lst[i]** — удалить элемент по индексу (или срез **del lst[i:j]** — удалить диапазон). Значение не возвращается.

Для удаления по условию (например, все отрицательные) обычно формируют новый список (цикл или list comprehension, [§5.5](chapter-05-05.md)) или перебирают копию и вызывают remove/pop, чтобы не сбивать индексы при обходе.

---

## 5.1.6. Другие полезные методы и операции

**lst.index(x)** — индекс первого вхождения **x**; при отсутствии — ValueError. Опционально: **lst.index(x, start, end)** — поиск в срезе.

**lst.count(x)** — количество вхождений **x** в списке.

**lst.sort()** — сортировка **на месте** (список изменяется); возвращает None. По умолчанию по возрастанию; **lst.sort(reverse=True)** — по убыванию. Для получения **нового** отсортированного списка без изменения исходного — встроенная функция **sorted(lst)**.

**lst.reverse()** — развернуть список на месте. Для нового списка в обратном порядке — срез **lst[::-1]**.

**lst.copy()** — поверхностная копия списка (новый список с теми же элементами; вложенные объекты не копируются).

---

## 5.1.7. Типичные ошибки

- **IndexError** при обращении к lst[i], если индекс вне диапазона. Проверять **i < len(lst)** или обрабатывать исключение.
- **Изменение списка во время перебора** (for x in lst с удалением/добавлением внутри цикла) — риск пропуска элементов или бесконечного цикла; перебирать копию или строить новый список.
- **Путать append и extend:** append добавляет один элемент (в том числе вложенный список целиком); extend добавляет элементы последовательности по одному.

---

## Ключевое

- **Список** — упорядоченная изменяемая последовательность: **[]**, **list()**; индексация и срезы как у строк (с нуля, отрицательные индексы).
- **Изменяемость:** присваивание по индексу **lst[i] = x** и срезу слева меняют список; несколько переменных могут ссылаться на один список — копия: **lst[:]**, **list(lst)**, **lst.copy()**.
- **Добавление:** **append(x)** — один элемент в конец; **extend(iterable)** — все элементы последовательности в конец; **insert(i, x)** — вставка на позицию i.
- **Удаление:** **remove(x)** — первое вхождение x; **pop(i)** — удалить и вернуть элемент по индексу (pop() — последний); **del lst[i]** — удаление по индексу.
- **index**, **count**, **sort**, **reverse**, **copy**; **sorted(lst)** — новый отсортированный список.
