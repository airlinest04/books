# §3.2 Цикл for

В [§3.1](chapter-03-01.md) мы разобрали условия if/elif/else. Теперь — **цикл for**: он перебирает элементы последовательности (строки, списка, результата range() и других итерируемых объектов) и выполняет блок кода для каждого элемента. В этом разделе — синтаксис for, перебор строки и списка, а также функция **range()** для последовательностей целых чисел. В [§3.3](chapter-03-03.md) рассмотрим цикл while и операторы break/continue.

---

## 3.2.1. Синтаксис for: перебор последовательности

Цикл for в Python записывается так:

```python
for переменная in последовательность:
    блок_тела_цикла
```

**Последовательность** (итерируемый объект) — объект, по элементам которого можно пройти один за другим: строка (по символам), список (по элементам), результат **range()** (по числам) и т.д. На каждой итерации **переменная** принимает значение очередного элемента; блок под строкой `for` выполняется для каждого значения.

Пример со строкой — перебор по символам:

```python
for char in "hello":
    print(char)
# выведет: h, e, l, l, o (каждый с новой строки)
```

Пример с последовательностью чисел (здесь — список, списки подробно в [§5.1](chapter-05-01.md)):

```python
for x in [10, 20, 30]:
    print(x * 2)
# выведет: 20, 40, 60
```

Переменная цикла (здесь `char`, `x`) существует внутри цикла и после него; после выхода из цикла в ней остаётся последнее значение. Имя переменной выбирают осмысленно: например, `item`, `value`, `row` при переборе данных.

## 3.2.2. Перебор строки и списка

**Строка** — последовательность символов; при переборе переменная принимает каждый символ:

```python
word = "data"
for c in word:
    print(c)   # d, a, t, a
```

Так можно проверять символы, считать вхождения, собирать новую строку по условию.

**Список** — последовательность элементов любого типа. При переборе переменная принимает элементы списка по порядку (не индексы):

```python
values = [1, 2, 3]
for v in values:
    print(v)   # 1, 2, 3
```

Часто список получают из метода строки (например, из **.split()** — [§2.4](chapter-02-04.md)) и обрабатывают элементы в цикле:

```python
line = "a,b,c"
for part in line.split(","):
    print(part.strip())   # a, b, c (если были пробелы — убираем)
```

Когда нужен не только элемент, но и его **индекс** (позиция), используют функцию **enumerate()**: она возвращает пары (индекс, элемент):

```python
for i, char in enumerate("ab"):
    print(i, char)   # 0 a, 1 b
```

Первый аргумент enumerate() — индекс (с нуля), второй — значение. Это удобно при записи в файл с нумерацией строк или при формировании отчётов.

## 3.2.3. Функция range()

**range()** — встроенная функция, задающая последовательность целых чисел без создания в памяти полного списка. Часто используется в for, когда нужно выполнить блок заданное число раз или перебрать индексы от 0 до n − 1.

**range(stop)** — числа от 0 до stop − 1 (stop не входит):

```python
for i in range(5):
    print(i)   # 0, 1, 2, 3, 4
```

**range(start, stop)** — от start до stop − 1:

```python
for i in range(2, 5):
    print(i)   # 2, 3, 4
```

**range(start, stop, step)** — шаг step (может быть отрицательным):

```python
for i in range(0, 10, 2):
    print(i)   # 0, 2, 4, 6, 8
for i in range(5, 0, -1):
    print(i)   # 5, 4, 3, 2, 1
```

Типичные случаи использования:

- Выполнить что-то n раз: `for _ in range(n): ...` (имя `_` часто используют для переменной, значение которой не нужно).
- Перебрать индексы списка или строки: `for i in range(len(s)):` — тогда элемент получают как `s[i]`. Если достаточно самого элемента, проще писать `for x in s:`; если нужен индекс — `for i, x in enumerate(s):`.

Преобразование в список: **list(range(5))** даёт `[0, 1, 2, 3, 4]` — бывает нужно, когда требуется именно список чисел.

## 3.2.4. Вложенные циклы и перебор пар

Внутри цикла for может быть другой цикл for — **вложенный**. Тогда для каждого значения внешней переменной полностью выполняется внутренний цикл:

```python
for i in range(2):
    for j in range(2):
        print(i, j)
# (0,0), (0,1), (1,0), (1,1)
```

При работе с таблицами или парами данных вложенные циклы иногда используют для перебора строк и столбцов; в Pandas чаще опираются на встроенные методы и векторизацию ([Глава 8](chapter-08-01.md)), но для небольших списков и разбора файлов цикл for по элементам или по range остаётся основным инструментом.

---

## 3.2.5. Типичные ошибки

- **Изменить список во время перебора по нему:** добавление или удаление элементов в цикле `for x in my_list:` может привести к неожиданному поведению или пропуску элементов. Если нужно изменить список, перебирают копию (`for x in my_list.copy():`) или строят новый список.
- **Путать «элемент» и «индекс»:** в `for x in sequence` в x попадает элемент, а не индекс. Для индексов используют `range(len(sequence))` или `enumerate(sequence)`.
- **Ожидать, что range включает правую границу:** `range(5)` даёт 0, 1, 2, 3, 4; число 5 не входит. Чтобы включить 5, пишут `range(6)` или `range(0, 6)`.

---

## Ключевое

- **for переменная in последовательность:** перебор элементов последовательности (строка — по символам, список — по элементам); блок выполняется для каждого значения.
- **range(stop)** — числа 0 … stop−1; **range(start, stop)** — от start до stop−1; **range(start, stop, step)** — с шагом step. Используют для «n раз» или для перебора индексов.
- Перебор с индексом: **enumerate(последовательность)** даёт пары (индекс, элемент). Индексы списка/строки: `for i in range(len(s))` или `for i, x in enumerate(s)`.
- Вложенные циклы допустимы; при изменении списка в цикле перебирают копию или строят новый список. range не включает правую границу.
