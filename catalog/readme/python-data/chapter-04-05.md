## 4.5.1. Модуль os

Модуль **os** даёт доступ к функциям операционной системы: работа с путями, текущий каталог, список файлов, переменные окружения.

**Пути:** подмодуль **os.path** содержит функции для склейки и разбора путей (корректно для текущей ОС):

```python
import os
path = os.path.join("data", "files", "report.csv")   # data/files/report.csv или data\files\report.csv
```

**os.path.exists(path)** — существует ли файл или каталог (True/False). **os.path.isfile(path)** и **os.path.isdir(path)** — проверка «это файл» или «это каталог». **os.path.abspath(path)** — полный (абсолютный) путь.

**Текущий каталог:** **os.getcwd()** возвращает текущую рабочую директорию. **os.chdir(path)** меняет её (использовать осторожно).

**Содержимое каталога:** **os.listdir(path)** возвращает список имён файлов и подкаталогов в указанном каталоге (по умолчанию — текущий). Для рекурсивного обхода и фильтрации удобнее модуль **pathlib** (современный API) или **os.walk()** — при необходимости смотрите документацию.

**Переменные окружения:** **os.environ** — объект, похожий на словарь; **os.environ.get("VAR")** возвращает значение переменной окружения или None, если переменной нет. Удобно для конфигурации (пути, ключи API) без захардкоженных значений в коде.

## 4.5.2. Модуль sys

Модуль **sys** — доступ к параметрам и настройкам интерпретатора.

**sys.argv** — список аргументов командной строки при запуске скрипта. **sys.argv[0]** — имя запущенного скрипта; **sys.argv[1]**, **sys.argv[2]** и т.д. — аргументы, переданные после имени. Пример: при запуске `python script.py data.csv` получится `sys.argv[0] == "script.py"`, `sys.argv[1] == "data.csv"`. Для разбора опций и флагов часто используют модуль **argparse** (стандартная библиотека).

**sys.path** — список каталогов, в которых интерпретатор ищет модули при import ([§4.4](chapter-04-04.md)). При необходимости в него можно добавить путь: **sys.path.append("/каталог")**.

**sys.exit(code)** — завершение программы с кодом выхода (0 — успех, ненулевой — ошибка). Удобно вызывать после обработки ошибки или после вывода справки.

## 4.5.3. Модуль datetime

Модуль **datetime** — работа с датами и временем. Основные типы: **date** (только дата), **datetime** (дата и время), **timedelta** (разница между моментами времени).

**Текущая дата и время:**

```python
from datetime import datetime, date
now = datetime.now()   # объект datetime с текущими датой и временем
today = date.today()   # только дата
```

**Создание даты/времени явно:** **date(year, month, day)**, **datetime(year, month, day, hour, minute, second, ...)**.

**Разность дат** даёт **timedelta**; к datetime/date можно прибавлять и вычитать timedelta:

```python
from datetime import datetime, timedelta
d = datetime(2024, 1, 15)
d + timedelta(days=7)   # через неделю
```

**Форматирование и разбор строк:** метод **.strftime(format)** формирует строку по формату (например, `"%Y-%m-%d"` — год-месяц-день). Функция **datetime.strptime(string, format)** разбирает строку в объект datetime. Форматы описаны в документации (например, %Y — год, %m — месяц, %d — день).

В данных даты часто приходят строками (из CSV, API); после разбора через strptime или **pd.to_datetime()** в Pandas ([§9.3](chapter-09-03.md)) с ними удобно сравнивать и считать разницы.

## 4.5.4. Модуль json

Модуль **json** — преобразование между объектами Python и текстом в формате **JSON** (JavaScript Object Notation). JSON широко используется в API и конфигурации; структуры — словари, списки, строки, числа, bool, None.

**json.loads(string)** — разбор JSON-строки в объект Python (словарь, список и т.д.):

```python
import json
s = '{"name": "Alice", "age": 30}'
data = json.loads(s)   # {'name': 'Alice', 'age': 30}
```

**json.dumps(obj)** — преобразование объекта Python в JSON-строку:

```python
json.dumps({"a": 1, "b": [2, 3]})   # '{"a": 1, "b": [2, 3]}'
```

Для работы с **файлами** используют **json.load(file_object)** и **json.dump(obj, file_object)** — чтение и запись напрямую в файл. Подробнее в [§6.4](chapter-06-04.md). Здесь достаточно знать, что json позволяет разбирать ответы API и сохранять структурированные данные в текстовом виде.

## Ключевое

- **os** — пути (os.path.join, exists, isfile, isdir), текущий каталог (getcwd), список файлов (listdir), переменные окружения (os.environ.get).
- **sys** — аргументы командной строки (sys.argv), путь поиска модулей (sys.path), завершение программы (sys.exit).
- **datetime** — date, datetime, timedelta; datetime.now(), date.today(); strftime и strptime для форматов строк; разность дат и прибавление timedelta.
- **json** — json.loads(s) и json.dumps(obj) для строк; json.load(file) и json.dump(obj, file) для файлов ([§6.4](chapter-06-04.md)).

В [§4.6](chapter-04-06.md) мы разберём обработку исключений: try/except, типы исключений и зачем это нужно в пайплайнах данных и при работе с файлами и API.
