# §4.2 Параметры

В [§4.1](chapter-04-01.md) мы разобрали определение методов через def. Теперь рассмотрим **параметры**: значения по умолчанию, именованные аргументы при вызове и **повторяющиеся параметры** (varargs) для передачи произвольного числа аргументов одного типа. В [§4.3](chapter-04-03.md) перейдём к анонимным функциям.

---

## 4.2.1. Параметры по умолчанию

Параметру можно задать **значение по умолчанию**. Если при вызове аргумент не передан, подставится это значение:

```scala
def greet(name: String, greeting: String = "Hello"): String =
  s"$greeting, $name!"

greet("Alice")           // "Hello, Alice!"
greet("Bob", "Hi")       // "Hi, Bob!"
```

Синтаксис: `параметр: Тип = значение`. Параметры с умолчанием обычно размещают после обязательных. При вызове можно опускать аргументы справа налево — недостающие берутся из умолчаний:

```scala
def connect(host: String, port: Int = 5432, ssl: Boolean = false): String =
  s"$host:$port (ssl=$ssl)"

connect("localhost")                    // localhost:5432 (ssl=false)
connect("localhost", 8080)              // localhost:8080 (ssl=false)
connect("localhost", 8080, true)        // localhost:8080 (ssl=true)
```

---

## 4.2.2. Именованные аргументы

При вызове можно передавать аргументы **по имени параметра**:

```scala
connect(host = "db.example.com", ssl = true)
// port берётся по умолчанию — 5432
```

Порядок именованных аргументов может быть любым; это удобно, когда нужно изменить только часть параметров с умолчанием:

```scala
connect(port = 3306, host = "mysql.example.com")
```

**Правило:** позиционные аргументы должны идти **перед** именованными. После первого именованного аргумента все следующие должны быть именованными:

```scala
connect("localhost", port = 8080)   // верно
connect(host = "localhost", 8080)   // ошибка: позиционный после именованного
```

Именованные аргументы улучшают читаемость, особенно при большом числе параметров и при совпадении типов (меньше риск перепутать порядок).

---

## 4.2.3. Повторяющиеся параметры (varargs)

**Повторяющиеся параметры** позволяют передать произвольное число аргументов одного типа. Синтаксис: после типа ставится `*`:

```scala
def sum(numbers: Int*): Int = numbers.sum
sum(1, 2, 3)        // 6
sum(1)              // 1
sum()               // 0
```

Внутри метода параметр `numbers` имеет тип `Seq[Int]` — последовательность переданных значений. У `Seq` есть методы `sum`, `foreach`, `toList` и др.

Повторяющийся параметр должен быть **последним** в списке. До него могут идти обычные параметры:

```scala
def join(sep: String, parts: String*): String = parts.mkString(sep)
join(", ", "a", "b", "c")   // "a, b, c"
join("; ", "x", "y")        // "x; y"
```

---

## 4.2.4. Передача коллекции в повторяющийся параметр

Если аргументы уже собраны в коллекцию (List, Array, Seq), их нужно «развернуть» в отдельные аргументы. Для этого используют **аннотацию типа** `: _*`:

```scala
val list = List(1, 2, 3)
sum(list: _*)   // то же, что sum(1, 2, 3)
```

`seq: _*` сообщает компилятору: трактовать `seq` как последовательность аргументов для повторяющегося параметра, а не как один аргумент типа `Seq`.

```scala
val words = Array("hello", "world", "scala")
join(" ", words: _*)   // "hello world scala"
```

---

## 4.2.5. Позиционные и именованные аргументы

**Позиционные** аргументы передаются по порядку: первый аргумент — первому параметру, второй — второму и т.д. Количество и порядок должны соответствовать объявлению (с учётом умолчаний).

**Именованные** аргументы передаются как `имя = значение`. Порядок не важен; один параметр не должен получать аргумент дважды (и позиционно, и по имени).

Можно комбинировать: сначала позиционные, затем именованные:

```scala
def f(a: Int, b: Int, c: Int = 0): Int = a + b + c
f(1, 2)              // 3 (c по умолчанию)
f(1, 2, 3)           // 6
f(1, b = 2)          // 3
f(a = 1, b = 2, c = 3)  // 6
```

---

## 4.2.6. Типичные ошибки

- **Позиционный аргумент после именованного** — вызов `f(b = 2, 1)` неверен; позиционные должны идти первыми.
- **Повторяющийся параметр не последний** — `def f(x: Int*, y: Int)` не компилируется; varargs только в конце.
- **Забыть `: _*` при передаче коллекции** — `sum(list)` передаёт один аргумент типа `List[Int]`, а `sum` ожидает `Int*`; нужно `sum(list: _*)`.
- **Изменяемые объекты как значение по умолчанию** — в Scala, как и в других языках, значение по умолчанию вычисляется один раз; не используйте `def f(x: List[Int] = List(1, 2))` и подобное, если список будет изменяться — используйте `Nil` или создавайте список внутри тела.

---

## Ключевое

- **Параметры по умолчанию:** `параметр: Тип = значение`; при вызове аргумент можно опустить.
- **Именованные аргументы:** `f(name = value)`; порядок не важен; позиционные должны предшествовать именованным.
- **Повторяющиеся параметры (varargs):** `параметр: Тип*` — последний в списке; внутри имеет тип `Seq[T]`.
- **Передача коллекции в varargs:** `coll: _*` — развернуть коллекцию в отдельные аргументы.
- Не использовать изменяемые объекты как значения по умолчанию.
