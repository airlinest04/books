# §4.5 Функции высшего порядка

В [§4.4](chapter-04-04.md) мы разобрали различие между методами и функциями. **Функция высшего порядка** (higher-order function) — это функция, которая принимает другую функцию как аргумент или возвращает функцию. В Scala методы коллекций `map`, `filter`, `foldLeft`, `reduce` и другие — типичные примеры; они составляют основу работы с данными. В [§5.1](chapter-05-01.md) мы начнём главу о коллекциях — List, Map, Set.

---

## 4.5.1. Что такое функция высшего порядка

Функция высшего порядка — метод или функция, у которой один из параметров (или возвращаемое значение) имеет функциональный тип, например `A => B` или `(A, B) => C`. Это позволяет абстрагировать общую схему обработки (например, «применить преобразование к каждому элементу») и передавать конкретную логику как аргумент.

Коллекции в Scala предоставляют множество таких методов; ниже разобраны основные.

---

## 4.5.2. map — преобразование каждого элемента

**map** принимает функцию `A => B` и возвращает новую коллекцию, в которой каждый элемент исходной коллекции заменён результатом применения функции:

```scala
val list = List(1, 2, 3)
list.map(x => x * 2)   // List(2, 4, 6)
list.map(_ * 2)        // то же
```

Тип результата — коллекция того же вида (List → List), но тип элементов может измениться (Int → String и т.д.):

```scala
List(1, 2, 3).map(_.toString)   // List("1", "2", "3")
List("a", "bb", "ccc").map(_.length)   // List(1, 2, 3)
```

map не изменяет исходную коллекцию; создаётся новая. В контексте данных map — базовый способ преобразования записей, полей или строк.

---

## 4.5.3. filter — отбор по условию

**filter** принимает предикат — функцию `A => Boolean`. Возвращает коллекцию только тех элементов, для которых предикат возвращает true:

```scala
val list = List(1, 2, 3, 4, 5)
list.filter(x => x % 2 == 0)   // List(2, 4)
list.filter(_ % 2 == 0)        // то же
list.filter(_ > 2)             // List(3, 4, 5)
```

Исходная коллекция не меняется. **filterNot** — обратная операция: оставляет элементы, для которых предикат false:

```scala
list.filterNot(_ % 2 == 0)   // List(1, 3, 5)
```

filter используется для отсеивания записей по условию (например, только активные пользователи, только непустые строки).

---

## 4.5.4. foldLeft — свёртка с начальным значением

**foldLeft** «сворачивает» коллекцию в одно значение, последовательно применяя функцию к аккумулятору и очередному элементу. Сигнатура: `foldLeft(начальное_значение)(функция)`, где функция имеет вид `(аккумулятор, элемент) => новый_аккумулятор`:

```scala
val list = List(1, 2, 3, 4, 5)
list.foldLeft(0)((acc, x) => acc + x)   // 15
list.foldLeft(0)(_ + _)                 // то же
```

Порядок обхода — слева направо. Начальное значение задаётся явно; тип результата может отличаться от типа элементов (например, сумма Int даёт Int, конкатенация строк — String):

```scala
List("a", "b", "c").foldLeft("")(_ + _)   // "abc"
List(1, 2, 3).foldLeft(1)(_ * _)          // 6 (произведение)
```

foldLeft — универсальный способ накопления результата (сумма, произведение, построение строки, счётчики и т.д.). См. [Глоссарий](glossary.md).

---

## 4.5.5. reduce — свёртка без явного начального значения

**reduce** похож на foldLeft, но в качестве начального аккумулятора берётся **первый элемент** коллекции. Функция применяется к парам: сначала к (elem1, elem2), затем к (результат, elem3) и т.д.:

```scala
List(1, 2, 3, 4, 5).reduce(_ + _)   // 15
List(1, 2, 3).reduce(_ * _)         // 6
```

Для пустой коллекции `reduce` выбрасывает исключение. Если коллекция может быть пустой, используйте `foldLeft` с начальным значением или `reduceOption`, который возвращает `Option`:

```scala
List.empty[Int].reduce(_ + _)       // UnsupportedOperationException
List(1, 2, 3).reduceOption(_ + _)   // Some(6)
List.empty[Int].reduceOption(_ + _) // None
```

---

## 4.5.6. foreach — побочные эффекты

**foreach** принимает функцию `A => Unit` и применяет её к каждому элементу ради побочных эффектов (вывод, запись и т.д.). Возвращает `Unit`:

```scala
List(1, 2, 3).foreach(println)
List(1, 2, 3).foreach(x => println(s"Value: $x"))
```

Для получения новой коллекции используют map; для эффектов — foreach.

---

## 4.5.7. Цепочки вызовов

Методы можно объединять в цепочки: результат одного вызова — коллекция, к которой применяется следующий метод:

```scala
List(1, 2, 3, 4, 5)
  .filter(_ % 2 == 0)
  .map(_ * 2)
  .foldLeft(0)(_ + _)
// 2*2 + 4*2 = 4 + 8 = 12
```

Так строятся пайплайны преобразований: фильтрация, преобразование, агрегация. Подробнее о коллекциях и дополнительных методах (flatMap, groupBy и др.) — в [Главе 5](chapter-05-01.md).

---

## 4.5.8. flatMap (кратко)

**flatMap** комбинирует map и «разворачивание» вложенных структур: применяет функцию `A => Collection[B]` и объединяет результаты в одну плоскую коллекцию:

```scala
List(List(1, 2), List(3, 4)).flatMap(x => x)   // List(1, 2, 3, 4)
List("hello", "world").flatMap(_.toList)       // List(h,e,l,l,o,w,o,r,l,d)
```

flatMap важен для работы с Option, Future и вложенными структурами; подробнее в [§5.5](chapter-05-05.md).

---

## Ключевое

- **Функция высшего порядка** — принимает или возвращает функцию. Методы map, filter, foldLeft, reduce — примеры.
- **map** — преобразование каждого элемента; тип результата может измениться. **filter** — отбор по предикату (A => Boolean).
- **foldLeft(init)(fn)** — свёртка в одно значение с начальным значением; fn: (acc, elem) => acc. **reduce** — то же без начального значения (начинает с первого элемента); для пустой коллекции — исключение.
- **foreach** — применение функции ради побочных эффектов; возвращает Unit.
- Методы можно объединять в цепочки: filter → map → foldLeft.
