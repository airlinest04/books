# §2.3 Операторы

В [§2.2](chapter-02-02.md) мы рассмотрели основные типы и приведение. Теперь — **операторы**: арифметические (включая целочисленное деление и остаток), операторы сравнения и логические. Важная особенность Scala — операторы реализованы как **методы**; выражение `a + b` эквивалентно вызову `a.+(b)`. В конце раздела — составное присваивание (`+=`, `-=` и т.д.). В [§2.4](chapter-02-04.md) перейдём к строкам: интерполяции, методам и работе с текстом.

---

## 2.3.1. Операторы как методы

В Scala **операторы — это методы**. Выражение `a + b` — синтаксический сахар для вызова метода `+` у объекта `a` с аргументом `b`:

```scala
a + b    // эквивалентно
a.+(b)
```

То же для других бинарных операторов: `a - b` → `a.-(b)`, `a * b` → `a.*(b)` и т.д. Унарные операторы (например, `-x`) записываются как `x.unary_-`. Благодаря этому можно определять свои операторы (методы с «операторными» именами) и вызывать их в инфиксной нотации. Это придаёт коду единообразие: арифметика и вызовы методов подчиняются одним правилам.

---

## 2.3.2. Арифметические операторы

Для числовых типов определены стандартные арифметические операции:

| Оператор | Операция       | Пример       |
|----------|----------------|--------------|
| `+`      | сложение       | `3 + 5` → 8  |
| `-`      | вычитание      | `10 - 4` → 6 |
| `*`      | умножение      | `6 * 7` → 42 |
| `/`      | деление        | см. ниже     |
| `%`      | остаток        | `10 % 4` → 2 |

**Деление `/`**

Поведение зависит от типов операндов:

- **Int / Int** — целочисленное деление (дробная часть отбрасывается, округление к нулю):

```scala
10 / 4    // 2
10 / 3    // 3
-10 / 4   // -2
```

- **Double / Double** или **Int / Double** (и т.п.) — обычное деление с дробным результатом:

```scala
10.0 / 4    // 2.5
10 / 4.0    // 2.5
```

Чтобы получить дробный результат при делении двух Int, приведите один из операндов к Double: `10.toDouble / 4` или `10 / 4.0`.

**Остаток от деления `%`**

```scala
10 % 4    // 2
10 % 2    // 0
```

**Возведение в степень**

Встроенного оператора `**` в Scala нет. Используйте `scala.math.pow`:

```scala
import scala.math.pow
pow(2, 10)    // 1024.0 (Double)
pow(4, 0.5)   // 2.0
```

`pow` принимает `(Double, Double)` и возвращает Double. Для целых степеней можно писать `pow(2, 10).toInt`.

## 2.3.3. Операторы сравнения

Операторы сравнения возвращают `Boolean`:

| Оператор | Значение         | Пример      |
|----------|------------------|-------------|
| `==`     | равно            | `5 == 5` → true |
| `!=`     | не равно         | `5 != 3` → true |
| `<`      | меньше           | `3 < 5` → true |
| `>`      | больше           | `5 > 3` → true |
| `<=`     | меньше или равно | `3 <= 3` → true |
| `>=`     | больше или равно | `5 >= 5` → true |

Примеры:

```scala
10 == 10    // true
10 != 5     // true
3 < 5       // true
5 >= 5      // true
```

**Сравнение по значению**

В Scala `==` сравнивает по **значению** (вызывает `equals`), а не по ссылке. Для ссылочных типов (объекты, строки) это означает семантическое равенство: `"hello" == "hello"` даёт `true`, даже если это разные объекты в памяти. Сравнение по ссылке (аналог Java `==`) выполняется методом `eq`: `a eq b`.

**Типы**

Сравнивать можно значения совместимых типов (числа с числами, строки со строками и т.д.). Смешивание несовместимых типов (например, `3 < "5"`) не скомпилируется.

## 2.3.4. Логические операторы

Логические операторы работают с `Boolean`:

| Оператор | Значение     | Пример                |
|----------|--------------|------------------------|
| `&&`     | логическое И | `true && false` → false |
| `\|\|`   | логическое ИЛИ | `true \|\| false` → true |
| `!`      | отрицание    | `!true` → false       |

```scala
true && true    // true
true && false   // false
true || false   // true
false || false  // false
!true           // false
!false          // true
```

**Короткое замыкание**

`&&` и `||` используют **короткое замыкание** (short-circuit evaluation): правый операнд не вычисляется, если результат уже определён левым. Для `&&` — если левый ложный; для `||` — если левый истинный. Это важно, когда справа стоит вызов с побочными эффектами или потенциальным исключением.

**Цепочки сравнений**

В Scala нет встроенных цепочек вида `0 < x < 10` как в Python. Пишут явно:

```scala
x > 0 && x < 10
// или
0 < x && x < 10
```

## 2.3.5. Составное присваивание

Операторы вида `op=` объединяют операцию и присваивание. Они работают с **var** и изменяемыми объектами; для val повторное присваивание невозможно.

| Оператор | Эквивалент    | Пример       |
|----------|---------------|--------------|
| `+=`     | `x = x + y`   | `count += 1` |
| `-=`     | `x = x - y`   | `total -= 5` |
| `*=`     | `x = x * y`   | `n *= 2`     |
| `/=`     | `x = x / y`   | `x /= 10`    |
| `%=`     | `x = x % y`   | `x %= 2`     |

Пример:

```scala
var count = 0
count += 1   // count = 1
count += 1   // count = 2
```

Для строк `+=` не определён как изменение строки на месте (String неизменяем). При `var s = "a"; s += "b"` на самом деле выполняется `s = s + "b"` — создаётся новая строка и присваивается переменной. Подробнее о строках — в [§2.4](chapter-02-04.md).

---

## 2.3.6. Приоритет операторов

Порядок выполнения операторов (от высшего приоритета к низшему):

1. Скобки `()`
2. Унарные `+x`, `-x`, `!x`
3. Умножение, деление, остаток: `*`, `/`, `%`
4. Сложение, вычитание: `+`, `-`
5. Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`
6. Логическое И: `&&`
7. Логическое ИЛИ: `||`

При сомнении лучше расставить скобки явно — это не влияет на производительность и улучшает читаемость.

## 2.3.7. Специальные операции для диапазонов и строк

**Диапазон (Range)**

Выражение `1 to 10` создаёт диапазон от 1 до 10 включительно; `1 until 10` — от 1 до 9. Методы `to` и `until` используются в циклах for ([§3.3](chapter-03-03.md)):

```scala
1 to 5       // Range(1, 2, 3, 4, 5)
1 until 5    // Range(1, 2, 3, 4)
```

**Конкатенация строк**

Оператор `+` для строк — конкатенация:

```scala
"Hello" + ", " + "World"   // "Hello, World"
```

## 2.3.8. Типичные ошибки

- **Целочисленное деление вместо дробного** — `10 / 4` даёт 2; для 2.5 используйте `10.0 / 4` или `10.toDouble / 4`.
- **Путаница `=` и `==`** — присваивание `=` и сравнение `==` разные; в условии нужен `==`.
- **Составное присваивание к val** — `val x = 0; x += 1` не скомпилируется; `+=` требует var.
- **`**` не существует** — для степени используйте `scala.math.pow`.

---

## Ключевое

- В Scala операторы — методы: `a + b` эквивалентно `a.+(b)`.
- **Арифметика:** `+`, `-`, `*`, `/` (Int/Int — целочисленное деление), `%` (остаток); степень — `scala.math.pow(x, y)`.
- **Сравнения:** `==`, `!=`, `<`, `>`, `<=`, `>=` возвращают Boolean; `==` сравнивает по значению.
- **Логические:** `&&`, `||`, `!`; короткое замыкание для `&&` и `||`.
- **Составное присваивание** `+=`, `-=`, `*=`, `/=`, `%=` — только с var.
- Приоритет при необходимости задают скобками.

В [§2.4](chapter-02-04.md) мы разберём строки: интерполяцию `s"$name"`, многострочные литералы и основные методы (.length, .split, .toInt).
