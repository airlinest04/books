# §3.3 Цикл for

В [§3.2](chapter-03-02.md) мы разобрали сопоставление с образцом (match). Теперь — **цикл for** в Scala: перебор диапазонов и коллекций, фильтрация элементов и **for-comprehension** с `yield` для создания новой коллекции. В Scala for — выражение, которое либо выполняет побочные эффекты (без yield), либо возвращает коллекцию (с yield). В [§3.4](chapter-03-04.md) рассмотрим циклы while и do-while.

---

## 3.3.1. Базовый синтаксис: генератор

Цикл for в Scala строится из **генераторов** (enumerators). Генератор имеет вид `переменная <- выражение`, где выражение — коллекция или диапазон:

```scala
for (i <- 1 to 5) {
  println(i)
}
// выведет: 1, 2, 3, 4, 5
```

`1 to 5` — диапазон от 1 до 5 **включительно** (Range). Метод `to` создаёт диапазон с правой границей. Метод `until` создаёт диапазон **без** правой границы:

```scala
for (i <- 1 until 5) {
  println(i)
}
// выведет: 1, 2, 3, 4
```

Типичные диапазоны: `1 to 10`, `0 until 5`, `1 to 10 by 2` (с шагом 2).

---

## 3.3.2. Перебор коллекций

Генератор `x <- коллекция` перебирает элементы коллекции по одному:

```scala
val list = List(10, 20, 30)
for (x <- list) {
  println(x * 2)
}
// выведет: 20, 40, 60
```

То же для строки (перебор символов), массива, Set и других коллекций, поддерживающих обход. Подробнее о List и других коллекциях — в [Главе 5](chapter-05-01.md).

```scala
for (c <- "hello") println(c)
// h, e, l, l, o
```

---

## 3.3.3. Фильтр (guard)

В for можно добавить **фильтр** — условие `if`, отсеивающее элементы:

```scala
for (i <- 1 to 10 if i % 2 == 0) {
  println(i)
}
// выведет: 2, 4, 6, 8, 10
```

Синтаксис: после генератора (или нескольких генераторов) пишут `if условие`. Обрабатываются только те элементы, для которых условие истинно. Несколько фильтров объединяют через пробел или точку с запятой:

```scala
for (i <- 1 to 20 if i % 2 == 0; if i % 3 == 0) {
  println(i)
}
// выведет: 6, 12, 18
```

---

## 3.3.4. Несколько генераторов

Несколько генераторов в одном for дают **вложенные циклы**: для каждого значения первого генератора перебираются все значения второго:

```scala
for (i <- 1 to 2; j <- 1 to 3) {
  println(s"$i, $j")
}
// (1,1), (1,2), (1,3), (2,1), (2,2), (2,3)
```

Генераторы разделяют точкой с запятой или переносом строки. Порядок важен: первый генератор — внешний цикл, последний — внутренний.

---

## 3.3.5. for-comprehension: yield

Ключевое слово **yield** превращает for в **выражение**, возвращающее коллекцию. Результат — новая коллекция того же типа, что и первый генератор (List → List, Vector → Vector и т.д.):

```scala
val doubled = for (i <- 1 to 5) yield i * 2
// doubled: IndexedSeq[Int] = Vector(2, 4, 6, 8, 10)
```

Без yield for выполняет тело ради побочных эффектов и возвращает `Unit`. С yield тело вычисляется для каждого элемента (с учётом фильтров), результаты собираются в коллекцию.

**for-comprehension** — for с yield. Типичные примеры:

```scala
val evens = for (i <- 1 to 10 if i % 2 == 0) yield i
// evens: IndexedSeq[Int] = Vector(2, 4, 6, 8, 10)

val words = List("hello", "world", "scala")
val upper = for (w <- words) yield w.toUpperCase
// upper: List[String] = List("HELLO", "WORLD", "SCALA")
```

---

## 3.3.6. Связывание переменных

Внутри for можно вводить **промежуточные переменные**:

```scala
for (i <- 1 to 5; doubled = i * 2; if doubled > 5) {
  println(doubled)
}
// выведет: 6, 8, 10
```

Синтаксис: `имя = выражение`. Переменная доступна в последующих генераторах, фильтрах и теле цикла. Это упрощает читаемость при сложных выражениях.

---

## 3.3.7. Фигурные скобки вместо точки с запятой

Генераторы и фильтры можно записывать в **фигурных скобках** — тогда элементы разделяют переносом строки, без точки с запятой:

```scala
val result = for {
  i <- 1 to 10
  if i % 2 == 0
  squared = i * i
} yield squared
// result: IndexedSeq[Int] = Vector(4, 16, 36, 64, 100)
```

Такой стиль часто удобнее для длинных или многострочных for-comprehension.

---

## 3.3.8. for-comprehension и эквиваленты map/filter

For-comprehension под капотом преобразуется в вызовы `map`, `flatMap` и `withFilter`. Например:

```scala
for (x <- list if x > 0) yield x * 2
```

эквивалентно:

```scala
list.withFilter(_ > 0).map(_ * 2)
```

Поэтому for-comprehension работает с любыми типами, у которых есть эти методы: List, Option, Future и др. Подробнее о map и filter — в [§4.5](chapter-04-05.md) и [§5.5](chapter-05-05.md).

---

## 3.3.9. Типичные ошибки

- **Путать `to` и `until`** — `1 to 5` включает 5, `1 until 5` — нет.
- **Ожидать yield при побочных эффектах** — без yield for возвращает Unit; для вывода и других эффектов yield не нужен.
- **Забыть, что результат for-comprehension — коллекция** — `for (x <- list) yield f(x)` даёт новую коллекцию; исходная не меняется.
- **Использовать var в генераторе** — генератор `x <- col` связывает `x` с элементом; переприсваивать `x` не нужно и не идиоматично.

---

## Ключевое

- **for (x <- коллекция)** — перебор элементов; `1 to n` — диапазон включительно, `1 until n` — без правой границы.
- **if условие** в for — фильтр (guard); обрабатываются только элементы, для которых условие истинно.
- **Несколько генераторов** — вложенные циклы; разделяются `;` или переносом в `{ }`.
- **yield** — for-comprehension: for возвращает новую коллекцию; без yield — побочные эффекты, результат Unit.
- For-comprehension эквивалентен цепочкам map, flatMap, withFilter.

В [§3.4](chapter-03-04.md) мы разберём циклы while и do-while и случаи их использования в Scala.
