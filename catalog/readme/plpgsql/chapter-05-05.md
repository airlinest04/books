# §5.5 Вызов функции

В [§5.4](chapter-05-04.md) мы разобрали VOLATILITY и параллелизм. В этом разделе рассмотрим **вызов функции** из SQL: в SELECT и в других выражениях, **позиционную** и **именованную** передачу аргументов (в том числе смешанную) и вызов функций, возвращающих набор строк. SECURITY DEFINER и права при вызове — в [§5.6](chapter-05-06.md). См. [Глоссарий](glossary.md).

---

## 5.5.1. Вызов в SELECT и в выражениях

Функция на PL/pgSQL вызывается так же, как встроенная или любая другая функция PostgreSQL: в любом выражении SQL, где допустима функция. Типичные контексты (по [§1.3](chapter-01-03.md)): **SELECT** (в списке выражений, в WHERE, в ORDER BY), **INSERT ... VALUES (..., func(...), ...)**, **UPDATE SET столбец = func(...)**, **DEFAULT** для столбца, подзапросы и CTE. Результат функции подставляется в выражение; выполнение идёт на сервере в контексте запроса. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT my_func(1, 'a');
SELECT id, my_func(id, name) AS computed FROM t WHERE my_func(id, name) > 0;
UPDATE t SET x = my_func(a, b) WHERE id = 1;
INSERT INTO log (msg, created) VALUES (format_msg(v), now());
```

Функция с **RETURNS SETOF** или **RETURNS TABLE** возвращает набор строк; её вызывают в FROM как таблицу: **SELECT * FROM func(args)** или **SELECT * FROM func(args) AS t(col1, col2)**. Без AS имена столбцов берутся из объявления функции (OUT или TABLE). См. [Глоссарий](glossary.md).

---

## 5.5.2. Позиционная нотация

При **позиционной** передаче аргументы перечисляются в том же порядке, что и параметры в определении функции. Пропускать можно только аргументы **справа налево** и только если у соответствующих параметров есть значение по умолчанию. См. [Глоссарий](glossary.md).

Пример (по документации PostgreSQL, адаптировано): функция с двумя обязательными и одним необязательным параметром:

```sql
CREATE FUNCTION concat_lower_or_upper(a text, b text, uppercase boolean DEFAULT false)
RETURNS text AS $$ ... $$ LANGUAGE sql;

SELECT concat_lower_or_upper('Hello', 'World', true);   -- все три
SELECT concat_lower_or_upper('Hello', 'World');        -- uppercase получит false
```

Нельзя опустить второй аргумент, оставив третий: позиционно задаются только «хвосты» с DEFAULT.

---

## 5.5.3. Именованная нотация (имя => значение)

При **именованной** нотации каждый аргумент задаётся как **имя_параметра => выражение**. Порядок аргументов может быть любым; можно передать только те параметры, которые нужны, если у остальных есть DEFAULT. Имя должно совпадать с именем параметра в определении функции (без учёта регистра, если имя не в кавычках). См. [Глоссарий](glossary.md).

Синтаксис **:=** тоже поддерживается (для совместимости):

```sql
SELECT concat_lower_or_upper(a => 'Hello', b => 'World');
SELECT concat_lower_or_upper(a => 'Hello', uppercase => true, b => 'World');
SELECT concat_lower_or_upper(b => 'World', a => 'Hello', uppercase => true);
```

Именованная нотация удобна при большом числе параметров и при многих значениях по умолчанию — не нужно подставлять лишние аргументы по позиции.

---

## 5.5.4. Смешанная нотация

Допускается **смешение**: сначала идут **позиционные** аргументы, затем **именованные**. Именованные не могут идти перед позиционными. См. [Глоссарий](glossary.md).

Пример:

```sql
SELECT concat_lower_or_upper('Hello', 'World', uppercase => true);
```

Здесь `a` и `b` заданы позиционно, `uppercase` — по имени. Так можно сэкономить на перечислении первых аргументов и явно указать только нужные необязательные.

---

## 5.5.5. Вызов функции, возвращающей набор строк

Функция, объявленная как **RETURNS SETOF тип** или **RETURNS TABLE(...)**, в запросе используется как **табличное выражение** в FROM. Синтаксис: **имя_функции(аргументы)** или с указанием алиаса и списка столбцов. См. [Глоссарий](glossary.md).

Примеры:

```sql
SELECT * FROM get_all_foo();
SELECT * FROM get_available_flightid('2025-01-15'::date) AS t(flight_id);
SELECT t.id, t.name FROM my_set_returning_func(1, 2) AS t(id int, name text);
```

В выражении (не в FROM) функцию, возвращающую набор, вызывать нельзя — только скаляр или одну строку. Для набора нужен контекст, где ожидается таблица (FROM, JOIN и т.д.).

---

## Ключевое

- Функция вызывается в **любом выражении** SQL (SELECT, WHERE, INSERT, UPDATE, DEFAULT и т.д.); выполнение на сервере.
- **Позиционная нотация** — аргументы в порядке параметров; опускать можно только справа налево при наличии DEFAULT.
- **Именованная нотация** — **имя => значение** (или :=); порядок произвольный; можно передавать только нужные аргументы при DEFAULT.
- **Смешанная** — сначала позиционные, затем именованные; именованные не могут предшествовать позиционным.
- Функция с **RETURNS SETOF/TABLE** вызывается в **FROM** как таблица: SELECT * FROM func(args) [AS alias(...)].

В [§5.6](chapter-05-06.md) мы разберём SECURITY DEFINER и SECURITY INVOKER: от чьего имени выполняется функция и как это влияет на права доступа к объектам.
