# §9.6 Сортировка и ранжирование

В [§9.5](chapter-09-05.md) мы разобрали merge() и concat(). Чтобы упорядочить строки таблицы по значениям столбцов или присвоить им **ранги** (порядковые номера при сортировке), в Pandas используются **sort_values()** и **rank()**. В этом разделе — сортировка по одному и нескольким столбцам, порядок (возрастание/убывание) и обработка пропусков, а также методы ранжирования при совпадающих значениях. В [§10.1](chapter-10-01.md) перейдём к подключению к базам данных (sqlalchemy, psycopg2, read_sql).

---

## 9.6.1. sort_values()

**df.sort_values(by, axis=0, ascending=True, inplace=False, na_position='last')** возвращает DataFrame с **строками, упорядоченными** по значениям столбца (или нескольких столбцов) **by**. **by** — имя столбца (строка) или список имён; при нескольких столбцах сначала сортировка по первому, при равенстве — по второму и т.д.

- **ascending** — порядок: **True** (по умолчанию) — по возрастанию, **False** — по убыванию. Для списка столбцов можно передать список булевых значений: **[True, False]** — первый столбец по возрастанию, второй по убыванию.
- **na_position** — куда помещать пропуски (NaN): **'last'** (по умолчанию) — в конец, **'first'** — в начало.
- **inplace** — при True исходный DataFrame изменяется, метод возвращает None.

Индексы строк в результате сохраняют исходные метки (порядок строк меняется). Чтобы получить последовательный целочисленный индекс 0, 1, 2, …, после сортировки вызывают **df.reset_index(drop=True)**.

```python
import pandas as pd
df = pd.DataFrame({"a": [3, 1, 2], "b": [10, 30, 20]})
df.sort_values("a")              # по a по возрастанию
df.sort_values("a", ascending=False)  # по a по убыванию
df.sort_values(["a", "b"])       # сначала по a, при равенстве — по b
df.sort_values(["a", "b"], ascending=[True, False])  # a вверх, b вниз
```

Для Series: **s.sort_values()** — сортировка по значениям; **s.sort_index()** — по меткам индекса.

## 9.6.2. rank()

**s.rank(method='average', ascending=True, na_option='keep')** (для Series) присваивает каждому элементу **ранг** — порядковый номер, если бы последовательность была отсортирована. Наименьшее значение получает ранг 1 (при ascending=True), следующее — 2 и т.д. Результат — Series той же длины с дробными или целыми рангами в зависимости от **method**.

**method** задаёт правило для **совпадающих** значений:

- **'average'** (по умолчанию) — совпадающим присваивается среднее занимаемых мест (например, два вторых места → оба 2.5).
- **'min'** — всем совпадающим — наименьший из занимаемых рангов (два вторых → оба 2).
- **'max'** — наибольший из занимаемых рангов.
- **'first'** — ранги в порядке появления в исходной последовательности (без дробей).
- **'dense'** — как min, но без «дыр»: следующая группа после двух вторых получает ранг 3, а не 4.

**ascending** — True (по умолчанию): меньшим значениям — меньший ранг; False — наоборот (например, для «топ по убыванию»). **na_option** — 'keep' (NaN остаётся NaN в рангах), 'top', 'bottom' — считать пропуски наименьшими или наибольшими.

Для DataFrame **df.rank()** вычисляет ранги по каждому столбцу отдельно (по умолчанию axis=0); можно указать столбец: **df['col'].rank()**.

```python
s = pd.Series([10, 20, 20, 30])
s.rank()                    # 1.0, 2.5, 2.5, 4.0 (average)
s.rank(method="min")        # 1, 2, 2, 4
s.rank(method="dense")      # 1, 2, 2, 3
s.rank(method="first")      # 1, 2, 3, 4 (порядок появления)
```

Ранги удобны для отбора «топ-N» по столбцу без изменения порядка строк или для построения метрик типа «место в рейтинге».

---

## Ключевое

- **sort_values(by, ascending=..., na_position=...)** — сортировка строк по столбцу(ам) **by**; **ascending** — по возрастанию или убыванию; для нескольких столбцов — список в by и список в ascending.
- **rank(method=..., ascending=...)** — присвоение рангов (порядковых номеров при сортировке); **method** — правило для совпадений: 'average', 'min', 'max', 'first', 'dense'.
- Для Series также **sort_index()** — сортировка по меткам индекса; после sort_values можно сбросить индекс: **reset_index(drop=True)**.
