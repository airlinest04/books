# §2.2 Основные типы

В [§2.1](chapter-02-01.md) мы ввели присваивание и динамическую типизацию. Теперь рассмотрим **основные встроенные типы** данных: целые и вещественные числа, строки и булевы значения. Они составляют основу для выражений и операций; в этом же разделе — проверка типа функцией `type()` и приведение между типами с помощью `int()`, `float()` и `str()`. Строки подробно разбираются в [§2.4](chapter-02-04.md); здесь даётся минимальное представление для работы с операторами в [§2.3](chapter-02-03.md).

---

## 2.2.1. Целые числа (int)

Тип **int** (integer) — целые числа произвольной величины. В Python 3 нет отдельного типа «длинное целое»: любое целое может быть сколь угодно большим, ограничения задаются лишь объёмом памяти.

Литералы целых записывают цифрами; ведущие нули не допускаются (в отличие от восьмеричной записи в старых версиях). Отрицательные числа — знак минус перед числом:

```python
a = 42
b = 0
c = -100
```

Подчёркивания между цифрами можно использовать для удобства чтения (с Python 3.6):

```python
million = 1_000_000
```

Арифметические операции над целыми дают целое (кроме деления `/`, которое возвращает float — см. [§2.3](chapter-02-03.md)). Целые неизменяемы: «изменить» число можно только присвоив переменной новый объект.

---

## 2.2.2. Вещественные числа (float)

Тип **float** — числа с плавающей точкой (приближённое представление вещественных чисел). Литералы записывают с десятичной точкой или в экспоненциальной форме:

```python
x = 3.14
y = 0.5
z = 2e3      # 2000.0
w = 1.5e-2   # 0.015
```

Целое и float в арифметике дают float:

```python
3 + 2.0   # 5.0
```

Из-за двоичного представления возможны ошибки округления при сравнении и накоплении операций; для денег и точной арифметики часто используют тип `Decimal` из стандартной библиотеки или целые (считают в копейках/центах). Для типичных задач анализа данных float обычно достаточен; при сравнении близких чисел иногда проверяют «почти равенство» (например, через функции из модуля `math` или NumPy).

---

## 2.2.3. Строки (str)

Тип **str** — строка символов (текст). Литералы задают в одинарных или двойных кавычках; они эквивалентны:

```python
s1 = "hello"
s2 = 'world'
```

Строки неизменяемы; операции над ними создают новые строки. Индексация, срезы и методы строк разбираются в [§2.4](chapter-02-04.md). Здесь достаточно знать, что строка — отдельный тип, с которым можно складывать (конкатенация) и повторять (`*` с целым), а также что числа и строки нельзя смешивать в арифметике без явного приведения.

---

## 2.2.4. Булевы значения (bool)

Тип **bool** (boolean) — логический тип; всего два значения: **True** и **False**. Используются в условиях и логических выражениях ([§2.3](chapter-02-03.md), [§3.1](chapter-03-01.md)).

```python
flag = True
ok = False
```

В Python имена булевых констант пишут с заглавной буквы. Булевы значения — подтип целых: `True` ведёт себя как `1`, `False` как `0` в арифметике (но для ясности кода лучше не полагаться на это). Многие объекты в логическом контексте (условие `if`, логические операторы) интерпретируются как «истина» или «ложь»; например, пустая строка `""` и число `0` считаются ложными — подробнее в главе об условиях.

---

## 2.2.5. Проверка типа: type()

Узнать тип объекта во время выполнения позволяет встроенная функция **type()**. Ей передают объект (или переменную); возвращается тип этого объекта:

```python
type(42)           # <class 'int'>
type(3.14)         # <class 'float'>
type("hello")      # <class 'str'>
type(True)         # <class 'bool'>
```

В выводе `<class 'int'>` слово `class` связано с тем, что в Python типы реализованы как классы; на этапе изучения основ достаточно понимать, что `type(x)` показывает, с каким типом вы работаете.

**Проверка «является ли x целым»** и т.п. делают так:

```python
x = 42
type(x) == int     # True
type(x) == str     # False
```

Для проверки типа часто используют **isinstance(obj, type)** — она учитывает наследование (подклассы считаются подходящими). Например, `isinstance(x, int)` вернёт `True` для целого и для наследников `int`. Для встроенных типов `int`, `float`, `str`, `bool` результат обычно совпадает с проверкой через `type()`.

---

## 2.2.6. Приведение типов: int(), float(), str()

Встроенные функции **int()**, **float()** и **str()** не только создают значения своих типов из литералов, но и **приводят** (преобразуют) объекты к соответствующему типу — когда такое преобразование определено.

**int(x)** — целое число. Из float дробная часть отбрасывается (округление к нулю); из строки — разбор целого числа:

```python
int(3.9)      # 3
int("42")     # 42
int("-10")    # -10
```

Строка должна представлять целое в десятичной записи; иначе будет ошибка `ValueError`.

**float(x)** — вещественное число. Из целого даёт то же значение в формате float; из строки — разбор числа с точкой или экспонентой:

```python
float(10)       # 10.0
float("3.14")   # 3.14
float("1e-1")   # 0.1
```

**str(x)** — строковое представление объекта. Практически любой объект можно преобразовать в строку; для чисел получается запись в десятичной форме:

```python
str(42)     # "42"
str(3.14)   # "3.14"
str(True)   # "True"
```

Приведение часто нужно при чтении данных из файлов или из API: числа могут приходить как строки (например, `"123"`), и перед расчётами их приводят к `int` или `float`; при выводе или записи в файл, наоборот, числа преобразуют в строки через `str()` или форматирование ([§2.4](chapter-02-04.md)).

**Типичные ошибки:**

- `int("3.14")` — ValueError: строка с точкой не является целым литералом; сначала приведите к float: `int(float("3.14"))`.
- Сложение числа и строки без приведения: `10 + "5"` вызовет TypeError; нужно `10 + int("5")` или `str(10) + "5"` в зависимости от цели.

---

## Ключевое

- **int** — целые числа произвольной величины; литералы: `42`, `-10`; подчёркивания в числах допустимы (`1_000_000`).
- **float** — вещественные числа; литералы: `3.14`, `2e3`; при арифметике с int результат — float; возможны ошибки округления.
- **str** — строки в кавычках `"..."` или `'...'`; подробнее в [§2.4](chapter-02-04.md).
- **bool** — значения `True` и `False`; используются в условиях и логических выражениях.
- **type(x)** — возвращает тип объекта; проверка: `type(x) == int` или `isinstance(x, int)`.
- **Приведение:** `int(x)`, `float(x)`, `str(x)` — преобразование к целому, вещественному или строке; при чтении/записи данных приведение типов используется постоянно.

В [§2.3](chapter-02-03.md) мы разберём операторы: арифметические, сравнения и логические.
