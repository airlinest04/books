# §7.4 Формы и преобразования

Это нужно при подготовке данных для расчётов и объединении массивов по строкам или столбцам. В [§8.1](chapter-08-01.md) мы перейдём к Pandas: Series и DataFrame.

## 7.4.1. reshape: изменение формы

Метод **arr.reshape(newshape)** возвращает массив с новой формой; число элементов должно сохраняться (произведение размеров shape не меняется). Исходный массив не изменяется; результат — вид (view), если это возможно без перестройки памяти, иначе — копия.

**Одномерный в двумерный:**

```python
import numpy as np
a = np.arange(6)       # array([0, 1, 2, 3, 4, 5])
a.reshape(2, 3)        # array([[0, 1, 2], [3, 4, 5]])
```

**Двумерный в одномерный или другую матрицу:**

```python
m = np.array([[1, 2, 3], [4, 5, 6]])
m.reshape(6)           # array([1, 2, 3, 4, 5, 6])  — порядок по строкам (C-order)
m.reshape(3, 2)       # array([[1, 2], [3, 4], [5, 6]])
```

**Одна размерность как -1:** можно указать **-1** для одной оси — она будет вычислена автоматически по числу элементов:

```python
a = np.arange(8)
a.reshape(2, -1)      # (2, 4)  — 8 элементов, 2 строки, 4 столбца
a.reshape(-1, 2)      # (4, 2)
```

Если произведение размеров не совпадает с числом элементов (например, reshape(3, 3) для массива из 8 элементов), возникает **ValueError**. Функция **np.reshape(arr, newshape)** эквивалентна методу.

## 7.4.2. ravel и flatten: развернуть в одномерный массив

**arr.ravel()** возвращает массив, «развёрнутый» в одну ось (все элементы подряд, порядок обхода по умолчанию — по строкам, C-order). По возможности возвращается вид (view), иначе копия.

**arr.flatten()** всегда возвращает **копию**, развёрнутую в одну ось. Используют, когда нужна именно копия и не хотят случайно изменить исходный массив при изменении результата.

```python
m = np.array([[1, 2], [3, 4]])
m.ravel()    # array([1, 2, 3, 4])
m.flatten()  # array([1, 2, 3, 4])
```

Для двумерного массива порядок по умолчанию — сначала первая строка, затем вторая и т.д. Параметр **order** ('C' — по строкам, 'F' — по столбцам) задаёт порядок обхода при ravel и reshape.

## 7.4.3. Конкатенация массивов

**np.concatenate((a1, a2, ...), axis=0)** объединяет массивы вдоль заданной **оси**. Массивы должны иметь **одинаковую форму** по всем осям, кроме оси конкатенации.

**По строкам (axis=0)** — массивы «ставятся друг под друга»:

```python
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])
np.concatenate((a, b), axis=0)   # array([[1, 2], [3, 4], [5, 6], [7, 8]])  — форма (4, 2)
```

**По столбцам (axis=1)** — массивы «ставятся рядом»:

```python
np.concatenate((a, b), axis=1)   # array([[1, 2, 5, 6], [3, 4, 7, 8]])  — форма (2, 4)
```

Для одномерных массивов единственная ось — 0; **np.concatenate((x, y))** склеивает два вектора в один.

**np.vstack((a, b))** — конкатенация по первой оси (вертикально, по строкам); для 1D массивов сначала превращает их в строки (1, n), затем склеивает. **np.hstack((a, b))** — по второй оси (горизонтально, по столбцам). Удобны, когда не хочется указывать axis; для 2D vstack эквивалентен concatenate(..., axis=0), hstack — axis=1.

Перед конкатенацией массивы разной размерности иногда приводят к одной форме (например, **np.newaxis** или **reshape**), чтобы по остальным осям размеры совпадали.

## 7.4.4. Преобразование типа: astype

Метод **arr.astype(dtype)** возвращает **копию** массива с приведением элементов к указанному типу. Исходный массив не меняется.

```python
a = np.array([1, 2, 3], dtype=float)
b = a.astype(int)     # array([1, 2, 3])  — целые
c = np.array([1.5, 2.7])
c.astype(int)         # array([1, 2])  — дробная часть отбрасывается
```

Удобно при загрузке данных, когда нужны целые индексы или экономия памяти (float32 вместо float64). При несовместимом преобразовании (например, строка в число) может возникнуть ошибка или неверный результат; для строковых массивов используют специализированные функции или предобработку.

---

## 7.4.5. Типичные ошибки

- **reshape с несовместимым числом элементов** — произведение размеров новой формы должно равняться arr.size; иначе ValueError.
- **concatenate по axis: несовпадение размеров по другим осям** — вдоль axis размеры могут различаться, по остальным осям формы массивов должны быть одинаковы. Иначе ValueError.
- **ravel возвращает вид** — изменение элементов результата ravel может изменить исходный массив; для копии использовать **flatten()** или **.copy()**.

---

## Ключевое

- **arr.reshape(newshape)** — массив с новой формой; число элементов сохраняется. Одна размерность может быть **-1** (вычисляется автоматически). **np.reshape(arr, newshape)** — то же.
- **arr.ravel()** — развернуть в 1D (по возможности view). **arr.flatten()** — развернуть в 1D, всегда копия.
- **np.concatenate((a1, a2, ...), axis=0)** — объединение вдоль оси; по оси axis размеры суммируются, по остальным — совпадают. **np.vstack** — по строкам (axis=0), **np.hstack** — по столбцам (axis=1).
- **arr.astype(dtype)** — копия массива с приведением к типу dtype.
