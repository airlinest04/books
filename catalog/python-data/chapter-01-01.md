# §1.1 Зачем Python для данных

Этот раздел открывает книгу «Python для данных». Мы разберём, почему Python стал одним из основных языков для анализа данных, инженерии данных и машинного обучения; какие свойства языка и экосистемы делают его удобным для работы с данными; и что вы получите, освоив материал этой книги. После этого в [§1.2](chapter-01-02.md) перейдём к установке Python и настройке среды.

## 1.1.1. Роль Python в аналитике и инженерии данных

**Python** — универсальный язык программирования, созданный Гвидо ван Россумом; первая публичная версия вышла в 1991 году. Изначально язык не проектировался специально «под данные», но благодаря простому синтаксису, расширяемости и появлению библиотек для численных расчётов и табличных данных он стал де-факто стандартом в областях, где нужно загружать данные, очищать их, считать статистики, строить модели и автоматизировать пайплайны.

В контексте данных Python используют:

- **Аналитики данных** — выгрузка из баз и файлов, очистка, агрегация, отчёты и визуализация.
- **Инженеры данных** — скрипты ETL/ELT, оркестрация задач, работа с API и файловыми хранилищами.
- **Специалисты по машинному обучению** — подготовка признаков, обучение и оценка моделей, эксперименты в ноутбуках.

Во многих командах один и тот же язык применяется и для разового анализа, и для продакшен-пайплайнов: это снижает порог входа и упрощает поддержку. Книга ориентирована на читателя, который ещё не знает Python или знает его поверхностно; мы пройдём от установки и базового синтаксиса до работы с таблицами (Pandas), массивами (NumPy) и краткого обзора инструментов машинного обучения (Scikit-learn, Keras и др.).

## 1.1.2. Экосистема библиотек: NumPy, Pandas, Scikit-learn

Сильная сторона Python для данных — не сам язык в изоляции, а **экосистема библиотек**. Они закрывают типичные задачи без необходимости писать низкоуровневый код.

**NumPy** (Numerical Python) — библиотека для работы с многомерными массивами и быстрыми вычислениями над ними. Обеспечивает:

- эффективное хранение однотипных данных (целые, вещественные);
- поэлементные и матричные операции, агрегации по осям;
- основу для многих других библиотек (Pandas, Scikit-learn используют массивы NumPy внутри).

Без NumPy тяжёлые численные расчёты на «чистом» Python были бы недопустимо медленными; NumPy переносит вычисления в скомпилированный код (C/Fortran) и векторизацию. См. [Глоссарий](glossary.md).

**Pandas** — библиотека для структурированных табличных данных (ряды и таблицы: Series и DataFrame). С её помощью удобно:

- загружать данные из CSV, Excel, баз данных, API;
- фильтровать строки, выбирать столбцы, добавлять и переименовывать колонки;
- обрабатывать пропуски и дубликаты, менять типы, группировать и агрегировать;
- объединять таблицы (join/merge) и подготавливать данные для моделей или отчётов.

Pandas опирается на NumPy и дополняет его семантикой «таблицы с метками» (индексы, имена столбцов). Для большинства задач анализа данных в Python Pandas — первая библиотека, к которой обращаются. См. [Глоссарий](glossary.md).

**Scikit-learn** — библиотека машинного обучения: регрессия, классификация, кластеризация, предобработка данных, разбиение на выборки и кросс-валидация. Отличается единым API: модели реализуют методы `fit()` и `predict()`, что упрощает смену алгоритма и встраивание в пайплайн. В этой книге мы даём краткий обзор Scikit-learn и примеры регрессии/классификации; углублённое изучение ML вынесено за рамки одного тома.

Помимо этого, в экосистеме широко используются:

- **SciPy** — научные вычисления (статистика, оптимизация, линейная алгебра, спецфункции);
- библиотеки визуализации (**Matplotlib**, **Seaborn**);
- фреймворки глубокого обучения (**TensorFlow**, **Keras**, **PyTorch**) для нейросетей.

Книга последовательно подводит к NumPy и Pandas (Часть II), затем даёт введение в SciPy/Scikit-learn и обзор фреймворков глубокого обучения (Часть III). Сначала важно заложить фундамент: установка, синтаксис Python, структуры данных и работа с файлами (Часть I).

## 1.1.3. Интерпретируемый язык и интерактивность

Python — **интерпретируемый** язык: программа выполняется по шагам интерпретатором, без обязательной предварительной компиляции в машинный код. Это не значит, что Python «медленный» во всех задачах: критичные по скорости участки реализованы в библиотеках (NumPy, Pandas и др.) на компилируемых языках; сам же язык даёт быстрый цикл разработки и экспериментов.

Для работы с данными важны два следствия интерпретируемости:

1. **REPL (Read–Eval–Print Loop)** — интерактивная оболочка: вы вводите выражения и сразу видите результат. Удобно проверять одну команду, смотреть тип переменной или результат вызова функции без запуска целого скрипта.
2. **Jupyter Notebook / JupyterLab** — среда, где код и вывод (таблицы, графики) объединены в одном документе. Широко используется в аналитике и ML: можно по ячейкам загрузить данные, посмотреть срез, построить график, добавить текст и затем повторить только нужные ячейки.

Таким образом, вы можете быстро перебирать варианты (другой фильтр, другая агрегация), смотреть промежуточные результаты и только потом оформлять логику в скрипт или пайплайн. В [§1.3](chapter-01-03.md) мы кратко рассмотрим запуск кода: REPL и выполнение файла, а также упомянем Jupyter.

## 1.1.4. Читаемость и скорость разработки

Синтаксис Python ориентирован на **читаемость**: меньше скобок и служебных символов, чем во многих других языках; блоки кода выделяются **отступами**, а не фигурными скобками. Это одновременно и правило языка, и стилевая норма, поэтому код разных авторов часто выглядит единообразно и легко читается.

Для работы с данными это особенно полезно:

- сложные пайплайны (загрузка → очистка → преобразование → агрегация) остаются обозримыми;
- коллеги и вы сами через полгода быстрее понимают, что делает скрипт;
- меньше времени уходит на отладку из-за опечаток в скобках или точках с запятой.

Кроме того, у Python большое сообщество и обширная документация; для NumPy, Pandas и Scikit-learn есть официальные руководства, примеры и ответы на типичные вопросы. Всё это снижает время от идеи до рабочего решения и делает Python практичным выбором для обучения и для работы.

## 1.1.5. О границах применимости

Python — не единственный инструмент в стеке данных. Стоит иметь в виду:

- **Производительность «сырого» кода:** тяжёлые алгоритмы, написанные только на Python, часто уступают реализациям на C/C++ или Rust. На практике критичные участки закрывают библиотеками (NumPy, Numba, Cython) или выносят в отдельные сервисы.
- **Очень большие данные:** когда данные не помещаются в память одной машины, используют распределённые системы (Apache Spark, Dask) или запросы к хранилищам (SQL, Trino и т.п.). Python часто выступает языком скриптов и API поверх таких систем.
- **Интеграция:** в реальных проектах Python соседствует с SQL-движками, очередями сообщений, облачными хранилищами; умение писать запросы и скрипты на Python дополняет друг друга.

Книга даёт базу: язык, структуры данных, файлы, NumPy и Pandas. Этого достаточно, чтобы уверенно писать скрипты анализа, готовить данные для моделей и переходить к более специализированным курсам или книгам по машинному обучению и инженерии данных.

## Ключевое

- Python широко используется в аналитике данных, инженерии данных и машинном обучении благодаря экосистеме библиотек и удобству разработки.
- NumPy даёт эффективные массивы и численные операции; Pandas — табличные данные (Series, DataFrame) и типичные операции загрузки, очистки и агрегации; Scikit-learn — единый API для моделей ML.
- Python интерпретируемый: удобны интерактивная оболочка (REPL) и Jupyter для пошаговых экспериментов с данными.
- Читаемый синтаксис и отступы как часть языка упрощают написание и поддержку скриптов; большое сообщество и документация ускоряют разработку.
- Для максимальной производительности тяжёлые вычисления опираются на библиотеки (NumPy и др.) или распределённые системы; Python остаётся языком скриптов и пайплайнов.
