# §4.1 Определение функции

В [§3.4](chapter-03-04.md) мы разобрали тернарное выражение. Теперь переходим к **функциям** и модулям: функции позволяют выделить повторяющуюся логику в отдельный блок с именем, параметрами и возвращаемым значением. В этом разделе — синтаксис **def**, параметры, **return** и **параметры по умолчанию**. В [§4.2](chapter-04-02.md) рассмотрим позиционные и именованные аргументы и приём *args, **kwargs.

---

## 4.1.1. Синтаксис def: имя и параметры

Функция определяется ключевым словом **def**, именем, списком параметров в скобках и двоеточием. Тело функции — блок с отступом:

```python
def имя_функции(параметр1, параметр2):
    инструкции
    return результат
```

Пример:

```python
def greet(name):
    return f"Hello, {name}!"
```

Здесь `name` — **параметр** (аргумент функции). При вызове `greet("Alice")` в параметр `name` подставляется переданное значение `"Alice"`, и функция возвращает строку `"Hello, Alice!"`.

**Вызов функции:** имя функции и в скобках — аргументы (значения для параметров):

```python
result = greet("Alice")   # result = "Hello, Alice!"
print(greet("Bob"))       # выведет Hello, Bob!
```

Количество аргументов при вызове должно совпадать с количеством параметров (если у параметров нет значений по умолчанию — см. ниже). Иначе возникнет TypeError.

Параметров может не быть — тогда скобки пустые:

```python
def say_hello():
    print("Hello")
say_hello()
```

## 4.1.2. return: возврат значения

Инструкция **return** завершает выполнение функции и возвращает значение вызывающему коду. После return дальнейшие инструкции в функции не выполняются.

```python
def add(a, b):
    return a + b
x = add(2, 3)   # x = 5
```

Можно вернуть любое выражение: число, строку, список, результат другой функции. Несколько значений возвращают в виде кортежа (одним return с перечислением через запятую); вызывающая сторона может распаковать результат ([§5.3](chapter-05-03.md)):

```python
def min_max(values):
    return min(values), max(values)
lo, hi = min_max([1, 5, 3])
```

**return без выражения** просто выходит из функции; при этом функция возвращает **None**:

```python
def log(msg):
    print(msg)
    return
result = log("test")   # выведет test, result = None
```

Если в функции нет ни одного return, выполнение доходит до конца тела и функция тоже возвращает **None**. Поэтому функции, которые «ничего не возвращают» по смыслу (например, только печатают или изменяют переданный объект), фактически возвращают None.

## 4.1.3. Параметры по умолчанию

Параметру можно задать **значение по умолчанию**: если при вызове аргумент не передан, подставится это значение. Синтаксис — знак присваивания в объявлении:

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"
greet("Alice")              # "Hello, Alice!"
greet("Bob", "Hi")          # "Hi, Bob!"
```

Правило: параметры **без значения по умолчанию** должны идти **перед** параметрами **с значением по умолчанию**. Иначе будет синтаксическая ошибка:

```python
def f(a, b=0):    # верно
def f(a=0, b):    # SyntaxError
```

При вызове можно передавать только часть аргументов — тогда недостающие берутся из умолчаний. Удобно для опциональных настроек (разделитель, кодировка, лимит и т.п.):

```python
def split_line(line, sep=","):
    return line.split(sep)
split_line("a,b,c")           # ['a', 'b', 'c']
split_line("a;b;c", sep=";")  # ['a', 'b', 'c']
```

**Важно про изменяемые значения по умолчанию:** не следует использовать изменяемый объект (список, словарь) как значение по умолчанию — один и тот же объект будет переиспользоваться при всех вызовах, что приводит к неожиданному накоплению данных. Подробнее и правильный приём (None и создание объекта внутри тела) — в [§4.2](chapter-04-02.md) и в литературе по Python.

## 4.1.4. Docstring: описание функции

Сразу после строки с def можно поместить **строку документации** (docstring) — обычно тройные кавычки в одну или несколько строк. В ней кратко описывают, что делает функция, какие параметры принимает и что возвращает. Эту строку можно прочитать через атрибут `__doc__` или в справке (help):

```python
def add(a, b):
    """Возвращает сумму двух чисел."""
    return a + b
help(add)   # выведет описание
```

Docstring не обязателен, но полезен для документирования модулей и публичных функций; при работе с данными часто описывают смысл параметров (например, «путь к CSV-файлу») и формат возвращаемого значения.

---

## 4.1.5. Типичные ошибки

- **Забыть двоеточие** после скобок с параметрами — синтаксическая ошибка.
- **Забыть return** там, где ожидается значение — функция вернёт None; вызывающий код может не заметить и использовать «результат» в расчётах.
- **Параметры с умолчанием слева от обязательных** — SyntaxError; порядок: сначала все без умолчания, потом с умолчанием.
- **Передать аргументов меньше или больше**, чем параметров (при отсутствии *args), — TypeError. Проверить сигнатуру функции и число аргументов при вызове.

---

## Ключевое

- **def имя(параметры):** — определение функции; тело с отступом. Вызов: **имя(аргументы)**.
- **return выражение** — возврат значения и выход из функции. **return** без выражения или отсутствие return — функция возвращает **None**.
- **Параметры по умолчанию:** в объявлении `параметр=значение`; при вызове аргумент можно не передавать. Обязательные параметры должны идти перед параметрами с умолчанием.
- **Docstring** — строка в тройных кавычках сразу после def; описывает назначение функции и параметры.
- Не использовать изменяемые объекты (списки, словари) как значения по умолчанию.

В [§4.2](chapter-04-02.md) мы разберём позиционные и именованные аргументы, порядок передачи и приёмы *args и **kwargs.
