# §5.3 Кортеж (tuple)

В [§5.2](chapter-05-02.md) мы разобрали словарь. **Кортеж (tuple)** — упорядоченная **неизменяемая** последовательность элементов. По индексации и срезам он похож на список, но его нельзя изменить после создания; это позволяет использовать кортежи как ключи словаря и как «записи» фиксированной структуры. Важный приём — **распаковка** кортежа в несколько переменных. В этом разделе: создание кортежа, неизменяемость, распаковка и случаи, когда кортеж уместнее списка. В [§5.4](chapter-05-04.md) рассмотрим множество (set).

---

## 5.3.1. Создание кортежа

**Кортеж** задаётся круглыми скобками с перечислением элементов через запятую. См. [Глоссарий](glossary.md).

```python
empty = ()
point = (10, 20)
mixed = (1, "hello", 3.14)
```

**Один элемент** в кортеже записывают с запятой после него — иначе скобки трактуются как группировка выражения, а не кортеж:

```python
single = (42,)   # кортеж из одного элемента
not_tuple = (42) # это просто число 42
```

Функция **tuple(iterable)** создаёт кортеж из последовательности (списка, строки, range и т.д.):

```python
tuple([1, 2, 3])   # (1, 2, 3)
tuple("ab")        # ('a', 'b')
```

Длина — **len(t)**; проверка вхождения — **x in t**. Индексация и срезы — как у списка: **t[0]**, **t[-1]**, **t[1:3]**; срез даёт **новый кортеж**.

---

## 5.3.2. Неизменяемость

Кортеж **неизменяемый** (immutable): после создания нельзя присвоить новое значение элементу, добавить или удалить элемент. Любая попытка изменить кортеж приводит к **TypeError**:

```python
t = (1, 2, 3)
t[0] = 10   # TypeError
t.append(4) # AttributeError: у кортежа нет append
```

Если элемент кортежа сам **изменяемый** (например, список), то содержимое этого элемента менять можно; неизменяемость кортежа касается только самой последовательности ссылок на элементы:

```python
t = (1, [2, 3])
t[1].append(4)   # допустимо: (1, [2, 3, 4])
t[1] = []        # TypeError: нельзя заменить элемент кортежа
```

Неизменяемость делает кортеж **хешируемым** (если все его элементы хешируемы), поэтому кортеж можно использовать как **ключ словаря** — в отличие от списка. Это удобно для составных ключей (например, (дата, регион) или (id, тип)).

---

## 5.3.3. Распаковка

**Распаковка** (unpacking) — присвоение элементов последовательности нескольким переменным за одну операцию: слева от = перечисляют переменные, справа — кортеж (или список, строка и т.д.) той же длины.

```python
x, y = (10, 20)   # x = 10, y = 20
a, b, c = [1, 2, 3]
```

Число переменных должно совпадать с числом элементов, иначе **ValueError**. Обмен значений двух переменных без временной переменной:

```python
a, b = b, a
```

Справа формируется кортеж (b, a), затем он распаковывается в a и b.

**Распаковка в цикле for** — когда перебирают последовательность кортежей (или списков фиксированной длины), удобно сразу распаковать в переменные:

```python
pairs = [(1, "a"), (2, "b")]
for num, letter in pairs:
    print(num, letter)
```

**Возврат нескольких значений из функции** — фактически возвращается один кортеж; вызывающая сторона может распаковать его в переменные ([§4.1](chapter-04-01.md)):

```python
def min_max(lst):
    return min(lst), max(lst)
lo, hi = min_max([3, 1, 4])
```

**Остаток в одну переменную:** в распаковке можно использовать **\*** перед именем, чтобы собрать «лишние» элементы в список (Python 3):

```python
first, *rest = (1, 2, 3, 4)   # first = 1, rest = [2, 3, 4]
```

## 5.3.4. Когда использовать кортеж вместо списка

- **Ключ словаря** — ключ должен быть хешируемым; кортеж из неизменяемых элементов подходит, список — нет. Например, пары (год, месяц) или (id, тип) как ключи.
- **Неизменяемая запись** — когда структура «полей» фиксирована и не должна меняться (координаты, настройки, возврат из функции). Кортеж явно сигнализирует «это не будет изменяться».
- **Возврат нескольких значений из функции** — по соглашению возвращают кортеж; вызывающий код распаковывает: `a, b = f()`.
- **Элементы множества (set)** — множество хранит только хешируемые объекты; кортежи допустимы, списки — нет ([§5.4](chapter-05-04.md)).

Когда нужны добавление, удаление или изменение элементов по месту — используют список. Когда нужна фиксированная структура, ключ словаря или хешируемость — кортеж.

---

## 5.3.5. Методы кортежа

У кортежа мало методов — только те, что не меняют объект: **t.index(x)** — индекс первого вхождения x; **t.count(x)** — количество вхождений x. При отсутствии x метод index вызывает ValueError.

Конкатенация **+** создаёт **новый** кортеж; повторение **\*** — тоже новый кортеж.

---

## Ключевое

- **Кортеж (tuple)** — неизменяемая упорядоченная последовательность: **()**, **(1,)**, **tuple()**; индексация и срезы только для чтения; срез даёт новый кортеж.
- **Неизменяемость** — нельзя менять элементы, добавлять или удалять; кортеж (из хешируемых элементов) можно использовать как ключ словаря.
- **Распаковка:** **a, b = (x, y)**; обмен **a, b = b, a**; распаковка в цикле **for a, b in pairs**; возврат из функции и распаковка результата; **\*rest** для остатка.
- Кортеж уместен для ключей словаря, неизменяемых записей, возврата нескольких значений из функции и как элемент множества.

В [§5.4](chapter-05-04.md) мы разберём множество (set): уникальные элементы и операции объединения и пересечения.
