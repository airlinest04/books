## 7.1.1. Импорт NumPy и тип ndarray

Библиотеку NumPy подключают по соглашению так:

```python
import numpy as np
```

Основной тип данных — **ndarray** (массив NumPy). Элементы массива имеют один общий **тип данных** (dtype): например, int64, float64. Это позволяет хранить данные компактно и выполнять операции над ними эффективно (векторизация). См. [Глоссарий](glossary.md).

NumPy должен быть установлен ([§1.4](chapter-01-04.md)); при импорте в интерактивной среде или в скрипте проверьте, что нет ошибки ImportError.

## 7.1.2. np.array(): создание из последовательности

**np.array(object, dtype=None, ...)** создаёт массив из последовательности (списка, вложенных списков, кортежа и т.д.).

**Одномерный массив** — из списка чисел:

```python
import numpy as np
a = np.array([1, 2, 3, 4, 5])
```

**Двумерный массив** (матрица) — из списка списков; каждый внутренний список — строка:

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])
```

Число элементов во вложенных списках должно совпадать, иначе получится массив из объектов (одномерный список списков разной длины), а не «правильная» матрица.

**Форма (shape)** — атрибут **.shape** возвращает кортеж размеров по каждой оси: для одномерного массива длины 5 — **(5,)**, для матрицы 2×3 — **(2, 3)**. Первое число — количество строк, второе — столбцов (для 2D).

**Размерность (ndim)** — атрибут **.ndim** возвращает число осей: 1 для вектора, 2 для матрицы. **.size** — общее число элементов (произведение размеров shape).

```python
a.shape   # (5,)
a.ndim    # 1
m.shape   # (2, 3)
m.ndim    # 2
m.size    # 6
```

## 7.1.3. np.zeros() и np.ones()

**np.zeros(shape)** создаёт массив заданной **формы**, заполненный нулями. **np.ones(shape)** — единицами. Форма задаётся целым числом (одномерный массив) или кортежем (многомерный).

```python
np.zeros(5)           # array([0., 0., 0., 0., 0.])  — по умолчанию float64
np.zeros((2, 3))     # матрица 2×3 из нулей
np.ones((2, 3))      # матрица 2×3 из единиц
```

Тип элементов по умолчанию — **float64**. Целочисленный массив нулей/единиц задают через **dtype**:

```python
np.zeros(5, dtype=int)    # array([0, 0, 0, 0, 0])
np.ones((2, 2), dtype=np.int32)
```

**np.full(shape, fill_value)** создаёт массив заданной формы, заполненный одним значением fill_value (любым числом).

## 7.1.4. np.arange()

**np.arange([start,] stop[, step])** создаёт одномерный массив с равномерным шагом (аналог встроенного **range()**, но результат — массив и по умолчанию тип float при вещественном шаге). **stop** не входит в массив.

```python
np.arange(5)           # array([0, 1, 2, 3, 4])
np.arange(2, 8, 2)    # array([2, 4, 6])
np.arange(0, 1, 0.2)  # array([0. , 0.2, 0.4, 0.6, 0.8])
```

Для получения равномерной сетки из **N** точек на отрезке часто используют **np.linspace(start, stop, num)** — границы **start** и **stop** входят в массив, точки распределены равномерно (включая концы). Это удобнее, когда важно именно число точек, а не шаг.

## 7.1.5. Тип элементов: dtype

У каждого массива есть атрибут **dtype** — тип элементов. Часто встречаются **int64**, **float64**, **bool_**. При создании тип выводится из данных или задаётся аргументом **dtype**:

```python
a = np.array([1, 2, 3])
a.dtype   # dtype('int64')  — на 64-битной системе
b = np.array([1.0, 2, 3])
b.dtype   # dtype('float64')  — смешение с float даёт float
np.array([1, 2, 3], dtype=float)   # явно float64
```

Преобразование типа существующего массива — **arr.astype(dtype)** ([§7.4](chapter-07-04.md) и далее). Для начала достаточно понимать, что shape, ndim и dtype показывают форму и тип массива.

---

## 7.1.6. Кратко: np.empty(), np.eye(), np.identity()

**np.empty(shape)** создаёт массив заданной формы **без инициализации** содержимого (значения могут быть «мусором»). Используют, когда массив сразу заполняют по индексам; для воспроизводимости и отладки надёжнее zeros/ones.

**np.eye(n)** — единичная матрица n×n (единицы на главной диагонали, остальные нули). **np.identity(n)** — то же. Полезно для линейной алгебры и тестов.

---

## Ключевое

- **import numpy as np**; основной тип — **ndarray**. Массив хранит элементы одного типа (dtype).
- **np.array(список или вложенные списки)** — массив из последовательности; вложенные списки одной длины дают 2D массив. **.shape** — размеры по осям, **.ndim** — число осей, **.size** — число элементов.
- **np.zeros(shape)**, **np.ones(shape)** — массив из нулей или единиц; shape — число или кортеж. **np.full(shape, value)** — заполнение заданным значением. По умолчанию dtype float64; для целых — **dtype=int**.
- **np.arange(start, stop, step)** — одномерный массив с шагом (stop не входит). **np.linspace(start, stop, num)** — num точек на отрезке, границы входят.
