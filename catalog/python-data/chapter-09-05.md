# §9.5 Слияние таблиц

В [§9.4](chapter-09-04.md) мы разобрали groupby() и .agg(). Нередко данные лежат в **нескольких таблицах** (справочник регионов, факты продаж по id) и их нужно **объединить** по общему ключу или просто склеить по строкам/столбцам. В этом разделе — **pd.merge()** для слияния двух DataFrame по ключу с выбором типа соединения (inner, left, right, outer) и **pd.concat()** для объединения таблиц по строкам или столбцам. В [§9.6](chapter-09-06.md) разберём сортировку и ранжирование: sort_values(), rank().

## 9.5.1. pd.merge() по ключу

**pd.merge(left, right, on=None, left_on=None, right_on=None, how='inner', ...)** объединяет два DataFrame **left** и **right** по **ключу** — столбцу (или нескольким столбцам), в котором совпадают значения. Результат — один DataFrame: каждая строка — пара совпавших строк из left и right с объединёнными столбцами (дубликаты ключа в одном из таблиц дают несколько строк в результате).

Если столбец ключа называется одинаково в обеих таблицах — задают **on='имя_столбца'** или **on=['col1', 'col2']**. Если имена разные — **left_on** и **right_on**: **merge(left, right, left_on='id_left', right_on='id_right')**. Слияние по индексу: **left_on** и **right_on** могут указывать на индекс (через **left_index=True**, **right_index=True** или передачей **left.index**).

По умолчанию **how='inner'** — в результат попадают только строки, у которых ключ найден в **обоих** таблицах.

```python
import pandas as pd
left = pd.DataFrame({"id": [1, 2, 3], "name": ["a", "b", "c"]})
right = pd.DataFrame({"id": [2, 3, 4], "value": [10, 20, 30]})
pd.merge(left, right, on="id")
#    id name  value
# 0   2    b     10
# 1   3    c     20
```

## 9.5.2. Типы join: inner, left, right, outer

Параметр **how** задаёт тип соединения (аналог JOIN в SQL):

- **how='inner'** (по умолчанию) — только строки с совпадающим ключом в **обеих** таблицах; ключи, есть только в left или только в right, не попадают в результат.
- **how='left'** — все строки из **left**; для каждой подставляются столбцы из **right** по ключу; если в right нет совпадения — в этих столбцах NaN.
- **how='right'** — все строки из **right**; для каждой подставляются столбцы из **left**; отсутствующие в left — NaN.
- **how='outer'** — все ключи из обеих таблиц; строки без пары дополняются NaN в столбцах второй таблицы.

Суффиксы **suffixes=('_left', '_right')** задают окончания имён столбцов при совпадении имён неключевых столбцов в left и right (по умолчанию '_x', '_y').

```python
pd.merge(left, right, on="id", how="left")
#    id name  value
# 0   1    a    NaN
# 1   2    b   10.0
# 2   3    c   20.0
pd.merge(left, right, on="id", how="outer")
#    id name  value
# 0   1    a    NaN
# 1   2    b   10.0
# 2   3    c   20.0
# 3   4  NaN   30.0
```

## 9.5.3. pd.concat() — по строкам и по столбцам

**pd.concat(objs, axis=0, join='outer', ignore_index=False)** объединяет **список** DataFrame (или Series) **objs** вдоль оси **axis**. Это не слияние по ключу, а склейка: таблицы ставятся друг под друга или рядом.

- **axis=0** (по умолчанию) — объединение **по строкам** (столбцы с одинаковыми именами выстраиваются в один столбец). Если у таблиц разный набор столбцов, при **join='outer'** в результате будут все столбцы, недостающие заполняются NaN; **join='inner'** — только общие столбцы.
- **axis=1** — объединение **по столбцам**: таблицы ставятся рядом; индексы выравниваются по меткам (по умолчанию join='outer'). Если индексы не совпадают, в «чужих» ячейках будет NaN.

**ignore_index=True** — после объединения по axis=0 индекс пересоздаётся как 0, 1, 2, … (удобно, когда исходные индексы не нужны).

```python
df1 = pd.DataFrame({"a": [1, 2], "b": [3, 4]})
df2 = pd.DataFrame({"a": [5, 6], "b": [7, 8]})
pd.concat([df1, df2], axis=0, ignore_index=True)
#    a  b
# 0  1  3
# 1  2  4
# 2  5  7
# 3  6  8

pd.concat([df1, df2], axis=1)  # столбцы рядом; индексы 0,1 общие — 4 столбца a, b, a, b
```

Один объект в списке: **pd.concat([df])** возвращает копию df; concat полезен для объединения нескольких загруженных файлов или результатов фильтрации в одну таблицу.

---

## Ключевое

- **pd.merge(left, right, on=..., how=...)** — слияние двух DataFrame по ключу (столбцу с общими значениями). **on** — имя(а) столбца ключа; при разных именах — **left_on**, **right_on**.
- **how**: **'inner'** — только совпадающие ключи; **'left'** — все строки left, правые подставляются или NaN; **'right'** — все строки right; **'outer'** — все ключи из обеих таблиц.
- **pd.concat([df1, df2, ...], axis=0)** — склейка по строкам (таблицы друг под другом); **axis=1** — по столбцам (рядом). **ignore_index=True** — сбросить индекс после объединения по строкам; **join='outer'/'inner'** — какие столбцы/индексы сохранять.
