# §5.3 DataFrame в PySpark

В [§5.2](chapter-05-02.md) мы разобрали SparkSession — точку входа к чтению данных и SQL. Все данные в PySpark для табличных операций представлены как **DataFrame**. В этом разделе рассмотрим **создание DataFrame** в PySpark: из списка словарей (createDataFrame) и из файла (spark.read), а также первые операции: **просмотр схемы** (printSchema), **просмотр данных** (show), **выбор столбцов** (select) и **фильтрация** (filter / where). Детали чтения из разных форматов и все варианты select и filter — в главе 6; здесь — минимальный набор для старта. В [§5.4](chapter-05-04.md) сравним PySpark DataFrame с Pandas. См. [Глоссарий](glossary.md).

---

## 5.3.1. Создание из списка словарей

Для небольших данных или тестов DataFrame можно создать из **коллекции** в памяти драйвера. Список словарей с одинаковыми ключами передаётся в **spark.createDataFrame()**:

```python
data = [
    {"name": "Alice", "age": 30, "city": "Moscow"},
    {"name": "Bob", "age": 25, "city": "SPb"},
]
df = spark.createDataFrame(data)
```

Имена ключей становятся именами столбцов; типы выводятся из значений (целые — integer, строки — string и т.д.). Если во всех строках какое-то поле отсутствует, в схеме оно будет помечено как nullable; при выводе типов по первым строкам возможны неточности (например, смесь типов в одном столбце). Для полного контроля над схемой можно передать второй аргумент — схему (StructType). См. [§3.2](chapter-03-02.md), [§6.1](chapter-06-01.md).

## 5.3.2. Создание из файла

Самый частый способ получить DataFrame — **прочитать** данные из хранилища через **spark.read**:

```python
df = spark.read.parquet("/path/to/data")
# или
df = spark.read.csv("/path/to/file.csv", header=True, inferSchema=True)
```

Формат (parquet, csv, json и т.д.) и опции (header, inferSchema, sep для CSV) определяют схему и способ разбора. Чтение **ленивое**: данные не загружаются до вызова действия (show, count, write и т.д.). Подробнее форматы и опции — в [§6.1](chapter-06-01.md) и [§4.1](chapter-04-01.md). См. [Глоссарий](glossary.md).

---

## 5.3.3. Просмотр схемы: printSchema()

Чтобы увидеть **схему** DataFrame — имена и типы столбцов — используется метод **printSchema()**:

```python
df.printSchema()
```

Вывод в консоль в виде дерева: для каждого столбца указывается имя и тип (например, `-- name: string`, `-- age: long`). Вложенные структуры (struct, array) отображаются с отступом. Это помогает проверить, что данные прочитаны с ожидаемыми типами, и подобрать правильные имена столбцов для select и filter. См. [§3.1](chapter-03-01.md), [Глоссарий](glossary.md).

---

## 5.3.4. Просмотр данных: show()

Метод **show(n, truncate)** выводит в консоль **первые n строк** (по умолчанию 20) в табличном виде. Это **действие**: оно запускает выполнение плана до момента, когда получено n строк.

```python
df.show()       # первые 20 строк
df.show(5)      # первые 5 строк
df.show(5, truncate=False)  # без обрезки длинных строк
```

Для отладки и быстрой проверки данных show удобнее, чем collect(): не загружает все данные на драйвер. См. [§2.4](chapter-02-04.md), [Глоссарий](glossary.md).

---

## 5.3.5. Выбор столбцов: select()

Метод **select()** задаёт **проекцию** — какие столбцы оставить и в каком порядке. В PySpark столбцы можно указывать строками (именами) или через **col()** из `pyspark.sql.functions`:

```python
from pyspark.sql.functions import col

df.select("name", "age").show()
df.select(col("name"), col("age").alias("user_age")).show()
```

В select можно передавать не только имена столбцов, но и выражения (col("age") + 1, функции и т.д.); подробнее — в [§6.2](chapter-06-02.md). select возвращает **новый** DataFrame; исходный не изменяется. См. [Глоссарий](glossary.md).

---

## 5.3.6. Фильтрация: filter() и where()

Методы **filter()** и **where()** эквивалентны: они оставляют только строки, удовлетворяющие **условию**. Условие задаётся выражением над столбцами:

```python
df.filter(col("age") > 25).show()
df.where(col("city") == "Moscow").show()
df.filter((col("age") >= 18) & (col("city").isNotNull())).show()
```

Сравнения и логические операторы (==, !=, <, >, &, |, ~) применяются к столбцам через col(); для проверки на null используется **isNull()** / **isNotNull()**. filter и where возвращают новый DataFrame; выполнение — при вызове действия. См. [§2.4](chapter-02-04.md), [§6.2](chapter-06-02.md), [Глоссарий](glossary.md).

---

## 5.3.7. Цепочка преобразований

Методы DataFrame возвращают новый DataFrame, поэтому вызовы можно объединять в **цепочку**:

```python
result = df.select("name", "age", "city") \
    .filter(col("age") >= 18) \
    .filter(col("city").isNotNull())
result.show()
```

Логический план строится на драйвере; выполнение произойдёт при вызове show() (или другого действия). Такой стиль типичен для пайплайнов: чтение → выборка → фильтрация → дальнейшие шаги (агрегация, запись) — в [§6.1](chapter-06-01.md)–[§6.4](chapter-06-04.md) и главе 7. См. [§2.2](chapter-02-02.md), [§2.4](chapter-02-04.md).

---

## Ключевое

- **Создание DataFrame:** из коллекции — `spark.createDataFrame(list_of_dicts)`; из файла — `spark.read.parquet(path)`, `spark.read.csv(path, header=True, inferSchema=True)` и т.д.; чтение ленивое.
- **Схема:** `df.printSchema()` выводит имена и типы столбцов; полезна для проверки после чтения.
- **Просмотр данных:** `df.show(n)` — первые n строк в консоль (действие); для отладки предпочтительнее collect() при больших данных.
- **Выбор столбцов:** `df.select("col1", "col2")` или с col() и alias; возвращает новый DataFrame.
- **Фильтрация:** `df.filter(условие)` и `df.where(условие)`; условие — выражение с col(); цепочки select и filter формируют пайплайн до вызова действия.
