# §13.3 Рекурсивные CTE

В [§13.2](chapter-13-02.md) мы рассмотрели использование CTE для читаемости. С модификатором **RECURSIVE** CTE может ссылаться на свой собственный результат — это даёт рекурсивные запросы для иерархий, последовательностей и графов. В этом разделе разберём структуру рекурсивного CTE, базовый и рекурсивный члены, примеры с числами и иерархией. CTE с изменением данных — в [§13.4](chapter-13-04.md). См. [документацию WITH Queries](https://www.postgresql.org/docs/current/queries-with.html).

---

## 13.3.1. Синтаксис RECURSIVE

```sql
WITH RECURSIVE имя(столбцы) AS (
  -- Базовый (нерекурсивный) член — исходные строки
  SELECT ...
  UNION [ALL]
  -- Рекурсивный член — ссылается на имя
  SELECT ... FROM имя ...
)
SELECT ... FROM имя ...;
```

Рекурсивный CTE состоит из двух частей, объединённых **UNION** или **UNION ALL**:

1. **Базовый член** — нерекурсивный SELECT, задаёт начальный набор строк.
2. **Рекурсивный член** — SELECT, в FROM которого используется само имя CTE. Он выполняется повторно, каждый раз получая на вход результат предыдущей итерации.

Выполнение идёт так: сначала вычисляется базовый член, затем рекурсивный — с подстановкой накопленного результата вместо ссылки на CTE. Цикл повторяется, пока рекурсивный член не вернёт пустой результат. Подробнее — в [документации](https://www.postgresql.org/docs/current/queries-with.html#QUERIES-WITH-RECURSIVE).

---

## 13.3.2. Пример: последовательность чисел

По [примеру из документации](https://www.postgresql.org/docs/current/queries-with.html): сумма целых от 1 до 100:

```sql
WITH RECURSIVE t(n) AS (
  SELECT 1
  UNION ALL
  SELECT n + 1 FROM t WHERE n < 100
)
SELECT sum(n) FROM t;
```

Базовый член: одна строка со значением 1. Рекурсивный: берёт текущие строки из `t`, добавляет 1 к `n`, отбирает только `n < 100`. Итерации: 1, затем 2, 3, ..., 100. При `n = 100` условие `n < 100` не выполняется — рекурсия останавливается. Результат: 5050.

## 13.3.3. Пример: иерархия (дерево)

Типичная задача — обход иерархии (подчинённые, части изделия, категории). Таблица с родительской связью:

```sql
-- Пример: employees(id, name, manager_id)
WITH RECURSIVE hierarchy AS (
  -- Базовый член: корень (например, руководитель без начальника)
  SELECT id, name, manager_id, 1 AS level
  FROM employees
  WHERE manager_id IS NULL
  UNION ALL
  -- Рекурсивный: подчинённые текущего уровня
  SELECT e.id, e.name, e.manager_id, h.level + 1
  FROM employees e
  JOIN hierarchy h ON e.manager_id = h.id
)
SELECT * FROM hierarchy ORDER BY level, id;
```

Базовый член — сотрудники без начальника (верхний уровень). Рекурсивный — сотрудники, чей `manager_id` совпадает с `id` кого-то из уже полученных. Каждая итерация добавляет следующий уровень. `level` — глубина в дереве.

## 13.3.4. Условие остановки

Рекурсия прекращается, когда рекурсивный член **не возвращает строк**. Важно задать условие в WHERE, иначе возможен бесконечный цикл.

В примере с числами условие — `WHERE n < 100`. В иерархии — естественная остановка, когда нет новых подчинённых (JOIN не даёт строк). В графах с циклами нужна дополнительная проверка (например, массив посещённых узлов); см. [документацию по обнаружению циклов](https://www.postgresql.org/docs/current/queries-with.html#QUERIES-WITH-CYCLE).

---

## 13.3.5. UNION и UNION ALL

- **UNION ALL** — все строки от всех итераций сохраняются; для последовательностей и деревьев обычно используют его.
- **UNION** — дубликаты отбрасываются; может понадобиться при обходе графов, чтобы не зацикливаться на повторных узлах.

Для иерархии без циклов (дерево) чаще достаточно UNION ALL.

---

## Ключевое

- **WITH RECURSIVE** — CTE, которое ссылается на само себя.
- Структура: базовый член UNION [ALL] рекурсивный член; рекурсивный ссылается на имя CTE.
- Выполнение: сначала базовый член, затем итерации рекурсивного до пустого результата.
- Типичные задачи: последовательности чисел, обход иерархий (деревья).
- Обязательно условие остановки в рекурсивном члене, иначе возможен бесконечный цикл.

В [§13.4](chapter-13-04.md) рассмотрим INSERT, UPDATE, DELETE в WITH и использование RETURNING с CTE.
