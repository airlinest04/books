# Глоссарий

Термины SQL и PostgreSQL, используемые в книге.

---

## A

**Агрегатная функция (aggregate function)** — функция, вычисляющая одно значение из набора строк: COUNT, SUM, AVG, MIN, MAX и др. См. [§7.1](chapter-07-01.md), гл. 7.

**AVG** — агрегатная функция; возвращает среднее арифметическое. Игнорирует NULL. См. [§7.1](chapter-07-01.md).

**autocommit** — режим работы клиента, при котором каждая SQL-команда выполняется как отдельная транзакция и сразу подтверждается; по умолчанию включён в psql и большинстве клиентов. См. [§6.4](chapter-06-04.md).

---

## P

**PostgreSQL** — свободная объектно-реляционная СУБД с открытым исходным кодом. Поддерживает стандарт SQL, расширяема, работает на множестве платформ. См. [§1.2](chapter-01-02.md).

**PRIMARY KEY** — ограничение, задающее уникальный идентификатор строки; эквивалентно UNIQUE NOT NULL. См. [§2.3](chapter-02-03.md).

**psql** — консольный интерактивный клиент PostgreSQL для выполнения SQL-запросов и администрирования. Входит в состав пакетов PostgreSQL. См. [§1.2](chapter-01-02.md), [§1.3](chapter-01-03.md).

**pgAdmin** — графический инструмент администрирования и разработки для PostgreSQL. Часто поставляется вместе с установщиком. См. [§1.2](chapter-01-02.md).

---

## К

**Клиент-серверная архитектура** — модель, при которой сервер (процесс PostgreSQL) принимает подключения и выполняет запросы, а клиент (psql, приложение, GUI) подключается к серверу и отправляет SQL. См. [§1.2](chapter-01-02.md).

---

## С

**Схема (schema)** — пространство имён внутри базы данных; содержит таблицы, представления, функции и другие объекты. В одной схеме имена объектов не должны повторяться; в разных схемах могут. По умолчанию используется схема `public`. См. [§1.3](chapter-01-03.md).

**Столбец (column)** — именованное поле таблицы с заданным типом данных; каждая строка содержит одно значение для каждого столбца. См. [§2.1](chapter-02-01.md).

**CREATE VIEW** — SQL-команда создания представления; сохраняет запрос как именованный объект, к которому обращаются как к таблице. См. [§6.6](chapter-06-06.md).

**search_path** — список схем, в которых PostgreSQL ищет объекты при неполном имени; первая схема в списке — текущая, в неё создаются новые объекты по умолчанию. См. [§1.3](chapter-01-03.md).

**Ссылочная целостность (referential integrity)** — свойство данных, при котором внешние ключи ссылаются только на существующие строки. Обеспечивается ограничением FOREIGN KEY. См. [§2.3](chapter-02-03.md).

---

## S

**SELECT** — SQL-команда выборки данных из таблиц и представлений. Минимальная форма: `SELECT * FROM таблица`. См. [§1.4](chapter-01-04.md), гл. 3–5.

**SUM** — агрегатная функция; возвращает сумму значений. Игнорирует NULL. См. [§7.1](chapter-07-01.md).

---

## Т

**Таблица (table)** — объект хранения данных в реляционной СУБД; состоит из столбцов (с именами и типами) и строк. См. [§2.1](chapter-02-01.md).

**CREATE TABLE** — SQL-команда создания таблицы; задаёт имя, столбцы и их типы данных. См. [§2.1](chapter-02-01.md).

**ALTER TABLE** — SQL-команда изменения структуры таблицы: добавление и удаление столбцов, переименование, изменение типа и ограничений. См. [§2.4](chapter-02-04.md).

**DROP TABLE** — SQL-команда удаления таблицы и всех её данных. См. [§2.1](chapter-02-01.md).

**DROP VIEW** — SQL-команда удаления представления. См. [§6.6](chapter-06-06.md).

**Тип данных (data type)** — описание допустимых значений столбца и операций над ними (integer, text, date, boolean и др.). См. [§2.2](chapter-02-02.md).

---

## О

**Оконная функция (window function)** — функция с предложением OVER; вычисляет значение по набору строк (окну), связанному с текущей строкой; строки не свёртываются, в отличие от GROUP BY. См. гл. 12.

**Ограничение (constraint)** — правило целостности для столбца или таблицы (NOT NULL, UNIQUE, PRIMARY KEY, CHECK, FOREIGN KEY). См. [§2.3](chapter-02-03.md).

---

## П

**PARTITION BY** — предложение OVER в оконной функции; разбивает строки на партиции (группы) по значениям выражений; функция вычисляется по партиции текущей строки. См. [§12.2](chapter-12-02.md).

**Подзапрос (subquery)** — запрос, вложенный в другой; может использоваться в FROM, WHERE, SELECT. Альтернатива JOIN для получения связанных данных и проверки существования. См. [§4.4](chapter-04-04.md), гл. 9.

**Представление (view)** — сохранённый SELECT-запрос; при обращении выполняется заново, данные не хранятся. Используется как виртуальная таблица. См. [§6.6](chapter-06-06.md).

**Псевдоним (alias)** — альтернативное имя для столбца или таблицы в результате запроса; задаётся через AS. См. [§3.1](chapter-03-01.md).

---

## R

**READ COMMITTED** — уровень изоляции транзакций по умолчанию в PostgreSQL; каждая команда видит данные на момент своего начала; грязное чтение невозможно. См. [§11.2](chapter-11-02.md).

**RETURNING** — предложение INSERT, UPDATE, DELETE, MERGE; возвращает затронутые строки (вставленные, обновлённые или удалённые). См. [§6.1](chapter-06-01.md), [§6.2](chapter-06-02.md), [§6.3](chapter-06-03.md).

**ROLLBACK** — SQL-команда отмены транзакции; все изменения, сделанные после BEGIN, отменяются. См. [§6.4](chapter-06-04.md), гл. 11.

---

## G

**GROUP BY** — предложение SELECT, задающее группировку строк; строки с одинаковыми значениями объединяются, агрегаты вычисляются по каждой группе. См. [§7.2](chapter-07-02.md).

---

## F

**FETCH FIRST ... ROWS ONLY** — стандартный SQL-синтаксис ограничения числа строк; эквивалентен LIMIT. Поддерживает WITH TIES. См. [§5.3](chapter-05-03.md).

**FILTER** — опция агрегатной функции; ограничивает строки, участвующие в расчёте: `count(*) FILTER (WHERE условие)`. См. [§7.1](chapter-07-01.md).

**FOREIGN KEY (внешний ключ)** — ограничение, связывающее столбец со столбцом другой таблицы; обеспечивает ссылочную целостность. См. [§2.3](chapter-02-03.md).

---

## H

**HAVING** — предложение SELECT; отбирает группы после GROUP BY. Позволяет фильтровать по результатам агрегации (count, sum и т.д.) и по столбцам групп. См. [§7.3](chapter-07-03.md).

---

## J

**JOIN (соединение)** — объединение строк из нескольких таблиц по условию; позволяет получать связанные данные в одном запросе. Виды: INNER JOIN, LEFT/RIGHT/FULL OUTER JOIN, CROSS JOIN. См. гл. 4.

**INNER JOIN** — соединение, возвращающее только строки с совпадением в обеих таблицах по условию ON или USING. См. [§4.2](chapter-04-02.md).

**LEFT JOIN (LEFT OUTER JOIN)** — соединение, возвращающее все строки левой таблицы и совпадения из правой; при отсутствии совпадения столбцы правой таблицы — NULL. См. [§4.3](chapter-04-03.md).

**Self-join** — соединение таблицы с собой; одна таблица участвует в FROM дважды под разными псевдонимами. Используется для иерархий, пар строк и сравнений внутри таблицы. См. [§4.5](chapter-04-05.md).

**jsonb** — бинарное представление JSON в PostgreSQL; удобен для запросов и индексирования. См. [§2.2](chapter-02-02.md).

---

## N

**numeric** — точный числовой тип с заданной точностью и масштабом; рекомендуется для денежных сумм. См. [§2.2](chapter-02-02.md).

---

## O

**OFFSET** — предложение SELECT, пропускающее заданное число строк в начале результата; используется с LIMIT для пейджинга. См. [§5.2](chapter-05-02.md).

**ON CONFLICT** — предложение INSERT; задаёт действие при нарушении уникальности (DO UPDATE или DO NOTHING); реализует UPSERT. См. [§6.5](chapter-06-05.md).

**ORDER BY** — предложение SELECT, задающее порядок вывода строк; поддерживает ASC, DESC, NULLS FIRST, NULLS LAST. См. [§5.1](chapter-05-01.md).

**OVER** — предложение оконной функции; задаёт окно (PARTITION BY, ORDER BY, рамку) для расчёта. См. [§12.1](chapter-12-01.md), [§12.2](chapter-12-02.md).

---

## В

**Вложенная агрегация** — вычисление агрегата от результата другого агрегата (например, max(count(*))); на одном уровне запроса запрещена; выполняется через подзапрос в FROM или CTE. См. [§8.3](chapter-08-03.md), [§9.3](chapter-09-03.md).

**Выражение (expression)** — комбинация констант, столбцов, операторов и функций, дающая одно значение. Может использоваться в SELECT, WHERE, ORDER BY и др. См. [§3.2](chapter-03-02.md).

---

## E

**EXCEPT** — оператор разности множеств: возвращает строки из первого запроса, которых нет во втором. EXCEPT ALL вычитает вхождения. Порядок запросов важен. См. [§10.3](chapter-10-03.md).

**EXCLUDED** — специальная таблица в предложении ON CONFLICT DO UPDATE; содержит строку, которую пытались вставить; используется для ссылки на её столбцы при обновлении. См. [§6.5](chapter-06-05.md).

**EXISTS** — предикат проверки существования строк в подзапросе; возвращает TRUE, если подзапрос вернул хотя бы одну строку. См. [§9.2](chapter-09-02.md).

---

## I

**INSERT** — SQL-команда добавления новых строк в таблицу; поддерживает VALUES, DEFAULT, INSERT ... SELECT, ON CONFLICT, RETURNING. См. [§6.1](chapter-06-01.md), [§6.5](chapter-06-05.md).

**interval** — тип данных для интервала времени; используется в арифметике с датами. Пример: `interval '7 days'`. См. [§3.2](chapter-03-02.md).

**IN** — предикат проверки принадлежности значения списку или результату подзапроса. См. [§3.3](chapter-03-03.md).

**INTERSECT** — оператор пересечения: возвращает только строки, присутствующие в обоих запросах. INTERSECT ALL сохраняет дубликаты по минимуму вхождений. См. [§10.2](chapter-10-02.md).

---

## C

**CTE (Common Table Expression, обобщённое табличное выражение)** — именованный подзапрос в предложении WITH в начале запроса; результат используется как временная таблица в основном запросе. См. гл. 13.

**COPY** — SQL-команда массовой загрузки (FROM) и выгрузки (TO) данных между таблицей и файлом; поддерживает форматы text, CSV, binary. Для файлов на стороне клиента — мета-команда `\copy` в psql. См. [§6.7](chapter-06-07.md).

**COUNT** — агрегатная функция: COUNT(*) — число строк, COUNT(выражение) — число непустых значений. См. [§7.1](chapter-07-01.md).

**COALESCE** — функция, возвращающая первый аргумент, отличный от NULL; используется для подстановки значения вместо NULL. См. [§3.2](chapter-03-02.md).

**COMMIT** — SQL-команда подтверждения транзакции; все изменения, сделанные после BEGIN, становятся постоянными. См. [§6.4](chapter-06-04.md), гл. 11.

**concat** — функция объединения строк; приводит аргументы к тексту и объединяет их; NULL-аргументы пропускаются. См. [§3.2](chapter-03-02.md).

---

## W

**WHERE** — предложение SELECT, задающее условие фильтрации строк; в результат попадают только строки, для которых условие даёт TRUE. См. [§3.3](chapter-03-03.md).

**WITH CHECK OPTION** — предложение CREATE VIEW; запрещает INSERT и UPDATE, создающие строки, невидимые через представление (не удовлетворяющие его WHERE). LOCAL — только своё условие, CASCADED — все вложенные. См. [§6.6](chapter-06-06.md).

---

## L

**LIMIT** — предложение SELECT, ограничивающее число возвращаемых строк. См. [§5.2](chapter-05-02.md).

**LIKE** — оператор поиска по шаблону; `%` — любая последовательность символов, `_` — ровно один символ. См. [§3.3](chapter-03-03.md).

**ILIKE** — расширение PostgreSQL; аналог LIKE без учёта регистра. См. [§3.3](chapter-03-03.md).

---

## M

**MERGE** — SQL-команда условной вставки, обновления и удаления; соединяет источник с целевой таблицей и выполняет действия по веткам WHEN MATCHED, WHEN NOT MATCHED [BY TARGET], WHEN NOT MATCHED BY SOURCE. PostgreSQL 15+. См. [§6.5](chapter-06-05.md).

**MAX** — агрегатная функция; возвращает максимальное значение. Игнорирует NULL. См. [§7.1](chapter-07-01.md).

**MIN** — агрегатная функция; возвращает минимальное значение. Игнорирует NULL. См. [§7.1](chapter-07-01.md).

**Материализованное представление (materialized view)** — представление с физическим хранением результата запроса; обновляется командой REFRESH MATERIALIZED VIEW. См. [§6.6](chapter-06-06.md).

---

## B

**BETWEEN** — предикат проверки вхождения значения в диапазон (границы включены). См. [§3.3](chapter-03-03.md).

**BEGIN** — SQL-команда начала транзакции; последующие команды выполняются в одной транзакции до COMMIT или ROLLBACK. См. [§6.4](chapter-06-04.md), гл. 11.

---

## D

**DELETE** — SQL-команда удаления строк из таблицы. См. [§6.3](chapter-06-03.md).

**DISTINCT** — ключевое слово SELECT, устраняющее дубликаты строк в результате; строки считаются одинаковыми, если совпадают значения всех столбцов в списке SELECT. См. [§3.4](chapter-03-04.md).

**DISTINCT ON** — расширение PostgreSQL; оставляет по одной строке для каждой уникальной комбинации указанных выражений; какая строка остаётся, задаётся ORDER BY. См. [§3.4](chapter-03-04.md).

---

## T

**Транзакция (transaction)** — логическая единица работы; группа SQL-команд выполняется атомарно: либо все изменения применяются (COMMIT), либо все отменяются (ROLLBACK). См. [§6.4](chapter-06-04.md), гл. 11.

**timestamptz** — дата и время с учётом часового пояса; хранится в UTC, отображается в часовом поясе сессии. См. [§2.2](chapter-02-02.md).

---

## U

**UNION** — оператор объединения результатов двух или более SELECT в один набор строк; устраняет дубликаты. UNION ALL сохраняет все строки. См. [§10.1](chapter-10-01.md).

**UPDATE** — SQL-команда изменения значений столбцов в существующих строках таблицы. См. [§6.2](chapter-06-02.md).

**UPSERT** — стратегия «вставить или обновить»: при наличии строки по уникальному ключу — обновить, при отсутствии — вставить. В PostgreSQL: MERGE или INSERT ... ON CONFLICT. См. [§6.5](chapter-06-05.md).
