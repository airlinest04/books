# §10.2 INTERSECT

В [§10.1](chapter-10-01.md) мы рассмотрели UNION — объединение результатов запросов. **INTERSECT** возвращает только те строки, которые есть **в обоих** результатах — пересечение множеств. Требования к столбцам те же: одинаковое число, совместимые типы. В этом разделе разберём синтаксис, INTERSECT и INTERSECT ALL, а также типичные сценарии. EXCEPT — в [§10.3](chapter-10-03.md). См. [документацию SELECT](https://www.postgresql.org/docs/current/sql-select.html).

---

## 10.2.1. Синтаксис

```sql
запрос1
INTERSECT [ALL]
запрос2
[ORDER BY ...]
[LIMIT ...];
```

Результат — строки, присутствующие и в `запрос1`, и в `запрос2`. Имена столбцов берутся из первого запроса. Правила совместимости столбцов те же, что у UNION.

---

## 10.2.2. INTERSECT и INTERSECT ALL

- **INTERSECT** (эквивалентно INTERSECT DISTINCT) — каждая строка в результате встречается **один раз**, дубликаты устраняются.
- **INTERSECT ALL** — сохраняет дубликаты. Количество экземпляров каждой строки равно **минимуму** из того, сколько раз она встречается в первом и во втором запросе.

Пример: клиенты, которые были и покупателями, и возвращали товар (есть в обеих таблицах):

```sql
SELECT customer_id FROM orders
INTERSECT
SELECT customer_id FROM refunds;
```

Только те `customer_id`, которые есть в `orders` и в `refunds`. Каждый id — один раз.

---

## 10.2.3. Сравнение с JOIN

INTERSECT и INNER JOIN по всем столбцам дают схожий результат, но:

- INTERSECT работает с **набором столбцов** — сравниваются целые строки. JOIN соединяет по условию и может удваивать столбцы.
- INTERSECT автоматически убирает дубликаты (без ALL). При JOIN дубликаты могут появиться, если совпадений несколько.
- Для одной колонки `INTERSECT` эквивалентен `IN (подзапрос)` при отборе по вхождению в множество.

Пример через подзапрос с IN:

```sql
-- Через INTERSECT:
SELECT customer_id FROM orders
INTERSECT
SELECT customer_id FROM refunds;

-- Через IN (для одной колонки):
SELECT DISTINCT customer_id FROM orders
WHERE customer_id IN (SELECT customer_id FROM refunds);
```

INTERSECT короче и явно выражает идею пересечения.

---

## 10.2.4. Пример: общие категории

Найти категории, в которых есть и дорогие товары (цена > 1000), и дешёвые (цена < 100):

```sql
SELECT category_id FROM products WHERE price > 1000
INTERSECT
SELECT category_id FROM products WHERE price < 100;
```

Результат — категории с разбросом цен. Каждая категория в результате — один раз.

---

## Ключевое

- **INTERSECT** возвращает строки, присутствующие в обоих запросах — пересечение множеств.
- INTERSECT устраняет дубликаты; **INTERSECT ALL** оставляет количество экземпляров, равное минимуму вхождений в каждом запросе.
- Требования к столбцам те же, что у UNION: одинаковое число, совместимые типы.
- Для одной колонки можно заменить подзапросом с IN, но INTERSECT часто нагляднее.

В [§10.3](chapter-10-03.md) рассмотрим EXCEPT — разность множеств.
