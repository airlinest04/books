# §12.3 Ранжирование

В [§12.2](chapter-12-02.md) мы рассмотрели синтаксис OVER. Функции **ранжирования** присваивают строкам номера или ранги в порядке, заданном ORDER BY внутри окна. В этом разделе разберём ROW_NUMBER, RANK, DENSE_RANK и NTILE. Смещение (LAG, LEAD) — в [§12.4](chapter-12-04.md). См. [документацию Window Functions](https://www.postgresql.org/docs/current/functions-window.html).

---

## 12.3.1. ROW_NUMBER

**ROW_NUMBER()** присваивает последовательный номер каждой строке в партиции (1, 2, 3, ...). Порядок задаётся ORDER BY в OVER. При равных значениях в ORDER BY номера различаются, но порядок среди равных не гарантирован.

```sql
SELECT depname, empno, salary,
  row_number() OVER (PARTITION BY depname ORDER BY salary DESC) AS rn
FROM empsalary;
```

В каждом отделе первая по убыванию зарплаты строка получает 1, вторая — 2 и т.д. При одинаковой зарплате у двух строк будут разные номера (например, 2 и 3), но кто получит 2, а кто 3 — не определено.

---

## 12.3.2. RANK и DENSE_RANK

**RANK()** — ранг с «дырами»: строки с одинаковыми значениями ORDER BY получают один ранг, следующая за ними — ранг с учётом пропусков.

**DENSE_RANK()** — ранг без пропусков: одинаковые значения — один ранг, следующие идут подряд.

Пример: зарплаты 6000, 5200, 5200, 4500:

| salary | ROW_NUMBER | RANK | DENSE_RANK |
|--------|------------|------|------------|
| 6000   | 1          | 1    | 1          |
| 5200   | 2          | 2    | 2          |
| 5200   | 3          | 2    | 2          |
| 4500   | 4          | 4    | 3          |

RANK пропускает 3; DENSE_RANK даёт 3.

```sql
SELECT depname, empno, salary,
  rank() OVER (PARTITION BY depname ORDER BY salary DESC) AS rk,
  dense_rank() OVER (PARTITION BY depname ORDER BY salary DESC) AS drk
FROM empsalary;
```

---

## 12.3.3. NTILE

**NTILE(n)** разбивает партицию на **n** групп (корзин) и возвращает номер группы (от 1 до n) для каждой строки. Распределение по возможности равное; при делении с остатком первые корзины получают по одной строке больше.

```sql
SELECT depname, empno, salary,
  ntile(3) OVER (PARTITION BY depname ORDER BY salary DESC) AS third
FROM empsalary;
```

В каждом отделе строки делятся на три группы (например, «верхняя треть», «средняя», «нижняя») по убыванию зарплаты.

---

## 12.3.4. Топ-N по группе

Типичное применение: взять N первых строк в каждой партиции. Подзапрос с ROW_NUMBER и фильтром:

```sql
SELECT depname, empno, salary, rn
FROM (
  SELECT depname, empno, salary,
    row_number() OVER (PARTITION BY depname ORDER BY salary DESC) AS rn
  FROM empsalary
) sub
WHERE rn <= 2;
```

Результат — два самых высокооплачиваемых сотрудника в каждом отделе. ROW_NUMBER используется, потому что при равенстве зарплат нужна однозначная выборка (без дубликатов); для «топ-2 с возможными ничьими» можно взять RANK или DENSE_RANK и условие `rk <= 2` или `drk <= 2`.

---

## Ключевое

- **ROW_NUMBER** — последовательный номер (1, 2, 3, ...); при равенстве номера разные.
- **RANK** — ранг с пропусками; равные — один ранг, следующая строка — с учётом пропуска.
- **DENSE_RANK** — ранг без пропусков; равные — один ранг, следующие подряд.
- **NTILE(n)** — разбиение партиции на n корзин, возвращается номер корзины.
- Для ранжирования в OVER обязателен ORDER BY. Топ-N по группе — подзапрос с фильтром по номеру/рангу.

В [§12.4](chapter-12-04.md) рассмотрим LAG, LEAD и FIRST_VALUE, LAST_VALUE — доступ к соседним строкам.
