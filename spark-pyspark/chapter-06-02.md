# §6.2 Выборка и фильтрация

В [§6.1](chapter-06-01.md) мы разобрали чтение данных в PySpark: форматы, опции и пути. Полученный DataFrame обычно подвергают **выборке столбцов** и **фильтрации строк** перед агрегацией или записью. В этом разделе рассмотрим методы **select()**, **filter()** / **where()**, **withColumn()**, **withColumnRenamed()** и **drop()** — основные инструменты для проекции и отбора данных. Выражения строятся с помощью **col()** и функций из **pyspark.sql.functions**. В [§6.3](chapter-06-03.md) перейдём к типам данных и приведению (cast). См. [Глоссарий](glossary.md).

---

## 6.2.1. select(): выбор столбцов и выражений

Метод **select()** задаёт **проекцию**: какие столбцы или выражения войдут в результат и под какими именами. Столбцы можно указывать строками (именами) или через **col()** из `pyspark.sql.functions`. См. [§5.3](chapter-05-03.md), [Глоссарий](glossary.md).

```python
from pyspark.sql.functions import col

# Только имена столбцов
df.select("name", "age", "city").show()

# С переименованием через alias
df.select(col("name"), col("age").alias("user_age")).show()

# Выражения: новый столбец как результат вычисления
df.select("name", col("age") + 1, col("city")).show()
```

В **select** можно передавать:
- строки — имена столбцов;
- **col("name")** — ссылка на столбец для использования в выражениях и **alias("new_name")** для переименования в результате;
- выражения из столбцов и функций: **col("a") + col("b")**, **upper(col("name"))**, **when(col("x") > 0, 1).otherwise(0)** и т.д.

Выбор **всех столбцов** с добавлением или заменой одного: **df.select("*", (col("a") + col("b")).alias("sum_ab"))**. select возвращает новый DataFrame; число строк не меняется (если не использованы агрегаты в выражениях — агрегаты обычно применяют в groupBy, см. [§7.1](chapter-07-01.md)). См. [Глоссарий](glossary.md).

---

## 6.2.2. filter() и where(): условия на строки

Методы **filter()** и **where()** эквивалентны: оставляют только те строки, для которых **условие** истинно. Условие — логическое выражение над столбцами. См. [§5.3](chapter-05-03.md), [Глоссарий](glossary.md).

```python
df.filter(col("age") >= 18).show()
df.where(col("city").isNotNull()).show()
df.filter((col("age") > 25) & (col("city") == "Moscow")).show()
```

Операторы сравнения: **==**, **!=**, **<**, **>**, **<=**, **>=**. Для проверки на null: **col("x").isNull()**, **col("x").isNotNull()**. Логические связки: **&** (и), **|** (или), **~** (отрицание); скобки обязательны из-за приоритета операторов в Python. Для «значение в списке» можно использовать **col("x").isin("a", "b", "c")** или **col("x").isin(list_of_values)**. Для строк: **col("name").like("%John%")**, **col("name").startswith("A")**. filter и where возвращают новый DataFrame; выполнение — при вызове действия. См. [§2.4](chapter-02-04.md).

---

## 6.2.3. withColumn(): добавление или замена столбца

Метод **withColumn(name, expression)** добавляет новый столбец с заданным именем или **заменяет** существующий столбец с таким именем. Второй аргумент — выражение (Column), обычно выражение над другими столбцами или константа. См. [Глоссарий](glossary.md).

```python
from pyspark.sql.functions import lit

df = df.withColumn("age_next_year", col("age") + 1)
df = df.withColumn("is_adult", (col("age") >= 18).cast("boolean"))
df = df.withColumn("constant_col", lit(1))
```

**lit(value)** создаёт константный столбец. Если столбец с именем name уже есть, withColumn(name, ...) перезапишет его. withColumn возвращает новый DataFrame; исходный не изменяется (если не переприсвоить переменную, как в примерах). Для добавления нескольких столбцов вызывают withColumn несколько раз или используют цепочку. См. [§6.3](chapter-06-03.md) про cast.

---

## 6.2.4. withColumnRenamed(): переименование столбца

Метод **withColumnRenamed(existing, new)** возвращает DataFrame с переименованным столбцом: первый аргумент — текущее имя, второй — новое. См. [Глоссарий](glossary.md).

```python
df = df.withColumnRenamed("user_id", "id")
df = df.withColumnRenamed("date", "event_date")
```

Переименование не меняет данные; полезно для приведения имён к единому стилю или для совместимости со схемой при записи. Переименовать несколько столбцов можно цепочкой вызовов or через select с alias.

---

## 6.2.5. drop(): удаление столбцов

Метод **drop(*cols)** возвращает DataFrame без указанных столбцов. См. [Глоссарий](glossary.md).

```python
df = df.drop("temp_col")
df = df.drop("col1", "col2")
df = df.drop(col("col_name"))  # по объекту Column тоже допустимо в части версий
```

Имена передаются строками или через col. Если указать несуществующий столбец, в зависимости от опций может быть ошибка или игнорирование. drop не меняет исходный DataFrame без переприсвоения.

---

## 6.2.6. Цепочка и порядок операций

Все перечисленные методы возвращают новый DataFrame, поэтому их удобно объединять в **цепочку**:

```python
result = df.select("user_id", "event", "amount") \
    .withColumn("amount_vat", col("amount") * 1.2) \
    .filter(col("amount") > 0) \
    .withColumnRenamed("event", "event_type") \
    .drop("amount")
result.show()
```

Порядок вызовов определяет логический план; оптимизатор Catalyst может переупорядочивать часть операций (например, проталкивать фильтры). Для читаемости обычно сначала select (оставить нужные столбцы), затем withColumn (добавить производные), затем filter (отсечь строки), при необходимости переименование и drop. См. [§3.1](chapter-03-01.md), [§5.3](chapter-05-03.md).

---

## 6.2.7. selectExpr(): SQL-подобные выражения

Метод **selectExpr(*exprs)** принимает строки с SQL-подобными выражениями; каждая строка — один столбец результата. Удобно для сложных выражений в привычном SQL-виде. См. [Глоссарий](glossary.md).

```python
df.selectExpr("name", "age", "age + 1 as age_next", "upper(city) as city_upper").show()
```

Имена столбцов и функции (upper, lower, substr и т.д.) записываются как в SQL; алиас через **as**. Эквивалентную логику можно записать через select с col() и функциями из pyspark.sql.functions; selectExpr часто короче для простых случаев.

---

## Ключевое

- **select()** — проекция: имена столбцов, col() с alias, выражения (col("a") + col("b"), функции); возвращает новый DataFrame.
- **filter()** и **where()** — условие на строки; сравнения, isNull/isNotNull, &, |, ~; скобки для составных условий.
- **withColumn(name, expr)** — добавить или заменить столбец; выражение через col() и функции; lit() для констант.
- **withColumnRenamed(existing, new)** — переименование одного столбца.
- **drop(*cols)** — удалить один или несколько столбцов.
- **selectExpr("expr as alias", ...)** — выбор через SQL-подобные строки; удобно для выражений и алиасов.
- Цепочка select → withColumn → filter → withColumnRenamed → drop формирует пайплайн до вызова действия.
