# §6.5 Обработка пропусков

В [§6.4](chapter-06-04.md) мы разобрали запись данных: режимы, партиционирование и форматы. Перед записью или агрегацией часто нужно решить, как поступить с **пропущенными значениями** (null): удалить строки с пропусками, заполнить их константой или производным значением. В PySpark доступ к операциям над пропусками даёт объект **df.na** (DataFrameNaFunctions): методы **fill()** и **drop()**. В этом разделе рассмотрим **na.fill()**, **na.drop()**, выбор подмножества столбцов и кратко — стратегии выбора (когда удалять, когда заполнять). В [§6.6](chapter-06-06.md) перейдём к кэшированию и партициям. См. [Глоссарий](glossary.md).

---

## 6.5.1. Пропуски (null) в Spark

В Spark SQL **null** обозначает отсутствие значения. Столбец может быть объявлен как nullable; при чтении из файлов пустые ячейки (или значения, заданные опцией nullValue) превращаются в null. В выражениях проверка на null — через **col("x").isNull()** и **col("x").isNotNull()**; сравнение с null даёт null (не true и не false), поэтому фильтр вида **col("x") == None** не отбирает строки с null — нужно явно isNull(). Агрегатные функции (sum, avg, count и т.д.) по умолчанию **игнорируют** null при расчёте. См. [§6.2](chapter-06-02.md), [§7.1](chapter-07-01.md).

---

## 6.5.2. na.fill(): замена null на значение

Метод **na.fill(value)** заменяет **null** во всех подходящих столбцах на указанное значение. См. [Глоссарий](glossary.md).

```python
# Одно значение для всех столбцов (тип должен подходить)
df = df.na.fill(0)           # числовые null → 0
df = df.na.fill("")          # строковые null → пустая строка
df = df.na.fill("unknown")   # строковые null → "unknown"

# Разные значения по столбцам: словарь {имя_столбца: значение}
df = df.na.fill({"city": "N/A", "age": 0, "amount": 0.0})
```

Тип значения должен быть совместим с типом столбца (число для числового столбца, строка для строкового и т.д.); иначе возможна ошибка или неожиданное приведение. fill возвращает новый DataFrame; исходный не изменяется. См. [§6.3](chapter-06-03.md).

---

## 6.5.3. na.drop(): удаление строк с null

Метод **na.drop()** удаляет строки, содержащие null. Без аргументов удаляются строки, у которых **хотя бы один** столбец равен null. См. [Глоссарий](glossary.md).

```python
# Удалить строки с null в любом столбце
df = df.na.drop()

# Удалить только если null в указанных столбцах
df = df.na.drop(subset=["city", "age"])

# how: "any" (хотя бы один null в subset) или "all" (все в subset — null)
df = df.na.drop(how="any", subset=["city"])   # строка удаляется, если city is null
df = df.na.drop(how="all", subset=["a", "b"]) # строка удаляется, если и a, и b null
```

**subset** — список имён столбцов; проверка на null только по ним. **how="any"** (по умолчанию) — удалить строку, если в subset есть null; **how="all"** — удалить только если во всех столбцах из subset значение null. drop возвращает новый DataFrame. См. [§6.2](chapter-06-02.md).

---

## 6.5.4. Стратегии: когда заполнять, когда удалять

Выбор между **fill** и **drop** (и в каких столбцах) зависит от смысла данных и целей анализа:

- **Удаление (drop):** когда пропуск означает «наблюдение неполное» и включать такие строки в агрегаты или модели нежелательно. Например, ключевые поля (id, дата) — если null, строку часто отбрасывают. Риск: при большом числе пропусков теряется много строк.
- **Заполнение (fill):** когда пропуск можно интерпретировать как «значение по умолчанию» (0 для счётчика, пустая строка для опционального поля, "N/A" для категории). Для числовых столбцов иногда заполняют средним или медианой (вычисленным отдельно через агрегат). Нельзя заполнять произвольными значениями без учёта смысла — это искажает статистику и модели.
- **Оставить null:** агрегаты (sum, avg, count) их игнорируют; в фильтрах нужно явно учитывать через isNull()/isNotNull() или coalesce. Для записи в целевые системы проверьте, допускает ли приёмник null в этих столбцах.

См. [§7.1](chapter-07-01.md).

---

## 6.5.5. Альтернатива: filter и withColumn

Ту же логику можно реализовать без na: **удаление** строк с null в заданных столбцах — через **filter(col("x").isNotNull())** (и при необходимости объединение условий для нескольких столбцов). **Заполнение** — через **when(col("x").isNull(), value).otherwise(col("x"))** в withColumn. Методы na.fill и na.drop удобны для массовой обработки по списку столбцов; для точечной логики (разные условия по столбцам, заполнение из другого столбца) часто используют filter и withColumn с when/otherwise. См. [§6.2](chapter-06-02.md).

## Ключевое

- В Spark **null** — отсутствие значения; проверка — isNull()/isNotNull(); в агрегатах null по умолчанию не участвуют.
- **na.fill(value)** — заменить null на значение во всех столбцах или в указанных (словарь {столбец: значение}); тип значения должен подходить к столбцу.
- **na.drop()** — удалить строки с null; **subset=[...]** — только по указанным столбцам; **how="any"** (есть null в subset) или **"all"** (все в subset null).
- **Стратегия:** удалять, когда пропуск делает строку непригодной; заполнять, когда можно задать осмысленное значение по умолчанию; при заполнении числами часто используют среднее/медиану, вычисленные отдельно.
- Ту же логику можно выразить через filter(isNotNull()) и withColumn(when(isNull(), value).otherwise(col("x"))).
