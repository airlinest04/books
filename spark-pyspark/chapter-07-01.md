# §7.1 Группировка и агрегация

В [§6.6](chapter-06-06.md) мы завершили главу 6 — чтение, преобразования, запись, обработка пропусков и кэширование. С этого раздела начинается глава об **агрегациях, окнах и соединениях** в PySpark. Группировка и агрегация — базовый способ получить сводные данные: разбить строки по ключу (groupBy) и вычислить для каждой группы суммы, счётчики, средние и т.д. В этом разделе рассмотрим **groupBy()**, **agg()**, встроенные агрегатные функции (**sum**, **count**, **avg**, **min**, **max**) и именованные агрегаты с алиасами. В [§7.2](chapter-07-02.md) перейдём к оконным функциям. См. [Глоссарий](glossary.md).

---

## 7.1.1. groupBy(): группировка по столбцам

Метод **groupBy(*cols)** разбивает DataFrame на группы по одинаковым значениям указанных столбцов. Аргументы — имена столбцов (строки) или выражения Column. Результат — объект **GroupedData**; сам по себе он не возвращает DataFrame, а служит для вызова агрегатных методов. См. [Глоссарий](glossary.md).

```python
from pyspark.sql.functions import col

# По одному столбцу
df.groupBy("region")

# По нескольким столбцам
df.groupBy("date", "region")

# По выражению
df.groupBy(col("date").alias("dt"))
```

Группировка вызывает **shuffle**: данные перераспределяются по ключу группировки (см. [§2.3](chapter-02-03.md)). После groupBy вызывают **agg()** или короткие методы (count, sum, avg и т.д.) — тогда возвращается DataFrame с одной строкой на группу и столбцами группировки плюс результатами агрегатов. См. [Глоссарий](glossary.md).

---

## 7.1.2. agg(): агрегатные выражения

Метод **agg(*exprs)** на объекте GroupedData задаёт агрегатные выражения: для каждой группы вычисляется одно значение на выражение. В качестве аргументов передают вызовы функций из **pyspark.sql.functions**: sum, count, avg, min, max и др. См. [Глоссарий](glossary.md).

```python
from pyspark.sql.functions import sum, count, avg, min as spark_min, max as spark_max

df.groupBy("region").agg(
    count("*").alias("cnt"),
    sum("amount").alias("total"),
    avg("amount").alias("avg_amount"),
).show()
```

Имена столбцов результата по умолчанию могут быть неудобными (например, count(1)); для читаемости задают **alias("имя")**. В одном agg() можно перечислить несколько агрегатов через запятую; каждый даст отдельный столбец. См. [Глоссарий](glossary.md).

---

## 7.1.3. Встроенные агрегатные функции

Основные функции из **pyspark.sql.functions** (при использовании в agg после groupBy):

| Функция | Описание | Пример |
|---------|----------|--------|
| **count** | Число строк (или не-null значений в столбце) | count("*"), count("col") |
| **sum** | Сумма | sum("amount") |
| **avg** | Среднее | avg("amount") |
| **min** | Минимум | min("price") — в PySpark min из functions, не встроенный |
| **max** | Максимум | max("price") |
| **first**, **last** | Первое/последнее значение (при недетерминированном порядке) | first("name") |

**count("*")** считает все строки группы, включая null во всех столбцах; **count("col")** считает только не-null значения в столбце col. sum, avg, min, max **игнорируют** null. Импорт: `from pyspark.sql.functions import sum, count, avg, min as fmin, max as fmax` — чтобы не путать с встроенными min/max Python. См. [Глоссарий](glossary.md).

## 7.1.4. Именованные агрегаты и алиасы

Чтобы в результирующем DataFrame столбцы агрегатов имели понятные имена, к каждому выражению добавляют **alias()**:

```python
df.groupBy("date").agg(
    count("*").alias("events"),
    sum("amount").alias("total_amount"),
    avg("amount").alias("avg_amount"),
)
```

Эквивалентная запись через словарь (в части версий API): **agg({"amount": "sum", "price": "avg"})** — имена столбцов задаются автоматически; для сложных выражений и алиасов удобнее явные вызовы функций с alias. См. [§6.2](chapter-06-02.md).

---

## 7.1.5. Короткие методы: count(), sum() и т.д.

У GroupedData есть короткие методы **count()**, **sum(col)**, **avg(col)**, **min(col)**, **max(col)** и др. Они возвращают DataFrame с одной агрегацией (и с именем столбца по умолчанию). Для нескольких агрегатов в одном запросе используют **agg()**:

```python
df.groupBy("region").count()                    # один столбец count
df.groupBy("region").agg(count("*"), sum("amount"))  # несколько столбцов
```

---

## 7.1.6. Фильтрация по результатам агрегации: having

В SQL условие на результат агрегации задаётся через **HAVING**. В PySpark эквивалент — отфильтровать результат groupBy().agg() по столбцу агрегата:

```python
df.groupBy("region").agg(sum("amount").alias("total")).filter(col("total") > 1000)
```

Сначала вычисляется агрегат, затем filter по результирующему DataFrame. Условия только по ключам группировки можно было бы применить до groupBy (filter до группировки); условия по агрегатам — только после agg. См. [§6.2](chapter-06-02.md).

---

## Ключевое

- **groupBy(*cols)** разбивает DataFrame на группы по ключу; возвращает GroupedData; вызывает shuffle. Далее вызывают agg() или короткие методы (count, sum и т.д.).
- **agg(*exprs)** задаёт агрегатные выражения для каждой группы; аргументы — вызовы sum(), count(), avg(), min(), max() и др. из pyspark.sql.functions; с **alias()** задают имена столбцов результата.
- **count("*")** — число строк в группе; **count("col")** — число не-null в столбце; sum, avg, min, max игнорируют null.
- Импорт min/max из functions под алиасом (fmin, fmax), чтобы не конфликтовать с встроенными Python.
- «HAVING» в PySpark — filter() по DataFrame после groupBy().agg() по столбцам агрегатов.
